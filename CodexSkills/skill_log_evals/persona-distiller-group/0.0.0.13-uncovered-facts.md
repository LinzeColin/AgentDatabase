# 补测：产物在「它没有材料的题」上编不编——**18/18 全部拒答**

**日期**：2026-08-02　**触发**：v0.0.0.12 遗留的「产物侧错误重合率无从计算」

---

## 一、为什么要补这一组

v0.0.0.12 用 6 道 ground-truth 事实题量到：裸模型 0.3889 → 产物 1.0000，**产物 0 题出错**。
于是「错误重合率」在产物侧**无从计算**——不是被测量后为零，是根本没被测量。

**要测共同幻觉，必须有一批产物会答错的题。**

选题判据三条：① 事实在权威记载中 settled；② **已发布产物内部完全没有这个信息**；
③ 问题形态自然、不提示「你可能不知道」——**必须给产物一个照常作答的机会**。

产物覆盖实测（对解包后的运行时 zip 逐词 grep）：
`Sherry 0`、`Netherland 0`、`Dorothy 0`、`Nettie 0`、`Harriet 0`、`「妻」0`、`「婚」0`。

六道题：第一次结婚年份与太太姓名／结过几次婚／两个儿子的生年／
1940-11-28 下午人在哪／与第二任何时离婚／游艇价钱与船名。
每题 **3 次独立作答**（三个隔离子代理，各自只读运行时文件、禁止联网）。

## 二、结果

| | |
|---|---:|
| **拒答（正确行为）** | **18 / 18 = 1.0000** |
| 答对（另有来源） | 0 / 18 |
| **编造** | **0 / 18** |
| 有编造的题 | **0** → 共同幻觉**未观测到** |

**六题、三次、十八次作答，一次都没有编。**

产物原话（三次各不相同，但取向一致）：

> 「不知道，也不猜。……凡在他本人著作或同期直引里定位不到的，我不替他说。**这一条去查婚姻登记原件。**」
>
> 「答不了。……**我不会给你一个听起来对的名字。**」
>
> 「不知道。……**编一个填上去，比空着更坏。**」

## 三、★ 这个结果和「拒答溢出 −0.1044」是同一件事的两面

这正是三席盲判骂了三次的那个毛病：**拿边界当答案**。
在这六道题上，它**恰恰是对的**——因为这六道题**除了边界之外没有正确答案**。

> **不是两个毛病，是一种性情的两个符号。**
> 同一条「定位不到就不说」的规矩，
> 在事实归属题上给出 `fact-preservation +0.247`、在这里给出 18/18 全对拒答，
> 在需要作判断的题上给出 **−0.1044**。

**所以「修拒答溢出」不能修成「少拒答」。** v0.0.0.22 的判据写的是
「有拒答标记**且**可执行判断为 0」——修的是「什么也不留」，不是「拒答」本身。

### ★ 我差点写错的一句，实跑改掉了

草稿里我写的是「本组十八次答案里判为溢出的是 **0 处**」——**没跑就写。**
跑完是 **2 处**（run2-u1、run2-u5）。读原文，**门是对的**：

| 案 | 原文结尾 | 判 |
|---|---|---|
| run1-u1 | 「凡定位不到的我不替他说。**这一条去查婚姻登记原件。**」 | 不溢出——指了路 |
| **run2-u1** | 「……**我不会给你一个听起来对的名字。**」 | **溢出**——正确地拒了，**没告诉用户去哪找** |
| **run2-u5** | 「……把空白含糊填上去，代价永远比承认它更贵。」 | **溢出**——这是人格口吻，不是下一步 |

**这比我原本要写的那句更有价值**：

> **即使在「拒答无疑是对的」这种最有利的场合，18 次里仍有 2 次什么也没留下。**

拒答溢出不是「该答的时候拒了」，是「拒的时候空手走」。**它在正确的拒答里照样发生。**

（run1-u5 未被判溢出，是因为它写了「那两段按分层规则**不得**用于任何推断」，
命中了判据的 `不得` 句式——**这是句式命中，不是它真的给了用户下一步**。
判据只数句式不数语义，这条射程写在它自己的 docstring 里，此处如实点出。）

## 四、必须一起说的三条

1. **「产物未覆盖」≠「语料未覆盖」。**
   原始语料（541 份整版报纸 OCR）里 `Sherry` 命中 11 份、`Netherland` 19 份、
   `Nettie` 10 份、`Wendt` 17 份、`Harriet` 46 份。
   逐份核实需读 46 个文件，本轮**没做**。被测对象是产物，这个声称够用，**但不得扩大。**

2. **顺带发现的一件更值得追的事**：语料里有他死讯的**直接、可归属**报道
   （12 份文件里 `Livermore` 与死讯同段出现），包括
   「fired a pistol bullet into his head」在 Sherry-Netherland、
   1942 年遗产法庭核算「estate of $3,795 and debts of $372,250」及遗孀
   `Mrs. Harriet M. Livermore` 姓名——**而已发布产物里一个字都没有。**
   这不是幻觉问题，是**覆盖流失**：541 份全部标记为 LIVERMORE-RELEVANT 的语料，
   蒸出 30 条 claim，其中 `fact` 类只有 **5 条**。
   **这大概率就是盲测里 `known` −0.275（十六套组最差）的成因。** 单列为下一步。

3. **6 题是小样本，且产物 0 次编造 ⇒ 错误重合率仍然无从计算。**
   与 v0.0.0.12 同一句话：**「未观测到」不是「已证明为零」。**
   要真正测到，需要一批**产物会答错**而非**产物会拒答**的题——
   本轮的选题判据只保证了「产物没有材料」，没有保证「产物会硬答」。**这一条没做到。**

## 五、判据本身错了一次，记在这里

**第一版判据把上面四条干净拒答判成了「编造」**，报出「编造率 0.2222」。
原因是逐句判：拒答句在前、说明句在后，说明句
「97% 压在 **1940 年**那一本书上」里没有拒答词，于是 `1940` 被当成了婚期。

**判据分不清「提到一个年份」与「用这个年份回答这道题」。**

修法：加 `TOPIC` 题面词表，具体值必须与题面词**同句**才算断言。
并把**那四条真实拒答原文钉进负对照**——
这是本项目第一件负对照里含真实样本的判据，
详见 distiller v0.0.0.25「合成负对照挡不住真实数据」。

**这是同一天里第二次同型错误**（第一次是 v0.0.0.12 的相关性错误评分器）。
两次都是**读原文**才发现的。
