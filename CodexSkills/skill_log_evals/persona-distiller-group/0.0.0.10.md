# persona-distiller-group v0.0.0.10 — 名册独立性第一次被量

**日期**：2026-08-02　**触发**：用户评分「真正独立性 40%」

---

## 实测（100 人全量，4950 对）

```
within_family_mean  0.0405      同族 974 对
cross_family_mean   0.0308      跨族 3976 对
ratio (跨族÷同族)   0.7603
```

**`ratio = 0.76`**：一个软件开发师与一个医疗护理师之间的措辞重叠，
已达到两个软件开发师之间的 **76%**。分族确实产生了差异，
但**同族只比跨族「像」约 1.3 倍**。

## ★ 这个数不能给名册洗白，三条必须同时说

1. **只测静态措辞重叠，测不了动态伪共识。** 用户问的是「同一问题过 k 个人物
   会不会产生相关性错误与共同幻觉」——**那要真把 k 个人物跑起来，本检查器做不到。**
2. **绝对值低（0.03–0.04）不是好消息。** 字段本身就短，短列表上的 Jaccard 天然偏低；
   **低相似度在这里主要反映字段短，不反映认知独立。**
3. **只提供下界**：能排除「字面克隆」，排除不了「同一套推理换了名词」。

## 负对照三类

克隆名册须被判为高度重叠且 `ratio ≈ 1`；分化良好的名册 `ratio` 须明显 <1；
**空字段的人物不得被伪装成「0 相似度＝高度独立」**——这条最容易漏，
一个字段全空的名册在任何相似度指标下都会显得极其独立。

**不设阈值**：合理相似度是多少要与外部对照（真人专家问卷）比，本项目没有那个对照。
