**那一行「选目是我自己定的」直接打在输出上。** 5 组，几行读完。

## 五、判据形状：只列不判

它**不判**两处结论是否真的互相否定——那要读懂中文语义。
它做的是把 32 题压成几组并排。**「只列不判」的语义就是不阻塞**，
故输出进 `content_review`，不进 `errors`。

### 负对照（4 条，含三条反向）

```
══ 负对照 ══
  ✓ 抓到 两题引同一段语料 → 并排列出

══ 反向对照 ══
  ✓ 两题无共同语料片段 → 不分组（0 组）
  ✓ 同一题内重复 → 不算跨题（0 组）
  ✓ 仅共享短套话 → 不分组（0 组）

  ✓ 负对照通过（4/4）
```

第二条与第四条是关键：没有它们，本件会把每一对都列出来，等于没用。

元检查器普查：可用负对照 **16 → 17**。测试 70/70，契约漂移 0。
