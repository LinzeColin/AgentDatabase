## 三、只能是散文（12 项）—— 逐条写明理由

**「只能是散文」不是「不重要」，是「不可自动判定」。**
这类条目的正确用法是写进 `judge_prompts/` 与开工前自查清单，
**靠人和评委执行，而不是假装它有门在守**。

| # | 发现 | 为什么只能是散文 |
|---|---|---|
| 第五种 | 机构官方自述不准确（Bridgewater 的 CIO 卸任日期） | **判据是「哪个来源更准」，属外部事实判断。** 检查器能发现两说不一致，但选哪一个必须由人核原始档案 |
| 第二十四种 | 同一段里前后指代不一致 | 需要指代消解。跨文件版本已由 `check_anchor_coherence` 覆盖；**段内指代的自动判据当前误报率不可接受**，而误报会驱动错误订正（引文检查器前两版误报率 100% 的教训） |
| 第三十种 | 连补四次词表都没修好，因为问题在句法不在词形 | **判据设计的元规则**，作用对象是「我怎么设计判据」，不是产物 |
| 第三十二种 | 「词出现得少」不是判据，「词在这里做什么」才是 | 同上，元规则 |
| 第五十一种 | 判据反复误报时换维度，不要加例外 | 同上。三条元规则合起来构成 `judge_prompts` 里的判据设计守则 |
| 第四十种 | 按标题挑读物，然后归纳「招牌手法」 | **选材判断。** 检查器能测覆盖率（可落成第 16 项），但「这批材料能不能支持这个归纳」需要读完材料 |
| 第六十四种 | 版面 PDF 文本流里标题署名排在正文之后 | **这是切片器的实现做法，不是判据。** 切错的后果由第六十三种的归属门兜住——**做法可以变，门不变** |
| 第五十七种（残余） | 「什么时候算加了一条自我限定」 | 可落成部分已进第 4 项；识别「我刚加了一条限定」依赖对自己文本的判断 |
| 第五十九种（残余） | 「把这条批评抽象成什么 pattern」 | 可落成部分已进第 4 项；抽象本身是判断 |
| 第五十种（残余） | holdout 证伪断言后**改成什么** | 可落成的是「两件事都要做」（第 24 项）；改成什么是判断 |
| 第二十七种（残余） | 词表该装哪些概念 | 可落成的是「取自语料」（第 17 项）；取哪些是判断 |
| 第四十五种（残余） | 「包装最厚的文件最容易分错」这条规律本身 | 可落成的是「强制复核最长最短」（第 25 项）；规律本身是解释，不是判据 |
