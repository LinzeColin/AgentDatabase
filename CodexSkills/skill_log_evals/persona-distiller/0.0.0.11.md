## 触发这次迭代的缺陷

**又是上一版自己写下的已知缺口**（连续第二次）：

> `tier=P1` 但 `author` 留空的源，本门不判，只在 metrics 报数。
> 这是**有意留的射程边界**……**下一步应是在 `ingest.py` 侧要求 P1 必须给 `--author`**。

v0.0.0.10 的门查的是「**账本声称本人所著**的源有没有证据」。
**没声称就无从查起** —— 于是「不写 `--author`」成了绕过整道门的路径，
而且它是**最省事的那条**：默认就是不写。

**一道门如果留着一个比走门更省事的旁路，它保护的只是守规矩的人。**

## 交付物

### 1. `ingest.py`：`--tier P1` 必须给 `--author`

依据是 RUNBOOK 对 P1 的定义（第 2644、2647 行）：

> tier 分开：**人工逐字稿、署名信件、印刷问答 = P1**；ASR = P2。
> 产物里凡是引号内的英文原话，**只许来自 P1**。

**一份没有作者字段的一手件本来就不成立。** 堵在源头比在门里补判据便宜：
门只能在语料已经落盘之后判，而 `ingest` 是它进库的唯一入口。

### 2. 测试夹具改成诚实的 P1

夹具此前 `--tier P1` 却不带 author —— **「声称是他的话，但不说是谁的话」**，
正是本版要消灭的形态。现改为 `--author 'Example Thinker'`
＋ 正文首行 `By Example Thinker`。

## 已知缺口

1. **已入库 97 人不受本版保护**——他们的语料多已随会话清掉，无法回溯核验。
   **这是「蒸馏后清空本地」这条规则的直接代价**，取舍待用户裁定。
2. `tier=P2`（ASR 逐字稿）同样是「他的话」，**本版未要求 author**。
   理由是 P2 的转写件常无署名，硬要会误伤；
   但这意味着**把 P1 降成 P2 仍可绕过归属门**。
   缺口比 v0.0.0.10 小（P2 不能用于引号内原话），**但没有消失**。
   下一版应考虑：P2 也要 author，只是归属证据的判据放宽到「转写来源可核」。
3. 6 个既有测试失败仍未处理。
