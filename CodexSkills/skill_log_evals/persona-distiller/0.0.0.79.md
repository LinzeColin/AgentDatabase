## ★ 为什么「结论对」还不够

**公有领域是随时间与法域变化的结论。** 最贴近的例子就在本名册里：

> **Fleming 卒于 1955。** 在「终身 + 70 年」法域里，
> 他的作品是 **2025 年 1 月 1 日**才进入公有领域的。
> **同样一句 `public-domain`，2024 年写就是错的。**

`rights` 记的是**结论**，不是**依据**。只记结论，事后**分不出**
是按卒年推定、查了出版方页面，还是照抄了 Unpaywall。

## 三种状态分开报

| 依据 | 判 |
|---|---|
| 出版方页面 / Crossref 原始记录 / 版权局（CCE、CPRS）/ 卒年规则 | 过 |
| **写着 Unpaywall／OpenAlex／CORE／BASE／Semantic Scholar 等** | **报** |
| **什么都没写** | **报「有结论无依据」——与上一条分开** |
| 不声称公有领域 | **不判** |

## ★ 顺带修 v0.0.0.76 留下的一句错话

`check_corpus_ceiling` 的收尾原本写死：
「这不是抓得不够勤，是这个人**传世的一手材料就这么多**」。

**那是 Slavyanov 的成因，在 Watson 身上是错的**——
她著作很多，只是**全部在保护期内**。
**判据知道数，不知道成因。** 已改为列出三种成因
（本就稀少／很多但取不到／这一轮没找着）并要求在延后记录里写明是哪一种。

## 判不了什么

- **判不了结论本身对不对。** 只看依据在不在、能不能作数。
  **今天那 642 条大概率结论都对**——报的是「依据不在产物里」，属 #29 重蒸范围。
- **判不了法域。** 「终身+70」与「发表+95」结论可能不同；
  本件不替你选法域，但**依据里写明了法域的**，将来复核才有得核。
- **它不设门。** 真正的把关在抓源侧：**只取公有领域，付费墙一律不碰。**
