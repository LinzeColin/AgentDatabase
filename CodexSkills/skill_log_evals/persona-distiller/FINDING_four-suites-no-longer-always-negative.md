## 三、★ 我说不清是什么改变了它

原结论指认的根因是断言层：四人的 `work-method` 断言**恰好都是 1 条**，
因为 `check_fact_density.py` 只数 `fact`——判据把力气推向了 fact，
而输掉的四组要的是 work-method。据此落成了 v0.0.0.36
（分 `reusable`／`retrospective`，分界是**有没有验证/弃置判据**）。

看上去像是「修好了」。**但这个推论我不敢下：**

- v0.0.0.36 之后到今天有**二十多版**改动，答案母版、长度门、题面自足门、
  承重人名门、实测声明门都在同一段时间里加进来。
- **没有做过隔离实验**——没有「关掉 v0.0.0.36 再跑一个人」这样的对照。
- 更麻烦的是**人物本身换了**：#101–104 是 Galen / Vesalius / Harvey / Jenner，
  #106–111 是 Pasteur / Koch / Lister / Virchow / Osler / Fleming。
  **后一批的语料条件普遍好得多**（PMC 有全文、有刊名卷期），
  「改进」与「换了容易的人」在数据上分不开。

所以本文件只记一件事：**那个「0/4」是在四个人身上量出来的，扩到九个人就不成立了。**
说「是 v0.0.0.36 救的」就是编因果。

## 五、对下一个人物（Nightingale #112）的意思

原结论里那条**操作建议仍然有效，而且与她特别相称**：

> 抓源与断言阶段就去语料里找**带判据的做法**
> （「怎么知道这步做对了／什么时候丢掉」），不要只找事实。

她的著作里这类东西极多——病院记录怎么记、什么样的死亡率不可比、
为什么必须写明分母。**这是把 work-method 断言真正做够的机会**，
不是因为「那四组恒负」（已不成立），而是因为她的语料本来就长这样。
