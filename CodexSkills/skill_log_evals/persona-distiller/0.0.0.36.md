## 二、★ 机制：读了两侧原文才敢说

## 三、★★ 根因在断言层，而且是判据造成的

| 人物 | `fact` | `work-method` |
|---|---:|---:|
| Galen | 15 | **1** |
| Vesalius | 23 | **1** |
| Harvey | 24 | **1** |

四个人、四批语料、四次独立蒸馏，`work-method` **一模一样都是 1**。

原因在 `check_fact_density.py` 一行：

```python
facts = [c for c in active if c.get("category") == "fact"]
```

**密度门只数 `fact`。`work-method` 全流程没有任何下限。**
所以每一轮我被判据推着补的都是 `fact`，而输掉的那四组要的是 `work-method`。

**与 v0.0.0.29（账本事实 ≠ 人物事实）同一形态：类别没分开，力气就流错方向。**

## 四、落成（只报不拦）

- `classify_method()` → `reusable` / `retrospective`
- **分界不是「有没有步骤」**——四条真实断言全都有步骤——**是有没有验证/弃置判据**：
  怎么知道这一步做对了、什么时候把结果丢掉。没有判据，照着做的人不知道自己做错没有。
- `METHOD_FLOOR = 3`，代码注释里明写「**暂定值，无实测支持**」。
  有实据的只是「四人恒为 1」这个事实，以及那四组每人 8 道题。
  取 3 是因为明确高于 1、又远低于 8——**不至于逼人凑数编方法**
  （Galen 那 5 条账本事实就是被凑数逼出来的）。
- **射程边界**：类别数 < 3 时标「未判（**不是通过**）」。

## 六、★★★ 必须一起说的两件（否则这条记录就是在自吹）

1. **它不预测 delta。**
   Harvey 有 1 条**可复用**做法，真 delta −0.0383；
   Jenner **0 条**可复用，真 delta −0.0015。**方向是反的。**
   可断言的只有盲区本身（四人恒为 1、判据只数 fact），**不是「补方法就会赢」**。

2. **补方法未必够，而且大概率不够。** 反事实实算：

   | 人物 | 实测 | 四组→0 | 四组→+0.05 |
   |---|---:|---:|---:|
   | Galen | −0.1456 | −0.1242 | −0.1117 |
   | Vesalius | +0.0156 | +0.0258 | **+0.0383 ✅** |
   | Harvey | −0.0383 | −0.0130 | −0.0005 |
   | Jenner | −0.0015 | +0.0151 | +0.0269 |

   **那四组即使全部拉到 +0.05（是个大胜），四人里也只有 Vesalius 过 quick 门 0.03。**
   十六组里十二组为负——**问题不是局部的，别把这一版当成解法。**

## 七、这一版没做、而且不许悄悄做的事

反事实那张表最容易被拿来论证「delta 门权重不合理，该给 `known` 加权」。
**不做，也不提议做。** 四次拒发都是同一条判据判的，
现在因为看清了自己弱在哪就去动权重，与「为凑数放宽判据」是同一件事。

> **量出来的是产物是什么，不是判据该改成什么。**
> 判据说的是「它不是一个更好的通用助手」——这句话是对的。
