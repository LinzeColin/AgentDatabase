## 一、要判的东西是真的

席 E 在 Jenner #104 的一条评语里点了两处，**批的是候选**（已核实：那句话在
`ej_candidate.json` 里，基线文件 0 处命中）：

> 它写「同年我因此入了皇家学会」是错的（当选在次年），
> **而且与它自己在 `long-horizon-02` 说的「入会确切日子不在我手上这批材料里」互相否定**

候选载荷里两句原文：

```
ej-fact-preservation-02：同年我因此入了皇家学会。**月份我不报。**
ej-long-horizon-02　　：宣读这一天我还不是会员。我入会的确切日子**不在我手上这批材料里**
```

**这是正确性缺陷，不是风格问题**：读者拿到的两句话互相取消。
而且它**跨题出现**——逐题看每一题都说得通，只有把整份载荷放在一起才看得见。

## 二、判据写了，两轮收紧，**仍然不成立**

判据：某题有弃权句（「不在我手上／我不报／没有记录…」）+ **另一题**里同一主题词
40 字内出现具体值（年份/日期/卷页）。九组反向对照全过，含「同题内分层表述不报」
「主题词不重合不报」「读不出正文要报出来」。

**真数据一跑就现原形。**

| 版本 | 全量命中 | 抽样精确率 |
|---|---:|---|
| 第一版（n-gram 2–6、特异性 ≤40%） | **28 处** | **12 条抽样里 0 条是真的** |
| 收紧后（n-gram ≥3、剔全虚词、特异性 ≤20%） | **7 处** | **约 0–1 / 7** |

第一版抽出来当「主题词」的是：`我手`、`手上`、`没有`、`也不`、`的东西`、`两篇`、`的误差`
——**虚词碎片，跟弃权的对象毫无关系**。收紧后剩下的仍是
「`Exp Path` 附近有 1928 年」「`我说不` 附近有 1806 年」这类。

## 三、★★ 而它**恰恰漏掉了那个动因用例**——原因是原理性的

```
弃权句：  「我入会的确切日子不在我手上这批材料里」
矛盾句：  「同年我因此入了皇家学会」
```

**两句没有任何共同的表层字串。**
「入会」与「入了皇家学会」的等同是**语义的**，不是字面的。

n-gram 匹配原理上就够不着这一类。要判它得做指代消解，
**而那已经不是一道判据能干的事**。

（另：我一度以为它是被「特异性 ≤20%」筛掉的。核了一遍——「皇家学会」在 4/34 = 12% 的答案里，
**在门内**，不是被筛掉的。**猜的原因和真的原因不是同一个。**）
