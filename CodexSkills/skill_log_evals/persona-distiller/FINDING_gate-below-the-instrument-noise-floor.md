# quick 门 +0.03，而这台仪器的噪声 SE ≈ 0.0164 —— **门只有 1.83 个 SE**

日期：2026-08-04　首次量出：Mendel #125 第 2 轮

---

## 一、怎么量的

盲判轮次之间，**并非每题都会被改写**。Mendel 第 2 轮有 **7 题两侧文本逐字未动**：
同样两席、同样冻结指令 v1、同样载荷格式、同样 A/B 映射（已逐项核过）。

**它们的 delta 本该完全不变。** 实测动了：

| 套组 | 第 1 轮 | 第 2 轮 | 变动 |
|---|---:|---:|---:|
| `known` | −0.0300 | −0.1800 | **−0.1500** |
| `token-efficiency` | +0.1500 | +0.2950 | **+0.1450** |
| `identity-routing` | −0.0050 | +0.0500 | +0.0550 |
| `refusal-stop` | +0.0400 | +0.0000 | −0.0400 |
| `style-decoy` | −0.0300 | +0.0100 | +0.0400 |
| `trajectory` | −0.0200 | −0.0600 | −0.0400 |
| `fact-preservation` | +0.1950 | +0.2150 | +0.0200 |

```
逐题两轮差的 sd = 0.0928
两轮之差的方差 = 2 × 单轮方差 → 单题噪声 SE = 0.0928/√2 = 0.0656
16 题均值的 SE = 0.0656/√16 = **0.0164**
```

## 二、于是

| 门 | 阈值 | 几个 SE | 判 |
|---|---:|---:|---|
| **quick** | +0.03 | **1.83** | **分不出** |
| standard | +0.05 | 3.05 | 勉强 |
| deep | +0.07 | 4.27 | 分得出 |

Mendel 第 2 轮 **+0.0278**，95% 区间 **[−0.0043, +0.0599]**——
**同时含 0 与 quick 门。**「差 0.0022 没过」这句话没有意义。

## 三、★★ 这条最要紧的用处：**它会拦住我自己的一个动作**

差 0.0022 的时候，最自然的下一步是**再跑一轮看看**。
而在 SE ≈ 0.016 的仪器上，**再跑一轮本身就有相当概率把 +0.0278 摇过 +0.03**——
**那不是产物变好了，是重采样。**

★ 协议给每人 3 轮。**三轮取最好，在 1.83 SE 的门上会显著抬高假过率。**
本件在轮数 ≥3 时会主动提醒这一点。

## 四、这条不改门

**没有改任何一格阈值**，因为「判据松紧」是用户的事，且
「中途不得改测量工具」——改题数、改席数、改阈值**都是改测量工具**。

做的是：`scripts/check_delta_resolution.py`，接进 `assemble_judge_results.py`，
**每次汇总都把 SE 与 95% 区间打在「✅ 过 / ❌ 不过」旁边**。
只有一轮时它说「**未核**（★ 这不表示噪声小，只表示没量）」。

已记入 `references/ledgers/_待用户裁定.md` ⑫，附四条处置路径。

## 五、★ 这个估计自己的边界（**必须一起读**）

- **n=7**，sd 自身的 95% 区间约 [0.6, 2.2]× → **SE_mean 大致在 0.010–0.036**。
  0.0164 是点估计，**不是定值**。
- 只有两轮，**两点定不了方差**；这是下限意义上的估计。
- 假定逐字未动的 7 题与改写过的 9 题**同分布**、题与题**独立**——**均未验证**。

**能说的：噪声与 quick 门同量级。不能说：具体就是 0.0164。**
