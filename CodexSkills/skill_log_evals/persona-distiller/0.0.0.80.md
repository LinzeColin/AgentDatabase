# v0.0.0.80 —— 「Mr Roosevelt is President」被当成了他人署名

日期：2026-08-04

## 触发

#117 Clara Barton 入库 208 份后跑研究门，`check_authorship` 报
**12 条「文中检出他人署名」**——这句话在本流水线里的含义是
**「这一卷里混有第三方材料」**，是要人回去切边界的。

**逐条回原文核，7 条是假阳。**


**第三条最能说明问题**：`OTHER_ROLE` 抓的是 `is the President` 前**最后一个大写词**，
于是「Emperor of **Japan**」里的 Japan 成了「另一个署名的人」。

## 根因：它没有锚行首，而它的兄弟规则锚了

```python
OTHER_BY   = re.compile(r"^[ \t]{0,4}By (…)[ \t]{0,4}$", re.M)      # 锚了
OTHER_ROLE = re.compile(r"\b(…) is (?:the |a |an )?(President|…)")   # **没锚**
```

**撰稿人小传是独占一行的**（`Jane Doe is President of the Foo Society.`）。
`X is President` 出现在**行中间**时是普通句子。按 `OTHER_BY` 同法锚上行首即可。

## ★ 这一条的形态

**判据一直在做正确的事，只是射程比它以为的宽**——
而它报出来的话（「卷内混有第三方材料」）**比它真正查到的东西重得多**。

**「判据报红」也要问那三问**：它跑了吗／它看的是哪一段／
**它报的这句话，与它实际查到的东西是同一件事吗？**
本次是第三问不成立。

## 判不了什么

- **判不了行首的 OCR 乱码**（`Landlord is President`）。
  硬去分会把真的撰稿人小传一起漏掉，**宁可留两条假阳**。
- **仍然判不了未刊手稿的归属**：Barton 的 54 条 `authorship-unproven` 里
  **46 条是「文中一个署名都没有」**——日记、未刊草稿、讲稿本来就不署名，
  它们的归属依据是**档案出处**（LOC 编目为 Clara Barton Papers），
  而本判据认的三种证据（署名／编者注／逐字稿轮次）**不含档案出处**。
  **这是已知缺口，不在本版处理**——要处理必须小心，
  别做成 v0.0.0.24 那种「一句声明整批免检」。
