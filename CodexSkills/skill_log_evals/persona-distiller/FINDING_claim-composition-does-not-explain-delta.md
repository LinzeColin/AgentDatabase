# 「多写点启发式断言」——查了，撑不住，不立判据

日期：2026-08-04　起因：Barton #117 三轮全负，逐套组显示「教我怎么做」一侧全输

---

## 一、假设从哪来

Barton 第 3 轮逐套组：

```
fact-preservation  +0.2250   ← 问「你是什么」，赢
token-efficiency   +0.0975
long-horizon       +0.0275
voice              +0.0100
─────────────────────────  以上为全部为正的 4 个
...
capability-calibration -0.0875
anonymous-fidelity     -0.0950
task-completion        -0.1050   ← 问「教我怎么做」，输
style-decoy            -0.2150
```

两席评语里也各点了几处「答非所问」。
**（★ 这些点名用的是盲判坐标，哪一侧是候选要过 key——见第四节，我第一版在这里写错过。）**

而 Barton 的断言配比确实偏：**58 条里 42 条是 `fact`（72%），
`heuristic`+`work-method` 只有 8 条（14%）**。

于是有个很顺手的假设：**「教我怎么做」输，是因为断言库里没有「怎么做」。**

## 二、查了

全仓 13 份 `claims.jsonl`，与各人末轮实测 delta 对起来。

**先剔除已知混杂**：Seth Godin（+0.7350，16 对）与 Michael Steinhardt（+0.7393，14 对）
属于**自撰稻草人基线**那一代，`_决策台账.md` 早写明「已入库 100 人的全部 delta 都是这个性质」。
带上这两点，r = +0.502——**那个数是混杂撑起来的，不能报。**

剩下 64 对真基线那一代，n=9：

| 人物 | 启发+工法占比 | 末轮 delta |
|---|---:|---:|
| clara-barton | 14% | −0.0273 |
| florence-nightingale | 17% | +0.1364 |
| rudolf-virchow | 17% | +0.1033 |
| robert-koch | 22% | +0.0820 |
| ws-jenner | 23% | −0.0015 |
| william-osler | 23% | +0.0803 |
| alexander-fleming | 24% | +0.1269 |
| joseph-lister | 29% | +0.1292 |
| louis-pasteur | 30% | +0.0973 |

```

```

## 三、结论：不立判据

**方向是对的，强度撑不住。** n=9 时 r=+0.39 的 95% 区间大致跨 −0.36 到 +0.84
——**跟噪声分不开。**

★ 这个 r 本身还被我的一个 bug 改过一次：Barton 的 delta 一开始读成 −0.0273 的十分之一
（见 `FINDING_assembler-divided-by-ten-twice.md`），当时算出 r=+0.340。
修正后 +0.388。**方向和结论都没变，但这说明 n=9 的 r 有多经不起一个数据点的扰动。**

反例就在表里：**Nightingale 17%（几乎和 Barton 一样低）拿到 +0.1364，
是全组最高**；Jenner 23%（高于 Nightingale 6 个百分点）却是 −0.0015。
**占比解释不了这两个人的差别。**

所以：

- **不许**因为这个数去给新人物「补启发式断言凑占比」。
  那与 [[style-learned-knowledge-lost]] 里那条同型——
  **「补 fact 救不了分，相关系数是负的（r=−0.465）」**，
  这次换成 heuristic，同样撑不住。**配比不是因，至少这批数据说不了它是因。**
- **不许**把这条写成门。判据一旦立起来就会被当成真理，
  而它现在的证据强度是「有个方向，n=9」。

## 四、★ 先纠一个我自己的错：评委的抱怨写在**盲判坐标**里

评委点名的方式是 `q-26B`、`q-10B` 这样的**盲判题号＋侧**。
**这些坐标只有过一遍 `cb_blind_key.json` 才知道指的是候选还是基线。**
我第一版写这份 FINDING 时没过 key，直接当成候选的毛病列了四条——**其中三条是基线的。**

逐条对回去（两席点名的 11 处）：

| 题·侧 | 实为 | 抱怨 |
|---|---|---|
| q-10B | **候选** | 要求用称号写自我介绍，改成否认称号＋履历条目（两席） |
| q-09A | **候选** | 题面已写「不用管史实」仍拒写（席 D） |
| q-23B | **候选** | 无视题设「三天后才能进场」（席 E） |
| q-24B | **候选** | 「挑最完整的当底本」与①「不取最厚的」自相矛盾（两席） |
| q-22B | **候选** | 单委员会先例搬到三委员会而不处理协调（席 E） |
| q-19B | **候选** | 「用已故者的名义是冒名」与第一人称在场口吻崩了（席 E） |
| q-30A | **候选** | 整段在论证一张卷题条能证什么（席 D） |
| q-17A | **候选**（有争议） | 席 E：对「五万美元」不作任何回应；**席 D 复核后结论相反**——「重读题面后才确认长侧是真接住了金额」 |
| q-26B | 基线 | 问唯一标准却给三条 |
| q-12B | 基线 | 三个问项一个未答 |
| q-11A | 基线 | 拒答国籍后的选人逻辑放到任何十九世纪救援都成立 |

**11 处里候选占 8 处**——方向站得住，**但我原先引的四个例子里三个引错了。**

**这条要单独记住：评委的话不许直接当成候选的缺陷抄，必须过盲判 key。**
不过 key 就写，三分之一会写反。

## 五、那「教我怎么做」输在哪，还是没答

**逐套组的负分是真的**（task-completion −0.1050、style-decoy −0.2150），
**只是原因不是断言配比。**

过完 key 之后，候选那 8 处里有**三处是干净的「没接住题面约束」**：

- **q-10B**：题目要「用这个称号写一段自我介绍」，答成了「否认称号＋履历条目」
- **q-09A**：题面已写明「不用管史实」，仍然拒写
- **q-23B**：题设「三天后才能进场」，头一条仍讲「能早到一刻就早到一刻」

**这三条都不是知识缺口，是没接住题面写死的约束。** 更像生成环节的问题，
不是断言库的问题。**下一步该查的是这个，不是配比。**

### 机械探针试过了，抓不住

拿「题面出现的数字，答案碰没碰」做过一次探针（32 题里 9 题题面带数字）：
**候选漏 2 道、基线漏 1 道**，而且**没抓到席 E 抱怨的那道**——
`cb-plan-01` 的题面写的是「**五万**美元」，汉字数词，正则看不见。

**所以这一类目前没有可靠的机械判据**：约束是自然语言写的
（「用这个称号写」「不用管史实」「三天后才能进场」），
提取它本身就要理解题面。**记下来是为了不再从数字通道重试一遍。**
