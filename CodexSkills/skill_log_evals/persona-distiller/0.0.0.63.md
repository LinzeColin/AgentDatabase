## 二、★★ 弃权不是缺陷——不写清楚，这道判据会把产物推向不诚实

Fleming 有一句：

> 那两篇的数值**我没逐个核过，不核就不报数**。

**席 E 专门表扬了它**（「自缚的规矩」）。
这一句有实测词、没有数。判据若把它一起报出来，
作者为了让门变绿会**去掉这句弃权、或者随便补一个数**——
判据把产物推向了它本该防的方向。

所以 `ABSTAIN` 是**独立成立、独立计数**的一类，不是「问题」。
自测反向对照 ④⑤⑥ 专守这一条。

### 自测当场抓出的接线错误

第一版把弃权判断写在实测声明**之内**：

```python
m = CLAIM.search(para)
if not m: continue
if ABSTAIN.search(para): acc["abstain"] += 1; continue   # ← 永远到不了
```

`我没逐个核过` 里「我」后面跟的是「没」，`CLAIM` 本来就不匹配，
于是**弃权一次都数不到**——报告会显示「诚实弃权 0 处」，
而产物里明明有一处，且是席 E 唯一表扬的那一处。

改成弃权先判、独立计数。

## 三、判得动与判不动

- **判得动**：借了实测的权威却没交出实测的内容。
- **判不动**：
  - 那个数**对不对**——那是 `check_self_reported_counts` 与人工的活。
  - 段落之外的数。读者的检索单位是段落，**数在三段之外等于没给**
    （反向对照 ③ 守）。
