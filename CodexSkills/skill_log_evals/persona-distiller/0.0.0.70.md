# v0.0.0.70 —— 判据报了一行绿，而那一行盖着 17 个工作区

日期：2026-08-04　**第四次「判据绿了却指错了文件」**

## 触发

为关掉 #40（语料缺口是否全部找回）跑 `check_corpus_presence --root .`：

```
工作区                          账本     语料    指得到  状态
_corpora                     55   2222     55  ✓

  ✓ 1 个工作区的语料都在，且字节与账本一致
```

**一行，绿的。** 而磁盘上有 **17 个工作区、24 份账本**。

## 洞

`scan()` 把 `--root` 的**每个直接子目录当作一个工作区**。
root 传成 `persona-distiller` 时，`_corpora` 被 collapse 成一行——
取 `leds[0]` 的 55 条账本、数它底下全部 2222 个 `.txt`，然后报绿。

**它没说谎，它只是在回答另一个问题。**

## 修

**一个目录里出现多份账本 → 它是容器不是工作区 → 下沉，不猜。**
反向对照 ⑨：两个各带账本的工作区放进同一容器，**必须出两行**。
