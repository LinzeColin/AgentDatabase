## 一、承重人名门把刊名缩写当人名：一次报出六个

### 实测输出（改之前）

```

        ↳ **全名一次都没出现，上面那串是姓氏撞的**
    **Exp Path**　全名命中：P2 1　｜姓氏命中：P1 57、P2 2、S1 12
    **Soc Med**　全名命中：0　｜姓氏命中：P1 138、P2 1、S1 24、S2 1
    **John Ambrose Fleming**　全名命中：0　｜姓氏命中：P1 244、P2 13、S1 141、S2 56
    ...
✓ 全名在 P1 里 13 个：Allison、Biochem、Chain、Colebrook、Douglas、Florey、
                     Heatley、Moran、Ogilvie、Royal Society、Studies、
                     Wound Infections、Wright
```

`Biochem`、`Studies`、`Wound Infections`、`Royal Society` 甚至进了「✓ 已确证的人名」那一档——
**判据在为刊名背书。**

全部来自 `*Br Med J* 2(4210):386` 这类著录。

### 修法：把著录当成又一种壳剥掉，**不是往停用词表加词**

刊名是开放集合。往 `NOT_A_NAME` 里加 `Br Med`、`Soc Med`，
下一个人物换一批刊物，这道判据照样从头误报一遍。

本流水线的写法是固定的：单星号 `*…*` 是刊名／篇名，双星号 `**…**` 是加粗。

```python
CITED = re.compile(r"(?<!\*)\*(?!\*)([^*\n]{2,120})\*(?!\*)")
...
prose = CITED.sub(" ", QUOTED.sub(" ", text))
```

### ★ 这里有一个能让判据**安静失明**的坑

加粗恰恰用在人名上：`**A. Grant Fleming（蒙特利尔公共卫生）**`。
若正则连双星号一起吃，判据就对它**最该抓的那一类名字**失明，
而且会打印「✓ 没有查无实据的人名」。

自测反向对照 ⑨⑩ 专守这一条：

```
── 反向对照 ⑨：**加粗不是著录，人名不许被剥掉** ──
  ✓ `**A. Grant Fleming**` → 仍抽得到
  ✓ 一行里两处加粗人名 → 两个都抽得到
── 反向对照 ⑩：加粗与著录相邻时，只剥著录那一段 ──
  ✓ `**Heatley**` 抽得到，而 `Biochem` 不抽
```

### 附带修掉 v0.0.0.60 一个**没盖住自己用例**的洞

v0.0.0.60 为「书名里的拉丁词不是人名」把 `Aconitum`、`Napellus` 加进了排除集。
但抽名器产出的是**词组** `Aconitum Napellus`，整串不在集合里——**照样报错**。

改成**逐词判：每个词都在排除集里才丢**。
反向对照 ⑪ 守住反方向：`Napellus Fleming` 只中一个词 → 仍抽得到
（否则「某某 Oxford」这类真名会被吃掉，而判据会**安静地少报**）。

### 实测输出（改之后）

```
语料 69 份；答案里的人名 13 个
  ✓ 没有查无实据的人名
⚠ **3 个不是一手依据**（只列不判）：Grant Fleming、John Ambrose Fleming、Lochfield
✓ 全名在 P1 里 9 个：Allison、Chain、Colebrook、Douglas、Florey、
                    Heatley、Moran、Ogilvie、Wright
```

**刊名噪声 6 → 0；确证名单从 13 个（含 4 个刊名）收缩到 9 个真人名。**
剩下 3 条软提示全部正确，且都已在答案里注明出处。

## 二、引文坐标门的刊名清单，是 Osler 那一批留下的

`LOCATOR` 里硬编码着 `Lancet` / `BMJ` / `Phil Trans` / `Collected Papers` / `Proceedings`。
Fleming 的刊物一本都不在里面。于是：

```
长逐字引文 26 条，同段带坐标 25 条，**缺坐标 1 条**
  ⚠ 答案/fl-fact-preservation-01: 「their Use in the Isolation of B. influenzæ…」
```

而那一段的原文是：

```
**题名后半截**（同上，*Br J Exp Path* 10(3):226-236）`their Use in the Isolation of B. influenzæ`
```

**坐标就在段内，紧贴引文之前。**

### 修法：按形状认，不按刊名认

```python
r"|\b\d{1,3}\s*\(\d{1,4}\)\s*:\s*\d{1,4}"      # 10(3):226-236
r"|\b\d{1,3}\s*:\s*\d{1,4}\s*[-–]\s*\d{1,4}",  # 93:306-317
```

卷(期):页 这种形状本身就够读者回查，与刊名叫什么无关。
**每换一个人物就往清单里加刊名，等于这道判据对新人物默认失灵。**

### 反向对照守住底线

通用式很容易把整道判据架空，所以要证明它没有：

```
  ✓ `10(3):226-236` 认得出（刊名不在硬编码清单里也算）
  ✓ `93:306-317` 也认得出
  ✓ 段里只有散落数字（无卷期页形状）→ 仍报缺坐标
  ✓ 段里只有引文本身 → 仍报缺坐标

  ✓ 负对照通过（9/9）
```

（`我做过 10 次，成功 3 次` 里的数字不会被当成坐标。）

实跑：发布门 `content.quote-no-locator` **1 条 → 0 条**；自测 5/5 → **9/9**。
