## 一、触发缺陷：两个都对的数，差 130 倍

```
primary_ratio   = 0.9887      ← deep 门槛 0.65，轻松通过
own_voice_ratio = 0.0076      ← 同一份语料
```

RUNBOOK 第 822 行定「第三人称叙述体（含关于他的报道）→ 降 `P2`」，
而 `primary_ratio` 的分子是 `P1 ∪ P2`。Livermore 的 532 份可用 train 里
**530 份是同期报纸对他的报道**，分子几乎等于分母。

**这不是 bug，是那个数从来就没在量「他的话有多少」。**
在此之前，**没有任何一个数在量它**。

## 二、实测

| 量 | 值 |
|---|---|
| train 源总数 | 536 |
| 其中**本人所著** | **2**（那本书的 train 卷与 holdout 章） |
| train 总字节 | 16,284,924 |
| 其中**本人所著字节** | **124,173** |
| `own_voice_ratio` | **0.0076** |
| 对照 `primary_ratio` | 0.9887 |

抓源报告给的另一组对照：他一生可公开抓取的原话约 **22,500 词**，
**97% 压在那一本书上**；去掉那本书只剩约 **600 词**（散在 33 年 14 份报纸里）。
Lefèvre 那本小说 **112,180 词**，是他全部存世文字的 **5 倍**——
**这就是「Livermore 语录」绝大多数出自小说的结构性原因，不是巧合。**

## 三、回归用例才是这一版的要害

```python
def test_own_voice_ratio_is_not_satisfied_by_reclassifying_tiers(self):
    self.assertAlmostEqual(measure('P2'), 0.1, places=4)
    self.assertAlmostEqual(measure('P1'), 0.1, places=4,
        msg='把第三方报道的 tier 改成 P1，own_voice_ratio 就变大了'
            '——那它又成了一个改标签就能满足的代理量')
```

**没有这条，这个新指标半年后就会变成第二个 `primary_ratio`。**
第七十种（门测代理量）在本项目里已经出现过两次，
两次都不是因为设计时没想到，而是因为**没有用例把「不能被什么满足」写下来**。

## 四、为什么只报不拦

对历史人物设阈值会**直接判死一整类人物**——他只出过一本书、没写过专栏、
无公开书信集，**瓶颈是史料本身不存在，不是抓取力度**（抓源子代理实测
541 份报纸后的原话：再抓 10 倍只会把 `external` 堆更高，
不改变 `writings`/`expression` 的分子）。

按既定裁定「门达不到时选诚实退路继续，**绝不为凑数放宽判据**」，
正确动作是把这个数报出来并写进硬边界——
**不是拦住流程，也不是假装没这回事。**

## 五、判定

**通过。** 指标落成、带反向回归用例、真实语料上给出与 `primary_ratio` 相差 130 倍的读数、
全量 67 绿、漂移 0。

## 六、已知缺口

1. **按字节算不按词算**。中英混排时字节会高估中文占比；本项目语料以英文为主暂不影响，**换语种要重看**。
2. **只认账本 `author` 字段，不读正文**。账本写错就算错——那由 `check_authorship.py` 另行把关，两件事分开。
3. **没有阈值，也不该现在定**。只有一个人物的实测值，**不足以定线**。
   要定得先看几十个人物的分布——这本身是个待办。
4. **它不区分「他写的」与「他说的」**。书（写）与访谈直引（说）在这个数里等价，
   而语体建模上两者不等价。
