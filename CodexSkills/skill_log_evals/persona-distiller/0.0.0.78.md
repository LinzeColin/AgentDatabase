## ★ 它说的不是「这些断言是编的」

**只说这个字段不再有信息量。** Koch 那一对
（`b21463608_0001.txt`、`b21353207_0001_0.txt`）两份都是 P1，
《Gesammelte Werke》确实是合集，也许真的覆盖了绝大多数内容。

但**合集级的挂靠 ≈ 没有挂靠**：出问题回不到是哪一段，
而**读它的判据于是在核一个常量**。

**同型第二例**：v0.0.0.24 一句 `attribution_basis` 让**整批免检**，
逐源检查从此十版没跑过。**填一次抄 N 遍，与一句话让整批免检，效果一样。**

## ★★★ 第一版拿总数当分母，真实数据一跑就误报三处

合成负对照全绿，**真数据一跑立刻错**：

| | 非空/总数 | 不同取值 | 第一版报 | 真值 |
|---|---:|---:|---|---|
| Jenner `counter_source_ids` | 1/35 | 1 | 表头 | **用得太少，不判** |
| Steinhardt `counter_source_ids` | 4/39 | 3 | 几乎是表头 | **不判**（4 条里 3 种） |
| Pasteur `counter_source_ids` | 3/33 | 3 | 几乎是表头 | **不判**（三条各不相同） |

**分母写错了**：拿记录总数比，该比的是**非空数**。
「这个字段用得少」与「这个字段填了假值」**是两回事**。
这与本会话另外几次同根——**两套标识符空间相减**。三处已固化为反向对照 ⑦。

## 与待裁定 ② 的关系（**只报事实，不替用户决定**）

Koch 的延后记录写着「比例门（45.8% < 65%）与**对手立场须指到原文**直接冲突」。
本次补一条实测：**`counter_source_ids` 0/46**，`source_ids` 46 条同一对。

**冲突目前只写在散文里，产物侧没有机器可核的对手引用。**
每条断言的 `evidence_clusters` 都写着「对手方原文（双方语料均在本机）」——
**那是自述，不是链接**（见 `self-report-is-not-evidence`）。

**这不改变裁定本身，只是把它的前提量清楚。** 我不自行开口子。

## 判不了什么

- **判不了那一对源是不是真的支持这条断言**——那要回读正文，是 `check_quote_integrity` 的活。
- **判不了散文里的证据说明**。本件只看字段，不解释散文。
- **断言少时不判**，字段用得少时也不判——**没有「变化」可谈**。
- **它不设门。** 只写 metrics。
