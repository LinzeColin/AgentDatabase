## 五、射程（必须与结果一起说）

- **它判「这是不是一份文档」，不判「这是不是这个人的文档」。**
  抓错了书、抓了同名者的书、抓了译本当原本——**本门一概看不见**，
  那是 `check_authorship.py` 与 `check_attribution_basis.py` 的事。
- **已知缺口如实留着**：第 2 条按正文关键词判「取不到」，
  **一份正经讨论 HTTP 错误码的文档会被误判**。负对照里有一条专门复现它。
  不修的理由与重做条件写在检查器文件末尾——
  **如果将来要蒸的人物写的就是网络工程，这条必须重做。**
- **它不联网、不重取。** 只看已经落盘的东西。
