## 五、★★ 第一版射程写错了，是判据的错

第一版没限 `subject_origin`，**把 6 个合成测试工作区一起拦了**——它们不是 historical，
也从不声明 `attribution_basis`。

**我没有去改测试。** 免检口子只在 historical 路上存在，其他 origin 走的是
`check_authorship` 的 A-* 证据路，**本门不该插手**。射程限制已写进代码并配了负对照
（五种非 historical origin 各跑一遍，一条都不许报）。

> 判据拦下了不该拦的东西时，**默认是判据的射程写错了，不是被拦者的错**。

## 六、射程（必须一起说）

- **它判「有没有被逐份认领」，不判「认领得对不对」。**
  在 `citation` 里写一个错的书名，本门照样放行——**它挡的是「整批免检」。**
- 报文只给该源开头 200 字，**不替人读扉页**。
  Jenner 那次的真相在**题献页**，不在第一屏——`b22006345` 第一屏看上去像他的书。
- 不判 P2／S1。
- **只在 `subject_origin == "historical"` 时生效。**
