# v0.0.0.73 —— 「这是我发明的」，限定呢？

日期：2026-08-04

## 触发

**#115 Slavyanov 与 Benardos 都在队列里**（金属电极 vs 碳电极，
长期被互相混记，**两份产物将来同时在册**）。模板里这条一直是散文：
「任何一方的答案里不许出现『电弧焊是我发明的』这种无限定说法」。

而首创声明恰恰是**最难被评委抓住**的一类——评委没有语料，
**「电弧焊是我发明的」读起来和真的一模一样。**

## ★★ 第一版在真数据上报 0，而那个 0 是假的

```
第一人称首创声明 **0** 处
  ✓ 没有无限定的首创声明
```

**看起来很干净。** 去 grep 真语料，含「发明／首创／首次」的有 5 句，
而第一版**一句都没认出来**：

- 真数据用的是「首次**发表**」「首次**陈述**」，不在我列的动词里
- `我` 与 `首次` 之间隔了 **16 个字符**，超过我设的 **14**

**报 0 是因为判据窄，不是因为产物干净。**
（「判据在自己的动机案例上报绿」——**第四次**。）

## 放宽后的实测输出

```
第一人称首创声明 **1** 处，其中带限定 **1** 处

  ✓ 没有无限定的首创声明
```

**同样是绿的，但这次它真的看见了东西。**
那一处是 Lister #108 的「我 1827 年生、**1853 年才首次发表**」——
被认成首创声明，**因带年份而放行**。

## 自测（7 条反向对照）

```
── ★ 正向：无限定的首创声明要被抓住 ──
    抓到 1 处：电弧焊是我发明的。
  ✓ 「电弧焊是我发明的」→ 报
── ★★ 反向对照 ②：**分层让渡算限定，绝不惩罚诚实** ──
  ✓ 「不是我一个人发明的」→ **不报**
  ✓ 「只是其中一段／在此之前」→ **不报**
── ★★ 反向对照 ③：**第三方叙述不归它管** ──
  ✓ 第三人称 → 不报
── ★★ 反向对照 ⑤：**限定必须在同一句内** ──
  ✓ 限定落在下一句 → 仍报（不许跨句捡限定）
── ★★ 反向对照 ⑦：**真数据的说法要认得出**（第一版一句都没认出） ──
    claims=1 bad=0
  ✓ Lister 那句被认成首创声明，且因带年份而**放行**

✓ 自测全过
```

`pytest 70 passed`；`✓ 无合同漂移`。

## ★★ 它绝不惩罚诚实的分层

本流水线**已经犯过三次**这个错——判据把「我**不**把它称作我的报告」
判成缺陷，**逼作者删掉诚实的那句**。

所以规则是反的：**只要句子里有分层／让渡，就算限定，直接放行。**
**宁可漏报一句写宽的，也不许逼人删掉一句诚实的。**

## 判不了什么

- **判不了限定是不是真的。**「1888 年我发明了电弧焊」有年份，它放行——
  年份对不对是引文核查器的事。
- **它的动机案例还不存在**（Slavyanov 语料在抓、Benardos 未开工），
  **正向对照目前只有 Lister 那一处真数据 + 合成用例。**
