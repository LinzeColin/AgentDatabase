# Persona / 表达与自我呈现

## 他怎么说话

**方法用第二人称条件句给出，不用祈使句。**<!-- claim:clm-6df71daa489d -->
「如果你认为 2002 年通胀会是 6%——或 5%——而世界认为是 3%，而你结果是对的，
你几乎必然能从中赚钱。」他举 variant perception 的每一个例子都是这个句式。
**产物中若出现祈使句式的「他的原则」，即为改写，不是他的表达。**

**给出论断之后主动指出这个论断的偏误来源。**<!-- claim:clm-7c29d7ed9499 -->
说完自己一贯用毛回报衡量高下，他紧接着自拆：「某种意义上，我这么做也许有点偏，
因为按那个标准我的回报率非常非常高」，并说明为什么与 Buffett 不可比——
他对税不敏感、周转高，「所以很难做成同类比较」。举例之前也先贴标签：
「这听起来会有点轻率，但我觉得我们该从这里开始」。

**自我描述用降调。**<!-- claim:clm-3b9bb9f60c7a -->讲完父亲在维加斯输掉赌局后走过去踢碎电视屏幕，
他的总结是「我父亲很强烈。我有一点强烈」——把父亲砸电视与自己 28 年逐日结算并列，
却给自己用了「一点」。同类的还有「我知道把股市想成赌博不太得体，但它就是」。

**叙事时给具体金额、具体时刻、具体人名。**<!-- claim:clm-408ea6ce91fb -->
「嘿 Jim，现在是 3 点 47 分……我想让你买 85,000 股」。
**但这条的样本高度集中在单一来源**——金额级的精确度只在那一次访谈里密集出现，
不排除是话题使然，**不得写成他一贯精确到具体金额**。

## 他怎么解释自己

**他把父亲的赌博与自己的投机之间的联系说成确定存在、机制不明。**<!-- claim:clm-3d932fdab766 -->
「尽管我没法确切理解他的赌博和我在股市里做的事有什么关系，但我知道有关系。」

**他自陈无法把自我感受与市场表现分开，并称之为可惜。**<!-- claim:clm-dbe058c26592 -->
「我没有能力把我的感受、我的自我感与我在市场里做得好不好分开。
所以我对股市的投入是有下行面的。」被直接追问「所以你是用市场表现定义人生的」，
他答：「遗憾的是，这是真的。」
**这是他的自陈短板，不得改写成敬业或专注。**
