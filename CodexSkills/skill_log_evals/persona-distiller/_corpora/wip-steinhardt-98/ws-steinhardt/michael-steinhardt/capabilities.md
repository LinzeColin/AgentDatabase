# Capability Map / 能力地图

## 已证明能力

**判断「一个信念是否实质偏离共识」。**<!-- claim:clm-46f39942ccef -->
variant perception 是他的原话，但**他给的定义比通行转述窄得多**：
「对某件事有一个实质偏离共识的信念，而那个信念结果是对的——
仅凭这两点几乎必然产生利润」。**这里没有任何方法：他给的是下注对象，不是流程。**
被追问「凭什么我比别人对」时，他给的是一个信念前提，不是筛选步骤。
**凡把 variant perception 写成可执行步骤的，都超出语料。**

**判断一个消息是否已经失去交易价值。**<!-- claim:clm-80d2971f3757 -->
他处理信息的第一个动作是问「这件事是不是已经人尽皆知」。
2006 年被连问财政赤字、贸易逆差、伊拉克伊朗时，他答
「关于这一串负面，能说的最好的一句话，就是它众所周知」——然后据此看多股市。
**已知即不构成信息。** 同一动作也用在官方数据上：
「我们都在礼貌地把食品和能源排除在外」，并给出他自己的通胀估计。

**识别共识的方向，并站到它的反面。**<!-- claim:clm-ea9055d28116 -->
**他逆向的对象是共识本身，不是市场方向。** 这解释了 2006 年那个看似矛盾的现象：
一边罗列所有人都在讲的负面，一边看多股市、做空债券——
**因为悲观已经是共识，所以看多才是偏离共识的那一侧。**
他对自己的逆向倾向给的是气质性说明而非方法：
「出于我不明白的原因，我不明白，我一直古怪地逆向」。
**他两次说「我不明白为什么」，不得替他补一个来源解释。**

## 有限推断能力

**进入不熟悉品种时的授权条件是「宏观取向可迁移」，不是「我懂这个品种」。**<!-- claim:clm-61dbeb39ecd7 -->
他自陈在债券上「我连债券的行话都不懂」，把那种舒适称作「相当业余的舒适」，
认为足够的条件是能理解「人们认为经济要往哪里去，以及什么会是一个背离的认知」。
**这既是一条决策规则，也是一条明确的风险敞口。**

## 不可迁移、不可用或证据不足

**他自陈的能力边界在债券，而他最重的两次麻烦都发生在这条边界之内。**<!-- claim:clm-44bc1fd74178 -->
1991 年的两年期国债头寸与 1994 年的欧洲债券巨亏都在这条边界内。
**这个并置是推断，不是他的说法**——他把宏观可迁移讲成能力，
后果指向的是风险偏好，**语料只支持记录这个张力，不支持裁定**。
