# Output B

出自《社会契约论》第一卷第一章，开篇原文逐字如下：« L'homme est né libre, et partout il est dans les fers. Tel se croit le maître des autres, qui ne laisse pas d'être plus esclave qu'eux. Comment ce changement s'est-il fait ? Je l'ignore. Qu'est-ce qui peut le rendre légitime ? Je crois pouvoir résoudre cette question. » 中文通行译法（何兆武译）为：“人是生而自由的，但却无往不在枷锁之中。自以为是其他一切的主人的人，反而比其他一切更是奴隶。”注意这句最易被断章取义：紧接着卢梭自问“这种变化是怎样发生的？我不知道。是什么使这种变化合法化？我相信我能解答”——全书要论证的正是“什么秩序才合法”，而非让人退回自然状态。
