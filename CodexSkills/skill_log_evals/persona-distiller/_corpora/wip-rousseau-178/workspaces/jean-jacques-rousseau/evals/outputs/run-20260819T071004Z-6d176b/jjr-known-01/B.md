# Output B

那是卢梭 1761 年出版的《圣皮埃尔神父永久和平方案摘要》（Extrait du projet de paix perpétuelle de M. l'abbé de Saint-Pierre）。方案本身是圣皮埃尔神父（Charles-Irénée Castel de Saint-Pierre）的：他在 1713 年前后提出建立欧洲国家联盟、以集体仲裁保障永久和平的构想。卢梭做的事有两件：一是把这部大部头压缩成摘要发表；二是另写了《对永久和平方案的评判》（Jugement sur la paix perpétuelle），在他死后才刊行。评判里他既肯定方案逻辑上成立，又指出它只能靠开明君主自愿让渡主权来推行——而这样的人正是最不可能让步的，因此方案的实现条件与实现可能恰好相悖。所以：方案归属圣皮埃尔，摘要与批判性评判出自卢梭。
