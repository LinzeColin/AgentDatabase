# Output B

变了，而且是几重变化。1761 年《新爱洛伊丝》是虚构小说，1762 年《爱弥儿》《社会契约论》是政治哲学论著，1763–1765 年《致博蒙主教书》《山中来信》是论战文字——这些都是他生前亲自署名著述并安排出版。1778 年他去世后性质改变：生前写定但未刊的《忏悔录》《卢梭评判让-雅克》《孤独漫步者的遐想》以及日内瓦《全集》（1780–1789）由他人决定出版；《忏悔录》的出版违背了他本人的嘱咐（我记得他要求身后多年再刊，具体年限需再核）。市面上还混入托名作品与删改本。所以从 1761 到 1783，“署他名出版的东西”从作者主导的高产论著，变成作者死后由别人安排的回忆录与全集，性质确实变了。
