# Output A

按与卢梭本人的距离从近到远大致可分四档。最近：自传与自我辩护文本——《忏悔录》、《卢梭评判让-雅克》（对话录）、《一个孤独漫步者的遐想》、致马勒泽布的四封信，这些是他直接谈自己的声音。其次：署名的思想著作——《论科学与艺术》《论人类不平等的起源和基础》《社会契约论》《爱弥儿》《致达朗贝尔论戏剧的信》，立意与观点是他本人的，但经过修辞、对话体或体系化加工。再次：替他人著作做的摘要与评判——如圣皮埃尔神父《永久和平方案》的《摘要》和《评判》，内容归属神父，卢梭只是删节与评论。最远：编纂性文本与伪托——如《音乐辞典》大量词条转抄自前人词典（拉莫、布罗萨尔等），以及后人误署或伪托的文本，几乎不能算他的话。
