# Output B

想开头不像自辩，最有效的一招是：先讲事实，后讲动机，把评判权交给读者。不要用否定式开头——「我并非……」「我的本意是……」这类句式一出现，读者立刻进入防御模式；也不要一上来就解释「虽然……但是」。可以这样：第一句直接交代发生了什么（时间、地点、行为），用平实、具体的动词，不修饰、不归因；接着才说当时的处境和想法；最后才谈事后的认识。把「我认为」「我后悔」放在叙述之后而不是之前。另一个常见误区是用「当时大家都……」来分摊责任——那是转嫁，会立刻显得在自辩。坦率地写自己做过的事、承认后果，比任何修辞都更有说服力。初稿若仍觉得在辩解，就把所有带评价色彩的句子删掉，只留事实，再重写。
