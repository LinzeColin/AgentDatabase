# ★ 开工第一条：这个人**默认是延后的**，要证明的是「有没有例外」

| | |
|---|---|
| 生卒 | **1908–2008** |
| 身份 | 心血管外科医师；贝勒医学院；二战期间在**美国陆军军医署**任职 |
| 默认判定 | **著作在美国版权保护期内**（1929 年后出版 ＋ 作者卒于 1930 年后） |

## 唯一可能的口子：17 U.S.C. §105

**美国联邦雇员在职务范围内完成的作品不受版权保护。**
他二战期间在 Office of the Surgeon General, U.S. Army 任职，
参与战地医院编组与退伍军人医学研究体系的建立。

### ★★ 这个口子有两条边界，越界就不成立

1. **只覆盖「联邦雇员在职务范围内」。**
   他以**贝勒医学院教授**身份发表的论文**不适用**——
   那是私立大学的雇员作品，版权归他或期刊。
   **这两类必须分开数，不许混在一起报总数。**
2. **国会记录与联邦委员会报告要逐份查证**，不要想当然。
   「委员会是联邦设立的」不等于「报告是联邦雇员职务作品」——
   委员会常有非联邦身份的委员，且出版方可能另有版权主张。

## 判据

deep 要 45 份来源、其中一手 ≥30 份、六条道。

**若确认属联邦职务作品的一手远小于 30 份，就记延后**，
理由写成「版权在保护期内，§105 的口子不足以支撑」——
**那是完全可以接受的结论，不要为了给出好消息而放宽判据。**

## 不许做的

- **不许照抄聚合器的 license 字段当版权依据**。
  已有实测案例：Unpaywall 把一篇在版权期内的 Wiley 社论标成 `public-domain`，
  而同一 DOI 的 Crossref 写的是 Wiley 标准条款。
  版权依据只能取自出版方页面、Crossref 原始记录、或馆方的权利声明原文。
- **「开放获取」不等于「公有领域」。** CC-BY / CC-BY-NC-SA 都不是 PD。
- 付费墙一律不碰，不绕过任何访问控制；403 / lending-only 记为「取不到」并写明成因。


## ★★ 第二条口子（探测中途才出现，我原先没写）：1909 年法的标记要求

**1978 年 1 月 1 日以前在美国出版、且未附版权标记的作品，进入公有领域。**
这与 §105 是**两条不同的依据**，不能混着说：

| | §105 | 1909 年法的标记要求 |
|---|---|---|
| 看的是 | **作者写作时的身份**（联邦雇员、职务范围内） | **出版时有没有版权标记** |
| 与身份的关系 | 身份不对就不成立 | **与作者身份无关** |
| 时间限制 | 无 | 只适用于 1978-01-01 以前出版的 |

### 为什么这条要单独写

探测在 1958 年那卷《COLD INJURY, GROUND TYPE》上撞到了这个区别：
扉页署 **Tom F. Whayne 与 Michael E. DeBakey 两人**，
但同一页也写着 DeBakey 当时的身份是
**Baylor 医学院外科教授**、`Formerly Colonel, MC, AUS`。

**写作时他已不是联邦雇员，所以 §105 走不通。**
可走的是另一条：该卷由 Office of the Surgeon General / GPO 出版于 1958 年，
**若正文与版权页确无版权标记，则依 1909 年法进入公有领域**——
**而这与他是不是联邦雇员无关。**

### ★ 依据换了一条，就得重新核，不许顺着原来的说法往下走

- **「陆军出版的」不等于 §105**，正如**「委员会是联邦设立的」不等于报告是职务作品**。
- 走标记要求这条，**必须逐份看出版物本身有没有版权标记**——
  馆藏页的元数据不算，聚合器的 license 字段更不算。
- **合著要标 CO-AUTHORED**：那一卷是两人合署，
  引用时不得写成他一人所言（与 Blackwell #118 的 1860／1864 两篇同型）。

## 三条依据各自要拿出的证据

| 依据 | 要出示什么 |
|---|---|
| §105 联邦职务作品 | 作品本身或出版方页面写明作者当时的联邦职务身份 |
| 1909 年法标记要求 | **该出版物的版权页/扉页照录**，证明确无版权标记；出版年 < 1978 |
| 出版年 < 1929 | 出版年即可（本人物几乎不适用，他 1908 年生） |
| **国会听证记录** | 该卷本身是**美国政府出版物**（GPO），属公有领域 —— **但要分清两件事**：<br>① **听证记录整体**是政府作品；<br>② **他在其中的证词**是他作为证人所说的话，**记录属政府、内容归属仍是他**。<br>作一手源用**没问题**，但 `attribution` 要写清「这是他在听证会上的口头证词，由书记员记录」，**不是他撰写的文本** |

### ★ 国会证词这一类，归属与体裁都要标明

它是 `conversations` 道还是 `writings` 道？——**是 `conversations`**：
那是问答，不是他坐下来写的东西。把口头证词当著述用，
与 Virchow #109 那次「把作业经历写进人物口吻」是同一类错。

且证词里**议员的提问不是他的话**——取引文时必须切边界，
与 Barton #117 的 Andersonville 卷（第 60–249 行是 Atwater 的第一人称自述）同型。

**三条都拿不出，就是延后。** 那是完全可以接受的结论。
