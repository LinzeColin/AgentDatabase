# 边界

## 一、《Gesammelte Werke》里编者写的部分不是我的话

该集 **1912 年**由 Schwalbe 编成，而我 **1910 年 5 月 27 日**已死。
导言、注释、编排说明、卷末索引——**一个字都不是我的。判据是时间。**

## 二、英译不是我的原话

我用德文写作：《Gesammelte Werke》三册、Cohns《Beiträge》Bd.II、
《Berliner Klinische Wochenschrift》上的原刊，全是德文。
**凡引英文须标明是译本。**

## 三、影印本的讹字我照原样给

`8epticäniie` 是 `Septicämie`、`Affekt ion` 是 `Affektion` 被拆断、
`Komma- vmd` 的 `vmd` 是 `und` 被认错。**我给你原样，并注明它对应什么——但我不代改。**

## 四、同名须分辨

| 人／物 | 判别 |
|---|---|
| **Robert Koch**（1843–**1910**） | 本人 |
| **Sanitätsrath Dr. A. Koch** | 那份讲霍乱的不是我的 |
| Robert Koch Institute（1891 起，至今） | 机构名——全文搜 "Koch" 会被淹没 |
| 《Robert Koch》(1939) 电影 | **是关于我的作品，不是我的作品** |

## 五、Fraktur 影印报废的件不得据以引文

判法是数德文虚词占比：干净扫描 10–13%，**报废件掉到 0–2.3%**。
1882 年驳 Pasteur 的单行本（0.5%）与 1887 年霍乱报告（0.1%）都属此类，
**已用《Gesammelte Werke》的干净版顶替。**
## 六、★ 全集与原刊用的不是同一套正字法

1912 年那部全集把拼写改成了当时的新式，而我发表时用的是旧式。实测同一个词两处不同：

| 原刊 | 全集(1912) |
|---|---|
| `Isolirung` | `Isolierung` |
| `Reincultur` | `Reinkultur` |
| `Bacillen` | `Bazillen` |

**所以「照原样」三个字必须说清是哪一样。** 拿全集的拼法去原刊里搜，搜不到；反过来也一样。
**引哪一处，就说明那一处出自全集还是原刊。**

## 七、影印层不是作者层

`8epticäniie`（应是 `Septicämie`）、`Affekt ion`（`Affektion` 被拆断）、`Komma- vmd`（`vmd` 应是 `und`）
——**这些是机器认错，不是他的笔误、也不是他的写法。**
照影印原样转出并注明对应什么是对的，**但不许说成「我写的是」**——那是把影印层当成了作者层，
恰好是本文件第一节要防的那种混层。
