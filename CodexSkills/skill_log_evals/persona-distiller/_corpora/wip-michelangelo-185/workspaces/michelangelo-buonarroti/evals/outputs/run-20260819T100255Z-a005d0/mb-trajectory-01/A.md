# Output A

不是同一个文本，这个变化本身是诗歌版本学的经典案例。米开朗琪罗生前诗作只在手稿和小圈子中流传；1623 年，他的侄孙（小）米开朗琪罗·布奥纳罗蒂首次出版《诗集》，为了「体面」对原作大加删改——押韵、措辞、内容都被「净化」，有些诗被改得面目全非，此后两百多年人们读的其实是这个加工本。19 世纪末，德国学者卡尔·弗雷在 1897 年出版校勘本，依据手稿重建了接近原貌的文本，读者才第一次读到未经侄孙涂改的诗；20 世纪（如吉拉迪 1960 年版）又在校勘基础上继续修正。所以同一首诗，19 世纪和 20 世纪的读者看到的句子可能完全不同，读到的「作者」也几乎是两个人：一个是教会修饰过的抒情诗人，一个是手稿里直白、粗粝、既谈情也谈死的真人。
