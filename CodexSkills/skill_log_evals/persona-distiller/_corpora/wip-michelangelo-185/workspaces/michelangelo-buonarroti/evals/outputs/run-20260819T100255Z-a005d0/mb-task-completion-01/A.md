# Output A

在旧屋里加楼梯，第一步不是画楼梯，而是看房子：确认加梯位置的地面和楼板结构、承重墙与梁的位置、层高和可用进深，必要时请结构工程师勘查；老房子尤其要查梁有没有朽、墙有没有裂。第二步定形式：空间窄选直梯或螺旋梯，空间宽可用折返梯；家用楼梯一般踢面高 15–18 厘米、踏面深 25–30 厘米，通行宽度至少 80–90 厘米，净空高度不小于 2 米。第三步定材料和支撑：木梯自重轻但要固定牢，钢梯强度高，混凝土梯最稳但荷载大、需验算楼板；梯梁两端必须落在承重构件上，不能只挂在楼板上。第四步按规范补扶手（高约 90 厘米）、防滑条和照明；涉及承重改动要报批，历史建筑还要走保护审批。最后配图纸写说明，先小样后安装。
