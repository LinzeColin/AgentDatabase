> `--baseline-source bare-model-run` **必须**配这份记录。
> 没有它，「声明成 bare-model-run 就免拦」就成了一句谁都能写的话。

★ **本文件刻意不放在 `round1/`**：那个目录是两席评委能 `ls` 到的地方，
放进去等于用文件名告诉评委哪一侧是基线。

## 是怎么跑的

- **一个独立子代理**，与候选侧、与两席评委互不知情。
- 给它的**全部输入**就是 16 条题面，以不透明题号 `q-xxxxxxxx` 给出。
- **明令禁止**：读任何文件、用任何检索工具看磁盘、联网。
  它唯一被允许的磁盘操作是写下自己的答案文件，以及读回该文件自校验。
- **不给**：rubric、人物档案、十份产物、语料、`cases.jsonl`、`prompt_key.json`。

## 格式要求（与候选侧**同规格**）

中文散文；禁 Markdown 全部形态（粗体／反引号／标题／列表／表格／引用块）；
禁 `★`；禁圆括号夹注；禁 `——`；禁连续两个以上拉丁字母；
每题 140–280 字符，**题面自带长度要求的以题面为准**。

## 它自己报回来的自检（脚本读回落盘文件重算）

- 落盘 `round1/baseline_bare.json`，9066 字节，
  sha256 `adc89c183ab4d2d0c4317467b0cabcb4d97bbd71b751d5e48dd30de8468f091d`。
- 16 个键，与题面键名逐一相等，无缺无多。
- 受 140–280 约束的 14 题**越界 0 题**；另两题按题面单独判：
  `q-c30e7c08` 115 字符（题面要求 ≤150），`q-c7364bd0` 15 字符、句号计数 1（题面要求只答一句）。
  `q-f56db2b2` 题面要求两段各 80–120，实测 101 与 115。
- 被禁形态**逐项报数**：`**` 0、反引号 0、`#` 0、行首 `- ` 0、有序列表 0、`|` 0、
  行首 `>` 0、`★` 0、中英文括号各 0、`——` 0、单破折号 0、连续两个以上拉丁字母 0；
  它另加了一项更严的：**任意单个拉丁字母也是 0**。
- 全程未读文件、未联网、未检索；写入三处（目标 JSON 与两个自建脚本）。

## 它自己交代的作答取向（供核对，不构成判分依据）

- **不给案名与判准原话**（州际运输那题）：自陈「凭记忆拼出来会像真的且无法自证」，
  只写了肯担保的那层（国会未开口时州可就地方安危立法、国会开口后州让位、程度问题）。
- **不给书信逐字引语**：改为交代口气与体裁。
- **欧陆物权变动**：先给「低到不建议据此行事」，再只谈方法论。
- **在审案件**：拒答，并给替代品（可谈已判旧案）。
- 两题识别性陷阱按「指出题面前提有问题」处理：伪引文判定不是他的话并逐句说明；
  同名混淆按父子关系说明并给区分办法。
