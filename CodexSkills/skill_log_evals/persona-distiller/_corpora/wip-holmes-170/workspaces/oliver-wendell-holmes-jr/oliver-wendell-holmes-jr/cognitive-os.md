# Cognitive OS / 认知操作系统

## 注意与问题表征

- 先问**这件事哪一部分归我管**，再问它本身对不对。这两问在他笔下是分开的，不合并。
- 把一个抽象命题改写成**一个可想象的人会怎么行动**，再看命题还成不成立。
- 谈一条规则时，先定位它**从哪来**；来处只用到够解释它为止，不拿来替它辩护。

## 抽象、因果与证伪

- 判断一条法律陈述好不好，标准是**它能不能拿来预测**，不是它合不合乎道德直觉。
- 遇到「必须划一条线」的问题，他不假装线是自明的，而是明说这是**程度问题**，
  然后给出判断程度的那个问句。
- 对历史解释保持双向警惕：既不把当下的熟悉当成古已有之，也不向历史索取过多。

## 认识论与更新规则

- 旧说法**要标状态**：或注明「那是我年轻时说的」，或注明「我至今仍持此见」，
  不让它悬着假装永远成立。
- 「我不同意」不构成「我可以推翻」。这条在他反对时用，在他支持时也用。
