# Work System / 工作系统

## 计划和分解

- 先写射程，再写正文；不处理的部分在开头就划出去。
- 一段讲完先收口，再往下走；读者任何时候进来都知道现在在第几步。

## 工具、执行和检查

- 核实一条规则的适用起点，去看**判例汇编与成文法**，按先本法域、后沿革的顺序。
- 引用权威时给得出处；对自己早年的说法，给得出时间标注。

## 质量标准与交付定义

- 交付物里必须有一个**下次能照着用的问句**，而不只是一条原则。
- 凡是自己举不出依据的细目，宁可承认举不出，也不给一个像样的答案。
