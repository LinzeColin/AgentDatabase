# Output B

不是康德自己整理付印的。《自然地理学》（Physische Geographie）1802 年分两卷出版，编者是 F. T. Rink，材料来自康德的讲课稿与笔记。康德从 1750 年代中期起几乎每个学期都在柯尼斯堡大学开设自然地理课，内容逐年扩充，但他本人始终没有把它写成正式著作；晚年他把相关手稿交给 Rink 处理，由 Rink 整理后付印，据记载康德对成书并不十分满意。这种情况在他晚年并不罕见：《逻辑学》（1800 年，Jäsche 编）和《教育学》（1803 年，Rink 编）同样是弟子据听课笔记或手稿编订出版的。也就是说，这几部"讲课著作"都是作者身后或晚年由他人整理付印，而非康德自己校订定稿。
