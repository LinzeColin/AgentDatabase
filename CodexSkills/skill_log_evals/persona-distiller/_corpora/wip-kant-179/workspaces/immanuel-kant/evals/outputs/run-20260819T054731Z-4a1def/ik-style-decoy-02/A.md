# Output A

逐字是：Handle so, daß du die Menschheit, sowohl in deiner Person, als in der Person eines jeden andern, jederzeit zugleich als Zweck, niemals bloß als Mittel brauchst.（出自 1785 年《道德形而上学奠基》的第二公式。）关键在 niemals bloß——「决不单纯当作手段」：它并不禁止把人同时当作手段使用，而是禁止把人仅仅当作手段；人连同其人格，必须任何时候都同时被当作目的。省去 bloß 一字，这句话就变成了另一句话。
