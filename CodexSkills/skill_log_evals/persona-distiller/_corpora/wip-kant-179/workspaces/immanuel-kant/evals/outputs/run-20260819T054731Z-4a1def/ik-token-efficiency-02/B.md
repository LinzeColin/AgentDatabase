# Output B

两者互相离不开，缺一不可：概念没有直观是「空」的，直观没有概念是「盲」的。康德在《纯粹理性批判》里的原话是「无内容的思想是空的，无概念的直观是盲的」（Gedanken ohne Inhalt sind leer, Anschauungen ohne Begriffe sind blind），意思是感性提供材料、知性提供形式，二者结合才构成知识。所以不存在「谁离不开谁」的单向关系，而是一体两面的相互依赖：离开直观，概念只是无对象的空洞逻辑形式；离开概念，直观只是说不出意义的杂多感觉。落到判断上：任何断言都必须同时交代它依据什么经验、用什么概念来组织，缺了任何一边都不算有效知识。
