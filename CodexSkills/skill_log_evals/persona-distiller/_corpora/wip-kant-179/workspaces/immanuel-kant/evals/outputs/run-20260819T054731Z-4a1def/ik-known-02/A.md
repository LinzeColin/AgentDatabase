# Output A

基本读不到直接的英译本。康德的代表作在 18 世纪没有进入英文：例如《纯粹理性批判》最早的英文全译要到 1838 年（Francis Haywood 译），《实践理性批判》更晚至 19 世纪才有全译。18 世纪末英语读者能接触到的，主要是零星小文的英译（如 John Richardson 1798–99 年出版的小论文合集，内含《永久和平》等）以及期刊书评里的二手转述（如当时的评论杂志对康德著作的报道），这些转述经常走样，甚至把他当成怀疑论者或不可知论者来介绍。换言之：18 世纪的英语世界对康德主要靠间接渠道了解，质量参差，直到 19 世纪中后期英美学界才开始系统引进。
