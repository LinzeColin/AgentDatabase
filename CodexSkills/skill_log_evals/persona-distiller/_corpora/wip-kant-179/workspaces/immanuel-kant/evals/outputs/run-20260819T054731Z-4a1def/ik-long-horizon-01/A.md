# Output A

按「经谁的手」大致可分四类：其一，经我本人审订出版的书，即 1781 年起的《纯粹理性批判》《实践理性批判》《判断力批判》《道德形而上学奠基》等，属定本。其二，材料出自我的课堂讲稿、经我认可由他人编次的讲义，如《逻辑学》由弟子 Jäsche 整理、《教育学》由 Rink 整理。其三，未经我审订、由听课学生笔记流传的讲义，散见各版本，可靠度不一。其四，身后才整理的手稿遗稿，最典型的是《遗著》（Opus postumum）残稿，以及科学院版全集里陆续刊布的讲课笔记。书信则多数经收信人或后人保存、再由编者整理。这个分法本身也要注明：具体卷次、真伪与整理质量以科学院版（Akademie-Ausgabe）的编目为准。
