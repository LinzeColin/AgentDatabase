# Output B

1746 年前后写成第一部著作《对活力的真正评估》（1746 年题署、1747 年出版），1748 年到 1754 年在柯尼斯堡附近几户人家任家庭教师。1755 年回柯尼斯堡大学以《论火》取得授课资格，同年发表《自然通史与天体理论》（即星云假说）。1756 年以《物理单子论》答辩并发表地震三篇；此后几年多次求职教授席位未果，靠讲课维持生计。1762–1766 年接连发表《三段论四格的错误繁琐》《上帝存在证明的唯一可能根据》《把负数概念引入哲学》《对美与崇高感的观察》《通灵者之梦》。1770 年就任逻辑学与形而上学教授，发表就职论文《论感觉界与理智界的形式与原则》；此后约十一年几乎不再发表著作（所谓"沉默的十年"），把精力放在重构形而上学、开讲逻辑、形而上学、人类学、自然地理、教育学等课程上，1772 年致赫茨的信中已预告"纯粹理性批判"的构想。1781 年《纯粹理性批判》初版问世。
