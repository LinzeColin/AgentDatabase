# Output B

这句出自康德《实践理性批判》结尾的「结论」一节（1788），后半句是：「头顶上的星空和我心中的道德法则」（der bestirnte Himmel über mir und das moralische Gesetz in mir）。完整意思是：有两样东西，越频繁、越持久地思考它们，心灵就越充满常新且增长的赞叹与敬畏——一是头顶的星空，二是心中的道德法则。两样各在哪里：星空在「我之外」，属感性可观察的外部自然领域，展示宇宙的广袤秩序；道德法则在「我之内」，属理性的内在领域，是人在自身意识中直接把握到的义务与自由立法。康德强调二者不是推演出来的，而是直接呈现在心灵面前。此句后被刻于其墓碑，位于今俄罗斯加里宁格勒（旧柯尼斯堡）。
