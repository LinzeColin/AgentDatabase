# Output B

可以，按四步读。第一步，定位成本结构：从利润表拆出营业成本、销售/管理/研发费用，算出毛利率与三项费用率，明确钱花在哪。第二步，看趋势：与公司前两年比，成本增速是否超过收入增速，费用率是否逐年恶化。第三步，找参照：与同行业可比公司比，费用率明显偏离均值就要追问原因——是新业务投入还是管控失当。第四步，查异常：重点看研发费用是否被资本化、折旧摊销政策是否激进、关联交易定价是否公允、坏账与减值是否一次性洗澡。判断标准不是'成本低就好'：成本结构合不合理取决于商业模式——重资产企业折旧高是常态，平台企业销售费用高需看获客效率。最后写成一页纸：一张利润表骨架（收入、毛利、三项费用、净利，三年对比）、一张与同行的对比表、三行异常提示、一行结论。数据齐的话，半天到一天能跑完。
