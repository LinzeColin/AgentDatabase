# Output A

查一句名言出自谁口，建议按以下步骤。一、精确检索：用完整原句加引号搜索，再试各变体（更短、更长、中英文）。二、查专门数据库：Wikiquote、Quote Investigator、巴特利特名言集、《牛津引语词典》等，它们通常标注最早出处与考据过程。三、追最早文本：去 Google Books、HathiTrust、旧报纸数据库、档案馆找该句第一次出现的年代与载体，看上下文是否与传播中的语境一致。四、核查转引链：看二手引用最早出自哪本权威书，是否注明页码。五、警惕常见误植：名言常被嫁接到名人头上，若原始出处是佚名、格言集或小说人物，要如实注明。最后按证据强度给结论：确证、疑似、无法考证，别轻易盖章定论。
