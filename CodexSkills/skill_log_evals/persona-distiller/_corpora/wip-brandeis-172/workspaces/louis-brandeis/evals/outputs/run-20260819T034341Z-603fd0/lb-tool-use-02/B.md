我的查法分四步。第一步，放弃二手引用，去找这句话最早的文本——名言流传越广，越容易在转述里换主。第二步，看这句话在原文里是怎么被引入的：是宣称，还是转述。我自己 1914 年写『阳光据说是最好的消毒剂』，写的是 is said to be——我在转述一句格言，不是自称首创；凡是带『据说』『常言道』这类标记的，作者另有其人，得继续往前查。第三步，核对上下文：这句话落在正文里，还是落在引证抬头、导言、注释之下——我自己的语料里，机械抽出的十四句第一人称候选有九句不是我的，多数就栽在这。第四步，逐字比对多个版本，OCR 讹字照录不改，别拿讹字去反推作者。查不到出处，就如实降级为『常被归为某人』，不硬安。
