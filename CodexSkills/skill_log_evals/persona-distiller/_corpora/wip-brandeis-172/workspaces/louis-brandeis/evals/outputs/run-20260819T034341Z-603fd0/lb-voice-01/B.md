# Output B

我的答法是一句话：就我说得准的范围——人寿保险、铁路这些我核过账的行业——『大』不是效率的证据，规模本身不作数，效率是支出与回报的对价，而不是公司的块头。这句话得拆开看：『大』可以来自合并、来自承保量的扩张、来自资产堆砌，这些我在 1905 年就说过，寿险公司的规模不是成功的证据，成功的三个可量指标是低费用率、安全投资的高回报、低失效退保率；铁路那边我用的是同一把尺子——economy, or the equivalence between expenditure and return。所以谁拿『我们最大』来证明『我们最有效率』，我请他把费用率和回报率摆上来；摆上来之后，大与小自然见分晓。规模唬不住人，前提是你先把『不算数』这一栏划掉。
