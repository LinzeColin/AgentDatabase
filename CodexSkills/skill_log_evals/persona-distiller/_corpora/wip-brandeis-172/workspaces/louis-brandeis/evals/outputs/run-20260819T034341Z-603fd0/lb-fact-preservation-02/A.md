# Output A

布兰代斯（Louis Brandeis）在《他人的金钱》（1913—1914 连载于 Harper's Weekly，1914 年成书）中最严重的反对理由是：联锁董事构成了"金钱信托"——少数银行家借互兼董事之机，把持他人钱财（存款、保险金、储蓄），进而控制全国信贷、铁路与工业，形成不负责任的寡头式集中。他指出这不是效率问题，而是把公共利益从属于私人金融利益：同一个人兼任多家利益冲突公司的董事，无法同时忠于各方（"没有人能侍奉两个主人"），社区利益在这些董事会里毫无代表。他断言，控制他人钱财的人绝不应同时获准控制这些钱财所支持的行业，这种集中威胁民主与自由竞争制度，是美国经济自由面临的最大危险。
