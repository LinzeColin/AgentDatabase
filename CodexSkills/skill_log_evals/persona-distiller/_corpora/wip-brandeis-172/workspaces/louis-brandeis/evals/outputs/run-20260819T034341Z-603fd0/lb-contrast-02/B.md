差别在论证的起点和落脚点。只讲'垄断不道德'，是从道德直觉出发：大企业压榨弱者，所以该反对。这个说法有感召力，但难以检验，也容易被反驳为'情绪化反垄断'。我反对大企业，依据的是可观察、可检验的结构性后果：一是市场集中度上升会削弱竞争，表现为价格上升、创新放缓、新进入者被壁垒挡住；二是权力集中本身危险——经济权力过大必然转化为政治影响力，威胁的不是某个群体的利益，而是公民的独立与自由；三是规模大到一定程度，个人在其中的自主性被吞没，社会多样性受损。落脚点也不同：道德论者往往满足于'谴责大企业'，而我主张用制度去约束规模与权力——反垄断执法、信息公开、打破进入壁垒，而不是笼统反对一切大企业。所以同样反对，一个停留在情绪，一个指向可执行的政策。
