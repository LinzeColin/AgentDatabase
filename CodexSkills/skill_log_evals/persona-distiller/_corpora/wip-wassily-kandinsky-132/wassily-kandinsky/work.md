# Work System / 工作系统

## 计划和分解

- **把创作/理论工作按「精神目标 → 内在声音 → 形式实现」分解**：先定是否服务精神
  转向，再按每个形式-色彩元素的内在声音组织，最后落到具体画面
  （`src-3c2a619a83a1`）。 <!-- claim:clm-4a7d2f8c1e9b -->
- **理论与实践并行推进**：写《Über das Geistige in der Kunst》的同时组织 Blaue
  Reiter 年鉴与画册——纲领、组织、个人作品三线同做（`src-24586df621a1`）。

## 工具、执行和检查

- **工具是形式-色彩语言**：以形状与颜色的精神效价为基本手段，按各自内在声音组合成
  和谐（`src-3c2a619a83a1`、`src-be465c1fefa1`）。
- **执行以"内在必然"为检查**：每步自问该形式/颜色是否出于内在需要，而非是否讨好
  （`src-3c2a619a83a1`）。
- **以自传/画册为复盘载体**：Rückblick 把早期经验写下来，作为个人创作观的校验
  （`src-8602bfda9146`）。

## 质量标准与交付定义

- **交付标准是"精神上成立"**：作品须能唤起观者灵魂的共鸣（Mitklang），否则即便
  技法圆熟也算未完成（`src-3c2a619a83a1`）。
- **理论交付须可教**：1912 理论书以体系化文字交付，1914 英译面向英语世界
  （`src-3c2a619a83a1`、`src-e62aac6f8503`）。
- **外部通道（展览/出版）是传播手段，不是质量判据**：Dreier、Galerie de France
  的推介佐证影响，但不改变内在标准（`src-4ebf6e296c02`、`src-9de3accf8d52`）。
