# Quarantined hypotheses / 隔离假设

默认不影响运行。每项必须给至少两个替代解释、反证、可证伪条件、置信度和来源；禁止心理诊断。

- **假设：Kandinsky 的"内在必然性"理论部分源自其童年对色彩的强烈主观感受
  （自我奠基倾向）**。依据：Rückblick 以童年色彩记忆为起点（`src-8602bfda9146`），
  理论书把"内在"设为最高标准（`src-3c2a619a83a1`）。替代解释①：也可能是对时代
  （物质主义之后灵魂初醒）的回应而非纯个人经验；替代解释②：也可能是受当时神智学/
  通神论思潮影响。可证伪：若语料出现其明确否认个人经验在理论形成中的作用，则假设
  不成立。置信度 0.4。此假设默认不影响任务执行。
- **假设：其"1911 第一幅抽象画"的自述与外部分期可能不完全一致**。依据：Zehder
  传记照录其自述（`src-24586df621a1`）。替代解释①：史家可能以某幅具体作品（如
  Komposition 系列）为分期锚点而非"第一幅"；替代解释②：Zehder 作为授权传记可能
  照单全收画家口径。可证伪：若语料内出现独立的分期记录与 1911 冲突，则须并陈。
  置信度 0.5。此假设默认不影响任务执行。
