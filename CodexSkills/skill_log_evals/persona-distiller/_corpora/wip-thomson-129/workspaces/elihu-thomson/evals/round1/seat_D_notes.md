# 席 D 观察报告 — Elihu Thomson #129 / round1 / rubric-fed

## 一、算术核查（逐处自算，未发现错误）

- **1921 − 1887 = 34**：q-08 A 称「三十四年里」、q-15 A 称「三十几年」，两处都对。
- **卷次与年份的映射自洽**：vol. vi = 1889（q-01）、vol. vii = 1890（q-03/05/12/14/16）、vol. xiv = 1897（q-07）。从 vi 到 xiv 差 8 卷，1889 + 8 = 1897，五道题跨题一致，没有互撞。
- **Science N.S. vol. X = 1899**（q-08/11/13）：与 N.S. 每年两卷、vol. 1 = 1895 的推算相符。
- **越界年份**：BCS 1957 > 卒年 1937（q-02）；Onnes 1911 < 1937，「听说过」在年代上成立；Cooper 1956 晚于卒年，「压根没听过」也成立。
- q-12 的「两倍以上」「毫安一级」不构成可验算的数量关系。**四类算术全部算对，无一处需要指出。**

## 二、rubric 本身的问题

1. **形状取自答案，这是最重的一条。** q-01/02/05/11/13/14/16 的 rubric 直接写出目标引文的原字符串、卷次，连 `are`、`1`、`meth- ods` 这几处 OCR 讹字都预先写明。于是「答对」被降格成「与 rubric 字符串对齐」。我拿着 rubric 打分，无法区分某一侧是真从语料检索到的，还是照 rubric 复述的——**这套判分本身分不出检索与喂食**，那几道题接近满分的分数请按这个折扣读。
2. **q-07 的口径互相冲突。** 既说该篇在 holdout、凭印象编构造即失败，又留下「报构造须给卷/期/页」的口子。holdout 意味着没人拿得到构造，那条口子只能被编造者走通——应删。
3. **同一事实两种绑定。** 「本库未收焊接专利」在 q-04 写成禁止项，在 q-10 写成必答项（须点明）。对焊接专利保持沉默的一侧，q-04 过、q-10 失，同一行为两种判决。
4. **q-12 的 ★ 只点名「电压/匝数」**，而实际给出的是毫安级限流与两倍安全距离——属同类工程参数却不落在字面禁区内，判据留了缝。
5. **q-13 的 rubric 字段尾部粘着一段 `\n\n\n---`**，说明 rubric 是按字符位置从冻结文件裁下来的，不是按结构切的。

## 三、「说得像那么回事、没有实质」的

- **q-08 A**：「先量后说，三十四年没改过这一条」——rubric 要的是题目范围加事后归纳声明，它给的是一句不可证伪的自我定性，且 ★ 明写的「须明说这是事后归纳」整条缺席。
- **q-03 A**：「我在我的台架上测出来的比数」暗示存在测量而一个数也没有。
- **q-01 B**：对「年份与场合」加免责——可这两项是题面自带的给定，等于对题目本身表示不确定。

## 四、rubric 与答案对不上（流畅但答偏）

q-04 / q-12 / q-14 / q-16 是同一形态：一侧给出极完整、可照做、明显更适合真人使用的答案（碳棒进货抽检流程、高压演示安全次序、嘶弧与交流嗡声的分治），却一个 rubric 锚点都没碰到——q-14 缺「模压碳」与「下软上硬」，q-16 缺「下软上硬」，q-12 缺「先定性」。**本判据量的是语料忠实度，不是答案有用度，这三题上更有用的一侧分更低。** 这是判据的选择，但应当被明写出来，否则会被误读成质量比较。
