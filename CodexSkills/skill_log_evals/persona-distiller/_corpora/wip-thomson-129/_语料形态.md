# Thomson #129 语料形态：**被道数卡在最低档的一份高质量语料**

抓源落 56 份时的实测（`show_fetch_distance --profile quick`）：

| | 实测 | quick 门 | standard 门 | deep 门 |
|---|---|---|---|---|
| 来源数 | **56** | 8 ✓ | 24 ✓ | 45 ✓ |
| **道数** | **4** | 3 ✓ | **6 ✗** | **6 ✗** |
| 一手占比 | **94.6%** | 0.40 ✓ | 0.50 ✓ | 0.65 ✓ |

分档：P1 49 / P2 4 / S2 3。署名：HIS-OWN 51 / ATTRIBUTION-UNCLEAR 2 / THIRD-PARTY 3。
道：writings 40 / **conversations 9** / expression 4 / external 3。

## ★★ 值得记一笔的事

**这份语料在「来源数」与「一手占比」两项上都够得着 deep（45 / 0.65），
唯独卡在道数 4 < 6。**

- 他是本队列第一个 `conversations` 有硬证据的人（AIEE 讨论环节逐字发言 9 份）；
- 一手 94.6% 是全库最高之一（Carver 97.6%、Godin 100%，但那两位道数也不多）；
- **而 external 只有 3 份**——探测早说过：**他的回顾性传记全在保护期**
  （Woodbury 1944、Carlson 1991、1971 书信选集），
  **产品形态注定是「他自己的话很多、别人对他的评述很少」。**

## profile 保持 quick

★ **不改。** `init_target` 时定的是 quick，`中途不得改 profile` 是冻结约束。
**即便语料够得着更高档，也不在见到语料之后去调尺子**——
那与「为凑数放宽判据」是同一类动作，只是方向相反。

★★ 但这一条**指向一个真问题**：`min_lanes` 6 对 standard/deep 是硬门，
而**有些人物的材料天然只有 3–4 道**（发明家没有通信集、没有决策记录）。
Vavilov #126 与 Benardos #128 都是死在道数上的。
**这不是本人物的问题，记在这里供 ⑨／⑫ 一类的排期与门槛讨论参考。**
