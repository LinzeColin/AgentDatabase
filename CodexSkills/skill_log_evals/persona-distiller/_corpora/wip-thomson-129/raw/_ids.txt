# == THE NAMESAKE PROBLEM, WHICH IS REAL HERE ==
#   - The company name Thomson-Houston contains his surname. Company output is not his.
#   - Sir William Thomson, Lord Kelvin, is a different man - and Elihu wrote a memoir OF him
#     (procaas-1916-william-thomson-lord-kelvin), so both names sit on the same pages.
#   - Thompson with a p is different again: Silvanus P. Thompson (his correspondent),
#     E. P. Thompson, and a dozen unrelated Thompsons in the patent index.
#   - Lynn, Massachusetts also produced a Robert W. Thomson in the same patent index, and
#     patent 361,382 is A. THOMSON.
#   - archive.org's creator search returns at least one outright false positive:
#     The Collegiate Algebra (collegiatealgeb00quimgoog / collegiatealgebr00thomrich),
#     which is James Bates Thomson and Elihu T. QUIMBY. Not taken.
#   Every row here was confirmed by a byline, a signature, or a speaker label ON THE PAGE,
#   except the two rows marked ATTRIBUTION-UNCLEAR, which say so.
