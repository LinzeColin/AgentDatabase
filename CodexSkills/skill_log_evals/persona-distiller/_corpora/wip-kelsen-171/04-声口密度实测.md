## 3. ★ 三条必须连着数一起说的话

### 3-1 体裁并没有把声口分开——分开的是**单篇**

- 体裁之间（严格 `ich`／万词）：`expression` **5.08** ／ `writings` **4.21** ／ `decisions` **0.00**。
  - expression : writings = **1.21 倍**；
  - decisions 的严格值 0.00 **不能进这个比**（仪器盲，见 3-2）；改用含讹形的 2.69，则 expression : decisions = **1.89 倍**。
  - ⇒ 三道之间最大跨度约 **1.9 倍**。**Holmes #170 的 35–65 倍在这个人物身上没有出现**，差两个数量级。
- 而**单篇之间**差得很开：最高 *Politische Weltanschauung und Erziehung*（`expression`）**29.39**／万词，
  最低 *Staat und Recht*（`expression`，文本干净：讹形族 0.5%、长 s 0、h→b 0.0%）**0.00** —— 通篇只用学术「我们」（`wir` 6.69），一次「我」都没有。
  ★ **但这个 0 要连样本量一起看**：该篇仅 7,472 词，按干净德语件的合并 `ich` 率 4.35／万词，期望值只有 **3.3** 次，观察到 0 次的概率约 **4%**（Poisson）。
  ⇒ **可以说「这一篇没出现 ich」，不能说「他在这一篇刻意不用 ich」** —— 后者这份样本撑不起。
- ⇒ **按体裁分道取样，取不到声口的方差；要按单篇取。** 这一条与探测报告的预期相反，
  探测报告预期最高的是三件 *Erwiderung*（论战），而那三件本机都没有 PD 全文。

### 3-2 `decisions` 那个 0 是**仪器看不见**，不是**不存在**

- `decisions` 两件严格 `ich` 合计 **0 次**，密度 **0.00**／万词。
- **但这两件的讹形比是 93.6% 与 99.4%** ——Fraktur 把 `ich` 打成了 `id)`／`idj`／`icb`。
  把讹形算进去是 **2.69**／万词，不是 0。
- ⇒ **不许把这个 0 写成「机构文书里他不出现第一人称」**。它是空默认值吞掉了「不知道」。

### 3-3 法语那件：**测出来是全批最高，正因如此更不能算**

- `rapports-de-systeme-1926-fr`：`nous` **69** 次 / 38,199 词 = **18.06／万词**，`je` 4 次 = 1.05／万词。
- 若把它并进 `expression` 的第一人称复数，该道会从 **2.65** 抬到 **10.28**／万词（**3.9 倍**）。
- **按指令⑥／⑧不算**：未见译者署名，也未见「本人以法文撰写」的声明。上面这个倍数就是**这条指令的实际代价**，写出来备查。

> ★★ **本轮抓到的一处真污染**：`kommentarzurste00kelsgoog` 全文 `wir` 共 **6** 次，

## 5. 口径声明（不给单个数，给口径）

- `ich`／`wir` 一律**词边界匹配、不分大小写**；词元定义 `[A-Za-zÀ-ÿſ]+`。
- 「严格」＝只数正形；「+讹形」＝加上本轮在该件里**实测到**的 OCR 讹形（`icb`/`id)`/`idj`/`id}`/`idi`/`id^`/`ic^`/`id]`）。
  **两个数都给**，因为在 Fraktur 件上二者差到 0.00 vs 2.69。
- 分母是**扣块后**的词数；扣块清单在 §4，一块不漏地列了出来。
- 德语件变音符密度（用来判 OCR 是否丢了变音符）：11 件排序 [0.0, 73.9, 74.5, 74.7, 90.9, 91.2, 94.4, 95.4, 99.2, 118.7, 123.4]，中位 **91.2**／千词；
  其中 `problem-der-souveraenitaet-1928` 是 **0.0**，是唯一的离群件。
