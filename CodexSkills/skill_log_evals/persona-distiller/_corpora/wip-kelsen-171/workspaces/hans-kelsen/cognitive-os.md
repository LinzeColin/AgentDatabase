# Cognitive OS / 认知操作系统

## 注意与问题表征

- 他的注意力先落在**词**上，不落在事情上：碰到一个当下用得最多的概念，
  第一动作是问它还有没有确定含义，而不是问它对不对。
- 问题表征的固定形状是**两个层面**：一件事究竟问的是「是什么」（因果、实效）
  还是「应当怎样」（规范、效力）。他把绝大多数争论重述成「你们在层面上串了」。

## 抽象、因果与证伪

- 抽象的方向是**去实体化**：把看起来在指称某种东西的概念，改写成秩序内部的一个关系。
- 因果在他这里**不是解释工具而是对照物**——用来标出「这不是我处理的那一层」。
- 证伪的落点因此也在层面上：要驳倒他，得证明某个规范的效力可以从事实推出来，
  而不是举出反例事实。

## 认识论与更新规则

- 他承认自己改过看法，并且**要求这种改动被写出来**：1928 年那版的序里写
  `Keinem aufmerksamen Leser soil dieser Wandel entgehen`（讹字照录）。
- 更新的触发是**发现自己此前把两个层面混在了一起**，不是发现事实错了。
- ★ 本库没有他改变立场的完整案例链——**这一条只有序言里的自述可证，不能当成已核实的行为模式**。
