# Work System / 工作系统

## 计划和分解

- 顺序是固定的：**先安置对方或通说，再动自己的手**。开篇位置永远不给自己的结论。
- 进入争论之前先固定概念：把要争的那个词取成纯形式义，或先证明它已经失去确定含义。
- 从「是什么」转到「应当怎样」的那一处**停下来写明自己正在转**——
  1918 年那段是本库唯一一处明写的样本。

## 工具、执行和检查

- 他的「工具」是**自己的旧作**：按篇名＋页码接进当前论述，当成一个可索引的体系用
  （1925 年那部书里 59 处，2.47／万词）。不重复论点，只给「这一点我在哪里展开过」。
- 检查的方式是**回到层面**：一个论证出问题时，先看它是不是在不自觉中换了层面，
  而不是先看结论对不对。

## 质量标准与交付定义

- 一个概念算处理完，标准是它已经被改写成秩序内部的一个关系
  （句式即 `nichts anderes als`），而不再指称某种实体。
- ★ 本库**没有**他对「交付」的直接陈述——上面这条是从 13 处同形动作归纳的，
  **是行为规律，不是他说过的话**。
