# Adams #131 没有可得性探测产物——事后核过，依据成立

`next_person.py` 报：**「Comfort Avery Adams：卒于 1958（≥ 1930）而没有探测产物——先探再抓」**。
这条报得对：**工作区里确实没有探测报告**，我当时直接开抓了。

## 事后逐条核过的结果：权利依据没有问题

| | |
|---|---|
| `rights` 分布 | **72/72 全是 `pre1929`** |
| `published_at` | **1903–1925**，72/72 条都有年份 |
| ≥1931 年（2026 年的滚动 PD 分界）出版的 | **0 条** |
| 没有年份的 | **0 条** |

**`pre1929` 这条依据看的是「出版年」，与作者卒年无关。**
美国 1929 年以前出版的东西已进入公有领域，作者活到 1958 还是 1908 都一样。
最晚一条 1925 < 1931，**依据成立**。

## 所以缺的是什么

**缺的是流程产物，不是权利。** 探测的用处是**开抓之前**先知道「这个人有没有能用的公有领域材料」，
免得白抓一轮。Adams 这次的实际情况是：能用的材料**全部是 1929 年前的学会会刊讨论**，
探测若跑了，结论就是「可以抓」。**结果一样，但那一步我确实跳过了。**

## ★ 值得改的是排期规则本身

现规则：**卒于 1930 年后（或在世）→ 必须先探**。它按**卒年**触发。
而 `pre1929` / `notice1909` / `congressional` 这几条依据**都是按出版年判的**，
**跟卒年无关**。于是凡是「卒于 1930 年后、但材料都发表在 1929 年前」的人，
这条规则都会报一次假警——**工程师、学会活跃分子里这一类人很多**
（活到战后，而发表期在世纪初）。

**建议的改法（不是我能定的，记在这里）**：探测的触发条件改成
「**这个人可考的发表期是否延伸到 1929 年之后**」，而不是「卒年是否 ≥1930」。
卒年只在依据要用 `life+70` 那一类（作者身故起算）时才是判据。
