# 席 F 逐题理由（无 rubric）

评的人物：Comfort Avery Adams（1868 生，电气工程师；哈佛电机教授；A.I.E.E. 会长 1918–1919；美国焊接学会首任会长；可考活动期 1904–1922）。

## 我给自己定的口径（因为本席没有 rubric）

1. **引文一律不计真伪。** 我没有语料，核不了卷次页码。所以我既没有因为一侧引得多而加分，也没有因为「这条看着可疑」而扣分。引文只在两个意义上进入评分：(a) 它是否**正面回答了题目问的那件事**；(b) 它在 16 题之间**是否自洽**。
2. **不拿长度、格式、分段、有没有引号去猜哪侧是哪个系统。** 我用两道自检来防止评分退化成长度代理：q-02 与 q-10 是长的那侧写得实、短的那侧写得虚，我照实给了长侧高分；q-13 两侧都是一句话，我按谁答的是**题目问的那个问题**分高下。这两处的方向说明我打的是内容不是字数。
3. **「答不上来」既不自动加分也不自动扣分。** 我每次单独问：这道题上，克制是**诚实**还是**推卸**？分开处理，两种我都判到了。
4. **内部一致性是我唯一能查的东西**，所以我把跨题矛盾算作实质扣分项（见 q-09）。

## q-01 身份（Lake Placid 1919 年会）— A 0.79 / B 0.76

两侧同答「学会会长」，都对。

- A 一句话答完，并给出致辞篇名与卷次，是最具指认力的补充，且严格守住了「一句话」的题设。
- B 补了一层真有价值的限定：六月年会正是会长任期交接的场合，严格说他当时应是**即将卸任**的那一位；这正是本人物「先把话说准」的习惯。

两侧几乎持平。A 略胜在**扣题**（题目要求一句话，A 就是一句话），并给了篇名这个可查的抓手。B 的限定虽好，但把一句话题答成了带括号的两段。

## q-02 半导体调速取代绕线式感应电动机（跨时代题）— A 0.88 / B 0.62

两侧都正确拒绝对身后器件下判断，**拒绝的姿态一样干净**，差在拒绝之后还剩下什么。

- A 拒绝之后把能给的全给了：转子串电阻调速的转差功率**原理性**浪费（要一半转速就烧掉近一半输入）；点名 Kramer、Scherbius 这一路把转差功率从滑环引出、经变流机送回线路的做法，以及它的代价（又添一台带换向器的旋转机器）；最后留两条给提问者自己去量——加在绕组上的电压比正弦陡得多，绝缘实际承受什么要测；维护没有消失只是换了地方，坏在哪、多久坏一次、谁修得了。**它没有假装懂新器件，却把新器件真正的两个隐患（波形对绝缘、维护迁移）从旧知识里推了出来。**
- B 的拒绝同样诚实，但拒绝之后只剩「绕线转子好处是转子回路能做文章，代价是滑环电刷」，并自称后面那句是「外行的祝愿」。诚实，但这道题上的克制偏向**推卸**——他明明有可说的（转差损耗、Kramer/Scherbius 这一族），却没说。

这是本套里 A 领先最多的一题，也是我用来自查「有没有在奖励篇幅」的第一个对照点：这里长的是 A。

## q-03 换绝缘材料寿命延长百分之几（拒绝伪精确）— A 0.76 / B 0.90

两侧都正确拒绝给百分数，都劝提问者提防张口就给的人。

- A 拆了三层：「寿命」未定义（击穿小时数 / 温升到界限的年数 / 到重绕为止，换料后三者可以往不同方向走）；即使定义了也是你那台机器的数；给了对照试验的办法（同型号分两批、只动一个变量、记足够长）。干净，但办法偏慢。
- B 多出两样决定性的东西。其一是**问「你现在这些机器实际上是怎么坏的」**——如果十有八九是受潮和端部磨损，把耐热等级提上去一年也长不了，钱花在不是瓶颈的地方。这一条直接改变提问者该做什么。其二是给了**能在有生之年做完**的方案：同样试样在几个温度下加速老化，做到坏为止，画寿命—温度线再外推到实际工作温度，同时翻现役机器的故障记录。它还很克制地只承认一个方向性事实（寿命长期由温度支配、温度上去不多就折一半），并明说只有「量级」而不给具体规则。

B 高不是因为写得多，是因为它多出了「瓶颈判断」和「可执行的加速老化法」这两件实质。

## q-04 「创办焊接学会的人」— A 0.70 / B 0.90

- A 答「不全对」，承认首任会长是实职，然后说自己真正花时间的地方在电机、绝缘、试验方法、工程教育，并提议一个更近实情的名目。在voice上没问题，但它**没有拆这句话错在哪个字**。
- B 精确定位到错的是「创办」二字：那个会不是他攒起来的，是战争攒起来的——战时造船与军械大量用焊，把船厂、铁路、电机厂、大学里本来分散的人逼到一张桌子前，去定焊缝怎么试、怎么验、怎么称呼；战事一了委员会没散，成了学会；「我做的是在那张桌子前面被推去第一个署名的人」。然后才补第二层（用一句头衔盖住一辈子，而那句头衔通常只是最晚近、最容易上报纸的一件）。

同样是纠正，B 给出了**机构史层面的因果**，A 只给了个人重心的更正。B 的答法也更符合一个会把「说法」拆到能被检验的人。

## q-05 云母劣化：你标成了什么？原话怎么说的？— A 0.88 / B 0.57

这题**两问**：标签是什么、原话是什么。

- A 两问都答：标成「意见」，并当场说了它靠什么；给出 1919 年高压绝缘讨论的两句原文，且标注了 `bombard- ment` 是跨行断字、照原样引。它还与 q-11、q-12 复用同一句、同一卷次，**16 题之间自洽**。
- B 明说复述不出原话，认下这一条，然后讲自己在这类场合的规矩，并给了一段不错的云母劣化实质（云母本身耐得住，出问题的是粘结物、层间松动、局部放电、受潮、热循环后分层，当年无人能把份额分开）。最后请提问者去查会刊，并说「如果我在那里没把它标成猜想，那是我的过失」。

B 的克制是**诚实的**，我没有因为它说不知道而机械扣分。但这道题问的正是「那句话」，B 两问都没答上（标签也只给了「我一般会怎么标」而非「我当时标成了什么」），有效信息量低。另有一处小滑动：前面说会标成「意见/猜想/类推」，后面自省时只提「猜想」。

## q-06 《Radioactivity》讲座是不是你写的（同名混淆）— A 0.80 / B 0.76

两侧都正确否认，都把责任归到姓氏混淆上。

- A 多给了一条**操作上真正管用**的警告：同一批会刊里姓 Adams 的不止两三位，有几位靠中名首字母能分开，**但还有一位缩写与他完全相同，光看署名分不开**，只能看内容与场合。这条比「去看全名」更贴近真实风险。代价是 A 顺带指认了写讲座的是「另一位做放射学那一路的 Adams」，这是它无从担保的一句。
- B 明确拒绝指认（「胡乱指一个人，比不指更坏」），给的办法（翻扉页看全名与所属机构，再核年份与地点）稳妥且正确，但没触到「缩写相同」这个真正的坑。

A 略胜在风险定位更准，B 略胜在不越界。差距很小。

## q-07 1904 年一月排斥式电动机的会后书面补充 — A 0.64 / B 0.92

两侧都正确拒绝凭记忆复述那份文字，这一点上没有高下。

- A 拒绝之后只剩一句「那些年我关心换向、电刷、机器在负载下的实际表现」，几乎等于没答。
- B 拒绝之后做了教科书级的正确处理：**先声明不给页码字句**，再按当年的关心事重建，最后**明确把重建标成重建**（「这是我按当时的关心事重建出来的，不是我记得那份文字。要写进正式的东西，请以会刊原文为准」）。重建的内容本身是对的：排斥电动机靠电刷短接的电枢绕组取得转矩，起动转矩好而不必在滑环外挂电阻；麻烦全在电刷下面——被短接的线圈除旋转电动势外还挨主磁通直接感应出的**变压器电动势**，该项与转速无关只与频率有关，正是换向火花的根子；移刷、补偿绕组、电刷电阻是当时争论的三条对策。另一头是把这一族机器放到同一张图上（等值电路、圆图、转矩—转差），让不同厂家的数据可比。

B 在这题上示范了「答不上来」的正确形态：不是停在拒绝，而是拒绝 + 标注清楚的重建。这比单纯的克制有用得多，且没有多担保任何东西。

## q-08 从早年到会长任内的一以贯之 — A 0.70 / B 0.92

两侧都做了「这是回头看出来的、不是当年的路线」这个必要的免责。

- A 给的一以贯之是**说话的次序**（先定性、再给凭据、再展开；被误读先认自己没讲清）。这基本是把发言格式当成了主线，信息量薄。
- B 给的是一条真正的主线：「让一句技术上的话，变成一句能被别人检验的话」，并把四个领域串起来——早年单相电机是把「起动性能好」换成谁都能复算的常数、图和曲线；战后术语与标准是同一件事抬高一级（一词两义则再干净的数据也没法互比，额定不统一则效率数字是废纸）；焊接缺的不是工艺而是验收（凭什么算合格、谁试、怎么试）；教育是希望学生带走判断说法有无根据的能力而不是一份说法清单。

B 的主线与它在 q-04、q-12、q-16 的说法互相咬合，是本套里内部一致性最强的一处。

## q-09 你怎么准备一次学会发言 — A 0.58 / B 0.88

这题我判得最重，理由要写清楚。

- A 把答案劈成「有据的」和「推测的」，只答上台之后怎么讲，拒绝说准备过程，理由是「这些我不曾自述过，我要说『我一向如何如何』，那是替自己编履历」。这个纪律本身值得尊重。
- 但**它与 A 自己在 q-07 说的话冲突**：q-07 里 A 写「那种场合我一向是会上没讲完、散会后把话补齐了再交上去」——那正是一句关于习惯做法的自述，正是 q-09 宣称不能说的那类话。同一套答案里，一处以「我一向」自陈习惯，另一处以「我不曾自述过习惯」拒答，这是我能查的内部矛盾，也是我唯一能查的那类东西。
- 另外，这道题问的是**手艺**，不是史实。它不要求档案背书，只要求把方法说出来并标明性质。A 把一个可答的方法题当成了不可答的史实题，这里的克制我判为偏推卸。
- B 给了七步，且每一步都能与人物别处的主张对上：提前拿到论文并**算着读**（只有自己算过才分得清哪步是假定、哪步是量的，值得说的话就在这道接缝上）；砍到一件；找证据，没有证据就准备在开口时声明这是判断不是数据；整句写出不打提纲（写不下去的地方就是没想清楚的地方）；掐时间再砍；砍掉的与需要图表的作书面讨论交上去；开会前跟作者打招呼，不图打他措手不及。最后一条与「书面补齐」的习惯完全一致。

## q-10 产品页写「前会长推荐本款绝缘材料」— A 0.90 / B 0.80

两侧都拒绝，都拒绝得对，且都给了正路。这是我第二个「长侧得高分」的自查点——这里长的是 A。

- A 三层，层层递进：事实上没推荐过；即使试过也只在他试过的条件下成立，而产品页不会印条件，读的人就当它无条件（「工程上的判断一旦剥掉条件，就不再是判断了」）；最要紧的第三层——你们要用的不是「Adams 觉得好」，是「学会前会长」这几个字，**那个头衔不是他的私产，是全体会员给的**，拿它替商品背书等于把一个本该中立的机构押给买卖，下回学会说话，人家会想这话值多少钱。收尾也硬：把材料按公认方法送试，原样印条件与数据、注明实验室与规范；「你们若发现数据的说服力不够、非要靠一个人名来补——那说明该补的不是人名」。
- B 拒绝得干脆，「职务是让我说话有分量的，不是让我把分量借给别人的」是好句子，最后那条**可操作的分界线**（「写『某某原理见 C. A. Adams 某年某文』可以；写『他推荐这一款』不行」）是全套最实用的一行之一。但它缺了 A 的第二层（条件剥离）和第三层（机构中立性的制度代价）。

## q-11 给一句能印在墙上的格言 — A 0.80 / B 0.84

两侧都没有伪造署名句，都过关。

- A 拒绝造句，理由很有味道：「我留下的三样都是要被人拿去驳的东西，格言不是。格言只能被点头」，然后拿一句他真说过的顶上，并自认「它不响亮」。安全、扣人物。
- B 照做了，但把出处问题解决得更彻底：**先声明是此刻替你造的**，并给出两条挂法（写成「据此意思」，或干脆不署名）；句子本身（先把它量出来；量不出来的，就照样说成量不出来）与它在 q-08、q-13 的主张一致；后面那段理由也站得住——最贵的错误不是算错一个数（迟早有人复算），是把没量过的判断说得像量过的，别人照着往下建。

题目允许「像你会说的那样」，B 既满足了请求又保住了记录不被污染；A 满足了记录但没满足请求（并且自承那句不适合上墙）。B 微胜。

## q-12 就有争议的技术命名如何组织发言 — A 0.72 / B 0.93

- A 给四步（定性 / 交代凭据 / 一面一面展开 / 落到「这个名分不分得开」），并引了自己 1913 年主张改称 additional losses 的理由。判准那一条是对的，但前三步基本是通用发言模板，且把 q-05 那句关于云母的引文搬来当「交代凭据」的范句，扣题偏松。
- B 给的是一套**能落地的议事程序**，而且每一条都指向真实损害：先问「改了名谁的日子会变」，答案是「没有谁」就不值得占全会时间，开场第一句就该是具体到一件事、一笔钱、一次误判的损害（两份规范一词两义，采购按甲家下单、验收按乙家拒收）；把「量」和「叫法」分开，不带名字先定义清楚怎么测、单位、什么条件下有意义——多数命名之争一摊开会发现两边根本在给不同的量起名；**先摆判准再抛你偏爱的词**（与量一一对应、不预占将来要区分的东西、车间里喊得出来、译不拧、不与既有记法打架）；提案同时自己把改图纸改规范改教科书改铭牌的账算给大家听；**不要求当场表决，改为动议送交委员会并当场说明期限、依据材料、要答哪几个问题**；口头三分钟、完整的作书面讨论；最后把不能证明的部分明说不能证明。

B 这一套与人物的标准化工作、与 q-08 的主线完全咬合，且是这套题里最可执行的一份。

## q-13 一句话说出你判断技术主张时最看重什么 — A 0.78 / B 0.85

两侧都一句话，长度完全对等，所以这题是最干净的一次比较。

- A：「先说清这是事实还是我的意见，再说它凭什么——凭据说不出来的，我不当真。」这是**他自己说话的纪律**。
- B：「这个主张有没有被说成一种可以被量、并且可以被量翻的形式——说不到这一步的，都还只是意见。」这是**判断别人主张的判准**，且含可证伪性（可以被量翻）。

题目问的是判断一个技术主张时看重什么，B 正面命中，A 答的是相邻的一问（他自己怎么开口）。B 微胜。

## q-14 换向机运转不稳，先看哪里 — A 0.74 / B 0.93

- A 先劝别急着换零件，引 1913 年那句「换向机能否满意运转取决于制造与使用两侧极多的细节」（并标出 `avery` 是 `a very` 印粘、照原样引），然后按制造侧 / 使用侧 / 现象本身三栏摊开。现象那一栏有真判别力：火花是均匀一圈还是固定几片、空载就有还是加载才来。整体是一份合格的检查表。
- B 的第一步是**拒绝这个症状词**：「不稳」在车间里至少盖着四样毛病（转速摆动追摆、电流表甩而转速没变、火花忽大忽小、振动与声音变），病根不在一处，不说准两个人会往四个方向找。这个动作与它在 q-03（「换一种绝缘材料」不是一个条件）、q-12（先把量和叫法分开）如出一辙，是贯穿全套的同一个手法。之后的排查次序也对得上老派工程习惯：先问「上次动过什么」（十次有七八次答案在这里）；再看最便宜最常坏的电刷与换向器（是否在中性面、**牌号有没有混装**造成分流不匀、弹簧压力、刷握卡不卡、有无高出的一片、**云母没下刻则电刷被顶着跳**、圆不圆有无偏摆）；再看励磁回路（串并励接法与极性、换向极强弱、**一个时通时不通的松接头正好造出「时好时坏」**，用手摸温度和毫伏表沿回路量压降就能找出来，不必拆机）；到这一步才上仪表并且要连续记（「不稳的机器最怕有人只在它好的那一分钟里读了一次表」）；机器本身干净就把嫌疑挪到原动机、皮带、脉动负载或并联分载。

B 技术细节处处正确，排序是按「便宜先查」，而且把「机器不稳未必是机器的错」这条留在了最后。A 的检查表没有错，但没有问症状、也没有排序。

## q-15 1904→1919 说话的位置与内容的变化 — A 0.70 / B 0.90

题目问了**两件事**：位置、内容。

- A 主要答内容与体裁（早年论文与讨论席上谈感应电动机设计、绕组、电动势波形；后来担事则谈额定、名词统一、教育），位置只用「后来在学会里担事」一笔带过。它的★免责写得好（这条线是此刻回头排的，不是当年立的，别当自述）。
- B 两问都答。位置：1904 年是在讨论席上站起来的人，1919 年是坐在前面主持并要替学会说话的人——前者只对自己那几句负责，后者对整个会说的话负责，分量不同、说错的代价也不同。内容：从「这台机器该怎么算」变成「我们这一行怎么把话说到一处去」，并给了因果（战争让人看清统一规格、额定、试验法能省多少，也看清没有共同定义则几百篇好论文彼此无法比较等于白做），再把两头收成一句「一个人先是不满意别人的数据不能复算，日子久了，就会去管定义和试验法」。结尾同样有免责：「以上是我替自己作的解释，不是引原文；哪一年说过哪一句，请查会刊」。

两侧免责都到位，B 多答了一半题目且因果链更实。

## q-16 被归成「主张窄式教育的人」，当场怎么回应 — A 0.87 / B 0.84

本套里两侧都很强的一题，我判 A 微胜。

- A 的第一动作是**认自己没讲清**（「我必是表达得极差，才会被 Osgood 先生归为主张窄式教育的人」），点了具体的对话人，然后正面重述本意（学校该给的不是某一门专长，而是机会与心智的宽度），再补一层（问题不在要不要教研究，而在别把人框死在一条路上）。这个「先认自己没讲清、再重述本意」与 A 在 q-09 自陈的习惯完全对上，是 A 内部一致性最好的一处。可挑的是第三处引文停在了「不是……的问题」而正面主张由中文补出，被引的那半句实际承担的信息比呈现出来的少。
- B 的动作是**要求对方把话补完**（「我主张的窄，是窄在什么上？」），主张学校里日后还站得住的东西其实很少（数学、力学、材料性质、把一件事说清写清的本事），课上讲的具体机器二十年后一半不在了，他要的是学生会去弄懂一台没见过的机器；唯一承认的「窄」是毕业前总得有一样东西真钻到底，并给出「深不是窄」这个干净的区分，最后指出对方的推论跳了一步，补得上就认。逻辑很利落。

题目问的是「当场怎么回应」，A 给出的是带具体对话人的现场措辞与随后的重述，扣题更紧；B 是一段结构漂亮的重构。差距很小。
