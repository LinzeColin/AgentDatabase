# Adams #131 补测：出戏门修好后新报 4 题，**对 +0.0375 没有影响**

## 起因

`check_persona_frame_break` 原先是**硬编码词表**（有「扫描件/OCR/语料」，
没有「照录/排印/跨行」），Sorby #133 撞出来之后补了词表，
并加了一条不靠词表的形状规则：

    [A-Za-z]{2,}-\s+[A-Za-z]{2,}     ← 扫描件行末断字，如 `bombard- ment`

全库回扫，**Adams 从 0 题变 4 题**（全库 4 → 11）。
Adams 是本项目**唯一诚实 delta 转正**的产物，所以要问一句：
**那个 +0.0375 是不是靠这 4 题堆出来的？**

## 四题分别是（都是「照原样引 + 当场解释这是排印/断字」）

| 题 | 命中 |
|---|---|
| `ca-capability-calibration-01` | `bombard- ment` 是跨行断字，照原样引 |
| `ca-known-01` | `e.m:f.` 是排印把 `e.m.f.` 的一个点排成了冒号 |
| `ca-long-horizon-01` | `pronuncia- tion` 是跨行断字 |
| `ca-planning-fidelity-01` | `hav- ing`、`sub- ject` 是跨行断字 |

## 拿第 3 轮的原始打分重算（四席，逐题按揭盲键归侧）

|  | 喂判据席 | **无 rubric 席** |
|---|---|---|
| **4 题出戏的** | +0.2712 | **+0.0387** |
| **其余 12 题** | +0.2992 | **+0.0371** |
| 全 16 题 | +0.2922 | **+0.0375** |

**两组在无 rubric 席上几乎一样（0.0387 vs 0.0371，差 0.0016）。**

## 结论

**出戏的 4 题没有给 delta 加分，也没有减分。** +0.0375 不是它们撑起来的——
去掉那 4 题，其余 12 题仍是 +0.0371。

★ 这是一个**阴性结果，而且是要的那种**：判据新抓到的缺陷是真的，
但它**不是**那个正数的来源。两件事各自成立，不许混为一谈。

★★ 顺带印证了一件事：Adams 报出去的 +0.0375 **本来就是无 rubric 席的数**
（喂判据席是 +0.2922，聚合四席是 +0.1648）。**报数口径此前就是诚实的那一档。**
