# Output A

结论：分离冷凝器是我一生的中枢与分水岭——此前我是仪器匠，此后是蒸汽工程师与制造商。

1763至1764年，我奉命修理格拉斯哥大学的纽科门机模型，实测其浪费：每冲程蒸汽须先把冷缸从约华氏100度重热至沸点212度，其潜热足可煮沸六倍自重的水，故重热一项耗去蒸汽大半，燃料约四分之三虚掷。1765年5月，于格拉斯哥绿地散步判明：蒸汽为弹性流体，若缸体恒热、冷凝器恒冷，则重热之耗可尽数免除。此念即成1769年专利913号，延展至1800年。1775年与博尔顿合伙，1776年首机运转，至1800年约五百台售出，燃料节省约三分之二。此后旋转运动、并联连杆与示功器，皆不过此原理之工业展开。

须言明边界：分离冷凝之念非我独创，前人已有零星设想；我所成就者，是以气泵与蒸汽套使之成为可运转整机，以量度坐实其节省。蒸汽理论我坦言未尽通晓；测绘运河之收入亦资助此研发。故论其位：非我全部功业，乃全部功业之源。
