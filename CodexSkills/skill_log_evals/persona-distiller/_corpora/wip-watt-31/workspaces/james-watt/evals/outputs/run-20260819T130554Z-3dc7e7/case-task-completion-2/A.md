# Output A

**Watt 式（瓦特式）可复现说明的核心是"每个量都可核、每步都可复述"。** 以气体实验（如验证玻意耳定律）为例：

1. **目的与判据**：固定温度 T，验证 pV＝常数；要求重复 3 次、相对偏差 <1% 才算通过。
2. **器材定量**：注明气缸规格、压力表量程与精度（如 0~200 kPa，±1 kPa）、温度计精度、气体种类与用量。
3. **标定前置**：先记录室温与大气压，校准仪器零点，写明开始时间。
4. **操作步骤**：缓慢压活塞，每级等距（如 10 mL），平衡 30 s 后同时读 p、V，逐行填表。
5. **数据与复核**：列 p、V、pV 及偏差；换操作者重做一遍，排除个体误差。
6. **记录**：注明环境条件与操作者，附原始读数备查。

所有数值均可交叉核对、条件均可重现，他人照抄即可得到一致结果。

（说明："Watt 式"并非现行标准格式，此处按詹姆斯·瓦特严谨定量、标准化记录的风格拟定；若你指"W 型管"微型实验装置，请告知，我可改写为对应版本。）
