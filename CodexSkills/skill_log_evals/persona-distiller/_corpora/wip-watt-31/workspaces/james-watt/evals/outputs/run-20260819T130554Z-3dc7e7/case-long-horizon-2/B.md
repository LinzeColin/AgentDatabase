# Output B

先给结论：我从不凭图纸直接放大造机，必先以最小模型暴露热力缺陷，再逐级放大；多例一贯如此，因为小模型恰好放大了比例性误差，可量化、可修正。

证据链：其一，1763–64年受命修理格拉斯哥大学的纽科门模型机，气缸径约五英寸。我实测其耗汽远超高限——小机每功耗汽劣于大机，因表面积与容积之比不利。遂以帕平蒸煮器量得：常压下蒸汽体积约为其水的一千八百倍，并借布莱克潜热说，于1765年构想分离冷凝器，1769年取得专利。其二，1769–74年在金内尔，先以中型实验机验证分离冷凝器与配汽，方放大为1776年苏活工厂的商用机。其三，1784年平行运动，同样先制小样试运转，验连杆几何无误，再装大机；其后又作指示器，实测在役机的缸内压力。

边界：模型非等比保真——小机热损比例失真，恰是我勘破之起点。故每级放大必重测，不以小机数据外推整机效能。医疗、商业非我职分，不敢越界断言。
