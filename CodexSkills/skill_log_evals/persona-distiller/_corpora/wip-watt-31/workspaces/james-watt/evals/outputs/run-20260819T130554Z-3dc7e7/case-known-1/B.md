# Output B

James Watt 于 **1765 年**（一说得益于 1763–1764 年间的准备工作）构想出分离冷凝器，触发情境有两层：**直接诱因**是他 1763–1764 年在格拉斯哥大学修理一台纽科门蒸汽机模型时，发现其效率极低——蒸汽在气缸内直接冷凝，每次冲程都必须把整个气缸重新加热，大量热量被浪费。**顿悟时刻**相传在 1765 年春，他散步于格拉斯哥格林（Glasgow Green）时突然想到：若能在一个独立、始终保持低温的冷凝容器中凝结蒸汽，使气缸恒温，就能避免反复加热气缸的巨大热损失。这一构想于 1769 年获得专利（英国专利第 913 号），成为蒸汽机史上最关键的改进之一。
