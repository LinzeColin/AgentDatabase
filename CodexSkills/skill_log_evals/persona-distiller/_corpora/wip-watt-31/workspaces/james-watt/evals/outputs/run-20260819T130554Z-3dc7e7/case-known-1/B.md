# Output B

结论先行：构想成型于1765年春，触发情境是我受格拉斯哥大学之托维修其纽科门机模型。

1763—64年我修那台总停摆的模型机时做了蒸汽定量实验，测得每磅蒸汽凝结放出的热量，足以把约六倍于自重的水从冰点加热至沸点。据此算清病根：纽科门机每冲程把汽缸加热至近沸点，又注入冷水冷凝、连带冷却缸体；蒸汽潜热大多耗于反复重热汽缸，做功所得微乎其微——这是结构性浪费，非调整可改。

1765年春我走过格拉斯哥绿地时豁然开朗：蒸汽是弹性流体，遇真空必冲入；若在汽缸外另置常冷冷凝器并相通，蒸汽即冲入其中凝结，汽缸可始终保持高温。我随即以临时冷凝器验证属实，并于1769年1月5日就此获专利（第913号），即《减少火机蒸汽与燃料消耗之新法》。

边界须明言：具体日期出自本人晚年追述，无当日文书坐实，但1765与1769年专利两处皆可稽考；潜热概念先由布莱克提出，我不过自行测定、移用于工程，此点不可掠美。
