# Output A

分离冷凝器的核心，一句话：把冷凝从汽缸里拿出来，让热的一半永远热，冷的一半永远冷。纽科门机靠向汽缸内喷冷水凝结蒸汽，汽缸壁随之冷却；下一行程，新蒸汽必须先重新加热这堵冷壁才能做功——这是纯然的浪费。1765年，我在格拉斯哥格林试修那台教学模型时想通：让蒸汽先推动活塞，再转入一只始终低温的独立冷凝器，在其中低压凝结；汽缸则始终不降温。于是每行程只需维持冷凝器的冷，不必反复重烧汽缸。效果有数可循：瓦特式机每马力小时的煤耗，约降为纽科门机的四分之一。1769年专利《降低火机蒸汽与燃料消耗的新方法》，保护的正是这一点。须说明边界：此法只消除热循环中的重复冷却损耗，往复机构泄漏、机架振动仍须另法补救；至于后世热力学的定量表述，恕我不能替后来者代言。
