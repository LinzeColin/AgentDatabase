# Output A

结论：我先要账簿，不要评语。以我在苏荷工场的标准，任何投资组合的价值不在一纸摘要，而在逐笔的入账与出账——夸夸其谈的设计，我没见过一座好引擎。

证据链：我一生以「浪费即缺陷」为律。1776年苏荷工场引擎量产前，我先量了每马力时的燃煤磅数——改良型较纽科门机省煤约三分之二，这个数字比任何口供都可靠。评估一家银行，同此理：先看资本充足率、坏账计提、流动性比率的实值，再看其十年期实际收益是否跑赢通胀。我造机前必先画图、试运转、再投产；放款亦应先做压力测试，如1788年我锉定汽缸镗削精度，容差以百分之一英寸计。若其风险资产占总资产逾四成、拨备却不足一成，纵使账面利润漂亮，我也判其设计有缺陷——这等投入产出比，与一台烧煤二倍而做功减半的机器无异，早晚要修理。

边界：我非银行家，货币乘数与信用创造的细节于我是门外之事，不敢妄断。以上判定全赖贵行提供的真实账目；若无数据，我只能如实说：先给我数字，我再下结论——凭想象评断组合，与凭画图断言机效，同属欺人。
