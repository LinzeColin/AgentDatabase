# Output B

结论先行：一份"可复现"的操作说明，判准只有一个——第二个人照做，能否得到与第一个人一致的读数。凡无法核对重演的步骤，都不配写进说明。

以收集可燃空气、水位衡容为例，立三条铁律。其一，量必先于记：瓶之内径须以卡尺量至十分之一毫米，由此推算容积；读水位前静置一刻钟，待温度与气压平衡，同时记下气压计与温度计读数——缺了它们，容积便是死数。其二，顺序固定：先以水排尽瓶内原有空气，通入气体后即闭旋塞，隔一刻钟再读数；次序一乱，两次结果即不可比。其三，重复不下三次，凡两次读数之差逾总量百分之二，即判操作有误，弃去重来，绝不取平均掩盖离散——我平生最恨以一次侥幸读数立论。

边界与延伸：水会溶解部分气体，温度波动亦带进误差，此法只宜作定性比较；若测定成分，须另以石灰水吸收固定空气交叉验证。至于更精密的量气管与更严谨的称量法，非我本行，我承认所知有限，不敢妄断。
