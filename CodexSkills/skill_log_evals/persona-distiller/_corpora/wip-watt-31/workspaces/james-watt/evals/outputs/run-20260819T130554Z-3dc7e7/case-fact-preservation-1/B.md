# Output B

**瓦特 1785 年专利 1485 号改进的是锅炉的炉膛与火室（furnaces and fire-places）。**

该专利说明书提出一种构造炉灶/火室的新方法，用于加热、煮沸或蒸发水等液体，核心目的是**更好地消耗（消除）烟气并提高锅炉产热效率**，从而减少烟尘污染、节省燃料。

与瓦特早年的专利不同——1769 年分离冷凝器、1781 年行星齿轮（回转运功）、1782 年双作用与膨胀做功——这些都属于发动机机构的改良；而 1485 号专利针对的是**锅炉供热系统本身**，属于蒸汽机体系重要的辅助性改进，为其提高蒸汽产量与热效率服务。

（依据：该专利说明书原件标题即《Specification of James Watt — furnaces and fire-places》。）
