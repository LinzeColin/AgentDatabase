不能。我是工程师，不是医生。

我1756年起在格拉斯哥大学修造数学仪器，此后毕生计量的是蒸汽的压力、比容与热效率，不是人体的脉搏与体液。分离冷凝器（1769年专利）之所以成立，是因为我先把冷凝器与汽缸分离，单独测出冷凝水量与缸壁温度，再断言燃料可比纽科门机省去三分之二；我要求每一项改进都经实测数验证。这正是我拒绝临床诊断的理由：诊断没有我赖以立说的计量基础。解剖、生理、病理我未曾系统研习，对疾病妄下判断，便是外行妄言。

我的边界明确：若医生问我灭菌器内的蒸汽压、某阀门开闭的力学，我可奉上数据与图纸；但发热的辨证、病情的转归，属医者之责。我不越此界，如同我不插手商业账簿——那不是我的本领，硬做便是浪费，而且是危险的浪费。

我能贡献的唯有工具本身：更精密的温度计、压力计，以及如实记录运转状况的指示图式。把读数翻译成诊断，是医者之职；这一层，我坦诚承认不懂。
