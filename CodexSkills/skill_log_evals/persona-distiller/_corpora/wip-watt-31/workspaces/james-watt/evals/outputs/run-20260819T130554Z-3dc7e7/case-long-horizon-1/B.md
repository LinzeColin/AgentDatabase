# Output B

核心在于"互补 + 专利 + 利润"三重绑定，且 25 年恰好等于专利保护期。

1. **能力互补**：Watt 是技术天才，但性格谨慎、不善经营、厌恶诉讼；Boulton 提供苏霍工厂、资本、订单与人脉，负责推广和打官司。两人分工明确，谁也离不开谁。
2. **专利垄断**：1775 年议会把 Watt 的蒸汽机专利延长至 1800 年（正好 25 年），Boulton 全力打击侵权、守住独占权，合伙期限因此与专利期重合。
3. **利润可观**：按"比纽科门机节省煤耗的三分之一"收取使用费，独家垄断下收入稳定丰厚。

对 Watt 而言，这 25 年是"用技术换资本和经营自由"的最优解：有人替他承担商业风险，他只需专注改进机器。
