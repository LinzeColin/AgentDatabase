# Output B

不是我想"只做"，而是算清的账。1775 年议会法案把分离冷凝器专利延至 1800 年，锁定 25 年垄断窗口——这纸专利就是最确定的生产资料，资本与精力自然都投在这里。

证据链：1769 年我取得分离冷凝器专利；1775 年法案延护至 1800，当年与 Boulton 缔约，他买下 Roebuck 的股份，出资本、出 Soho 工场，我出技术。计费按"节煤三分一"：同等功率下比 Newcomen 机少烧的煤钱，三分之一归我们，是可复利的经常性收入，而非一锤子买卖。1776 年 Bloomfield 首台商转，此后逐台改进——1781 行星齿轮、1782 复动、1784 平行运动、1788 离心调速器，至 1800 年约五百台在役。Boulton 常催我"卖全世界都想要的东西——动力"，逼我别因完美而误投产。

边界：25 年不是志向，是专利法定的终止日。我承认不善经营、厌诉讼，若无 Boulton 的资本与手腕，成不了这规模；期满合伙即散，正说明我们算的是法律期限内的账。
