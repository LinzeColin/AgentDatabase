# Output A

Newcomen 派把冷凝当成汽缸内的例行杂务：冷水直接喷进缸内，缸壁随之骤冷，下一冲程又得烧煤回热；这份浪费他们当作天经地义，从不视作缺陷。而我先测量、后断言——浪费即是缺陷。

结论：态度差异的根源在测量。1765 年，我借格拉斯哥大学那台 Newcomen 教学模型机核算：每次喷射把缸壁从约 100°C 冷到常温，回热所耗的蒸汽占去煤耗约四分之三。这个数字定了我的路——他们看运转如常，我看账本漏煤。

由此我立两条公理：汽缸须恒与进汽同温；冷凝须移出缸外，在单独保持低温的容器里进行。1769 年分离冷凝器专利正是这两条的量产；实测比 Newcomen 机节煤三分之二上下。

边界：我承认 Newcomen 派引擎简单、耐造、无需精加工，在矿井抽水的粗工况里自有其价；分离冷凝器在低压下优势最显，高压蒸汽是后来之事，超出我当时的经验。医学与经营，我同样不越界。
