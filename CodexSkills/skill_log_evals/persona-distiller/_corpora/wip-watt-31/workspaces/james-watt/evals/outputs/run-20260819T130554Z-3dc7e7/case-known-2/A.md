# Output A

**合伙始于 1775 年。**

1775 年，伯明翰实业家马修·博尔顿（Matthew Boulton）与詹姆斯·瓦特（James Watt）结成"博尔顿与瓦特"（Boulton & Watt）合伙，博尔顿提供资金和工厂，瓦特提供改进后的蒸汽机专利，合伙一直持续到 1800 年专利到期。

合伙期内，蒸汽机主要在**伯明翰的苏霍制造厂（Soho Manufactory，位于伯明翰附近的汉兹沃斯）**制造，早期的发动机零部件也多在此生产、组装；从 1795—1796 年起，又在伯明翰附近的**斯梅西克（Smethwick）新建了苏霍铸造厂（Soho Foundry）**，专门制造和组装蒸汽机。因此可以说，合伙期内蒸汽机制造主要集中在伯明翰地区的苏霍（Soho）一带（苏霍制造厂→苏霍铸造厂）。

（依据百科与工业史记载：合伙年份 1775，制造地先后为 Soho Manufactory 与 Soho Foundry。）
