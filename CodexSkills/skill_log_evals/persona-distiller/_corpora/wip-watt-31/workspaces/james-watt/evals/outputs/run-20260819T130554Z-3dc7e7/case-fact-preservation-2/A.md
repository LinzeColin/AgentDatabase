# Output A

詹姆斯·瓦特（James Watt）晚年与英国医师托马斯·贝多斯（Thomas Beddoes）合作研究人工气体（当时称"factitious airs"，人造气体）的医疗用途。1780 年代末起，两人合作开展"气体医学"（pneumatic medicine）研究，测制多种气体的吸入疗法，共同撰写了多卷本《关于人造气体医疗用途的思考》（*Considerations on the Medicinal Use of Factitious Airs*，1794–1796）。1799 年，贝多斯在布里斯托尔创办"气体医学研究所"（Pneumatic Institution），瓦特提供仪器与经费支持，其子格雷戈里·瓦特（Gregory Watt）也参与实验。该研究后来对发现笑气（一氧化二氮）的麻醉作用起到了推动作用。
