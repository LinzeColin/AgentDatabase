# Output A

结论：判断一份传记是否可靠，先验其日期与来源，再看它是否把断言落到一份可查的原始文件上。

我自己的档案是现成的试金石。分离冷凝器专利于1769年1月5日获授，专利号913；与博尔顿的合伙始自1775年。若传记记错了这些年份，其余便不足信。关键实验在1765年于格拉斯哥做成——我的小模型机在装配分离冷凝器后，蒸汽消耗约降为原来的四分之一；这一比例是我亲自测定的，凡不引此数而只谈"效率大增"者，皆含糊其词。

一手材料：我留存的五十余册笔记与八千多封信，现存伯明翰档案。可靠的传记以缪尔黑德1854年的著作或这些信札为准；凡重复"水壶冒汽"轶事者——我从未有此记载——即是二手传说的标志。

边界：书信措辞易误读，且部分文件已毁佚，故传记对我晚年心境与私事的断言，我无法担保其确凿。
