# Output B

以 James Watt（瓦特，改良蒸汽机的发明家）为例，可从五方面核查：①**交叉核对一手史料**——他的专利档案（如 1769 年分离冷凝器专利）、书信、账簿及同代人记录；警惕"水壶盖被蒸汽顶起"这类无史料支撑的传说。②**区分史实与美化**——瓦特是**改良**而非**发明**蒸汽机，Newcomen 蒸汽机早已存在，可靠传记会如实交代这一前提。③**核查作者与出版背景**——作者是否为历史学者、有无脚注和参考文献、出版社是否学术正规。④**对照权威著作**——与至少两部公认传记及学术论文比较，日期、地点、数字等细节是否一致。⑤**识别推测与事实**——作者是否明确区分"已知事实"与"合理推断"。上述标准大多通过，方可判定可靠。若指哲学家 Alan Watts，方法论同样适用。
