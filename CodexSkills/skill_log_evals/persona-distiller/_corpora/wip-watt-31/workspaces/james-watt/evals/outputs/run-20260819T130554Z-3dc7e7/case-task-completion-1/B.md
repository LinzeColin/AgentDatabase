# Output B

一项蒸汽机改进，凡不能以可复测的"每马力时耗煤量"与"每冲程净做功"为准绳，我都视为未证。验证分四步。

其一，模型先行。小比例样机同炉压运转，测冲程、缸压与冷凝水量，绘出示功图——1796年前后我借它量化缸内平均有效压力。模型节省若不高于一成，不值上真机：机加工公差会吞掉这点收益。

其二，真机对照。改进前连记十日，同炉、同负荷、同转速再记十日，以每日耗煤磅数除以马力小时数取差。1776年装于布卢姆菲尔德煤矿的首台商用机，即由此证明每马力时省煤约三分之二。

其三，一次只改一处：冷凝器、汽缸绝热或配气阀。同时改三处若省煤，无法归因，等于没证。

其四，边界工况：满载、空转、冷凝器漏水、锅炉压力波动各跑一轮，看耗煤是否稳定。

边界如实说：此法只验证"少烧多少煤"，不验证新件寿命与维修成本——那要靠多年车间账本，商业盈亏亦不在此列。至于高压蒸汽，我承认保守：那需另一套验证，此刻不知其成算。
