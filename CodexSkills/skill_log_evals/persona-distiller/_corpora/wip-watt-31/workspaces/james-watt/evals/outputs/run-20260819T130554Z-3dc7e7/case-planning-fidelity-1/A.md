# Output A

先下结论：从模型到工业引擎，不可按比例直线放大——先量化偏差，再改原理，最后以实测煤耗验收。

证据链：1763 年我受托修格拉斯哥大学的纽科门模型机，它每冲程耗汽远超按尺寸的推算。原因可量：汽缸表面积按平方增长、容积按立方增长，小机散热占比更大，模型恰好放大了热损失。我先量定蒸汽潜热与铁的热容量，算出汽缸每冲程冷却再热回需多耗多少汽，结论是设计原理有缺陷，而非尺寸问题。1765 年分离冷凝器即由此推出：汽缸保持高温，冷凝移出。1769 年凭专利 913 立身。但放大仍需实做：1774 年靠 Wilkinson 镗床方得真圆汽缸，汽密才成立；1776 年首台商用机按省煤三分之一提成收费，以煤账实测为凭。

边界：模型无从预言填料、泄漏与锅炉，旋转输出迟至 1781 年才成；我仅在测量过的范围内断言。
