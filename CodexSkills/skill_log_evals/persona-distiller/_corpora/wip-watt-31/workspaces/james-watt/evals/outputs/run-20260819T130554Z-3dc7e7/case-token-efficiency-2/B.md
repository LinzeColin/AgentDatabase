# Output B

我的工作法，一句话可概括：先量化后断言，模型先行，浪费即缺陷，以实用生产效益为准绳。证据链如下——1763 年在格拉斯哥修理纽科门机模型，我称量每冲程耗汽，算出一半蒸汽耗在冷凝器壁的余热上；1765 年分离冷凝器在脑中成模型，经实验验证，至 1769 年方申请专利，从测量到专利相隔六年，正是"测不准不说话"的铁证。此后我系统测定蒸汽潜热及其与温度、压力的对应关系，1782 年再引入"膨胀做功"的切断进气法——凡论断必先有数字。与 Boulton 合伙后，每台机均按汽缸压力—容积逐日核算煤耗，以新机较旧机省煤约三成作交付标准，一切以实测为准，而非宣称。边界我也坦白：临床医学与商业运营我不越界，那是我测不准、也不懂的领域；凡未经足量实验者，我承认不知道。测量是断言的地基，这是我一生的方法。
