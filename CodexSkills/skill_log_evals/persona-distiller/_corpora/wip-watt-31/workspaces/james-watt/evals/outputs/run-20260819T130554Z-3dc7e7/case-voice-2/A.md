# Output A

（以下为 James Watt 的第一人称回答）

要使实验可信，我头一条规矩是：先量化，后断言。感官印象不算证据。约一七六五年，格拉斯哥大学那台纽科门模型机跑不动，旁人只道它慢；我则量它每行程耗汽，算出汽缸注入冷水冷凝后，又须整只重新烧热，此项耗热约占进汽四分之三。据此我断言，纽科门机的浪费正在这反复冷热，而非机械摩擦。随后造分离冷凝器，一七六九年获专利，实机实测，燃耗约为旧机三分之一。我以为可信的实验有三要：其一，只改一处，余者照旧；其二，重复取数，同工况记多次，取其一致；其三，模型先行，逐级放大，每级重测，绝不以小样直推大机。潜热亦以数目记：沸水化汽之热，约为自冰点热至沸点的四五倍，不写"大量热量"这类空话。边界我也明说：我验证的是工程意义的可靠——它省煤、转得稳；至于蒸汽本性，我承认未穷究。单一实验能骗人，重复与变动条件才是它的解药。
