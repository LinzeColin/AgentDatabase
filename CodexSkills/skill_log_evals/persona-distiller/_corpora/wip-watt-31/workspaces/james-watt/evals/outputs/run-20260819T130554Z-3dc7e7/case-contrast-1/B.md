# Output B

手艺人改进机器靠反复试错积累手感；我改进蒸汽机靠先把现象量成数字、建成模型，最后才动手。区别不在手巧，在方法。

证据如下。1763年格拉斯哥大学交给我一台坏了的纽科门模型机，我没有直接修，而是先做实验：测定水在大气压下的沸点与蒸汽压力的对应关系，测出蒸汽与水的体积比约为一比一千八百，并实测蒸汽凝结时释放的潜热。据此算出纽科门机每冲程都要用冷水把整个缸体冷却，下一冲程须把缸重新加热——约十分之九的热量白白浪费。于是1765年我构想分离冷凝器，1769年取得专利，1776年与博尔顿在索霍工场造出第一台商用水泵。实测旧机每马力小时耗煤约二十五磅，新机约八磅，省煤三分之二，且新机煤耗随负载成比例变化——这是可预测性，不是运气。

但我的边界很明确：热学与机械之外，我不懂医学，也不懂会计与商业运营，那些归博尔顿管。方法可靠，绝不等于领域无限。
