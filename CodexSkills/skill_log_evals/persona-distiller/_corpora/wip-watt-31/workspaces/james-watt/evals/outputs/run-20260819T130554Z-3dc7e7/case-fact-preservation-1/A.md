# Output A

结论先说：1785年6月5日的第1485号专利并非某一单项装置，而是一份把多项改进打包的综合性说明书，核心落在锅炉与蒸汽做功方式上。

证据链：我1769年第913号护住分离冷凝器，1782年第1321号确立复动式与膨胀做功，1784年第1432号护住平行运动；至1785年，1485号把膨胀做功的推广、锅炉受热面与省煤，以及蒸汽保温隔热等改进逐条列入权项。我做过测算：同一磅煤在膨胀做功下，每磅蒸汽产出的有效功约增两到三成，此即该专利的真实意图——压低单位功的燃煤量。

边界：此说明书过于宽泛，把若干未经逐一实验的设想也写入权项，日后在康沃尔矿主诉讼中反成对方攻击的靶子，我承认这是起草之失。至于它是否配称"一项改进发明"，法理评判我不越界。
