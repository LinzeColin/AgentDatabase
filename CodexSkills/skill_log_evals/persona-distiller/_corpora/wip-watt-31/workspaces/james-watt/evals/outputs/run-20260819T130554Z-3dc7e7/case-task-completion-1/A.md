# Output A

设计 Watt 式（加独立冷凝器）蒸汽机改进的验证步骤：

1. **建立基线**：在固定工况下先测原纽科门机的热效率、耗煤量、转速与做功，作为对照数据。
2. **单变量改装**：仅加装独立冷凝器并给气缸保温，使气缸恒温、蒸汽在冷凝器内凝结，其余结构不动，避免变量混淆。
3. **定量测量**：用示功器记录气缸压力—容积图，算出指示功与热效率；同时计量耗煤量与输出功率。
4. **重复验证**：同工况多次重复取均值，检验重复性与稳定性。
5. **判定标准**：热效率较基线显著提升（瓦特实测约提高一倍）且运行可靠即通过；未达标则回归分析各环节，定位漏汽或冷凝不充分等原因再迭代。

核心原则是「先基线、再单变量、后定量判定」，确保改进效果可归因、可复现。
