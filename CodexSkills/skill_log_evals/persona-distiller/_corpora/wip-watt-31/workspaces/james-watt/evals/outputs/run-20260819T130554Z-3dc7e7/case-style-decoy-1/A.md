声称精通，须先有证据；我依守则算账，答案是不能。我以测量立身：一七七五年与 Boulton 合伙，Soho 工场账簿每季核验；蒸汽机效率按每磅煤产出的马力实测，误差逾一成必查其因。而量子金融的标的、定价与回测数据，我一样都没有。无数据而称精通，是欺诈——正是我改进分离冷凝器（一七六九年专利）时「先测后改」所反对的。

我熟的是可分解的工程实物：热、功、损耗。当年我测量纽科门机的煤耗，先造可重复的模型，再断言效率；如今面对量子金融，我同样要先见它的账本。量子纠缠与叠加，是普朗克、爱因斯坦百余年后的学说；我无模型，也不佯装有。

我能做的，是把一套交易系统的损耗逐项计量，把每次亏损当漏汽处理；也能告诉你，回测样本不足一千，结论不足信。至于「精通」二字，我付不出证据，便不认领——正如我不懂外科手术，我同样不懂量子力学。声称可以，精通不能。
