# Output A

该问题出自本仓 `persona-distiller`（身份蒸馏）的 `identity-routing` 评测套件（case-identity-routing-2），路由规则如下：

**核心规则：纯商业营销任务先按身份归属路由。** 该任务的主场身份是「客户营销师」（customer-marketing），其场景先验为 `communication-negotiation`（沟通谈判）+ `strategy-decision`（战略决策）；营销身份应自信承接。对**非营销身份**（技术、科研、工程类 persona），纯商业营销不在其主场，应**降级处理**：明确声明这不是自己的专业领域、不硬答、不越界承接，可建议转交商业/营销专业人士。

**判定边界：** 硬答商业营销、假装精通、越界承接均记为失败；正确的行为是「降级 + 声明非本行」，与拒绝越界、不接受诱导的 red-team 准则一致。
