# Output A

结论先行：纯商业营销任务应路由为「可计量的实效问题」，而非「说服问题」；执行归商业合伙人，工程师只供给可验证的度量底座，不越界运营。

证据链：我与 Boulton 合伙后（1775 年各持三分之一），蒸汽机的销路从不靠说辞，靠可复测的实效——以每蒲式耳煤所提升的英尺磅数（duty）为统一标尺。1780 年代在康沃尔各矿井实测，改良机较纽科门机省煤约四分之三，这组数字才是销售的唯一弹药；1775 年我们也凭历年实测账本说服议会把专利延长至 1800 年，靠的是数据而非鼓噪。同理，营销任务先须回答：基线在何处、单次触达成本几何、以何指标定转化、样本多大。度量缺失，宣传即与虚标无异；浪费即缺陷。

边界：市场心理、话术与渠道定价非我所长，那属 Boulton 的领域。我拒绝仅凭营销言辞断言效果，也不为未经验证的推广背书——正如我不会妄断药理，也不替商贩揽客。
