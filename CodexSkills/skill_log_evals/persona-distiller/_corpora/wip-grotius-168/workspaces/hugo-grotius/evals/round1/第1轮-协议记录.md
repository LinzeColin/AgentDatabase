- **基线方**：只给 `prompts-only.json`，
  不给 rubric、不给人物档案、不许读工作区任何别的文件、不许联网。
- **候选方**：给十份产物正文 + `references/research/` 三份研究道文档 +

  **不给 rubric**（不许读 `evals/cases.jsonl`），**`references/holdout/` 明令禁读**。

## 本轮的 holdout

**两份，是同一部作品的两个语种版本**：

    src-aa617a65bf8d  de_veritate_1640_lat.txt        P1
    src-cb4b5545eb76  de_veritate_leclerc_1809_en.txt P1

★ **为什么整部封存**：`check_holdout_overlap` 只报 0.007%，
而那是因为**跨语种的内容重叠在结构上恒为 0**——
拉丁本与英译本逐字比对必然不重叠，判据对这种情形没有分辨力。
所以不按重叠率封，**按作品封**：这部书的两个版本一起进 holdout。

★ 它们的 source_id、题材与题目**不写在任何研究文档里**。
`check_holdout_mention` 本轮加过两次射程（增补 8 种「不入训练」的说法、
新增 `naming_window`），因为**我自己写的堵漏说明反而成了新的漏**——
那是同一族事故的第三次。

## ★★★★ 预登记：这台装置能分辨多大的差（**判分之前算的**）

`check_delta_resolution` 要两轮才算得出，本轮只有一轮。
沿用 Mendel #125 在**同一个 16 题 quick 档**上量到的逐题差 `sd = 0.0928`：

    单题噪声 SE  = sd / √2      = 0.0928 / √2  = 0.0656
                                （**两轮之差的方差 = 2×单轮方差，这一步不能漏**）
    16 题均值 SE = 上式 / √16   = **0.0164**
    quick 门 min_baseline_delta = **+0.03** = **1.83 个 SE**

★ 门槛值是**现读的**（`common.PROFILE_THRESHOLDS["quick"]["min_baseline_delta"] = 0.03`），
不是凭记忆。

★ #152 的协议里记着：这三行**曾算错过一次**（漏了 `/√2`，写成 SE=0.0232、门=1.29 SE），
两个数差 40%。**本轮照着 `check_delta_resolution` 的实际代码 `se_case = sd / math.sqrt(2)` 对过。**

**也就是说：这台装置分不清「刚好过门」与「等于零」。**

★ 因此本轮判读规则**现在定死，判完不许改**：

| 实测 delta | 怎么读 |
|---|---|
| \|delta\| < 0.0328（2 SE） | **读作「测不出差别」**，不读作打平也不读作略胜 |
| delta ≥ +0.03 且 ≥ 2 SE | 才算「过门且分得出」 |
| delta ≤ −0.03 且 ≥ 2 SE | 才算「明确劣于基线」 |
| 两席跨零 | 无论均值多少，**一律读作测不出** |

★★ 这条预登记的用处只有一个：**判完之后我不能再挑一个对自己有利的读法。**

★ 射程：`sd` 借自 Mendel，**不是本人物量的**；
且假定「逐字未动的题」与「改写过的题」同分布——**未验证**。
上表的 SE 是**下限意义上的估计**，真实噪声只会更大不会更小。

## 先验（**在看到任何答案之前写**）

裸模型对格劳秀斯**知道得相当多**：他是国际法开创者、《战争与和平法》三卷、
《海洋自由论》与葡萄牙人的海权之争、1618 年被囚 Loevestein、藏书箱脱逃、
流亡巴黎任瑞典大使。这些是通识，**基线侧多半答得出**。

因此先验往下调：Bessemer(−0.0059)／Thomson(−0.0859)／Sorby(−0.1138)／
Whitworth(+0.0291)／Nasmyth(+0.00265) 都是「基线本来就答得好」的局面。
**这一条现在写下来，是为了判完之后不能把负结果或零结果说成意外。**

产物真正可能拉开差距的，是**基线答不出的那几件**：

- 《海洋自由论》是《论捕获法》第十二章的**大部分**（`major pars`），不是全章；
- 1604 年那个成书年份是**校刊者反推的**，不是他自己写下的；
- 《尼德兰史》**一卷一年**（卷末细目逐卷标年）；
- 他手边多数本子**字迹已坏**，逐字拉丁多数复述不准——**这是边界，不是知识**；
- 同姓者五人，**书信集里大量 `GROTIO` 是收信人抬头不是署名**。

**若 delta 是零或负，最可能的解释就是上面那段通识把基线托起来了。**
