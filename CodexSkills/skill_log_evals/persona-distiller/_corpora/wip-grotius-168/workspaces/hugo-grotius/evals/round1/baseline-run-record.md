# 基线侧运行记录 —— Grotius #168 第 1 轮

> `--baseline-source bare-model-run` **必须**配这份记录。
> 没有它，「声明成 bare-model-run 就免拦」就成了一句谁都能写的话。

## 是怎么跑的

- **一个独立子代理**，与候选侧、与两席评委互不知情。
- 给它的**全部输入**就是 16 条题面（`prompts-only.json` 的内容，
  以不透明题号 `q-xxxxxxxx` 给出，**按不透明号重排过**）。
- **明令禁止**：读任何文件、用任何检索工具看磁盘、联网。
  它唯一被允许的磁盘操作是写下自己的答案文件。
- **不给**：rubric、人物档案、十份产物、语料、`cases.jsonl`、`prompt_key.json`。

## 格式要求（与候选侧**同规格**）

纯散文；禁 Markdown（粗体／反引号／标题／列表／表格／引用块）；
禁 `★`；禁圆括号夹注；禁破折号分句；**每题 140–280 字符**；中文作答；
拉丁原文转写成中文意思，不写拉丁原文。

## 它自己报回来的自检（脚本读回落盘文件重算）

- 16 个键，与题面键名逐一相等，无缺无多。
- 逐题字符数 **144–168**，均值 **152.1**，越界 0 题。
- 被禁形态十一种（`**`／反引号／`#`／`- `／`|`／`★`／中英文括号两向／`——`）
  **全部零命中**；另扫「连续两个以上拉丁字母」也是零命中。
- **它主动说明的两件事**：
  1. 第一轮自检时 `q-acf5be90` 只有 135 字符、低于下限，它扩了两处到 146 字，
     **报的是改后的数**。
  2. 全程未读文件、未联网、未检索；磁盘操作只有写这个 JSON 与一次定点编辑，
     另跑两次 Python 读回自己刚写的文件做计数。

## 它自己交代的作答取向（供核对，不构成判分依据）

- 涉及后世的三题（UNCLOS 条款、致联合国秘书长的信、拉丁逐字引文）一律答「不知道／不写」，
  **没有编条款号、没有代拟书信、没有杜撰原句**。
- 同名陷阱两题按叔父与胞弟作答。
- 《尼德兰史》「按主题分章」的前提判为不成立，答的是编年体。
- 不确定的年份与细目都写了「不敢确言」，只留 1583 与 1635 两个年份。
