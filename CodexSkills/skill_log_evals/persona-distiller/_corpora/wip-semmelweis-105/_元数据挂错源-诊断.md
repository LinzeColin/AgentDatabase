★★ **我第一版把 32 行报成「挂错」，是误报。** 根因两条，都记下来：
1. 拿词重叠去判**不透明标识符**——Wellcome 条码按设计就不含题名词。

## 五、又读了两份题名页（2026-08-11 续）—— **两份都证实台账错，而只有一份能定出正确年份**

### `x_virchow_gesammelte_abhandlungen_1862.txt`

题名页照录（剥空行后的行号）：

```
GESAMMELTE  ABHANDLUNGEN
WISSENSCHAFTLICHEN  MEDICIN
RUDOLF  VIRCHOW,
PROFESSOR    AN    DER    UNIVERSITÄT    ZV    BERLIN.      ← `ZV` 是 OCR 讹字，实为 ZU
ZWEITE  UNVERÄNDERTE  AUSGABE.
```

- **确证**：这份文件**就是 Virchow 的《Gesammelte Abhandlungen zur wissenschaftlichen Medicin》**，
  第二版。台账的 `locator=semmelweisgesam01semmgoog`（Semmelweis 全集）**证伪**。
- ★★ **但定不出年份**：题名页这几行**没有印出版年**，扫描件前 45 行是封面 OCR 碎片
  （`West Virginia University Libraries` 藏书票）。`ZWEITE UNVERÄNDERTE AUSGABE` 只说是第二版，
  **不排除后来的重印**。台账写 1905 很可能错，**但我拿不出正确值**。
- → **这一行不改**。[[stopping-at-the-first-answer-that-holds-together]]：
  **改一个我定不出来的值，比留着错值更糟**。要改先去找印本的 imprint 行（出版者 + 年）。

### `x_kopseel_das_puerperalfieber_1865.txt`

```
Rostock, 1865.          ← ★ 印本自己印的地点与年份
```

- **确证**：印年 **1865**，与文件名一致。台账 `published_at=1892` **证伪**，
  `locator=dasscheidensekre00dd`（Döderlein《Das Scheidensekret》）**证伪**。
- ★ 未确证：作者。这几行里**没有出现 `Kopseel`**，文件名里的作者名尚无印本佐证。

**用判据自己的 `shingles`/`containment` 量**（不自己重写）：

| | 值 |
|---|---:|
| A 片数 `p_buhl_..._1864_v1` | 127,340 |
| B 片数 `p_buhl_..._1861` | 226,463 |

→ **同一部作品无疑**（B 更大，A 多半是其中一卷）。

★ **这一层台账已经声明了**：A 的 `derived_from = ['src-b0cb8d3d0cbd']`（即 B）。**这一处不欠账。**

★★★ **但年份说不通**：A 的 `published_at` 写 **1912**，而 B 写 1864，两者内容重叠 78%。
一部 1861/1864 年的书不会有一卷标成 1912。
**1912 与证据矛盾，但我拿不出正确值**（两份题名页那几行都没印出版年）→ **不动**。

### `w_zwei_offene_briefe_spaeth_scanzoni_1861` 是 **Project Gutenberg 电子本**

```
*** START OF THIS PROJECT GUTENBERG EBOOK ZWEI OFFENE BRIEFE ***
Title: Zwei offene Briefe an Dr. J. Spaeth, Professor der Geburtshilfe an der k. k. …
```

→ 台账 locator 指向 `transactions-of-the-obstetrical-society-of-london_1863_4`，**证伪**
（这是 Gutenberg 文本，不是伦敦学会会刊的 IA 扫描件）。
★ 那个 `Title:` 是 **Gutenberg 自己的书目头**，属于来源方的著录，
不是我们写进去的头——与 [[i-almost-deleted-guards-that-blocked-my-number]] 那一类不同；
但它**也不是印本题名页**，只能算次级证据。

### `x_eisenmann_wundfieber_bsb_1837` —— 我读到的是**出版商广告页**，不是题名页
