# Work System / 工作系统

## 计划和分解

- **理论工作**：实测古物 → 提炼规范 → 成书——罗马古迹（1555，`src-eecef2cf93b7`）
  是实测，四书（1570，`src-104fc055b0da`）是成书，二者构成"从古物到文本"的工作链。
  <!-- claim:clm-000000000006 -->
- **图样工作**：以图为主、文字为辅记录设计与古物——Le Fabbriche 的平面/立面/剖面
  图是其交付主体（1785，`src-ea04367ec274`；1843，`src-cec1934c8ebb`）。
- **教学浓缩**：把四书柱式规范抽为"metodo facile"教学本与多语种编译本，降低阅读
  门槛（1801，`src-0717a438e7a2`；1679，`src-117866e8800c`）。
  <!-- claim:clm-000000000009 -->

## 工具、执行和检查

- **工具**：古建筑实测（测绘）、图版（木刻/铜版）——四书原版木刻与图集铜版
  （1570，`src-104fc055b0da`；1796，`src-df8f1e0dfc8b`）。
- **执行纪律**：以柱式性格与场地条件裁定比例——"the Ancients made them fometimes
  fquare... becaufe it requires more folidity"（1742，`src-56047aa2b2bd`）。
  <!-- claim:clm-000000000007 -->
- **检查方式**：设计以古例对照，无古例即无据（1570，`src-104fc055b0da`）。

## 质量标准与交付定义

- **理论标准**：规范必须可度量、可教——五柱式是量化体系（1742，`src-56047aa2b2bd`）。
- **作品标准**：建成作品以其"正确性"（合古法）为准，图样必须忠实（1785，
  `src-ea04367ec274`）。 <!-- claim:clm-000000000004 -->
- **交付物**：理论著作（四书/罗马古迹/五柱式）+ 图样总集（Le Fabbriche/Terme）+
  战史评注（恺撒评注，1598，`src-d729c800ee5c`）。
- **受众**：庇护人与读者（序献）、后世建筑师（图集与规范）。
