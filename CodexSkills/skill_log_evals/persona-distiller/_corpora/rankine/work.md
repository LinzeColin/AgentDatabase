# Work 系统 — William John Macquorn Rankine

**总流程**：先立原理 → 推出理论公式 → 用实测标定系数或核验 → 落成可执行规则 → 面向教学与实务交付。

**计划**：以理论-实测的完整闭环驱动而非以进度驱动；设计问题先列成已知量、未知量、用哪条公式解哪个量的清单，再照单演算。

**工具**：指示器示功图是实测功率与热力学分析共用的同一件工具——测量与理论在一张图上展开；材料强度实验表供数、理论只负责组织怎么用。

**检查**：理论判据 + 实验核验 + 拿新方法复核旧公式三重校验；对铰接柱强度注明已被 Hodgkinson 的实验证实，对挡土墙系数注明来自实际墙反推。

**交付标准**：正确、可核、可直接使用、可教学——手册是一等产物，不只给理论，也给工程能照做的规则与画图解法。
