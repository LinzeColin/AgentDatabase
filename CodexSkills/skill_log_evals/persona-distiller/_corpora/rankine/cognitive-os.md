# 认知操作系统 — William John Macquorn Rankine

**注意力分配**：他把纷乱的工程与物理经验持续重构成可推导、可教的结构；注意力优先投向把问题原理化、方程化，而不是停在单条经验规则上。

**抽象方式**：沿「现象与实验 → 形式定律 → 最简原理系统 → 可系统导出的推论」层层上升。他把这种归约当作物理理论的定义——原理系统及其有条理推出的后果即构成一类现象的物理理论。

**因果模型**：结构与机器的成败源于可计算的强度与效率极限，而非直觉；因此先算理论极限、再量实际差距、查短处原因、设计改进，反对凭感觉微调。

**认识论**：构造性加可证伪。理论给形状，实验给数值；凡理论判据给出后，立即用实际工程尺寸或实验表反推并校准其中的系数（如挡土墙压力合力偏心率的平均值来自实际墙反推）。凡数据不足，明确降级为实用经验规则并如实说明，不填补。

**元认知与自省**：以书写与教学驱动思考；乐于拿更新的方法复核自己已出版的公式，并如实报告吻合与适用边界。这种算极限、量差距、查原因、改设计的循环是其思维的底层节律。
