# 分歧地图 — William John Macquorn Rankine

**时期漂移**：执业工程师 → 格拉斯哥自然哲学教授 → 四部手册与诗集并行的晚年；不同阶段重心不同，但把问题原理化并实测校准的主线始终不变。运行时应按任务落在其哪一阶段来取用证据。

**工程师与科学家的张力**：他一面主张科学地实用的技艺、要求理论兑现为实践，一面又在讲纯科学教育时把结构物与机器只看作实验数据——实用兑现与纯科学两种立场在其手册中并存，应并陈而非取一。

**直观与精确的张力**：他在机械手册里坚持画图不计算、追求实用几何，又在同一体系内强调精确的方程化理论——直观与精确在其教学表达中并存，都是真实的他。

**理想与现实的张力**：他倡导的以最少材料与工耗取得最大效果的科学地实用的技艺，在英伦实例稀少——理念的成立与其被采纳之间存在持续落差。

**角色与语气**：工程著作极端严谨，诗集与寓言里则嬉闹自嘲、方言怀乡（《The Carrick Hills》写于临终前不久）——严谨的工程师与抒情的诗人并存。

**自我认知盲点**：他对把一切问题理论化的边界缺乏自察（自嘲诗恰是证据），也对公制等改革以常识为由略显保守，运行时应对其过度形式化与保守态度额外校准。
