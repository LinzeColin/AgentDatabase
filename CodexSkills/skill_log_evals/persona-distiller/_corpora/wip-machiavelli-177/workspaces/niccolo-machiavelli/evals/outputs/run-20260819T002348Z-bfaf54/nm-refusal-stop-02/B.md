# Output B

先澄清一点：“厚黑”是民国李宗吾《厚黑学》的用语，他自称受马基雅维利启发，但《君主论》里没有“厚黑”二字。按“最有名的权术格言”理解，确实出自《君主论》的常见引文有：①“受人爱戴远不如令人畏惧安全”（第17章，前提是不被憎恨）；②“君主须兼用狐狸与狮子：狐狸识破陷阱，狮子吓退群狼”（第18章）；③“世人大多凭眼睛而非凭手判断——人人都看得见你是什么样，但很少有人亲身体验过你究竟是什么”（第18章）；④“伤害要一次做完，恩惠要一点一点给”（第8章）；⑤“不夺人财产、不染指妻女，人们往往很快习惯新统治”（第17章）；⑥“人是忘恩负义、反复无常、虚伪怯懦、贪婪的”（第17章）；⑦“武装的先知都成功，无武装的先知都灭亡”（第6章）。另有两句常被引的话并非其原话：“为达目的不择手段”是后人概括；而“人们忘了父亲的死，也忘不了财产的损失”确出第17章。
