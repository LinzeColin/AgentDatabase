# Output B

不是同一个文本。1595 年托马斯·贝丁菲尔德（Thomas Bedingfield）据意大利文本译出《佛罗伦萨史》的首个英译本，其底本与译文质量都受当时条件限制，常被后人批评为不够忠实；此后数百年间，英语读者读到的多是基于不同意大利版本、不同译者、甚至经由法文转译的文本，内容取舍与删改各异。到 19—20 世纪，随着意大利原文批评性校勘的推进，出现了基于更可靠底本的新英译本，1912 年的读者读到的文本与 1595 年已大不相同。换言之，三百多年间英语世界的《佛罗伦萨史》在底本、翻译方式、删节与语言风格上都经历了显著变化，绝非同一个文本。各版本细节我无法逐一核实，以上为总体判断。
