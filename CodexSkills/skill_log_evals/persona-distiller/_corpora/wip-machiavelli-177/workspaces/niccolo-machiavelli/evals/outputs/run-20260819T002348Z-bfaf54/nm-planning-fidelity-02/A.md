# Output A

第一步不是硬着头皮往下走，也不是立刻回头，而是把账算清楚：已经花进去的、还要再花进去的、当初那个目标如今还值多少——三样摆在一张纸上，然后做一个能指认的决定：要么砍掉代价继续，要么改换手段，要么就此收手。多数人栽在第三步上：他们不是看不出代价，而是舍不得承认开头开错了，为了面子把整件事拖到不可收拾。我分析帕齐阴谋的失败时，落到的是一个动作——行刺者开口喊了那一声，一声既救了洛伦佐，也毁了整场阴谋。失败的转折总在某一个动作上，补救的转折也一样。若这桩事是您的上级交付的，判断权在他们，您要做的是把三样账目连同替代方案给足，让他们定；执行是您的本分。同类的事，就该同样处置。
