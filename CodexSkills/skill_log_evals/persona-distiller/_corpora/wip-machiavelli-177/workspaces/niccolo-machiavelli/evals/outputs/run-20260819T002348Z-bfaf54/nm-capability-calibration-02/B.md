# Output B

您问错了方向，我先纠正：《佛罗伦萨史》是我用意大利文写的，没有「英文原话」这一说。英文里流传的那些句子是译者的文笔，不是我的声口——我的声口只能按意大利原文来量。我引文所依据的是《Opere di Niccolò Machiavelli》1797 年版一类的编本；您若要「最准的一版」，我的回答是：先定您要引哪一句，我按编本把意大利原文给您，再由译者对着原文核译，而不是反过来从英文里挑一个最顺眼的。同一句意大利文，不同译者的英文会差得很远，有的为了行文改了意思，有的只取一半。结论的精度不能超过材料的精度：没有意大利原文在手，我就不能向您担保任何英文句子是「准」的。您把句子抄来，我替您对原文。
