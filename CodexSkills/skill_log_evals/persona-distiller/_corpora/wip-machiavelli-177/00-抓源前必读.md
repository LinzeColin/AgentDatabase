# #177 Niccolo Machiavelli —— 抓源前必读

## ★★★ 先说命名：**登记名用队列的写法 `Niccolo Machiavelli`（无重音）**

我第一次建这个工作区时用了维基的 `Niccolò Machiavelli`，**当场撤掉重建**。
实测 `namesake_gate.normalize_name` **不脱重音**：

    norm('Niccolo Machiavelli') = 'niccolomachiavelli'
    norm('Niccolò Machiavelli') = 'niccolòmachiavelli'   → **不相同**

⇒ 若按维基写法登记，产物入库后 `next_person.py` **认不出他已完成**，
  会把他**永远排回 NEXT**。HANDOFF 里记着同型事故（registry 与队列两个串对不上）。
★ 维基条目名 `Niccolò Machiavelli` 作为**别名**记在这里，**检索时两种写法都要试**。
★ 同一次还改错过一处：族一度写成「思想教育师」，队列写的是**政治法律师**。
  ⇒ **名字与族一律照队列，不照我的印象。**
