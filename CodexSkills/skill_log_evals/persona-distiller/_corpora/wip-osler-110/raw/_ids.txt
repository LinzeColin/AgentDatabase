# ══ HOW THE YEAR AND EDITION COLUMNS WERE PRODUCED ══
#   Every value in the YEAR and EDITION columns was READ OFF THE PRINTED TITLE LEAF of the
#   downloaded scan, not taken from the filename, the archive.org identifier, or the catalogue
#   `year` field.  Where the title leaf carries no year, the cell says so
#   ("[title leaf undated]" / "[no year printed on leaf]") and the flag TITLEPAGE-UNDATED is set;
#   where the leaf is present but the OCR of the year is dead, the cell says "illegible" and the
#   flag TITLEPAGE-YEAR-ILLEGIBLE is set.  NOTHING was back-filled from the catalogue.
#
#   Three rows where catalogue and title leaf DISAGREE, and the leaf won:
#     ppm-ed9-1921-POSTHUMOUS   archive.org says 1920; the title leaf says 1921.
#     aequanimitas-POSTHUMOUS-impr  archive.org says 1906; the leaf is undated, says
#                               "Late Regius Professor", and its impression table runs to 1930.
#     ppm-ed6-yr-illegible      archive.org says 1892 — impossible for a SIXTH EDITION.
#
# ══ TIERS (verbatim from the task brief, not re-interpreted) ══
#   P1 = his own hand / signed  (books, papers, addresses, letters written by him)
#   P2 = a DEGRADED version of the SAME material (inferior scan, same text re-scanned,
#        a later printing of the same edition, another imprint of the same text)
#   S1 = contemporary third-party account (someone else writing about him, in his time)
#   S2 = later scholarship
#
# COUNTS: 104 sources — P1 76 / P2 17 / S1 7 / S2 4
#         P1 share = 0.7308   (deep tier needs >= 0.65)
#         NO P1 row carries an imprint dated after 1919: 63 of them show an explicit
#         title-page year, every one of which is <= 1919, and the remaining 13 carry no
#         legible year at all (undated leaf, or the year OCRs to noise) and are flagged, not guessed.
#         Rows carrying a POSTHUMOUS flag: 8.  Rows carrying CO-AUTHORED: 7.
#         Rows whose title leaf gives no usable year: 21 (all flagged, none guessed).
#
# ══ ★ HAZARD 1 — THE LATER EDITIONS OF THE TEXTBOOK ARE NOT BY HIM ★ ══
#   `The Principles and Practice of Medicine` first appeared 1892.  He died 1919-12-29.
#   The book kept coming out into the 1940s: from the NINTH edition it was continued by
#   THOMAS McCRAE, and later by HENRY A. CHRISTIAN.
#   What the title leaves in this corpus actually say:
#     1892-1909 (ed. 1-7):  "BY WILLIAM OSLER, M.D."                     -> him alone
#     1912-1919 (ed. 8):    "BY SIR WILLIAM OSLER, BT. ...
#                            EIGHTH EDITION - WITH THE ASSISTANCE OF THOMAS McCRAE, M.D."
#                           -> still his byline; McCrae is named as ASSISTANT, not co-author.
#                           flagged ASSISTED-BY-McCRAE.
#     1920/1921 (ed. 9):    "BY THE LATE SIR WILLIAM OSLER, BT., M.D., F.R.S. ...
#                            AND THOMAS McCRAE, M.D.  /  NINTH THOROUGHLY REVISED EDITION"
#                           -> "THE LATE" + "AND" = posthumous and co-authored.
#                           NOT P1.  flagged POSTHUMOUS-REVISED;CO-AUTHORED.
#   No printing later than the ninth edition was taken into this corpus at all.
#   Every imprint dated after 1919 is P2 and flagged; none is counted as his hand.
#
# ══ ★ HAZARD 2 — CO-AUTHORED WORK IS NOT SOLE-AUTHORED WORK ★ ══
#   Seven rows are flagged CO-AUTHORED.  In each the title leaf names a second author:
#     cancer-of-stomach-1900-CO   "WILLIAM OSLER, M.D. AND THOMAS McCRAE, M.B. (TOR.)"
#     latent-cancer-stomach-1900-CO "WILLIAM OSLER, M.D., AND THOMAS McCRAE, M.B."
#     atrophy-of-stomach-1886-CO  "FREDERICK P. HENRY, M.D. ... AND WILLIAM OSLER, M.D."  (Henry is FIRST author)
#     pernicious-anaemia-1877-CO  clinical report by JOHN BELL; only the pathological report is Osler's
#     pork-parasites-1883-CO      "WILLIAM OSLER ... [AND] A. W. CLEMENT"
#     ppm-ed9-* (x2)              "THE LATE SIR WILLIAM OSLER ... AND THOMAS McCRAE"
#   Quoting any of these as "Osler said" without checking which part is his is an error.
#
# ══ ★ HAZARD 3 — SAME SURNAME ★ ══
#   Excluded people are logged one line each in raw/_EXCLUDED.txt with the rule applied.
#   The brief named two (Sir Edmund Boyd Osler, 1845-1924, financier/MP; Edward Revere Osler,
#   1895-1917, his son).  A THIRD turned up that the brief did not name and that a naive
#   "creator contains William + Osler" filter would have swallowed:
#     WILLIAM ROSCOE OSLER, author of `Tintoretto` (1879) — six archive.org items.
#   Also excluded: Edward Osler 1798-1863 (naturalist/poet), Annie F. Osler, and several
#   firms and modern authors carrying the surname.
#
# ══ STRUCTURAL NOTE — NO TRANSLATION LAYER ══
#   He wrote in ENGLISH.  Every row in this ledger is language `en` and is his own wording,
#   so the whole class of "the translator's words got quoted as his" cannot arise here.
#   Translations DO exist (a German `Lehrbuch der internen Medizin` 1909, a Chinese
#   `Ou shi nei ke xue`); none was taken into the corpus, and both are logged in _EXCLUDED.txt
#   so that the decision is visible rather than silent.
#
# ══ WHAT `COUNSELS AND IDEALS` IS ══
#   Four rows are flagged COMPILED-BY-CAMAC.  The sentences are Osler's; the SELECTION and
#   arrangement are C. N. B. Camac's.  Treat it as an anthology of him, not a work by him.
#
