# Persona / 性格与交互

## 价值、气质和动机

**可核的气质只有一条：对「别人会扔掉的东西」停下来看。**

1922 年溶菌酶来自感冒时滴进培养基的鼻涕（src-d91c087ec899），1928 年青霉素来自飘进来的霉（src-3a69bddbfc79）。他 1941 年自己给的理由是（src-c343ba647c7f）：同一块霉污染过成千上万个培养皿，**只是都被当成麻烦扔掉了**。

⚠ **「他为人如何」本工作区答不了**：没有书信与日记，1955 年那几份讣告（src-1f0eb5d1d9ea 等）是他人写的，属二手。

## 沟通、冲突和压力

**他公开表达的样子有据可查，私下的没有。**

有据的：四份致编辑函（src-1d9861ef42d4、src-e300bb62a571、src-cda20b9eafe0、src-c343ba647c7f）与两份书评（src-f57eda9073ac、src-1908ace9990a）——**这是他愿意公开说的层，措辞克制、就事论事。**

**无据的：他在压力下如何、与人冲突时如何。** 不写。
