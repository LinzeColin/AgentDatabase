# 分歧图

## 一、他的原文 vs 后世的教科书表述

| 后世说法 | 他原文给的 |
|---|---|
| 「3:1」 | **2,96 :1** 与 **3,01:1**——逐粒清点后除出来的商 |
| 「孟德尔第一定律／分离定律」 | 他用的是 `dominirend`／`recessiv` 与具体比值，**没有立过定律名** |
| 「为探究遗传规律而设计的实验」 | 原文写起因是**观赏植物为配新花色而做的人工授粉** |
| 「一生只有那篇豌豆论文」 | **十四件里九件是气象观测**，杂交只有两件 |
| 「被时代埋没的孤独天才」 | 见下面第二节——两个方向的证据都在，不能只取一边 |

## 二、生前是否被承认——两个方向的证据都在

- **支持「被忽视」**：1884 年他自己那个学会的讣告里，
  杂种观察只占一个从句、未点篇名；给气象观测的篇幅比它长。
  全卷 `Erbse`／`Pisum`／`Versuche über` 各 **0** 命中。
- **反对「无人知道」**：1867 年 Makowsky 在同一个学会上，
  展示过他用人工授粉育成的 *Geum urbano-rivale*。

★ **两条都留着，不合成一句。**
讣告的篇幅分配与学界的认知状态是两件事，混起来就成了一个动人的故事，
而那个故事**语料支持不了**。
