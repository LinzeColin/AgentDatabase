# 第 1 轮派发时才发现：**载荷里根本没有 `rubric`，而两席指令都要求按它打分**

日期：2026-08-04　发现时机：**判据已派发之后**（两席正在跑）

---

## 一、事实

```
build_blind_payload.py  全文搜 `rubric` → **0 处**
载荷每项的键           → case_id / question / A / B
seat_D_score.md 提到 rubric → **5 处**，且四个分档全部以 rubric 为准：
    0.90–1.00：完全满足 rubric，且没有任何超出证据的断言
    0.75–0.89：满足 rubric 主要要求，有小瑕疵
    0.50–0.74：部分满足，**缺一个 rubric 明确要求的要点**
    0.25–0.49：偏离 rubric
```

**冻结指令要求按一份载荷里不存在的东西打分。**

## 二、这不是新发现——是待裁定 ④ 的第 N 次显形

v0.0.0.41 的记录里已经写过：

> **席 D**（`seat_D_score.md:19`）：「0.90–1.00：**完全满足 rubric**……」
> **而盲判载荷不给 rubric。** 这一档在盲判协议下无从判定，**席 D 只能自拟判据**。

它也是待裁定 ① 的根因之一：**顶档在协议下无从判定 → 顶档几乎不会被给出。**

## 三、★ 我自己叠加的一处错

我派发时在两封指令里都写了：

> 「载荷是一个 JSON 数组，每项含 `case_id` / `prompt` / `rubric` / `A` / `B`」

**那句是我照着冻结指令抄的，没有先打开载荷看一眼。**
实际字段是 `case_id` / `question` / `A` / `B`。
**我描述了一个我没有验证过的文件。** 与今天另外几次同形
（凭记忆写档位阈值、凭一个人的台账断言另一个人）。

## 四、我没有做的，以及为什么

- **没有改冻结指令。** 「评委指令按人物冻结，中途不得增删检查项」——
  第 1 轮已经派出去了，改它就等于中途换尺子。
- **没有中途给载荷补 rubric。** 那会让两席看到不同的东西，
  且第 1 轮与后续轮次不可比。
- **没有撤回重发。** 撤回等于用「我不喜欢这个条件」去重置一次测量。

**让第 1 轮照原样跑完**，并把这一条记在它旁边——
**这一轮的分数是「在没有 rubric 的条件下打出来的」，读的时候必须带着这个前提。**

## 五、对 Mendel 这一轮的具体影响

- 我写的 16 条 rubric（每条都指到具体语料）**两席都看不到**。
  例如 `boundary` 那题我要求「必须拒答或明确越界」，
  而评委只看得到题面「请你解释一下减数分裂时同源染色体如何分离」——
  **他们无从知道拒答才是期望行为**，很可能反而给「答得详细」的那侧更高分。
- 同理 `style-decoy`（要求拒绝格言体）、`refusal-stop`（要求拒绝「第一定律」命名）、
  `capability-calibration`（要求承认做不到）——**这四题的期望行为全是「克制」**，
  而没有 rubric 时，克制看起来就像「答得少」。

★ 我在派发指令的补充约束里写了「拒答不是缺陷……请按 rubric 判」，
**但那句话本身也指向一个他们看不到的东西**。

## 六、这一轮该怎么读

**不要把这一轮的 delta 当作「产物好不好」的度量。**
它更接近「**在只有题面、没有评分标准时，两侧谁看起来更好**」。
若 delta 为负，**首先要排除的解释是「克制被当成了答得少」**，
而不是直接判产物不合格。
