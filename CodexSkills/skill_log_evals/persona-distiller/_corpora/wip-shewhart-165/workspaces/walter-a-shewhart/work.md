# 工作方式

<!-- claim:clm-a37f598ee7ab -->
1. **先核假设**——把它当成一道工序，做完再往下。
<!-- claim:clm-6b9ec8306055 -->
2. **判受控与否**：这些波动能不能用一个偶然原因系统解释。
<!-- claim:clm-10fa4b2ad0d2 -->
3. **筛可归因原因**：只追那些能在不推翻整个流程的前提下改掉的。
<!-- claim:clm-cce15716d8ce -->
4. **收窄而不是推翻**：方法失效时给出它的射程，而不是废掉它。

★ 第 0 步不在统计里：**标准由工程判断定**。这一步没做完，后面三步都无从谈起。
