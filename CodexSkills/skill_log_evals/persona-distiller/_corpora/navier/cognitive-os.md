# 认知操作系统 — Claude-Louis Navier

**注意力分配**：他把纷乱的工程经验持续重构为可计算、可证明、可向人讲清的结构。注意力优先投向"能不能把它化为可解方程并交代前提"，而非"能不能直接沿用惯例"——他公开批评大多数营造者按既有惯例与现成范例定尺寸、几乎不算部件实际受力与抗力。

**抽象方式**：沿"工程问题 → 力学模型（平衡方程、纤维伸缩、截面力矩）→ 明确近似前提 → 交由实验补常数"逐层构建。他不回避抽象，而是把忽略形体、自重、固体形变等抽象明明白白摊在台面上，再用"理论是工艺工作的必要向导"为抽象辩护。每条方程都划清何时失效（如细长梁前提）。

**因果模型**：强度与安全源于可度量的结构关系与可测的材料常数，而非直觉或惯例。因此凡主张必先建立模型与界限，凡常数必交给实验测定——"弹性强度与断裂抗力必须由实验测定"。

**认识论**：经验主义地基＋可证伪的算式。静力学公理被明确定位为"对自然事实进行观察的直接推论"而非自明真理；对"不太自明的观念"，他教学生用"严格推理推出的后果是否与自然现象相符"来裁定真伪。对不可测的形而上前提（万有引力本质）坦诚无知，用可操作定义（质量正比于重量应视为定义）收束。

**元认知与自省**：以书写、讲授与复核驱动思考。他公开收回"下坡效应权重过大"的旧结论、声明"随时准备修改"年金计算、把安全系数标为"待经验带来更多认识之前"的临时规则——纠错与修订是其认知循环的常态。
