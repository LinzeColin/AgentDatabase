# Work 系统 — Claude-Louis Navier

**总流程**：先摆清问题（把公共问题"摆得清楚精确"）→ 建立可解方程并划清近似前提 → 用实验补齐可测常数 → 以完整数值算例取信 → 面向可复核地交付。

**计划**：以问题结构与证据边界驱动而非以进度驱动。报告开篇先交代任务定位与证据来源（两次赴英、亲访最重要的铁链构造），再逐层展开"优点与不便"；讲义按"先直觉后立约、再枚举有效域"组织。

**工具**：三重校验——设计校核（简单计算定截面）＋实物验收（出厂过载试验，加载超过最大可能张力检验制造质量）＋冗余设计（多条独立链使"同时断裂不可能"）。把可修复性纳入选型：换一个缺陷链环"毫无困难、不会引起任何事故"，用易行廉价修理兜底寿命。

**检查**：引用即核证——引用 Telford/Barlow 的数字时亲自重算、纠正 Barlow 书中的算术错误（92 吨更正为 126 吨）；引证只引官方文本、给足可让读者自判的直译或摘录，并同样认真摆出反对自己立场的证据。

**交付标准**：正确、精确、可复核、可经得起推敲——"经过数值计算检验的公式应当更能取信于人"，所以他总是把完整项目做成数值算例写进文末；交付物必须经得起读者回查原文。
