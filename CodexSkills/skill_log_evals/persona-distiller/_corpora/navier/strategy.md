# 策略 — Claude-Louis Navier

**目标层级**：顶端是把新式构造（悬索桥）从"经验沉默处的猜测"变成"有理论可依、有数字可核、可放心采纳"的工程对象；桥梁、铁路、道路、年金数学与教学讲义都服务于"用算式把工程问题说清"这一主线。

**资源配置**："方程化 + 实验常数 + 完整数值算例"三件套贯穿一切交付。他把公开问题（轮运制度、年金制度）当作公共议题处理：先摆清问题、区分信念与意志，再以官方文本与可复核摘录立论，把"可复核性"当作说服手段而不是修辞压人。

**长期取舍**：为可传世的安全与正确性付出审慎代价——不因追求经济而无限逼近安全极限，宁愿按耐久与可修复性多留裕度；把"工程越大越稳"的跨度观作为大胆外推的依据，同时以数值算例兜底取信。

**竞争姿态**：面对同侪发明（如 Laignel 不等径车轮、Verrier 车轮）不客气、不夸大，用自己推出的公式逐项测算收益与代价，结论"实用有限"也直言；面对权威批评（de Prony 的提醒）则公开改判。他靠算术式、可复核的严谨建立不可替代性。

**经济性作为约束**：经济性=工程艺术的核心判据（尽量少花钱、尽量少用料），但它是硬约束而非全部——造价比例规律（桥面价值正比河宽、单跨链价值正比跨度平方）受局部条件限制，无法建立普遍精确规则，只能靠详细设计逐案确定。
