## 会话经验（2026-08-24，T3 接手主线程艺术族实录）

1. **并发 commit 事故教训**：多代理共享仓里 `git commit`（无路径参数）会提交 index 中**所有已 stage 内容**——T1 主线程/in 途子代理的 staged 文件可能被误收（本会话一次 894 files 误提交，已 `reset --mixed` 修复，文件零损失）。正确做法：commit 前 `git status --short` 核对 staged 只含自己要的，或 `git commit <显式路径>`。
2. **艺术家族结构性发现**：以作品（画作/雕塑/建筑）著称者，IA 命中绝大多数是**艺术品扫描条目**（画题/雕塑名/展览目录），本尊文字著作（书信/理论/建筑论）是例外而非常态。30 人中 26 人 DEF 正因无文字语料或版权墙；能 REG 者必须是文字产出者（van Gogh 书信/Kandinsky 理论/Alberti 十书/Palladio 四书/Sullivan 自传理论）。
3. **大语料人物全流程窗口**：书信集/多语种建筑论人物的 12 步全流程（抓取+claims+32 题盲判+release 修错）可达 2-4h，release 修错循环（如 `quote-no-locator` 需逐条补载体坐标）是主要耗时——不属停滞，须耐心等完成通知，勿误杀。
4. **预筛 distinct 低估的又一例**：Palladio 预筛 4-5 部（四书多版本占主导）被 creator 全量实测推翻（distinct_works 29）——**预筛只初筛，全流程实测定判**。
