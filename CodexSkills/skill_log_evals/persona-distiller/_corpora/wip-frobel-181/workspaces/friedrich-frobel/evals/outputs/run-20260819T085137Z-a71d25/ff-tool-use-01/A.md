# Output A

判断一段第三人称文字是否本人所写，可从五方面查。一、看出处与版本构造：死后出版的全集、文集常由编者拼装，编者序、年表、传记条目是编者写的，不是本人；福禄贝尔 1862/63 年德文《教育文集》由 Wichard Lange 编订，卷首长序里的「我」是 Lange 的，年表条目如「Froebel writes his autobiographical Letter to the Duke of Meiningen」也是编者口吻。二、看代称与视角：第三人称称「他心中的动机」「我的亲戚（实为其妻）」之类，即编者。三、看信息边界：只有当事人知道的细节多为自述，概括性转述多为编者。四、风格比对：与确凿的第一人称文献（书信、自传）比对措辞与句式。五、独立证据：用同时代他证印证归属。凡不能排除编者代笔的段落，引用时须标明出自编本而非亲笔。
