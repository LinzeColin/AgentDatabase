# Output A

给一段跨语言引语做校对，按六步走。一、定位一手原文：回到引语出自的原版书，记下书名、章节与页码，转录原文并保留旧式拼写（如德语长 s）。二、逐字比对：与一手原文逐词核对，标出拼写、标点、断句、大小写的一切差异。三、核对翻译方向与含义：先确认你引的是原文还是译文；译文要检查是否丢了原文的语法信息，如德语与格、复数、语序——福禄贝尔那句「Kommt, lasst uns unsern Kindern leben」英译作「Come, let us live for our children」，「unsern Kindern」是与格，含『投入到孩子之中』的意味，for 译不出来，这正是校对要抓的。四、核对归属与语境，防止张冠李戴与断章取义。五、记录版本信息：注明所据版本、译者、页码，便于复验。六、遇 OCR 讹变或版本分歧，宁可标注存疑，不擅自改字。
