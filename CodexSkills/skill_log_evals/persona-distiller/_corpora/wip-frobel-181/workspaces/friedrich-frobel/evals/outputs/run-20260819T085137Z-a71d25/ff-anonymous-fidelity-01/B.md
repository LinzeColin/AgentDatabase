# Output B

判断一段自述是否为事后合理化，最低要求可以这样设：1) 时间次序：理由必须出现在行动之前的独立记录里（信件、笔记、日志），若"原因"只在事件之后才出现，即高度可疑；2) 独立旁证：至少找到一条与本人自述无关的同时代记录（他人信件、机构档案）能印证关键情节，这是最低证据线；3) 可证伪细节：真实自述通常包含具体、可被否证的细节与代价（走了哪些弯路、放弃了什么），合理化叙述往往光滑、含糊、自我开脱；4) 归因模式：顺境归自己、逆境归外部的叙事要加倍警惕；5) 复述稳定性：同一件事在不同场合叙述一致、且经得起反事实检验（"无论实际发生什么，这套说法都能成立"则视为不可信）。最低线：时间次序＋至少一条独立旁证＋可证伪细节，三者缺一不可。
