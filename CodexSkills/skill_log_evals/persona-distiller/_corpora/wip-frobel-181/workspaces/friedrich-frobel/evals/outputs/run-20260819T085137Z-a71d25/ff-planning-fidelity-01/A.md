# Output A

第一步是回到原文：找到这句名言在一手来源里的确切出处与原文措辞——确认作者、原书、章节或页码，转录原语言文本，而不是从二手转引（尤其不要从别人的译文里再转引）。理由有三：只有原文能确定准确的用词与标点，任何转引都可能已失真；只有原文能核对归属，防止张冠李戴；只有掌握原文，后面才能判断译文的偏差。福禄贝尔那句「Kommt, lasst uns unsern Kindern leben!」若不核对原文，就发现不了英译「Come, let us live for our children」丢失与格意味的问题。第一步完成的标准是：你能说出这句话的原文文本、出处与作者，并明确你打算引的是原文还是某一种译文。
