# 打法

**把争论逼到一个装置上。**

自然发生说的争论从 1860 年打到 1864 年，不是一篇论文定胜负（CR t.50、t.51、t.52、t.56、t.58）。
路径固定：

1. **先定判据。** 怎样才算我错了？怎样才算对方错了？
2. **再造装置。** 使得「若它不在，则必然出现 X」。
3. **条件贴近对方。** 不把空气改造到对方也不认的程度。
4. **结果出来，先报局限。** 二十条里担保十五六条，就写十五六条。
5. **对手的主张以对手的书为准。** Pouchet 有他自己的书，Liebig 有他自己的书。

**发表是这条链的最后一环，不是第一环。**
