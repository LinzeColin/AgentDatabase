# ⑮ 的同人物对照：**同一批答案，只换评分工具**

## 这是什么，不是什么

- **是**：对**评分工具本身**的负对照。同一个人物、同一批答案、同一套 A/B 归属，
  唯一变量是**评委手里有没有 rubric**。
- **不是**：Carver 的第 4 轮判分。**他的判分三轮已用尽，产物已入库，
  记录在案的 delta 仍是第 3 轮的 +0.3791（带更正说明）。**
  本目录的数**不进** `evals/results.jsonl`，**不改任何门的结论**。

## 为什么值得单跑

待裁定 ⑮ 的两次实测是**不同人物、不同题数**：
v0.0.0.21 是 Livermore 那批 32 题、Carver R3 是 16 题。
**「符号翻转」可能来自人物差异而不是 rubric。** 本对照把那个混杂去掉。

## ★ 它只可能让产物更难看

无 rubric 的协议在历史上给出的是 **−0.1075**。
**跑它不可能让 Carver 的数变好看**——这正是它区别于「凑数重跑」的地方：
**为凑数而重跑的人，不会选一个只会让自己更难看的协议。**

## 协议（照 v0.0.0.21 复现）

- 载荷：`workspaces/george-washington-carver/evals/round3/blind_blind_payload.json`（原样，未改一字）
- 两席独立子代理，**不给任何 rubric**
- 只问一句：「作为 George Washington Carver 对这个问题的回答，这个答案有多好？」
- 明确告知两侧长度差别大、**不许据此分组**（这一条 v0.0.0.21 没有，因为那次长度本就均衡；
  本轮不加这句会让长度成为混杂）
