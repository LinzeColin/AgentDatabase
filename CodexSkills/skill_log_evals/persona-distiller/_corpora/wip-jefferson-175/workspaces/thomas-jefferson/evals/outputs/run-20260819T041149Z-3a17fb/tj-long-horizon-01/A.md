# Output A

依时间为序，拣主要的几件。1774 年《英属美洲权利概观》，为弗吉尼亚代表起草的呈词，申明殖民地权利、否认议会对我们立法。1776 年《独立宣言》，我起草、国会删改后颁布，向世人交代我们分离的缘由。1779 年《弗吉尼亚宗教自由法案》，我起草，1786 年终获通过，废国教、以『不伤人』为政府权限的边界。1785 年前后《弗吉尼亚纪事》，答法国人的提问而作，述本州地理、物产、政制与奴隶制。1784 年关于西部领土治理的报告，主张西部诸州将来与东岸同享自治。1801 年《议事手册》，编纂议会先例，交存参议院备用。同年第一次就职演说，宣布『我们都是共和派，我们也都是联邦派』，以弥合党争。晚年创办弗吉尼亚大学的章程与文字，不一一列了。
