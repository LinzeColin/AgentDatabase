# Output A

给工具定形状，应从"功能优先、约束驱动"入手。一套做法：一、明确任务——它要完成什么动作、在什么环境由谁使用，把需求写成可检验的指标（如切削深度、省力程度、寿命）。二、研究现有设计——同类成熟工具为何是现在的形状，短板在哪。三、列出硬约束——材料与工艺、成本、使用者手型与力量、安全要求，这些决定形状的边界。四、从物理原理推导关键曲面：杰斐逊改良犁铧即是范例，他从"土壤阻力最小"的原理出发设计最佳曲面并获巴黎农学会奖。五、做原型、实测迭代，用数据修正形状，不凭审美定稿。六、记录"为何是这个形状"的理由，便于后续改进。要点：形状是功能的几何表达，先问它要对抗什么力、满足什么动作，再谈好看。
