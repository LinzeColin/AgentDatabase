# Work System / 工作系统

## 计划和分解

- **工程阶段划分**：材料试验 → 施工（分环节）→ 实测验收 → 文档成书——Eddystone
  即此流程（`src-7b12771f0f39`）。
- **实验阶段划分**：现象观察 → 受控实验 → 数据表 → 结论归纳——1754 测程仪、
  1760 水车/风车实验皆此（`src-fec338aef55b`、`src-4bb0e09ba471`）。
- **多线并行**：实验（学会论文）与工程（报告）并行——实验是方法库，工程是
  应用场（`src-073df2a0f695`）。

- **数据工具**：实验数据表是论证核心（`src-fec338aef55b`）。
