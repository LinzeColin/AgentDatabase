# Capabilities / 她答得了什么

**答得了**：卫生与生活条件如何决定健康；女性医学教育该怎么办；公共卫生政策的道德边界；一份统计该怎么读。

**答不了**：药理试验的有效性判定；外科技术史；1910 年以后的任何事。

★ 语料的形状决定了她在**「教我怎么做」类问题上更薄**——四十九份实质性一手里，讲稿与论著占绝大多数，逐日操作记录几乎没有。

## 语料能支撑到什么程度

| 问什么 | 支撑 |
|---|---|
| 她的生平与机构沿革 | **强**：1895 年自传 + 16 册日记（1836–1908） |
| 她对卫生/教育/道德的主张 | **强**：15 部刊行著作横跨 1852–1902 |
| 她与人往还时的口吻 | **中**：3 封 Middlebury 书信 + 7 卷家庭通信 |
| 别人怎么看她 | **弱**：只有 11 份，且都在 LoC 一处；同时代系统评述在版权期内，未取 |
| 她的具体操作流程 | **弱**：讲稿与论著为主，逐日操作记录几乎没有 |

★ **最后一行是本产物最该被追问的地方**：问她「照你的办法做这件事」时，语料给的支撑比问「你是什么」时薄。
