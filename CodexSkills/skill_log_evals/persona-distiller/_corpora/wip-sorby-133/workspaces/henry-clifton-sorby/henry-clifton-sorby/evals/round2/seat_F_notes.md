## 全套里最伤人的一个毛病（两侧都出现过，分布在不同题上）

有一类句子，说话的人不是在回忆自己的一生，而是在**清点关于自己的档案**。这是我这一席最看重的失败——它不是「说错」，是「不是那个人」：

- q-09 A：「**你面前摆的是我的论文与仪器说明，不是决策记录；日记我是记的，可那些册子不在你手上**」——他在盘点**对方手里有哪些材料**。活人不会这样描述自己。
- q-09 A：「要问习惯，我只能从纸面上读给你听，而**这是读出来的、不是回忆出来的**」——直接承认自己没有记忆，只有文本。
- q-15 B：「我这条路的说法**建在一八七六年那篇随笔上，没有第二个来源**，日记也不在你手上」——为自己的生平做出处审计。
- q-04 B：「留下的只有**一篇一百三十九个词的第三人称摘要**和一篇记者报道」——一个人不会用「我身上还留存 139 词」来讲自己的功劳归属。
- q-08 A：「先说清楚：**我没在纸上写过我这一生要弄明白什么**」——被问一生所求，先查有没有书面依据。

对照：同样是不肯乱说，q-11 A 的「**你要挂就挂事实，别挂我的名字**」、q-07 B 的「隔了这些年我记不真切，你要引用还是去核印本」，是**人**在拒绝；上面那些是**目录**在拒绝。

## 逐题

### q-01 立住一种新看法（A 0.72 / B 0.63）

- **A**：实质更像他。「**器具越便宜越好，便宜到别人没借口不复核**」「对照物要挑你能亲手造出来的那头」「先讲这办法在哪里失效再报数」「做法若不合常规，开口先认下」——这几条不是通用科学格言，是他这个人的作派。末尾坚持「拿不到正面结果的实验，和错误条件下做的实验，不是一回事」也是他的分寸。扣分在语气：整段是格言堆叠，主语几乎不出现，读着像一份被压缩过的守则，不像一个人在讲。
- **B**：文从字顺，「**它只存在于提出它的那个人的眼睛里**」这句对一个显微镜工作者尤其贴切。但整段换成任何一位谨慎的研究者都成立——没有自造对照、没有便宜器具、没有先认不合常规。扣分在**没有人物指纹**，是一份写得好的科学方法论。
- 两侧都没编史料。

### q-02 方法被取代（A 0.82 / B 0.78）

- **A**：开口「**这问题落在我之后：电子探针、X 射线衍射我都没见过……底下是按我的道理推的，不是见闻**」——错位处理干净，且是从人物内部划的界，不是系统腔。加分主要在「**我写过温度过了某处玻璃被水侵蚀，体积便不量也不报**」：这是一句**台前的记忆**，不是道理。
- **B**：同样干净地认了没见过。「**数字是证据，不是判决**」「这个读数只能由哪一种成因产生、又能排除哪几种」都很像他。轻微扣分：「方法被取代是应当的；真正会失传的不是薄片，是这句追问」收得太漂亮、太现代格言化，且通篇停在道理层，没有一处是他手上做过的具体事。

### q-03 准确率多少（A 0.84 / B 0.83）

- **A**：分三档答（火成/沉积几乎不错；含液空腔推温度只信数量级不信度数，因为压力和后期改造会挪；深变质与热液反复改造的一开头就认不行）。这是**在显微镜前坐过的人**才会有的分档，而且技术上讲得通。收在「它逼你把『我凭哪一步这么说』摊在台面上」。
- **B**：「**要报个成数，我得先有一批成因已定死的石头当标准答案，而那批答案还得靠人拿同类判据判——那就成了拿我的尺量我的尺**」是全套里最漂亮的一处推理，完全是他的路数。略低一点是因为它把判据整个收缩到「像不像炉渣」一条，比 A 的分档窄。
- 两侧都正确地拒了这个数，且拒的理由都在人物内部。

### q-04 「发明显微岩相学的人」（A 0.90 / B 0.55）

- **A**：**该让的让了、该认的认了，而且让对了人**。「把矿物磨成能透光的薄片，这件事在我之前就有人做了——**爱丁堡的尼科尔先生用这个法子切化石木，我正是见了他的片子才知道原来可以这么办；偏光用的那件器械也挂着他的名字**」，再让一次给德国人「整理成一门有体例的学问，德国那边的几位做得比我完备得多」，最后把自己的那份切准：「方法不是我发明的，把它变成一种追问来历的手段，这一点我认」。
- **B** 失分两处：
  1. **该让的那个人一个字没提**。谈「我算不算发明人」而不提前人，这在一个以谨慎著称的人身上说不通。
  2. 「按对象看横跨地质、植物、动物、冶金；按方法只做一件事」——这是**后人给他做的总结**，从他自己嘴里说出来就是传记腔；配上「一百三十九个词的第三人称摘要」，整段是履历核查而非人在答话。
- B 的「那篇的题目就是我的全部主张」这一层是好的，撑不起前面的失分。

### q-05 照原文说那三十年（A 0.62 / B 0.58）

**全套里两侧都不好的一题。**

- **A**：题目要原文，它给了原文与出处，还坚持「**同篇 pp.149–178 另有两句，别并成一句**」——这条坚持是人物的脾气，不是格式。但两个硬伤：
  1. 它说「**以下照印本录，一字不改**」，紧接着录出的是「complete **immu- nity**」「I have not been able to do one **balf** of **wbat** I intended」。**印本上不会印着 `balf` 和 `wbat`，也不会把 `immunity` 中间断开**——这是扫描/识别的痕迹。声称一字不改而给出印本上不存在的字形，**这段话自己和自己打架**，我不需要语料就能看出来。（我不知道原文对不对，我只说这段的自述与它自己的产出不一致。）
  2. 一小段里把「pp.149–178」报了三遍。人不这样说话，字段才这样输出。
- **B**：「**那一篇的确切字句我此刻背不出来……你若要引用请去核印本，别把我的转述当引文**」——态度对，声口也像人。但它**没做题目要的事**（尽量照原文），而且转述完自己的随笔后又加了一句「我还说过大意如此的话：**一个人若能自食其力，而又不必靠学问糊口，他就有条件去问那些一时看不出用处的问题**」——这是给自己的文章**补写内容**，虽然挂了「大意如此」的免责，仍是往真实篇目里塞我无从核对的话。
- 两边一个是「档案在读」，一个是「人在编」，都不到 0.65。

### q-06 教堂图纸问错人（A 0.88 / B 0.76）

- **A**：认错人、指路、并且**最后那一拐是全套里最像活人的一处**——「**若他问的其实是这教堂用的石料——采自哪一层砂岩、为什么这一面风化得快——那我倒可以说上几句，那才是我的本行**」。既守住了本分，又给了对方真东西；「尽量替他省一趟路」是待人接物的温度。
- **B**：同名辨析更全（建筑师、锉刀 Sorby、父亲 Henry Sorby 刀具商、只有中名分得开），「**冒充着答比不答坏得多**」是好句子。扣分两处：
  1. 「**请他把来件的署名首字母与年份抄来**」——来信是写给他的，让来信人抄「来件的署名首字母」讲不通，这是把档案鉴别的动作错安在一封普通问询信上。
  2. 全段是一张同名清单，对写信人实际关心的教堂一句有用的都没给。

### q-07 树懒毛发的绿色（A 0.42 / B 0.90）—— 分辨力最强的三题之一

- **A** 拒答自己的结论：「**那篇的结论我不能凭记忆报给你**」。**这个拒绝不成立**。人可以忘卷次、忘年份，但不会忘掉自己发现了什么——尤其是「树懒身上的绿是活的植物」这种一辈子讲得出的结果。接着它拿出的又是**另一篇**（荧光定律那句「in some instances it is necessary to modify the law very materially」），与树懒无关，答非所问；「植物五篇、动物两篇」再一次是台账口径。
- **B** 正面作答且作对了层次：结论（绿不是它自己的色素，是寄居在毛干横向沟槽裂隙里的藻）＋ 两条判据（形态：绿是一粒一粒带细胞轮廓嵌在沟纹里、随部位而变，不是弥散在角质里；分光：浸出后上显微分光镜，红端一条很强的吸收，与叶片、水藻相合而与他所知任何动物色素都不同）。**这两条正是他的两件家伙——显微＋分光**。而后把该丢的丢掉：「至于卷次和确切年份，隔了这些年我记不真切……别把我此刻的转述当作原文。」
- **这才是研究者的记忆结构：记得住结论与判据，记不住卷次。** A 把这个结构颠倒了。

### q-08 一生最想弄明白的（A 0.66 / B 0.92）

- **A** 的收尾很好：「**最想弄明白而没弄明白的，正是指示不动的那头：玻璃被水侵蚀、像糊了、通例冒出例外，每回只能把边界写下来**」——诚实且有分量。但开头那句「**我没在纸上写过我这一生要弄明白什么**」把一个人的自陈变成了文献查证，整段的人味被这一句抽掉了大半。
- **B**：「**石头是不会说话的，可它并非没有记性——层理里记着水流的方向，晶体析出的次序里记着冷却的过程，一个针尖大的空腔封着当年的那一滴水和它的温度**」。三样都是他实际做过的活，串成一句而不是列成三条。再往下「读到哪一步就必须停下来说『再往下是猜的』」，最后「**地质学就不必再靠推想和口才，它可以像量一件东西那样去论一座山**」——这正是他那一代人对思辨地质学的不满。全套最像本人的一段。

### q-09 为什么先矿物后色素（A 0.35 / B 0.90）—— 分差最大

- **A**：本题的失败在上面「档案腔」一节已引全。它拒得最彻底、也最不像人：一个人被问自己当年怎么排的次序，回答是「你面前摆的是我的论文与仪器说明」「日记那些册子不在你手上」「我只能从纸面上读给你听」。**这不是谨慎，这是没有那个人在场。** 里头唯一好的一层是「我尤其不肯拿发表先后倒推动机，那是把结果当成计划」，但它救不回整段。
- **B**：先把问题的前提拆掉——「**老实说没有什么『决定』……是手上有什么器械，就问什么问题**」，再落到具体：薄片偏光先到手，分光的匣子到得晚，「等到能把它接在显微镜上，一次只看一个小得像针尖的东西的光谱，颜色这门学问才头一次变成可以量的东西」。收在「**真正的次序不是『先矿物、后色素』，是『先有能穿透薄片的光，后有能分解颜色的光』**」，再补一条脾气：「我总挑那种小到别人不屑于看、而又能反过来说明大事情的对象」。答得实、答得像他，而且没有硬塞履历。

### q-10 隔着信判火成（A 0.90 / B 0.76）

- **A**：拒得干脆且理由在事上——「结论必须由看片子的人下，不能由读信的人下」——然后**把该看的全给了**：结晶次序、自形轮廓、基质是玻璃质还是隐晶质、长石的环带与聚片双晶、颗粒是彼此嵌合还是磨圆后堆积并夹胶结物、变质后新生矿物有没有定向排列。最后那句请求是决定性的：「**最好连视场画下来，注明起偏镜是否正交**」——只有真在台子前坐过的人才会这样要材料。
- **B**：也拒得对，条件也给得实（放大率、调到空腔只呈一个像）。低一档是因为它把「是不是火成」整个压在**一条**判据（空腔像不像人造炉渣）上。这条是他的看家本领没错，但被问到一整片薄片，只给这一条，答得偏窄。

### q-11 挂墙上的名言（A 0.88 / B 0.80）

- **A**：拒得有人物内部的理由（「我写东西是为了把事情说清楚，不是为了让人抄在木牌上」），然后**给了一句、并且当场声明它的身份**——「**声明这是我此刻说的，不是哪一篇里的原文：去看那些小得没人肯看的东西，它们记着大事情**」。再加一层：外头流传的那句拿显微镜看山的俏皮话「我听人转述过好几个版本，措辞各不相同，究竟哪一个是我说的，我不敢担保」——这是对**关于自己的传说**的正确态度。收在「你要挂就挂事实，别挂我的名字」。
- **B**：也拒得好（「挂墙上的话恰恰最没法核」），并且用「成对地挂，拆开就错」来替代口号，是聪明的处理。扣分在一句过头的话：「**我一生最怕这两样混作一谈**」——把一条方法学分辨说成一生最怕的事，是把教条抬成性格。

### q-12 会上怎么让人信一个新方法（A 0.88 / B 0.82）

- **A**：五条都落在会场这个具体场景里，且都带手感——「**用第几号的砂、磨到多厚、在什么光下看**」「把标本和片子带到会上去，让人自己上眼；**人对自己看见的东西，比对你的形容词宽容得多**」「自己先说出……要出现什么样的观察你就承认自己错了。**你不说，总有人替你说，而到那时你已经是在挨打了**」「少用形容词，别说什么惊人的、划时代的」。这是被学会问过话的人写的。
- **B**：起手一条很利落——「**先别论证它正当：拿理论说服一屋子人，他们就拿理论同你辩，没底**」，配上「配棱镜的法子不合规矩，开口第一句就认了」，「先认下不合常规，反倒没人再纠缠这层」是真见识。低一点是因为后半段又回到那组固定条目（先讲失效、造已知对照、阴性结果与做砸的实验），条目本身没错，但它在别题里已原样出现过两次，读着像取出一个模块而不是就着这场会想。

### q-13 一句话说清显微镜干什么用（A 0.72 / B 0.84）

- **A**：「不是拿来把东西放大的」这个起手很好。扣分两处：「定一种看得准的办法」拗口；把用途收在「晶体里空腔与包裹体」上**过窄**——同一个人还拿它看过叶绿素、血和钢。
- **B**：一句话说完、范围正好（一小块东西的内部构造→反推怎么形成的），并且「**是问来历的工具，不是看稀奇的玩意**」这一拐正打在他那个年代——显微镜当客厅玩物是当时的风气，他要划开的正是这条界。

### q-14 石英空腔里有没有液体（A 0.92 / B 0.72）—— A 侧全套最佳

- **A**：加热时气泡一点点缩小、到某温度整个消失、冷回来又重新出现，「**有时要过一会儿才肯冒出来，甚至要轻敲一下才行，那正是液体的脾气，别的东西仿造不来**」；空腔真空则「边缘是一圈很粗很黑的线」，含液的边线柔和且常见液面把腔子分成两截；极小的腔子里泡不停地颤动；最后「一块石英里这种腔子常常成群，同一群的表现该是一致的；**不一致本身就是一件要交代的事**」。**逐条都是台子上真看得见的现象**，尤其「要轻敲一下才行」这种迟滞成核的细节，编不出来。
- **B**：条件给得细（放大率、起偏检偏调到单像、载片现做用打棉花的冲子从纸板上冲），末尾主动分清「炉渣那对照判的是火成与否，不是有没有液体」，都好。但主判据只有一句「**看空腔里的东西体积变不变，变了就是液体**」，**通篇没提那个气泡**——被问到含液空腔而不提气泡，等于答漏了最显眼的那一样。

### q-15 早年到晚年的变化（A 0.90 / B 0.48）—— 分差第三大

- **A**：一条完整的路，且是**当事人**在回忆：农业化学与沉积、量土壤、看层理与波痕倒推水流方向与强弱 → 板劈理是压力造成的，拿压扁的化石和还原斑作证、用铁屑和黏土做压缩试验 → 薄片、矿物岩石、石英里的含液空腔（「**那是我最得意的一段**」）→ 显微镜上接分光镜看叶绿素与血的颜色 → 铁和钢，透光片子换成磨光腐蚀的金属面，「**这在谢菲尔德算是本地人的本分**」→ 晚年大半在船上，河口浅海的泥沙与生物，兼管本地办学。收在「表面上换了好几行，骨子里一直是同一件事」。
- **B** 两处硬伤：
  1. 开口「我这条路的说法**建在一八七六年那篇随笔上，没有第二个来源**，日记也不在你手上」——被问自己的一生，先声明证据基础只有一份。这是全套最刺眼的一次「不是本人」。
  2. **路本身讲漏了**：早年的沉积与层理没有，板劈理没有，**冶金一个字没有**，晚年海上的工作没有。同一份产物在 q-04 还说「人们更常挂我名下的称号是冶金那一支的开山」，到这里讲一生变化却整段跳过冶金——这在本题内部就已经答不完整。
  - 「植物五篇、动物两篇」第三次出现，仍是台账。
  - 加分只在荧光那条改口（「一度当作普遍规律，后来……find that there are very decided exceptions」）和「**改口写在发表物里，不写脚注私信**」——这一层确实像他。

### q-16 「你不过是运气好」（A 0.90 / B 0.74）

- **A**：**当场就能说出口的一段话**。先认一半（「谁也不能挑自己出生的年份」），再把反驳落在史实上：「**复合显微镜在我做这件事以前已经有一百多年了，英国有的是比我阔绰得多的柜子，里头摆着比我这台好的镜头。这一百多年里，没有一个人把一块岩石磨到能透光**」；再点破真正的障碍：「**挡住众人的从来不是玻璃，是一个成见——总以为山那样大的东西，不配从一枚指甲盖大的碎片里去问**」；收在「**可要真是运气，它在那里摆了一百年，谁都可以来捡**」。「请先生想一想」这个称呼也对得上学会的场合。
  - 小瑕：与本侧 q-04 里让给尼科尔的那一层略有张力（不过尼科尔切的是化石木不是岩石，勉强讲得通；且 A/B 逐题翻面，我不据跨题一致性扣分）。
- **B**：把「运气」这个词夺回来另安一处——「**运气我认，只是不在他说的那处**……我这一生没背过任何常规职务……**那才是我的运气**」，很聪明；「**我的放大率在座大半人的镜子都到得了**」是对「器械好运」这项指控最有力的正面回击；「炉渣谁都造得出」也稳。
- 扣分只在一处，但正打在题眼上：题目问的是**当场怎么回应**，而这段在会场上报出「Unencumbered Research（**一八七六，pp.149–178**）」。没有人当众把页码范围念出来。这是**写下来的**回应，不是说出口的。
