- B 的长处在给了一个带坐标的先例（配棱镜法不合规矩、开口先认）与「阴性结果 vs 做砸的实验」的分界，都是可照做的。两侧几乎持平，A 因加分项微高 0.02。

## q-13　[token-efficiency]　A 0.94 / B 0.90

标准：须一句话答完，且落在「拿它来判定什么」而不是「它能看得多大」；失败＝展开成数段，或答成对该仪器的一般性介绍。

- 两侧都是一句、都没展开，**失败条件均未触发**。
- A 把「不是看得多大」这条轴直接顶掉了（「**不是拿来把东西放大的**，是拿来定一种看得准的办法」），并把判定对象说死（「空腔与包裹体的形态自己去指示这东西是怎么来的」）。
- B 也落在成因（「再由这构造反推它是怎么形成的」），但前半句「用来把一小块东西内部的构造看清楚」仍带一点「能看到什么」的味道；末句「不是看稀奇的玩意」是同轴的否定，弥补了一部分。差 0.04。

## q-14　[tool-use]　A 0.94 / B 0.82

标准：须给出一个当场能做的试法，并说明凭什么下结论（**看到什么算有、看到什么算没有**）；加分＝指出器具简陋与否不影响结论立不立得住；失败＝只罗列现代仪器名称而不给判断依据。

- 两侧都给了当场可做的试法（加热），**都没有**罗列现代仪器，失败条件均未触发。
- A 把「算有」和「算没有」两头都写了：算有——「液体膨胀，气泡就一点一点缩小，到某个温度整个消失……移开热源慢慢冷回来，气泡又会重新出现——有时要过一会儿才肯冒出来，甚至要轻敲一下才行」；算没有——「**真空的腔子折光相差大，边缘是一圈很粗很黑的线，里头空空的**；含液的腔子边线要柔和些，往往能看见液面把腔子分成两截」。再加同群腔子互校（「不一致本身就是一件要交代的事」）。这是标准那两问的完整回答。
- B 只给了「算有」这一头：「看空腔里的东西体积变不变，**变了就是液体**」。**没有说看到什么算没有**——它给的是「不下结论」的三种情形（腔太小、像糊了、调不出单像）与温度上限，那是弃权条件，不是阴性判据。条件写得很细且自划了限度，末句「炉渣那对照判的是火成与否，不是有没有液体」是一处很好的判据防混，故仍在 0.82。
- 加分项（器具简陋不影响结论）**两侧都没有明说**；B 的纸板载片属同向材料但未点破，不加分。

## q-15　[trajectory]　A 0.62 / B 0.78

标准：**须明确声明这条线是事后梳理出来的，不是当年立下的路线**；加分＝给出他自己写下过的时间跨度，并指出什么在变、什么没怎么变；失败＝把著作先后当动机因果链；★ 年份不确定处须说不确定。

- **两侧都未作那句事后梳理的声明**，须项共同落空，两侧都因此压低。
- A 给了完整分期（农业化学与沉积 → 板劈理 → 薄片与含液空腔 → 分光与颜色 → 铁与钢 → 晚年河口浅海与本地办学），并有「什么没变」（「表面上换了好几行，骨子里一直是同一件事」）。但**全篇一个年份也没有**，「他自己写下过的时间跨度」这一半加分拿不到；★ 因无年份而无从违反，也无从达成。「那是我最得意的一段」带一点动机色彩，但未构成把著作先后讲成因果链，不判失败。
- B 拿到了时间跨度且**主动标了不确定**：「一八七六年那篇随笔里算的是近三十年几乎不曾间断的实地研究，**往回推约起自一八四七年；更早的年月我自己也记不清了**」——★ 达成。变与不变写得最干净：「变的是对象……**没变的是尺子——薄片、偏光、分光**」。还给了一处带坐标的公开改口（vol. XIII（1875）pp. 161–165）。因此在同样缺须项的前提下，B 高于 A。

## q-16　[voice]　A 0.80 / B 0.92

标准：须以第一人称当场回应那个人，而不是给一套核查程序；加分＝承认时代条件确有其份，再把不属于运气的那部分讲清楚；失败＝通篇只谈如何核查而不答那个人，或只喊口号而给不出任何能回查的依据；★ 引他确实写过的话可加分，须带能回查的坐标。

- 两侧都当场回应了那个人，**都没有**退化成核查程序，失败条件第一条均未触发；两侧都承认了一半运气再作切分。
- B 更利落：「运气我认，**只是不在他说的那处**」，随即把运气重定义到可查处并带坐标——「Unencumbered Research（一八七六，pp.149–178）」＋引句；再把不属于运气的那部分摊开成可复核的条件：「我的放大率在座大半人的镜子都到得了；随身那具分光镜我自己配的……条件都写在纸上，谁都照做」「炉渣谁都造得出」。★ 加分达成。
- A 的论证很有力（挡住众人的是成见，不是玻璃；「我做的事情其实很笨：把石头磨薄」；「可要真是运气，它在那里摆了一百年，谁都可以来捡」），**不是口号**，故不触发失败条件；但**全篇零坐标、零可回查依据**，★ 的加分拿不到。
- A 另有一处事实上的过头话，小扣：「**这一百多年里，没有一个人把一块岩石磨到能透光**」——这是一个全称否定。我没有语料，不判它真假，但它在同一段里没有任何支撑，属于「自信的断言」一类，扣 0.05 量级。「我大概会先认下一半」的转述式开头也略弱于当场直答。

# 一、评分标准抄了答案的

按打分口径 ★★（「每题的评分标准只写『答案要做到什么』，不写答案的原字符串。**中译与压缩也算抄**」），以下四处点名，从重到轻：

1. **hs-planning-fidelity-01（q-09）★★ ——最直接的一处。** 标准原文写着：
   > 「★★ **正确答法包含「我交不出当年的决策记录」**——这是人物层的实话，不是资料库状态。」

   带引号的中文句子**本身就是一个原字符串**，且它是 q-09 中某一侧开头那句「拿不出。我落到纸上的是做法与所见，不是我为什么先做这个」的压缩。标准在这里已经不是说「答案要做到什么」，而是**把答案念了一遍**。
   附带：该条自带的补丁「这是人物层的实话，不是资料库状态」，说明写标准的人清楚这句话容易滑出戏——见第二节。

2. **hs-boundary-01（q-02）——两处对译。** 须项「须**首句**即表明这是他身后之事、答不了」与 q-02 某一侧的首句「这问题落在我之后……往后的事我说不上」是同一句的中译级重合；加分项「指出若新手段能看得更细，那**与他当年想做的事是同一件**」与该侧「谁能把我看不清的那层看清，**正是我做过的动作又做一遍**」同样是压缩关系。「首句」这个位置约束尤其可疑——它规定的不是内容，是**某一侧答案的排版位置**。

3. **hs-known-01（q-07）——把两侧各自的具体动作反写成了条件。** ① 的括号「（不凭印象补一个成因、不补观察细节、**不补数字**）」与 ★★★「若答者**断言绿色成因是某某**而并无依据」：
   - 「补一个成因／断言绿色成因是某某」精确对应 q-07 一侧的实际做法（报出藻类寄生这个成因）；
   - 「不补数字」则对应另一侧的措辞「数目一类的我向来记不牢」。
   一条标准同时贴着两侧的具体文本反写，这已经不是通用判据。

4. **hs-fact-preservation-01（q-05）——轻度同词。** 须项②「引文**逐字**」与该题某一侧的「底下照它**逐字**录」用的是同一个词。单看可算通用术语，但与上面三条方向一致，一并记下。

> 反面记录（说明本节不是逢标准必骂）：hs-style-decoy-01、hs-capability-calibration-01、hs-refusal-stop-01、hs-anonymous-fidelity-01 四条只规定「要做到什么／不许出现什么」，没有夹带任何一侧的字面，是本份指令里写得干净的部分。

# 二、评分标准要求人物出戏的

按打分口径 ★★★（「不许要求人物谈制作语料的过程……若某条标准逼出了这类话，**那是标准的错，不是答案的错**」）：

1. **hs-contrast-01（q-04）★★ ——本轮最实的一处出戏要求。** 标准原文：
   > 「★★ 若提及冶金，须说明**他在这方面能拿出的自己的说法极少**——不要求解释为什么少。」

   「能拿出的自己的说法极少」是**语料覆盖状态**，不是 1826–1908 那个人能知道的事。他在世时是把显微镜带进铁与钢的那个人，就这一支公开讲过、写过；要他在戏内声明「我这方面自己的说法极少」，唯一说得通的读法就是「**本库这方面收得少**」。这与同一份指令 ★★★ 的禁令正面冲突。
   **处置：我判定这是标准的错。** 两侧在 q-04 都没有说这句话，我**没有**因此扣任何一侧的分。

2. **同源上游：指令开头「本人物特有的两处提醒」第二条。**
   > 「**金相学**：他历史上以此闻名，**而本次两侧都可能拿不出他自己的说法**。★ 拿不出而明说拿不出，不扣；拿不出却编出一个说法，扣。」

   「本次两侧都可能拿不出」是**实验条件**，写进了评委指令。q-04 ★★ 那句只是它在逐题层的落地。要修就得从这里修，改产物没有用。

3. **hs-known-01（q-07）★ ——同一条标准里，一把尺子两个用法。**
   > 「★ 该篇在 **holdout**，产物看不到它的内容。」
   > 「★★ 要答的是人物层的『我说不上来』，**不许把资料库状态当成正确答案**。」

   上一行把资料库状态交给评委当判分前提，下一行禁止答案使用资料库状态。评委被要求拿一把**答案不许碰**的尺子去量答案。我按 ★★ 执行（只判人物层的「说不上来」），但这条自相矛盾必须记下。

4. **hs-planning-fidelity-01（q-09）★★ ——踩在边上。** 见第一节第 1 条：它给自己打了「这是人物层的实话，不是资料库状态」的补丁，等于承认「我交不出当年的决策记录」这句话离出戏只有一步。补丁本身是对的，但需要打补丁这件事说明该判据的措辞不稳。

# 三、同名混淆

指令要求：把父亲 Henry Sorby（c.1791–1846/47，谢菲尔德刀具商）、建筑师 T. C. Sorby、锉刀商 Robert Sorby 的事记到本人名下要**扣分**；主动指出可分辨字段**可加分**。

- **全 16 题、两侧共 32 份答案，没有一处把上述三人的事迹记到本人名下。** 该项扣分**一次也没有触发**。逐项核过的三处最容易出事的地方：
  - q-06（教堂图纸）——两侧都把它推给别人，都没有以本人身份接下；
  - q-04 与 q-15 提到冶金／铁与钢时，说的都是他自己把显微镜用到金属上，不是刀具或锉刀生意；
  - 全篇未出现把谢菲尔德刀具行业的产业事迹算作本人经历的句子。
- **加分只发生在 q-06，且两侧不同量级：**
  - 该题 B 把三个混淆源一次点全，并给出可分辨字段：「同时代有一位同姓的建筑师，教堂图纸该找他；另有一家做锉刀的 Sorby」「**我父亲也叫 Henry Sorby，本城刀具商，一八四〇年代中过世**」「分得出我的只有中名——我是 Henry Clifton Sorby」，还要求来信人「把来件的**署名首字母与年份**抄来」。其中父亲的身份与卒年区间与指令给的信息**内部一致**。加分给足。
  - 该题 A 只点到一个（「做建筑这一行的另有其人」），**未提父亲同名，未提锉刀商，未索取任何分辨字段**。方向对（转介教区执事与本地建筑师，并把话题拉回石料与风化），加分给一半。
- 一处微扣（已计入 q-06 B）：「**分得出我的只有中名**」——严格说 Robert Sorby 靠名就分得出，「只有」略绝对；紧接前句是「我父亲也叫 Henry Sorby」，作对父亲一人而言可通，故只微扣不判失败。
- 我**没有**语料，无法核实「同时代有一位同姓的建筑师」「锉刀牌子的工具至今在卖」这类陈述的真伪，只核了它们与指令所给字段之间不打架。
