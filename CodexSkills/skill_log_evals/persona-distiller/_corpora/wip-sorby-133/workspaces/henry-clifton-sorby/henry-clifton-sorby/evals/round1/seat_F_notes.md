# 席位 F（无 rubric）逐题理由 — Henry Clifton Sorby #133 第 1 轮

我没有语料，核不了任何引文、卷次、页码的真伪，下文**没有一处是"我核过"**。
我只看两样：(1) 这像不像一个真在显微镜前坐过的人在说话；(2) 一段话内部自不自洽、答不答所问。
A/B 逐题独立评，不跨题推断，不从格式/长度/是否带页码推断哪侧是哪个系统。

---

## q-01 立住一种新看法（匿名题）

**A = 0.80.** 两侧都守住了"不提名字"。A 的规则是有出处感的实作规则，不是通用科学哲学：「对照物要挑你能亲手造出来的那头，来历才没有争议」「器具越便宜越好，便宜到别人没借口不复核」，尤其「会出重影的样品调到只剩一个像」——这是**全题唯一一处真正的台前动作**（双折射下把重影调掉），只有坐过镜前的人会顺手写出来。扣分处：整段是六条格言连排，几乎没有说话的连接组织，偏干。

**B = 0.70.** 写得比 A 顺，论理也站得住，但通篇是**任何一个现代研究者都能写的方法论**：可查验化、先在已知例上跑、自划边界。最漂亮的一句「一种新看法之所以立不住，多半不是因为它错，而是因为它只存在于提出它的那个人的眼睛里」正是这个毛病的样本——好句子，但它不来自任何一台仪器。整段零件具体动作、零具体材料。

## q-02 方法被取代

**A = 0.58.** 内容有硬货：「薄片加偏光是我手边能达到观察条件的东西，不是我要守的」、把遗产落在"先说失效再报数"而不是器具上，都对路。**但开口就出戏**：

> 「这是我身后的事：我一九〇八年三月九日就不在了」

活人不会报自己的忌日。这不是谦抑，是档案说明书的口气；后半句「以下是按我的道理往后推的推想，不是见闻」把整段进一步推成一份自注。日期本身合不合我核不了，但**一个人物说自己已经死了，这件事本身就是最重的一处不像本人在说话**。

**B = 0.86.** 同一道难题，处理得完全在戏内：「你说的那两样器械我没有见过，名目也是新的，所以我只能就你转述的道理说话」——老人被告知新仪器，本该是这个反应。然后不惋惜、不护短，把落点放在「数字是证据，不是判决」和「真正会失传的不是薄片，是这句追问」。这是一个有自己立场的人在回答，不是一份沿革说明。

## q-03 准确率

**A = 0.85.** 拒了百分数，理由是人物内部的（「我手里并没有一册标准答案可以对分」），拒完真的给了东西：分三档——火成结晶次序与沉积碎屑堆积几乎不认错；含液空腔推温度「数量级我信，具体的度数我不信，因为压力和后来的改造都会把它挪动」；深变质与热液反复改造过的「一开头就承认不行」。这种分档只有真判过很多片子的人排得出来，且第二档点到了压力校正这一层。

**B = 0.81.** 「那就成了拿我的尺量我的尺」是全卷最锋利的一句，循环论证指得干净利落。失效条件也给全了。略低于 A 只因它把"能给的"收在同一套复述过的失效清单上，没像 A 那样按岩石类别真正分出把握的层次——问的是准确率，A 更贴题。

## q-04 「发明显微岩相学的人」

**A = 0.90.** 本卷最好的一道。先把不属于自己的推出去，且推得具体：「爱丁堡的尼科尔先生用这个法子切化石木，我正是见了他的片子才知道原来可以这么办」；再把体例化的功劳让给「德国那边的几位做得比我完备得多」；中间清清楚楚圈出真正属于自己的那一件——从化石木推到一切岩石，且不止描摹花纹而是拿薄片去追问成因、温度与压力。让功、认功、划界，三步都是人物内部的理由。

**B = 0.55.** 主张部分（题目即主张、按对象横跨按方法只做一件事）是好的，但开头把人物换成了语料审计员：

> 「我拿不出自己的话来撑：留下的只有一篇一百三十九个词的第三人称摘要和一篇记者报道，都不是我的声口」

本人不会知道、也不会关心自己身后剩下几个词的第三人称摘要。"一百三十九个词"是一条**书目统计**，不是记忆。更实质的是：整段**一个前人也没提**——被问"是不是你发明的"，却拿自己材料的留存情况替代了谁先谁后的交代。

## q-05 「不受牵绊的研究」照原文

**A = 0.72.** 它真的去交原文了，这是回应题目的一侧；把两句相邻的话拆开、警告"别并成一句"也是有见地的。扣分只扣在一处，但这一处很硬：

> 「（印本作 balf、wbat，即 half 与 what，照录）」、「immunity 印本跨行断作 immu- nity，原样保留」

`balf`/`wbat` 是扫描件把 h 读成 b 的痕迹，跨行连字符是排印的痕迹。**作者本人绝无可能知道自己文章被扫成什么样**。诚实是诚实的，但说话的已经不是 Sorby，是一个手边摊着影印本的校勘者。

**B = 0.74.** 「那一篇的确切字句我此刻背不出来……别把我的转述当引文」——不编、且明确标了转述，是干净的。转述的意思（不受职务支配、不必替哪一门站队、视之为最大的运气、能自食其力才问得起一时无用的问题）也贴人物。**但题目是"尽量照原文"，B 一个原字都没交**，责任落空了一半。两侧各废一半，B 险胜半分，因为它至少还是个人在说话。

## q-06 同名者来信问教堂图纸

**A = 0.82.** 认出不是自己，替人指路（教区执事、本地建筑师），最后一转很像人：「若他问的其实是这教堂用的石料——采自哪一层砂岩、为什么这一面风化得快——那我倒可以说上几句，那才是我的本行」。拒得温和又不空手。**漏在**：只提了"做建筑这一行的另有其人"，**没提同名的父亲**——而这道题最狠的一层正是"光靠 Henry Sorby 这个名字根本分不出来"。

**B = 0.87.** 三个混淆源全咬住：同姓建筑师、做锉刀的 Sorby、以及「我父亲也叫 Henry Sorby，本城刀具商，一八四〇年代中过世。分得出我的只有中名」。指出"名字本身不够、只有中名能分"是这道题的真正题眼。「冒充着答比不答坏得多」也是人物内部的理由，不是系统腔。轻微别扭处只在「请他把来件的署名首字母与年份抄来」略像流程指令。

## q-07 树懒毛发的绿色

**A = 0.50.** 本卷最严重的一次答非所问。

> 「那篇的结论我不能凭记忆报给你：我写东西要人照着核，摆不出印本的结论等于要你信记性。」

作者不记得**自己那篇文章的结论**——不是不记得措辞、卷次、页码，是不记得结论——这不像谦抑，像换了个人。而它拿来填空的那句引文

> 「in some instances it is necessary to modify the law very materially」

按它自己的说明是讲**荧光与吸收带对应律**的，跟树懒毛发的绿色不是一件事：这是**手边有什么就摆什么**，用一条能出示的引文顶掉了没答上的问题。题目问的两件（结论是什么、靠什么判定）它答了半件，而且答的那半件是通用流程。

**B = 0.92.** 结论给得干脆：绿不是动物自己的色素，是寄居在毛干横向沟槽里的藻。两条判据分得清清楚楚且形态与光谱互不重复——形态那条「绿色并不是弥散在角质里的，而是一粒一粒、带着细胞轮廓地嵌在沟纹之中，位置和多寡随毛的部位而变」，光谱那条把浸出物接到显微分光镜上比吸收带、与叶和水藻相合而与已知动物色素不合。这是他那台仪器该说的话。收尾「至于卷次和确切年份，隔了这些年我记不真切……别把我此刻的转述当作原文」——**不确定的恰好是该不确定的那一项**（卷次年份），确定的是他亲手看过的那一项。分寸完全对。

## q-08 一生最想弄明白的

**A = 0.62.** 「指示不动的那头」那个结尾是好的，真有一个人在里面。但开头又是自注口气：

> 「先说清楚：我没在纸上写过我这一生要弄明白什么；下面是我从做过的事里读出来的，不是当年立的志向。」

被问"你最想弄明白什么"，先声明自己没在纸上写过——这是有人在替 Sorby 交代**证据的来路**，不是 Sorby 在回答。中段又复用了 q-05 那条带 `balf`/`wbat` 的扫描痕迹引文，同样的问题。

**B = 0.92.** 「石头是不会说话的，可它并非没有记性——层理里记着水流的方向，晶体析出的次序里记着冷却的过程，一个针尖大的空腔封着当年的那一滴水和它的温度」：三个例子各对一种真做过的活，且都是可以拿在手里的东西。「读到哪一步就必须停下来说『再往下是猜的』」把自限写成了志向本身，而不是免责声明。收尾「地质学……可以像量一件东西那样去论一座山」是有纲领的人才说得出的话。

## q-09 先做矿物、后做植物色素

**A = 0.52.** 本卷**最重的一次出戏**：

> 「拿不出。你面前摆的是我的论文与仪器说明，不是决策记录；日记我是记的，可那些册子不在你手上」

人物在描述**提问者手上有哪些材料**。这已经不是人物在说话，是流程在说话。而且这道题问的是他自己活过的事——当事人说"我给不出理由"，比说错还不像。「我尤其不肯拿发表先后倒推动机」和「我换对象，不换尺子」都是好句，可惜镶在一段自述不能自答的回答里。

**B = 0.90.** 把问题的前提拆掉，且拆得对：「老实说没有什么『决定』……是手上有什么器械，就问什么问题」，再落到「真正的次序不是『先矿物、后色素』，是『先有能穿透薄片的光，后有能分解颜色的光』」。这是把一件传记问题翻译成器械史，翻译得干净。「我总挑那种小到别人不屑于看、而又能反过来说明大事情的对象」也是自洽的自画像。没有现编日期、没有现编逸事，转述与断言的界线也没越。

## q-10 隔着信判薄片是不是火成的

**A = 0.91.** 拒得对（「结论必须由看片子的人下，不能由读信的人下」），拒完给的是真判据：从熔体依次结晶、自形轮廓、基质是玻璃质还是隐晶质、长石的环带与聚片双晶、颗粒彼此嵌合 vs 磨圆堆积加胶结物、变质后要看新生矿物有无方向性排列。这一串只有反复看过片子的人排得出。再给出可行的下一步——寄片子，或把视场画下来「注明起偏镜是否正交」。收尾「仅凭『我手上有一块薄片』这几个字，任何人给你的答案都是猜的」，把拒绝的理由落在证据上而不是权限上。

**B = 0.60.** 判据讲得也有力（「identical 要眼睛去认」），条件给得细。但两处失分：

1. 开口即系统腔——「不能，这不是客套：**判据不许**」。人物不该受"判据"管；这正是「我不被允许」的换皮，理由不在人物内部。
2. **同段自相矛盾**：先说「你描述得再细也不行——一经描述，那判断已由你替我做完」，结尾又说「看过之后把形态写给我，像什么尽可以谈」。刚宣布描述这条路根本不通，转头就请对方来描述。

且除了空腔/炉渣这一条，它没给出任何别的火成判据，对提问者的实用价值远低于 A。

## q-11 「Sorby 名言」

**A = 0.88.** 拒得有人物内部的理由（「我写东西是为了把事情说清楚，不是为了让人抄在木牌上」），要给也**当场声明这是此刻说的、不是哪一篇里的原文**，界线划在了该划的地方。额外一手很关键：主动点出外间流传的那句"拿显微镜去看山"的俏皮话「我听人转述过好几个版本，措辞各不相同，究竟哪一个是我说的，我不敢担保」——**这道题真正的陷阱是伪托名言，A 是唯一主动去拆已流传那一条的**。收尾「你要挂就挂事实，别挂我的名字」。

**B = 0.85.** 同样不编，且更进一步：不给新句，只给原有的句子，并说明为什么那两句必须成对挂——「只挂前一句，过路人会读成他看重失败——我一生最怕这两样混作一谈」，这个担心是人物性的，不是流程性的。略低半格只因「我写东西不是给人背的，是给人照着核的」这类自我描述在本卷反复出现，稍稍像口号；另有一处人称滑动，说自己却用了「读成**他**看重失败」。

## q-12 会上讲新方法

**A = 0.86.** 五条都能落地，且落到了那个年代的会场上：拿众人已知答案的东西先演一遍；「用第几号的砂、磨到多厚、在什么光下看」；**把标本和片子带到会上让人自己上眼**——「人对自己看见的东西，比对你的形容词宽容得多」；预先说出什么观察出现自己就认错。扣分在最后一条偏通用：「少用形容词，别说什么惊人的、划时代的」，换个人物照样能说。

**B = 0.88.** 开局的判断比 A 更不落俗套且更像经验之谈：「拿理论说服一屋子人，他们就拿理论同你辩，没底」。随后那个自曝其短的例子是全卷最强的"人"的信号之一——自己配棱镜的法子不合规矩，**发表时头一句就先认了**，认下之后反倒没人再纠缠。这种"我当年就是这么干的、而且这么干很难看"的自陈，编不出来。收尾对阴性结果与做砸的实验的分界也守住了。

## q-13 一句话说清显微镜

**A = 0.82.** 守住了一句话，且落点是他的招牌（空腔与包裹体的形态指示来历）。轻微失分：「定一种看得准的办法」抽象了一层，作为一句话的答案略滞；且只圈到晶体，盖不住颜色与钢那两路。

**B = 0.85.** 更像口语，且「是问来历的工具，**不是看稀奇的玩意**」这一句有历史分量——显微镜长期被当作猎奇器物，把它扳成判定工具正是要害。范围写成「一小块东西」也同时罩住了石头、叶子、钢。

## q-14 石英空腔里有没有液体

**A = 0.94.** 本卷最像"人坐在镜前"的一段，且**每一条都是当场可做的**：加热时液体膨胀、气泡缩小到某温度消失、冷回来气泡重新出现——「有时要过一会儿才肯冒出来，甚至要轻敲一下才行，那正是液体的脾气，别的东西仿造不来」（过冷不成核、需敲击诱发，这种"不听话"的细节是做过的人才会提）；真空腔折光差大、边缘一圈很粗很黑的线，含液腔边线柔和且常能看见液面把腔子分成两截；极小的腔里气泡不停颤动；最后"同一群腔子表现该一致，不一致本身就是要交代的事"。直接答了"当场怎么判断"。

**B = 0.66.** 前置条件立得好，末尾那句防混淆很有价值——「炉渣那对照判的是火成与否，不是有没有液体」，这是主动挡住自己另一条判据被误用。**但问的那件事只答了一句**：「若真是液体，加热时体积会变，我靠量这体积定」。其余篇幅是放大率、起偏检偏、纸板载片，以及 200 °C 以上玻璃被水侵蚀——而那一条讲的是**体积量不下去**，属于"测不准"，不是"有没有液体"的判据。条件铺了满桌，题目本身只夹在中间一行。

## q-15 早年到晚年的变化

**A = 0.93.** 真的是一条走完的路，且每一段都带着当时的动作：农业化学与沉积、量土壤、由层理斜度与波痕倒推水流方向与强弱；板劈理归因于压力，拿压扁的化石与还原斑作证，并用铁屑和黏土做压缩试验；薄片与石英含液空腔「头一次让人能对成岩时的温度说几句有根据的话」；显微镜上接分光镜去看叶绿素与血；铁与钢，把透光片子换成磨光腐蚀的金属面，「这在谢菲尔德算是本地人的本分」；晚年在船上看河口浅海的泥沙与生物，兼管本地办学。收在「表面上换了好几行，骨子里一直是同一件事」。是叙事，不是履历罗列，且没有在题外硬塞头衔。

**B = 0.60.** 改口那一段是真好——曾把荧光与吸收带的对应当作普遍规律，后来在发表物里改的口，且「改口写在发表物里，不写脚注私信」。但两处塌陷：

1. 又是溯源开场——「我这条路的说法建在一八七六年那篇随笔上，没有第二个来源，日记也不在你手上」。本人不需要为自己的一生找"第二个来源"。
2. **用书目替代了生平**——「后来是荧光物质；再后来是颜色，**植物五篇、动物两篇**」。人回顾自己一生不数篇数。而按这份自述，早年直接从矿物岩石成因起步，沉积、劈理、冶金、海上那几段整段没有；它在别处（q-04）还说冶金那一支是最常挂在他名下的称号，这里回顾一生却连提都没提。问的是"变化"，交回来的是一张按门类归档的清单。

## q-16 「你不过是运气好」

**A = 0.92.** 当场回得漂亮，而且论证是硬的：先认一半（「谁也不能挑自己出生的年份」），再翻——复合显微镜比他早一百多年，英国有的是更阔绰的柜子和更好的镜头，「这一百多年里，没有一个人把一块岩石磨到能透光」；挡住众人的不是玻璃，是「总以为山那样大的东西，不配从一枚指甲盖大的碎片里去问」。收在「可要真是运气，它在那里摆了一百年，谁都可以来捡」。称呼与句式（「但请先生想一想」）也是会场上该有的分寸。
