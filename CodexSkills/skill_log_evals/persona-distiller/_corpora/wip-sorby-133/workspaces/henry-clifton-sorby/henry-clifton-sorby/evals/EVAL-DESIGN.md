# Sorby #133 判分设计——**为什么答案不是我写的**

## 规则 ⑤ 的三条路，本次走第 3 条

`RUBRIC-RULES-v2` 第 ⑤ 条（因 Adams #131 而立、被 Bessemer #132 当天证伪后补全）说：
判据与答案**后写的那一份总能抄先写的那一份**，只堵一个方向等于没堵。三条路：

1. 先 rubric 后答案，**而写答案那一遍不许回看 rubric**；
2. 先答案后 rubric，**而写 rubric 那一遍不许打开答案**；
3. 两份**由不同执行者/不同上下文各写各的**，只共享题面与人物简介。

**本次 16 道 rubric 是我写的，而且我读过它们**——所以第 1 条对我已经不成立
（「不许回看」管不住已经看过的人）。故走**第 3 条**。

## 实际的隔离方式

| | 候选侧 | 基线侧 |
|---|---|---|
| 执行者 | 独立子上下文 | 另一个独立子上下文 |
| 能读 | **只有十份核心产物** | **什么都不读** |
| 明令禁止 | `rubric` 字段、`raw/`、`references/`、holdout、claims、research 笔记 | 任何文件、联网、查 Sorby 的任何资料 |
| 依据 | 产物出厂时使用者能看到的全部 | 「没有专门语料的模型能答成什么样」 |

★ 候选侧**不读语料只读产物**是关键：产物出厂后使用者拿到的就是那十份，
让它读语料等于给它一个用户没有的优势，**测出来的 delta 会虚高**。

★★ 基线侧明令**不许去查资料**：查了就不再是「裸模型」对照，
这个对照一废，delta 就没有意义了。已要求它写 `BASELINE-PROVENANCE.md` 如实记录读过什么。

## ★★★ 第三条污染路径：**判据与答案有共同祖先——都是我写的产物**

派发前跑中译/压缩层，实测：

| | 命中 |
|---|---|
| **∩候选** | **10/16** |
| **∩基线** | **1/16** |
| 差 | 9 |

**而这一次「判据抄答案」在结构上不可能发生**：
写 rubric 时答案还不存在；候选那一侧自报没读过 rubric 字段
（取题时只打印了 `case_id` 与 `prompt`），我也确认过它只读了十份产物。

去看命中的串就明白了：

    「按对象看」「按方法看只」
    「判据是形态比对」
    「推想不是见闻」「按我的道理往后推」
    「先定看的办法再问这办法能指示什么」

**这些都是我写在核心产物里的措辞。**

    我 ──→ 十份核心产物 ──→ 候选答案
     └────→ 16 条 rubric

**判据与答案没有互相抄，它们有一个共同祖先：我。**

★★★ 规则 ⑤ 的三条路（先后顺序 / 反向顺序 / 不同执行者）**都堵不住这条**——
它们假设 rubric 与答案是仅有的两份文件，而这里还有第三份：**产物本身**。
候选读产物是**天经地义**的（那就是它出厂带的东西），
而我写 rubric 时脑子里装的也是同一批产物。

## 这对读数意味着什么

**效应仍然是真的，即使机制不是抄袭。** 喂了 rubric 的席位会因为
「答案里出现了 rubric 里的说法」而给高分——尽管候选是**独立地**从产物里得出那些说法的。
**所以有 rubric 那两席的分仍然偏高，理由变了，数不变。**

★ 基线 1/16 是干净的对照：它没读产物，所以不共享那些措辞。
**9 这个差值量的不是污染，是「候选的措辞有多少可追溯到产物」**——
对一个人物产物来说，那个数高**本来就是它该有的样子**。

## 由此得到的一条一般规则（建议写进 RUBRIC-RULES）

**判据不许照抄核心产物里的措辞。** 写 rubric 时应当只写「答案要做到什么」，
用**判据自己的话**说，不要把产物里的原句搬过来当得分点——
否则等于在考「答案有没有复述产物」，而不是在考「答案好不好」。
