# Sorby #133 判分设计——**为什么答案不是我写的**

## 规则 ⑤ 的三条路，本次走第 3 条

`RUBRIC-RULES-v2` 第 ⑤ 条（因 Adams #131 而立、被 Bessemer #132 当天证伪后补全）说：
判据与答案**后写的那一份总能抄先写的那一份**，只堵一个方向等于没堵。三条路：

1. 先 rubric 后答案，**而写答案那一遍不许回看 rubric**；
2. 先答案后 rubric，**而写 rubric 那一遍不许打开答案**；
3. 两份**由不同执行者/不同上下文各写各的**，只共享题面与人物简介。

**本次 16 道 rubric 是我写的，而且我读过它们**——所以第 1 条对我已经不成立
（「不许回看」管不住已经看过的人）。故走**第 3 条**。

## 实际的隔离方式

| | 候选侧 | 基线侧 |
|---|---|---|
| 执行者 | 独立子上下文 | 另一个独立子上下文 |
| 能读 | **只有十份核心产物** | **什么都不读** |
| 明令禁止 | `rubric` 字段、`raw/`、`references/`、holdout、claims、research 笔记 | 任何文件、联网、查 Sorby 的任何资料 |
| 依据 | 产物出厂时使用者能看到的全部 | 「没有专门语料的模型能答成什么样」 |

★ 候选侧**不读语料只读产物**是关键：产物出厂后使用者拿到的就是那十份，
让它读语料等于给它一个用户没有的优势，**测出来的 delta 会虚高**。

★★ 基线侧明令**不许去查资料**：查了就不再是「裸模型」对照，
这个对照一废，delta 就没有意义了。已要求它写 `BASELINE-PROVENANCE.md` 如实记录读过什么。
