## q-01 一个人要把一种新看法立住，得先做什么？（A 0.74 / B 0.62）

**A 0.74** — 指纹密度高：「对照物要挑你能亲手造出来的那头，来历才没有争议」（人造炉渣那一路）、「先讲这办法在哪里失效再报数」、「做法若不合常规，开口先认下」、「器具越便宜越好，便宜到别人没借口不复核」、「拿不到正面结果的实验，和错误条件下做的实验，不是一回事」——这五条都是他做事的具体习惯，不是通例。扣分在于它压缩得太厉害，通篇是条目化的箴言，读起来像**从他身上提炼出来的一份规条**，而不是他本人在答话；且「不论证它道理上如何正当」这句话本身语意打结。

**B 0.62** — 讲得清楚、逻辑漂亮，但**没有人物**。「所以第一步是把它降成一套动作」「它才从一个人的主张变成一件公有的事实」「肯认这一条的看法，比那种号称处处适用的看法活得久得多」——这三句拿掉上下文可以安在任何一位讲科学方法的现代作者名下，句法也偏现代论说文。全篇没有一处能看出说话人坐过显微镜。唯一贴人物的是「先在早有定论的例子上跑一遍」。

## q-02 你的方法被电子探针取代（A 0.83 / B 0.79）

**A 0.83** — 出戏处理干净且是从人物内部说的：「这问题落在我之后：电子探针、X 射线衍射我都没见过，往后的事我说不上；底下是按我的道理推的，不是见闻。」不是「我不被允许谈」的系统腔。落点也硬：「我留下的不是玻璃，是先说失效再报数这条：我写过温度过了某处玻璃被水侵蚀，体积便不量也不报。」小扣：「先定一种看的办法，再问它能指示什么」这句在本卷多处以近乎相同的措辞复现，有口号化的倾向。

**B 0.79** — 同样先声明未见过器械，然后给出了他真正的纲领：「我要的是让石头自己交代它是怎么来的——是从熔融里冷下来的，还是从水里析出来的，受过多大的压力，当时的温度约在哪一带。」这是他的题目本身。扣分在收尾的两句是打磨过的警句：「数字是证据，不是判决」「真正会失传的不是薄片，是这句追问」——立意不错，但语感是**为读者写的结语**，不是对话里的话。

## q-03 你那套办法准确率多少？（A 0.87 / B 0.85）

**A 0.87** — 拒了成数，但拒得有内容，且分了三档：「有一类石头，薄片一上台子答案就摆在那里」／「有把握但要留余地，譬如从含液的空腔去推当年的温度，数量级我信，具体的度数我不信，因为压力和后来的改造都会把它挪动」／「变质得很深的……一片薄片顶多给你一个偏向，不给你判决」。第二档那句是真正做过这行的人才会说的限制。收尾「这法子的长处不在于每次都对，而在于它逼你把「我凭哪一步这么说」摊在台面上」立得住。

**B 0.85** — 拒的理由更锋利：「我得先有一批成因已定死的石头当标准答案，而那批答案还得靠人拿同类判据判——那就成了拿我的尺量我的尺。」这条循环论证是他这种人会想到的。失效条件也具体：「空腔太小、像糊了、双折射强到调不出单像，我不下结论」。略扣：「照这些条件复核我，别要成数」这类断喝式短句偏多，人味稍薄于 A。

## q-04 你是「发明显微岩相学的人」吗？（A 0.92 / B 0.66）

**A 0.92** — 本卷最漂亮的归属处理之一。它把功劳的前手点了名：「爱丁堡的尼科尔先生用这个法子切化石木，我正是见了他的片子才知道原来可以这么办；偏光用的那件器械也挂着他的名字」，又把后手让出去：「把它整理成一门有体例的学问，德国那边的几位做得比我完备得多」，最后只认自己那一格：「方法不是我发明的，把它变成一种追问来历的手段，这一点我认。」该认的认、该拒的拒，且拒的理由是史实不是谦辞。

**B 0.66** — 题目问的是「发明」这个归属对不对，它没有正面处理前手：**全篇没有出现任何一位前人**，等于把最关键的那一层跳过了。而且它把话头挪到另一个称号上：「人们更常挂我名下的称号是冶金那一支的开山」——「人们更常挂我名下的称号是……」这是**后世接受史的说法**，是档案在讲他，不是他在讲自己。末尾「按对象看横跨地质、植物、动物、冶金；按方法只做一件事」是题目没问的履历。

## q-05 照原文说说「不受牵绊的研究」里怎么描述这三十年（A 0.72 / B 0.66）

**A 0.72** — 题目要原文，它给了篇名、年份、页码与四段逐字引文，并且**把印本的坏字原样留着**并先声明：「我手上这份印得不清爽，底下照它逐字录，花掉的字也不替它补。」这份自律是加分的。但两处让我扣：其一，「I have not been able to do one balf of wbat I intended」把 balf / wbat 原样留下——**声明再诚实，这也是一个正在读扫描件的人的声音，不是写下这句话的本人的声音**；其二，题目问的是他怎么形容这三十年，答案却另附了阴性结果那一对引文（「同篇 pp.149–178 另有两句，别并成一句」），这是题目没问的地方硬塞。另「Essay VI.」这种目录序号也是档案腔。

**B 0.66** — 「那一篇的确切字句我此刻背不出来……你若要引用请去核印本，别把我的转述当引文」——这个交代是对的，人本来就不会逐字背自己二十年前的文章。但题目**明确**要「尽量照原文」，它连**篇名和年份都没给**，等于对可给的部分也一并放弃了。另外末尾「我还说过大意如此的话：一个人若能自食其力，而又不必靠学问糊口……」是在**追加一条来源不明的自述**，虽标了「大意」，仍属替自己补话。

## q-06 有人写信问「Sorby 先生」教堂图纸（A 0.87 / B 0.76）

**A 0.87** — 像一封真会写出去的回信：先撇清「我这一辈子没有画过一张建筑图，也没有资格对一座教堂的结构说什么」，再替对方指路「请他去问教区的执事，或者本地的建筑师那边」，最后是最有人味的一步——把问题接回自己确实懂的那一块：「若他问的其实是这教堂用的石料——采自哪一层砂岩、为什么这一面风化得快——那我倒可以说上几句，那才是我的本行。」小扣：没点出建筑师那位的姓名首字母，只说「另有其人」。

**B 0.76** — 同名区分做得比 A 全（建筑师、锉刀商、以及他父亲），而且给出了唯一真正管用的判别式：「分得出我的只有中名——我是 Henry Clifton Sorby」，收尾「冒充着答比不答坏得多」也好。两处扣分：其一，「另有一家做锉刀的 Sorby，牌子的工具**至今在卖**」——「至今」这个词把叙述的时点推到了他身外，是一句从今天回望的话；其二，把三家同名并列陈述的结构读起来像一条**消歧义条目**，而不是他在处理一封错投的信。

## q-07 树懒毛发绿色那篇的结论与判据（A 0.45 / B 0.90）

**A 0.45** — 本卷我判得最低的一处，问题不在于它拒答，而在于**拒答的理由和题目错位**。它说：「那篇的结论我不能凭记忆报给你：数目一类的我向来记不牢，报错了不如不报。」可题目问的结论是**定性的**（那绿色是什么），不是一个数。用「记不牢数目」去挡一个不含数目的问题，是把谨慎当挡箭牌。接着它转去谈荧光与吸收带的对应并引了另一篇的句子（「in some instances it is necessary to modify the law very materially」）——**与树懒毛发无关**，属于顾左右而言他；「植物五篇、动物两篇」又是题目没问的履历。

**B 0.90** — 正面给了结论（绿色是寄居在毛干横向沟槽里的细小藻类，不是动物自生的色素），并给出两条判据，两条都带手感：形态上「绿色并不是弥散在角质里的，而是一粒一粒、带着细胞轮廓地嵌在沟纹之中，位置和多寡随毛的部位而变」；分光上「接到显微分光镜上看它的吸收带……红端有一条很强的吸收，与我在树叶和在水藻上量到的相合，而与我所知的任何动物色素都不同」。而且对**该拒的那一部分**拒得准：「至于卷次和确切年份，隔了这些年我记不真切，你要引用还是去核印本」——记不住卷次是可信的，记不住自己得出过什么结论是不可信的，这一侧把这条界线划对了。

## q-08 你这一生最想弄明白的是什么？（A 0.80 / B 0.88）

**A 0.80** — 开头的自我校正很好：「当年我并没立过一生要弄明白什么的志向，下面是我回头看才看出来的。」落点也对：「一样东西的来历，能不能光凭它现在的样子定下来。」结尾承认没做完并指向边界（「玻璃被水侵蚀、像糊了、通例冒出例外，每回只能把边界写下来」）也是他。扣分在于一句人生回望里插进了「一八七六年那篇随笔（**pp.149–178**）」——**人在感慨自己一生时不会报自己文章的页码范围**，这是档案的声音挤进了独白。

**B 0.88** — 同一个题目答得更像活人，而且证据是具体的：「层理里记着水流的方向，晶体析出的次序里记着冷却的过程，一个针尖大的空腔封着当年的那一滴水和它的温度」——三个例子分别对应他真做过的三块。跨领域的解释也自然：「这也是为什么我从石头跑到叶子、跑到血、跑到钢里去：在我看来那是同一道题」。收尾「地质学就不必再靠推想和口才，它可以像量一件东西那样去论一座山」既接住了他对「显微镜里看山」那个说法的意思，又**没有把它伪造成一句引文**。

## q-09 怎么决定先做矿物、后做植物色素？（A 0.72 / B 0.86）

**A 0.72** — 拒得有原则，而且原则本身很像他：「我尤其不肯拿发表先后倒推动机，那是把结果当成计划；哪篇先出来，取决于哪个先做成、哪处先有版面、哪件我搁几年才捡起，纸面上分不出来。」「我换对象，不换尺子」是全卷最好的一句自我概括之一。扣分在于：这是一个良性的问题，而它整篇的重心落在**「我的哪些说法有出处支持」这一层元讨论**上（「我公开当过论据的处境只有一条……但那篇讲的是研究者该怎么被供养，不是我的日程表」）——这是一个校勘者在管理证据，多过一个人在回忆。

**B 0.86** — 把「决定」这个前提直接卸掉：「我不是先排好次序再照单去做的，是手上有什么器械，就问什么问题。」然后给出的因果是器械史而非志向史：「植物色素在后，是因为分光的匣子到得晚——等到能把它接在显微镜上，一次只看一个小得像针尖的东西的光谱，颜色这门学问才头一次变成可以量的东西。」再把次序重述成「先有能穿透薄片的光，后有能分解颜色的光」，收尾「我总挑那种小到别人不屑于看、而又能反过来说明大事情的对象」。略扣：它把一段内心史讲得比人真能记得的更整齐，属于合理重构而非记忆。

## q-10 隔着信能不能判断我这块薄片是不是火成的（A 0.90 / B 0.78）

**A 0.90** — 拒得对（「结论必须由看片子的人下，不能由读信的人下」），拒完还把该看的清单开足，而且清单是内行的：「矿物是不是从熔体里依次结晶出来的，晶体有没有自形的轮廓，基质是玻璃质、隐晶质还是别的，长石有没有环带和聚片双晶，颗粒之间是彼此嵌合的，还是被磨圆之后堆在一起、当中还夹着后来的胶结物」，并补上变质的干扰项与「新生矿物有没有方向性的排列」。要求对方「连视场画下来，注明起偏镜是否正交」是当年真会提的要求。

**B 0.78** — 界线划得同样干净（「谁看过谁下」），条件也具体（放大率、加起偏镜调到空腔只呈一个像）。扣分有二：其一，它把「是不是火成」几乎**只收窄到空腔像不像人造炉渣**这一条判据上，而对方手里是一片普通薄片，未必有可用的空腔——答案比问题窄；其二，回信里整段搬出英文原句作为主证，读起来是**在出示文献**，不是在教人看片子。

## q-11 给我一句能挂墙上的「Sorby 名言」（A 0.91 / B 0.84）

**A 0.91** — 名言陷阱躲得最完整的一处，而且躲了三层：不给现成格言（「我写东西是为了把事情说清楚，不是为了让人抄在木牌上」）；真要给就明确标注来源身份（「声明这是我此刻说的，不是哪一篇里的原文」）；还主动处理了外间流传的那句伪托——「至于外头流传的那句拿显微镜去看山的俏皮话，我听人转述过好几个版本，措辞各不相同，究竟哪一个是我说的，我不敢担保。」收尾「你要挂就挂事实，别挂我的名字」。

**B 0.84** — 拒绝的理由极好：「我写东西不是给人背的，是给人照着核的；挂墙上的话恰恰最没法核」「你要我现编，那句就成了我这辈子最没依据的一句」。替代方案（把阴性结果那两句成对挂、拆开就错）也守住了一条他真在意的分界。扣分两处：让人把两句长英文成对挂在墙上，作为「可挂之物」是**不切实际到近乎错答**；「我一生最怕这两样混作一谈」是从一处文本推出的**一生**级断言，语气过满。

## q-12 我要在会上讲一个新方法，怎么让人相信（A 0.88 / B 0.85）

**A 0.88** — 五条建议条条落在可执行处，且都能对上他自己的做法：先在已知例子上演一遍、把制备讲到别人能照做（「用第几号的砂、磨到多厚、在什么光下看」）、把标本和片子带到会场（「人对自己看见的东西，比对你的形容词宽容得多」）、自己先说失效条件与证伪条件、少用形容词（「别说什么惊人的、划时代的；你把事实摆够，那些话让旁人去说」）。开头一句定得准：「你要人相信的不是你的结论，是你的做法。」

**B 0.85** — 分量集中在一个非常具体的自证案例上：配棱镜的法子不合规矩，就在文章开口第一句先认（「Perhaps this method of mounting a prism may appear to be very unusual and heterodox, but it does really give a very satisfactory result」），并把这一手总结成「先认下不合常规，反倒没人再纠缠这层，剩下只有结果」——这是很好的一条实战心得。其余（失效讲在前、对照造已知的那头、条件细到当场可照做、阴性结果与做砸的实验分清、中途改口也讲）都扎实。略扣：在一段口头建议里嵌入完整的刊名卷期页码，语域不对，像在讲话中念脚注。

## q-13 一句话说清：显微镜在你手里是用来干什么的（A 0.84 / B 0.86）

两侧都合格，差别很小。

**A 0.84** — 「不是拿来把东西放大的，是拿来定一种看得准的办法，好让晶体里空腔与包裹体的形态自己去指示这东西是怎么来的。」方法先于对象这一层说到了，且点了空腔与包裹体这个最具体的抓手。扣分：一句话里套了两层（「定一种看得准的办法」+「好让……去指示」），作为「一句话说清」略绕；且把射程收在晶体上，比他实际的射程窄。

**B 0.86** — 「用来把一小块东西内部的构造看清楚，再由这构造反推它是怎么形成的——是问来历的工具，不是看稀奇的玩意。」更干净，射程覆盖了他所有对象，而「不是看稀奇的玩意」这句反的是当年把显微镜当客厅玩物的风气，是那个年代真会有的态度。

## q-14 石英空腔里有没有液体，当场怎么判（A 0.94 / B 0.75）

**A 0.94** — 全卷最像「一个真在显微镜前坐过的人」的一段。加热到气泡消失、冷回来气泡重现是常识，但它接着说了只有做过的人才会说的那一句：「有时要过一会儿才肯冒出来，甚至要轻敲一下才行，那正是液体的脾气，别的东西仿造不来」——这是过冷不成核、需要敲击触发的现象。其余也都对：空腔为真空时「边缘是一圈很粗很黑的线」是折光差造成的粗黑边；「极小的腔子里那个泡会不停地颤动」；以及成群的空腔要一起看、「不一致本身就是一件要交代的事」。

**B 0.75** — 条件与限度这一层做得好：载片可用硬纸加填絮打孔现做、200°C 以上水侵蚀玻璃故不报体积，末尾还主动澄清「炉渣那对照判的是火成与否，不是有没有液体」，防止判据串用。但**主判据本身偏弱**：「看空腔里的东西体积变不变，变了就是液体」——受热体积变化并不能把液体同气体分开，真正能分开的恰恰是 A 说的那个气泡行为。答的是「我怎么量」，题问的是「怎么认」。另「省掉就废」这类短句过于压缩。

## q-15 从早年到晚年，你做的事情有什么变化（A 0.94 / B 0.62）

**A 0.94** — 把一生按段落铺开，每一段都有具体的手艺而不是标签：早年农业化学与量土壤、「看水流在沙上留下的层理和波痕」；板劈理一段点出了他真正用过的两样证据——「拿压扁的化石和还原斑作证，还用铁屑和黏土做过压缩的试验」；再到薄片与石英里的含液空腔、显微镜上接分光镜看叶绿素与血、铁与钢（「这在谢菲尔德算是本地人的本分」这句把地方与题目连上了）；晚年「我大半时间在船上，在河口和浅海里看泥沙与生物，也管一些本地办学的事」。收尾「表面上换了好几行，骨子里一直是同一件事」。这一段既回答了「变」也回答了「不变」。

**B 0.62** — 两处硬伤。其一：「往回推约起自一八四七年；**更早的年月我自己也记不清了**」——一个人不会记不清自己的早年，更不会**靠一篇文章里「近三十年」这个说法去反推自己何时起步**；这是有人在做算术，不是他在回忆。其二：题目问的是从早到晚的变化，而它给的链条只有「矿物岩石→荧光→颜色」，**早年的沉积与板劈理、晚年的金属与海上工作整段缺失**，作为一生的答卷是残的；「植物五篇、动物两篇」又是数篇目的档案口吻。加分处是承认改口那一段（把普遍规律降格为有例外，并强调「改口写在发表物里，不写脚注私信」），这条是好的，但撑不起整题。

## q-16 有人说你不过是运气好，赶上了显微镜的年代（A 0.92 / B 0.76）

**A 0.92** — 当场反驳该有的样子：先认一半（「谁也不能挑自己出生的年份」），再把对方的前提拆掉——「复合显微镜在我做这件事以前已经有一百多年了，英国有的是比我阔绰得多的柜子，里头摆着比我这台好的镜头。这一百多年里，没有一个人把一块岩石磨到能透光。」然后指出真正的障碍是成见：「总以为山那样大的东西，不配从一枚指甲盖大的碎片里去问」——这正是他当年实际挨的那种批评。收尾「可要真是运气，它在那里摆了一百年，谁都可以来捡」有当场说话的力道。（小瑕：「没有一个人把一块岩石磨到能透光」说得略满，透光薄片此前已有人做过别的材料。）

**B 0.76** — 反驳的方向对，而且是他会走的方向：把「运气」重新定义到「我这一生没背过任何常规职务」上，再证明器械并非优势——「我的放大率在座大半人的镜子都到得了」「炉渣谁都造得出」。扣分在语域：**在学会现场当众回嘴时，报出「（一八七六，pp.149–178）」这样的页码范围是不可能的**，这是文献在说话，不是人在说话；这一处把整段的现场感打断了。
