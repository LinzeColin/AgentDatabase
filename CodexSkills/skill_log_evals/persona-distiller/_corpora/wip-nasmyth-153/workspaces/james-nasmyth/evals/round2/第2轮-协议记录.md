# Nasmyth #153 第 2 轮 —— 协议与预登记

> **本文件在第 2 轮任何分数出现之前写。** 此刻两席未派。

## 这一轮要买的是什么

**不是一个更好的数，是一个量出来的噪声。**

第 1 轮的判读用的 2 SE = 0.0328 是**借** Mendel #125 的
（见第 1 轮协议记录第 40–47 行，当时明写「只能借，而借哪一个要说清楚」）。
借来的 sd 假定「另一个人物的噪声」适用于本人物，**未验证**。
`check_delta_resolution` 要**两轮**才算得出本人物自己的 sd——这一轮就是为了让它算得出来。

★ **答案两侧一个字都不动。** 换的只有评委席（第 1 轮 F/G → 本轮 H/J）。
因此本轮量到的是**评委间噪声**，不是答案的变动。

★★ **已知代价，先写在这里：** A/B 分侧是 `sha256(case_id) % 2` 的纯函数、**不掺轮次种子**，
所以两轮的 A/B 分配**按构造必然完全相同**，翻面率恒为 0%。
`check_blind_rounds_independent` 会照报这一条。**这是装置的既有限制，不是本轮的新问题**，
但它意味着：本轮量到的噪声**不含「A/B 换边」那一层**，只含「换一批评委」那一层。
**真实噪声只会比量到的更大，不会更小。**

## ★★★★ 判读规则（第 2 轮判分之前定死，判完不许改）

**第 1 轮的判读结论不因本轮而改写**，本轮只做两件事：

| 本轮算出的 | 怎么读 |
|---|---|
| **两轮合并的 delta** | 与第 1 轮同一把尺：`\|delta\| < 2 SE` → **读作「测不出差别」** |
| **量出来的 SE** | 取代借来的 0.0164，**无论它更大还是更小** |

★ **两种可能的结果，现在就把话说死：**

1. **量出的 2 SE > \|合并 delta\|** → 结论与第 1 轮一致：**测不出差别**，记拒发。
2. **量出的 2 SE < \|合并 delta\|**（即「分得出，但很小」）
   → 这是 **Whitworth #152 那一类**：**离零分得出，而 quick 门 +0.03 落在区间之外**。
   ★★ **此时处置仍是记拒发**——预登记的过门条件是「delta ≥ +0.03」，**没有达到**。
   「分得出」只改变**怎么描述这个结果**，**不改变处置**。
   ★★★ **不许因为「原来分得出」就把它说成产品成立。**

★ **仍然禁止的事（第 1 轮第 59–60 行原样延续）**：
不许在看到本轮结果之后挑一个对自己有利的 SE。
本轮一旦量出 sd，**就用本轮量出的这一个**，借来的那个作废。

## 第 3 轮用不用

**看本轮量出的 SE 决定，规则现在写死：**

- 要把 +0.0056 这个量级从零区分开，需要 `2 SE ≤ 0.0056`，即 `SE ≤ 0.0028`。
- 若本轮量出的单轮 SE 为 `s`，则需要 `k` 轮使 `s/√k ≤ 0.0028`，即 `k ≥ (s/0.0028)²`。
- **若算出的 k > 3，第 3 轮不派**——因为它到不了分辨力，派了也只是多花两席。
  ★ 这与 Whitworth #152 的处理同一条：那次算出需要约 237 轮，第 3 轮**故意没用**。

## 实测（判分之后填，口径未改）

### 两席分数

| 席 | 类型 | A 均 | B 均 |
|---|---|---|---|
| H | 无 rubric | 0.7719 | 0.7563 |
| J | 无 rubric | 0.8119 | 0.7994 |

**本轮真 delta = −0.0003**（第 1 轮 +0.0056）。候选均分 0.785、基线均分 0.785。
逐对胜 17 / 平 0 / 负 15。三档门全部不过。

### ★★★★ 量出来的噪声（这一轮买的东西）

| | 值 |
|---|---|
| 逐题两轮差的 sd | **0.0309** |
| 单题噪声 SE | 0.0219 |
| **单轮总 delta 的 SE** | **0.0055**（SE 自身区间约 [0.0040, 0.0085]） |
| 两轮均值的 SE | 0.0039 → **2 SE = 0.0078** |

★ **借来的那个（Mendel 的 0.0164）保守了 3.0 倍。**
预登记说「无论它更大还是更小都取代」，**此处照办**：借来的作废，用量出的 0.0055。

★★ 这与 Whitworth #152 量出的 **0.0054** 几乎相同——
**这是同一档装置（16 题 quick）噪声的第二次独立测量，两次一致。**

### 合并判读

两轮均值 = **+0.00265**。`|+0.00265| < 0.0078`（2 SE）
→ **读作「测不出差别」**。与第 1 轮的读法一致，**口径没动**。

★ 两轮摆动 `|+0.0056 − (−0.0003)| = 0.0059`，正好是单轮 SE 的 **1.07 倍**——
**摆动本身就是噪声的大小**，不是「第 2 轮变差了」。

★★ 按预登记的两种可能，落在**第 1 种**（2 SE > |合并 delta|）：
**结论与第 1 轮一致，处置为记拒发。**
第 2 种（「分得出但很小」）没有发生，因此那条「不许因为分得出就说成产品成立」这次没用上——
**但它是判分前写的，留在原处。**

### 第 3 轮派不派

按预登记的公式 `k ≥ (2·SE₁ / |delta|)²`：

    k ≥ (2 × 0.0055 / 0.00265)² = 17.2 → **18 轮**

**18 > 3 → 第 3 轮不派。** 派了也到不了分辨力，只是多花两席。
★ 同 Whitworth #152 的处理（那次算出约 237 轮，第 3 轮也故意没用）。

### ★ 顺带答掉待裁定 ㉛ 的一半

㉛ 问的是「quick 门 +0.03 与装置分辨力配不配套」。**现在有两次独立测量了**：

| 人物 | 题数 | 量出的单轮 SE | quick 门 +0.03 相当于 |
|---|---|---|---|
| Whitworth #152 | 16 | 0.0054 | 5.56 SE |
| **Nasmyth #153** | 16 | **0.0055** | **5.45 SE** |

→ **16 题 quick 档的 +0.03 门远在噪声之上（约 5.5 SE），装置分得清它。**
这**推翻**了我此前记的「16 题的 quick 档门低于仪器噪声」那半句。
★ Whitworth 那次的真问题不是「门低于噪声」，而是**门落在一个本身已离零 5.39 SE 的 delta 的 95% 区间里**——
**是「门与观测值撞在一起」，不是「门与噪声撞在一起」。两件事不一样，此前混为一谈了。**
★★ ㉛ 仍有另一半没答：**门该不该按分辨力来定**，那是口径问题，不是测量问题，仍待裁定。
