# 为什么这两份挪到这里

`00-勘察记录.md`（抓源勘察）与 `00-抓取清单.md`（抓取记录）原先放在工作区根目录。
**它们里面有 holdout 那一篇的完整标题、卷期页码与日期**——
建模者打开根目录就能看见，等于把那道题的答案摆在他面前。

★ **发现它的不是判据，是我事后手打的一条 grep。** 当时 `check_holdout_mention`
报的是「✓ 没有字面提及，也没有内容重叠」，因为**它的扫描清单只列了十份产物正文**，
根目录里其它 `.md` 根本没被打开过。判据已改成「十份产物 + 根目录下一切 `.md`」，
改完立刻在同一份材料上报出「与 holdout 正文重叠 2 处」。

★★ **这两份没有删**——抓源的记录是资产，只是搬到建模者读不到的地方。
恢复方法：把它们移回工作区根目录即可，**但那要等 holdout 判分结束之后**。
