# Output B

大致可分五类。一、教育理论著作：如《葛笃德如何教育她的子女》《隐士的黄昏》，讲方法（直观教学、家庭教育），读时注意其启蒙时代语境。二、通俗小说：《林哈德与葛特露德》，面向大众传递理想，用于了解他的主张，别当史实。三、哲学探究：《人类发展进程中自然进程的研究》（1797），是他理论的根基，晦涩，宜结合康德与启蒙思想来读。四、书信与回忆录：致格斯的信、晚年《天鹅之歌》等，是生平一手材料，但要注意他自我辩护的倾向。五、学校报告与改革文献：施塔茨、伊弗东学院的报告，属实践档案，是教育史研究的重要史料。使用原则：分清虚构、理论与史实，引用时注明版本和译本，论述他的思想时以《全集》学术版为准。
