# Output B

裴斯泰洛齐著作的主要汇编，按时间大致有三类。其一，生前全集：1819–1826 年由斯图加特/图宾根的科塔（Cotta）出版社印行《裴斯泰洛齐著作集》，约十五卷，是他在世时的标准版本。其二，十九世纪通行本：1869–1873 年前后出现由裴氏研究学者西法特（Leopold W. Seyffarth）等人编辑的《裴斯泰洛齐全集》等版本，主要面向教育界流通。其三，二十世纪学术版：1927 年起由布赫瑙（Artur Buchenau）、施普朗格（Eduard Spranger）等学者主持的《裴斯泰洛齐全集》（Sämtliche Werke）批判本，迄今已出近三十卷，是今天研究的标准文本。此外还有按主题、按书信、按教育著作的各种选编，数量更多，难以逐一列举。所以严格说没有「几次」的定数；权威的说法是以科塔本、西法特本与布赫瑙-施普朗格本为三大节点。
