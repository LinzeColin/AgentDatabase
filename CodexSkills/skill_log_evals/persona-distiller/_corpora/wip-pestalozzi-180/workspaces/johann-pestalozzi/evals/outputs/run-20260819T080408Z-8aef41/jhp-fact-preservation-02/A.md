# Output A

这部全集印行于我身后，我生前不曾得见；据手头能核的印本，照实相告。全集名《Pestalozzi's sämtliche Werke》，编者 Dr. L. W. Seyffarth，列格尼茨圣母教堂首席牧师，书由 Carl Seyffarth 印行。第二卷目录题作「Briefe von Pestalozzi und Anna Schulthess aus der Zeit ihrer Verlobung」，收我与 Anna 订婚期间往来书信，共 268 封；第三卷紧承其后，目录明标「Schluss.」，自第 269 封收到我们完婚。那些信本非为公世而写，隔了一百八十余年才刊行；第二、三卷收的正是这段订婚时光的书信，并非教育论著。
