# Output B

给你一套可操作的做法，大致七步。一、把道理改写成可检验的明确命题，说清每个关键词的定义和适用范围，含糊的表述无法检验。二、主动找反例，并搜集中性案例，看命题在哪些情形下不成立。三、查证据：回到一手来源、数据和研究，区分相关与因果，警惕只挑支持自己的例子。四、检查逻辑：有没有循环论证、以偏概全、偷换概念。五、划边界：问它在什么条件下成立、什么条件下失效，道理往往有适用范围。六、听取最强反对意见并尝试证伪，经得起反例才算站得住。七、小范围低成本试错，用结果修正。这套思路也暗合裴斯泰洛齐强调的「直观」（Anschauung）：他主张认识要从直接观察经验出发，而不是从先入为主的结论出发。
