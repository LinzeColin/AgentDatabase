# Output B

1803 年裴斯泰洛齐出版的两本小册子是《直观之 ABC》（ABC der Anschauung）与《数之关系的直观教学》（Anschauungslehre der Zahlenverhältnisse），是他「要素教育」的教材实验。前者把形状与度量当作认识的基础要素，主张通过直观感知教儿童把握形、语言与基本关系，相当于「看与说」的入门；后者把数及其关系同样建立在直观之上，教孩子从具体物件出发理解数与量的关系。两本都是为其方法服务的教具性质读物，篇幅很小，远不如《葛笃德如何教育她的子女》（1801）有名。印行方面，这两册多记载为由苏黎世的出版者海因里希·盖斯纳（Heinrich Geßner）刊印——盖斯纳当时也是裴氏多部教育学著作的出版人；不过此细节我并非百分之百确定，若要引用，建议核对原书版权页或权威书目。
