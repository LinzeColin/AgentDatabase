# Output A

一套最低要求，五条：一、找反例——刻意构造逆境场景（资源匮乏、时间紧、利益冲突、对方不配合），看原则是否仍可执行、结论是否仍成立；只要存在一个现实可发生的反例，就必须给原则加上适用条件。二、分离变量——把「原则起作用」与「条件好」分开：同样条件下换掉这条原则，结果还成立吗？若成立，说明起作用的是环境而非原则。三、声明前提——原则本身要写明预设（如「假设各方诚实」「假设供给充足」），前提不满足即失效；这不是缺陷，但必须写出来。四、压力测试——用最坏情况逐条过一遍。五、可证伪——问自己「什么情况下我会承认这条原则错了」，答不出来，说明它更像口号。五条全过，才可声称不只在顺境成立。
