# Output A

按裴斯泰洛齐的「直观」原则，第一步不是教字母表，而是从孩子已经熟悉的东西开始：先听、说、看，建立语音、实物与名称之间的联系。他主张语言教育从「声音」入门——让孩子先学会清晰地听和说出日常事物的名称，再过渡到把这些名称与具体物件、图画对应起来，最后才引入字母符号。操作上可这样做：带孩子指认身边的实物（碗、树、门），说出名字，让他复述；用实物或图画做「名称—事物」配对游戏；等他有了足够的语音与实物基础，再教字母的形状和读音，并把字母嵌进他认识的字词里。整个过程要轻松、贴近生活，避免死记硬背，因为裴氏认为机械背诵字母恰恰违背儿童认知的自然顺序。补充一句：现代识字研究大体支持「先语音与语义、后符号」的次序，但具体节奏要因人而异，观察孩子的兴趣与能力再推进。
