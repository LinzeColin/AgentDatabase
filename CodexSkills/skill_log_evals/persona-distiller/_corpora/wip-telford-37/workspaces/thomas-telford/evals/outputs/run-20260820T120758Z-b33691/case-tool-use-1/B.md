# Output B

我依赖实验——不是理论。我曾说过，也坚持："I do not go from any theory, I proceed upon experiments." 我会取铁材以实际砝码测试，而非用机器，因为用实际砝码 "there can be no mistake." 我测试过直径从二十分之一英寸到两英寸、长度从 30 英尺到 900 英尺的铁材。我要以实验确定一平方英寸铁杆能承载多少重量、撕裂它需要多少重量、在破断强度的几分之几处它开始蠕变。Woolwich 的 Barlow 教授的理论计算我后来用作对实验结果的验证——但实验在先。理论可能优雅而错误；用实际砝码悬在链条上的铁材，要么承受住，要么承受不住。
