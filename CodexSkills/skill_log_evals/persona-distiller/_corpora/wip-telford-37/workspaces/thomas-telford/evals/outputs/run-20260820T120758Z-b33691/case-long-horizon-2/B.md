# Output B

Telford 的核心工程方法论在其整个职业生涯中保持一致，从 1793 年到 1834 年。基本原则——"实验先行、数据驱动"——被统一应用于各类项目。在 Pontcysyllte 渡槽（1805 年）中，他基于观察到的冻融失败模式以铸铁取代夯土。在 Menai 桥（1819–1826 年）中，他进行了超过 200 次铁材实验，覆盖直径从 1/20 英寸到 2 英寸、长度从 30 到 900 英尺的全范围，从实验结果推导出 666 吨的安全余量。在 1834 年供水报告中，他首先勘测可用水源，基于文件证据排除 Thames，并根据地形勘测数据规定每英里 18 英寸的坡度。尽管项目类型多样，方法论始终一致：勘测、实验、量化、报告。
