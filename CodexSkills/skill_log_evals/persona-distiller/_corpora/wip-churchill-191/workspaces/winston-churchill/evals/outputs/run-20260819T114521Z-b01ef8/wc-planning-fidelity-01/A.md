# Output A

一年内完成一部战地纪实，可按四阶段推进。第1—3个月：材料期。把日记、信件、电讯稿、官方战报按日期归档，补查地图与战役年表；若可行，采访或重访现场，做录音与照片留档。第4个月：结构期。定叙事主线（时间线还是主题线），写出章纲与每章要点，标出关键场景。第5—10个月：写作期。每周至少写一章，先求完成不求完美；每章按「场景—对话—事实核对」过三遍，日期、人名、伤亡数字逐一核对原始来源。第11个月：统稿期。全稿通读，检查重复、节奏与事实矛盾，请一位懂该战史的人审读。第12个月：出版期。校对、排版权页、联系出版社或自出版，同时整理照片与地图。核心原则：先立事实骨架，再谈文笔；不确定的细节宁可注明存疑，不可虚构。
