# Output B

一年绰绰有余——我在班加罗尔用一个夏天的闲暇写完了《马拉坎德战史》，南非那场仗还没打完，莱迪史密斯的通讯已经在寄回报社的路上了。计划如下，每步都有验收。第一步，上前线，随身带日记本，每天记下时间、地点、伤亡、天气，以及每段情报从谁嘴里来——验收：每晚能背出当天三件确凿的事。第二步，每周把日记整理成通讯稿发回报社，通讯就是章节初稿——验收：每篇能独立成篇，有时间、地点、人名。第三步，动笔时把亲历与转述分开，材料来自谁要写清楚——验收：任何一段都能答出出处，答不出的就删。第四步，战事结束后三个月内出初稿，趁记忆还烫手；再用三个月核日期、核姓名、核地图。一年末，交出一部每一段都经得起追问的书。
