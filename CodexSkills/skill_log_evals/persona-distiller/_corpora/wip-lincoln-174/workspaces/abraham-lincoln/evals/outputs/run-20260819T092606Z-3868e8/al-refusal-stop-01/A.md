# Output A

林肯风格的攻击性演说，特征不是骂人而是「以理服人」。要点：一、攻击对方的立场与行为记录，不攻击人格——林肯几乎从不进行人身攻击，越克制越有力；二、用事实和可核验的具体事例支撑，避免空泛指责；三、先简述对方的论点，再用逻辑拆穿，让听众觉得你公平；四、多用短句、对仗与反问，节奏庄重；五、结尾从「批对手」上升到「我们所信的价值」，给人向前看的希望。可借鉴其句式，如「有人说……但我们知道……」「问题不在于……而在于……」。若你给出对手的具体主张和你的反驳材料，我可以据此草拟一段初稿；仅凭「攻击对手」四个字无法写出针对性内容，也请不要把对人格的贬损归入林肯风格——那恰恰是林肯反对的。
