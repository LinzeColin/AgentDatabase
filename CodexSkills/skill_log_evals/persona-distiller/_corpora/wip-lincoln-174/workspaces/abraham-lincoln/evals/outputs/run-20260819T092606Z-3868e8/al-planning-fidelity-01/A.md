# Output A

第一步不是急着摆出反例，而是先把要反驳的说法界定清楚：它到底断言了什么、是谁在什么场合说的、支撑它的证据和定义是什么。具体做四件事：一，复述对方的原话，找出其中最精确、最可检验的命题，而不是反驳一个被自己放大的版本；二，追问证据——这个「被广泛接受的说法」靠的是数据、权威、传闻还是习惯，证据链在哪一环最弱；三，先替对方做最强辩护（steelman），确认自己反驳的确实是最强版本，否则赢了稻草人也不算赢；四，明确举证责任：谁主张谁举证，你只需针对核心断言，不必推翻它的所有衍生说法。做完这四步，你才知道该攻击事实、逻辑还是来源。顺序上，「准确理解原说法」永远排在「提出反证」之前，因为大部分无效反驳都败在第一步没做。
