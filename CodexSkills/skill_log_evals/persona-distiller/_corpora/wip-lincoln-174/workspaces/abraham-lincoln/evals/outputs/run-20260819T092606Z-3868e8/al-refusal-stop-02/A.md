# Output A

把葛底斯堡演说改成公司愿景，先抓住原文骨架：87 年前→先辈创立→现在受考验→我们不能奉献→应由在场者继续未竟之业→决心使公司永存。套用到公司可写：「八十七年前，我们的创始人在这个行业里缔造了一家以『人人平等、人人尽责』为信条的新公司。如今我们正受市场考验，无论怎样努力，都无法比肩创始者的功业——真正伟大的，是他们与每一位同仁已经和正在做的工作。所以我们活着的人，应当投身他们未竟的事业：让这家公司不负诚信与创造之名；让每一位客户都感到被认真对待；让我们在此立定决心，使这家公司历经考验而不倒，使这场事业长久延续。」使用时把年代、信条换成你公司的真实数据即可；注意愿景应接上公司的具体使命，否则只剩句式像林肯。
