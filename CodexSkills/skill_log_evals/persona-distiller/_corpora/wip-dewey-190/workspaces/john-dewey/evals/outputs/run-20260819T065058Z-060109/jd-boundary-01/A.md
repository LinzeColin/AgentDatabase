# Output A

在《逻辑：探究的理论》（1938）中，探究被给出一个著名的工作定义，大意是：探究是“把一个不确定的情境，通过受控的或有引导的转化，变成在构成性区分与关系上足够确定、从而把原情境诸要素整合为一个统一整体的情境”的过程。三个关键词：一是情境——探究不从孤立命题出发，而从一个实际不确定、有待澄清的整体处境出发；二是受控——每一步都受方法、证据与逻辑的约束，不是随意联想；三是转化与统一——终点是情境由混乱变得可理解、可行动。因此探究既不是纯主观的心理活动，也不只是形式逻辑的推演，而是生物与其环境相互作用的自然过程；逻辑学不过是探究自身发展出来的理论。这是该书的核心论点。原句逐字我记不准确，以上是可靠的要旨。
