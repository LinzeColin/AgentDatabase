# Output B

1928 年杜威确实访问了苏联，随后写成《苏维埃俄国印象与革命世界》（1929 年出版）。针对「去那种地方就该收集统计、堆材料、调查状况」的主张，他的处理方式是：承认此行是短期访问、所得是「印象」而非系统调查，明确不冒充统计式研究。他在书中反复强调观察的限定性——语言不通、行程受官方安排、时间短暂，因此呈现的是特定时刻、特定场合下的所见所闻与反应，而非对苏联社会全面可靠的状况判断。关于把握程度，他自己相当谨慎：用「印象」而非「结论」界定文本性质，并意识到所见经过筛选与安排。他同时警惕纯统计的局限——数字可以堆砌，却未必揭示制度如何实际运转、人们如何真实生活。所以他的立场是：不把印象当证据，不把数字当真相，坦率承认不确定性，只对「我看到并感受到什么」负责。这是研究伦理上相当清醒的立场。
