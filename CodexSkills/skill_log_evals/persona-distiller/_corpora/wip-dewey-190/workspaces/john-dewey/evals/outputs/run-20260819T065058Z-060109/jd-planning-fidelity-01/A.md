# Output A

一年改完课程表，先划掉不算的：这事不是把「探究」两个字写进各科大纲就算数。合格条件——一门师范课程要经过什么才算以探究为主：学生的起点是一桩他们自己卡住的疑难，而不是教师替他准备好的答案。计划分三段。头三个月不动课表，先让师范生把见习里真正解不掉的难题一件件写出来，翻成可供全班共同查问的材料；说不出的困难，就还没开始思考。中间五个月，把方法课改成围绕这些真实难题展开：要查什么、怎么查、查完如何验证，由他们自己定，教师只做质疑。末四个月，让师范生带着自己设计的方案回课堂去教，把结果带回班上复盘。指标不是讲了多少章，而是多少学生在见习里自己解决了一个起初不会的问题。教师的角色若不先从传授者改成共同探究者，改课表只会造出新的灌输。
