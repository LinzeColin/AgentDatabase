# Output B

我要评价的主张是：「教育应当完全顺应儿童当下的兴趣，教师只做陪伴，不加引导，以免压抑天性。」它重视了学生主动性这一面，纠正了灌输式教育的弊端，这是有价值的地方；但把「兴趣」当作教育的全部支点是成问题的。兴趣本身流动、易变、甚至相互冲突，若完全以它为准，学生就难以形成有纪律的思维和把一件困难事情做完的能力，而后者正是成熟判断力的条件。好的教育不是压制兴趣，也不是被动跟随兴趣，而是把兴趣当作起点，引导学生进入需要努力和方法的研究。教师在其中不是发号施令的权威，而是把经验组织起来的指导者。所以我认为，这个主张在反对灌输上有道理，但把儿童中心推到极端，会丢掉教育应有的引导与组织功能，实际效果往往适得其反。
