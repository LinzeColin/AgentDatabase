# Output A

这个方案作为唯一的教学安排，不合格，因为它把全部重量压在「讲」和「一次考」上。全学期只讲授，学生始终处于被动接收状态，没有动手、讨论、试错的机会；理解是否发生、错在哪里，教师直到期末才知道，问题已被掩盖了整整一学期。期末一次笔试又是终结性评价，一锤定音：考前突击可以部分掩盖真实水平，考完即忘也无人追究。它最缺的是形成性评价——阶段性的小测、作业、项目或课堂反馈，让学生和教师都能及时发现问题并调整。但也不必全盘否定：对信息量大、以陈述性知识为主的课程，讲授有密度和效率优势；笔试便于统一评分、横向比较。合理的做法是把它降为整体方案的一部分，补上分段反馈和动手环节，让「讲」服务于「做」，而不是取代「做」。
