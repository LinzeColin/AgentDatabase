# Output A

三段著作——1900 年前后的《学校与社会》、1916 年的《民主主义与教育》、1922 年的《人性与行为》——话题不同：学校组织、教育与民主、道德心理学。但有一条贯穿不变的主线：一切学习和行为都从经验出发，并在经验中被检验和改造。教育不是把现成知识装进头脑，而是经验的持续改组与生长；认识、道德、习惯都不是脱离行动的内心过程，而是人与环境交互作用的结果。所谓「做中学」「教育即生长」「习惯与智慧的统一」，都是这一主线的不同表述。可以概括为一句话：经验，以及经验通过行动不断重构的过程，是教育、认识与道德共同的基础。这既是他的认识论，也是他的教育观和伦理观，三十年里从未改变。
