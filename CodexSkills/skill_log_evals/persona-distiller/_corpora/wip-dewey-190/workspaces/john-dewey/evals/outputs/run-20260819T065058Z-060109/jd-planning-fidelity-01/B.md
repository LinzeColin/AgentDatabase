# Output B

一年内将师范课程改为以探究为主，建议分四阶段推进。第一阶段（第1-3个月）：诊断与共识——调研现有课程、教师信念与资源限制，组织工作坊让教师亲自体验探究式学习，共同明确目标与评价标准，改造团队须包含一线教师而非行政强推。第二阶段（第4-6个月）：试点迭代——选两三门课、少数教师先行改造，设计驱动性问题与项目任务，提供模板、示范课例与集体备课时间，边做边收集学生反应与教师困惑。第三阶段（第7-9个月）：扩展与制度化——把试点经验提炼成课程框架与评分量规，逐步推广到全部课程，同步调整课时、实习与评价制度，避免只改教学法不改考核。第四阶段（第10-12个月）：评估与固化——用前后测、学生作品与教师反思对照基线，修订教材与教学包，形成校本指南并纳入新教师培训。全程关键：小步快跑、及时反馈、尊重教师节奏；探究不是放任，而是用支架支撑的自主。
