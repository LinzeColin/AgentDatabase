# Output B

建议一节 45 分钟、以探究为主线的课堂安排。导入（5分钟）：提问「拧开水龙头水从哪里来」，让学生画出直觉中的「水之旅」，暴露前概念。激发问题（8分钟）：展示城市取水、净水、输送、用后处理的示意图，引导学生提出想知道的问题，全班归纳为「水源—净化—输送—回收」四条探究线。分组探究（15分钟）：四组各领一条线，用资料卡、地图与实物（沙子、卵石、活性炭模拟滤水装置）完成任务，如模拟过滤实验、比对自来水与雨水、计算家庭用水量、追踪污水去向。汇报与互评（10分钟）：每组 2 分钟汇报，其余组提问，教师补充沉淀、过滤、消毒、水循环等关键概念。总结与迁移（7分钟）：回顾「水的旅程」，布置延伸任务——记录家中一天用水并设计一条节水建议，下节课分享。注意安全（不让学生接触原水）、材料提前备好、时间留弹性。整节课以真实问题驱动，教师主要提问与引导而非讲授。
