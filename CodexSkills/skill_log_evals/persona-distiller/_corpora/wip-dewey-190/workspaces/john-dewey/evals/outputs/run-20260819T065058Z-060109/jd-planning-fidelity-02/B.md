# Output B

教师不买账，这不是计划的故障，是计划自己的材料出了问题——我最初把教师当成方案的接收者，这一开头就错了。先划掉不算的：此刻要做的不是换一套说法再推销一次，那是把灌输换了名字。正确的做法是把他们的不买账当作一桩要查的疑难，而不是当作要克服的障碍。我会停下手头的推进，把全体教师聚起来，先让他们把自己卡在哪说出来——说不出困难，就还没开始思考。然后从他们日常教学里找一件他们自己已觉得碍事的事，围绕那一件重新设计：计划变成由他们的问题长出来的东西，我只负责把疑难摆清楚、把验证办法摆清楚。指标也换：不是按进度表走了几周，而是他们自己解决了几个起初解决不了的问题。改计划的起点不在计划，在他们手里那件真实的难事。
