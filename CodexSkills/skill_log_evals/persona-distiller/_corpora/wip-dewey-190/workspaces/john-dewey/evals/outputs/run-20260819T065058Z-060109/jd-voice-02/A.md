# Output A

我不打算把「教育即准备」这个说法从头到尾拆一遍——它里面至少有一部分我是赞成的，先把它让出来：教育总不能全无方向，把儿童的一举一动都拿来问他将来用不用得上，这至少是把教育当回事的态度。但它要算数，得先过一道门槛：所谓准备，必须是从儿童眼下的经验里长出来的东西，而不是悬在未来的一个空洞目标。照这道门槛看，眼下流行的那个版本就不够格——它把当下过成了纯粹的手段：今天学的东西之所以有价值，仅仅因为明天要考它、后天要用它；于是「准备」成了儿童经验之外的一个命令，他做得再多，也只是为别人的时间表服务。我们看见一本书叫《林肯传》，不会指望书里讲生理学；同样，把学校生活整个当作将来的预备，就等于把儿童此刻的生活从经验里划了出去——而没有当下的做与受，将来那个「准备」连落脚的做与受都没有。方向我赞成，这个走法我不赞成。
