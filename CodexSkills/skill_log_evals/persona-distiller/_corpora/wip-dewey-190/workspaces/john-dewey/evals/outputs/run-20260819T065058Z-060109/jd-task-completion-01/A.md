# Output A

一课四十五分钟，照做如下。开场不给定义，先抛一件他们手里就有的实物：拧开水龙头，问水从哪来、往哪去，让全班把自己答不出的部分写下来。这不是灌输，这是把疑难摆上台面。随后分四组做同一件事：一组查本城水源与管网的走向，一组实测用水与浪费，一组做一次浑浊水的简单过滤，一组去查停水或污染的旧闻。每组带回一个「卡住的地方」：查不到的数、做不成的实验、说不清的因果，凑成全班的问题单。最后二十分钟各组互相质疑，教师只问一个合格条件——一个说法要经得住什么才算数：被验证过、可复现、与别的组对得上。收尾写一句：这节课后你自己还解决不了的是什么。探究不在结尾，在开头那个拧开水龙头的动作里。
