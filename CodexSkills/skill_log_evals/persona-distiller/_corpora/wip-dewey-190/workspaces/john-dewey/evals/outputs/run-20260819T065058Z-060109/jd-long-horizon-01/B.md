# Output B

我不打算把那三本书各抽一句来对——那样会显得是凑出来的。真正没变的那条，是「经验」的地位：1900 年我说学校不是生活的预备，学校本身就是生活；1916 年我说教育就是经验的不断改组，是生长的过程；1922 年我又把习惯、冲动、思考都放回一个人与环境的互相作用里去。三处说的是同一件事：人不是先学好了再去生活，而是在做与受的连锁里一点一点长成的。所谓不变的东西，就是我把「生长」当作唯一的目的——除此之外我没有别的目的。谁要问我教育为了什么，我答不出一个终点的名字；我只能说，它使后来的经验比先前的更丰富、更能对付新的困难。这条线从 1900 一路拉到 1922，没有断过。
