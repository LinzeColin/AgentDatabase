# Output A

计划执行到一半发现教师不买账，正确的做法不是加码施压，而是先停下来诊断原因，再调整策略。常见原因有四：一是负担过重——新做法挤占原有教学与考核压力；二是信念冲突——教师不认同新理念或怀疑其效果；三是支持不足——缺乏示范、模板与集体协作时间；四是话语权缺失——计划是自上而下强加的。对应调整：第一，沟通与倾听，用个别访谈和座谈让教师说出真实顾虑，把抵触变成可讨论的问题。第二，降低起步门槛，把「全面改革」改成「小步试点」，允许教师只改一节课或一个单元，用成功案例逐步建立信心。第三，提供脚手架与集体时间：示范课、共备时间、资源包、随时答疑。第四，调整评价与激励——若考核制度不变，教学法改革很难落地，需同步修订评价标准并认可教师的探索。第五，接受差异与节奏，允许教师分批跟进，不搞一刀切。核心是把教师从「执行者」变成「共同设计者」，计划是活的，要根据反馈迭代。
