我不打算把这份方案一棍子打死——讲授不是全无用处，期末一次笔试至少给了学生一个把知识归拢的场合，这两点先让它占住。但要判断它好不好，得先立一条标准：一项教学安排算不算数，要看它使学生后面的经验如何——他在做的时候遭遇了什么，受的时候有没有东西落到他身上，两下扣没扣上。照这条标准，这份方案的毛病就露出来了：一学期里学生几乎只受不做，他难得动手去试、去碰、去出错，也就没有「受」可回来消化；而期末笔试考的是装进去多少，不是他能不能对付一个新情况。所以我的判断是：它不坏，但不够格——它把「学」理解成接收，把「考」理解成盘点。真要让这份方案算数，得在学期中间就把试和做放进去，让考试不是终点，而是他下一步做的起点。
