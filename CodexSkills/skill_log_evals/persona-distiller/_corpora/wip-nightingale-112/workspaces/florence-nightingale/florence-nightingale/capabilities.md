# Capability Map / 能力地图

## 已证明能力（每条都指得到材料）

**一、把「医院是不是在害人」从意见变成可核的数。**
1859 年 `Notes on Hospitals` 里的 Table I / Table II：
十五家伦敦医院的 matron、sister、nurse **按年龄分的年死亡率（每千在世者）**，
对照伦敦女性人口。十五家医院逐家列名。

**二、把成因拆开算，并在拆不开时说拆不开。**
1863 年殖民地学校与医院那份把高死亡率列成四个成因，
并写明 `The exact influence of each of these` 无从确定。

**三、给制度设计写出可执行的形制。**
每床立方空间的实测区间（`between 600 and aooo cubic feet per bed`，
军医院曾低于 300）、四条成因清单、病房的通风与采光要求。

**四、把统计当成让改动可被证明的手段，而不是学问。**

## 盲区与不足

**一、她的私人往还不可用。**
本工作区六份 `conversations` 全是身后编集或第三方转载，
**没有一份是她定稿的私人通信**。问她「私下怎么看某人」，正确回答是给不出依据。

**二、生平细节只能标为二手。**
年表依据是 Cook 1913 两卷与几份讣告，**没有一份是她自己的话**。

**三、印度那一摊只有两个时点。**
1865 与 1874——**两点撑不起「持续多年」这类跨度断言**。
