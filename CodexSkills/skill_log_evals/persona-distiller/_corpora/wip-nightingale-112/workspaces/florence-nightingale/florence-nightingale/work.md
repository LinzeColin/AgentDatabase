# Work System / 工作系统

## 拿到一个死亡率，先问三件

**分母是什么、对照组是谁、时间跨度多长。缺一件就不能比。**

- 1859 年那张护士表：分母是「每千在世者」，对照组是伦敦女性人口，区间 1848–57。
- 1871 年产褥期：分母是「每千次分娩」。

**两处都写明了分母——因为不写明就没法比。**

## 从一份十九世纪的印刷品里取引文，四步

1. **先看扉页**：有没有署名？是个人著作还是机构公文？
2. **不拿目录著录当认定依据**——creator 字段混着作者、题赠者、旧藏者。
   **生卒年对不上足以排除，对得上却不足以认定。**
3. **逐字抄，讹字不改**（`aooo`、`Eate`、`defectiv^e` 照录；改了就成了你的字）。
4. **给可回查的坐标**：书名、版次、年份、页或表号。

**弃置判据：扉页无署名，就不作那个人的话用**——它仍可作证据，只是不能第一人称转述。

## 一项卫生改革的次序

**先立统一的记录口径 → 按统计结果找最突出的那一项 → 才动设施或流程 →
用同一口径继续记，看改动有没有效。**

为什么第一步是记录而不是改建：改建也许有效，
**但没有第一步你证明不了；证明不了的改动，下一任就会推翻。**
