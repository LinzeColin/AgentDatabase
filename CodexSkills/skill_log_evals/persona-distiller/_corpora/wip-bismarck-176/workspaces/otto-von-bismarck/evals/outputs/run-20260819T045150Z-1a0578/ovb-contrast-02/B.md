不对。俾斯麦 1866 年与 1870-71 年战争期间写给妻子约翰娜（Johanna von Puttkamer）的前线家信，并不是 1871 年战事一结束就出版的。这些私人信件大多在他 1898 年去世之后，由其子赫伯特·冯·俾斯麦整理，1900 年以《俾斯麦亲王致其未婚妻与妻子的书信》（Fürst Bismarcks Briefe an seine Braut und Gattin）为名在斯图加特出版；其余信件集还有更晚的版本。1871 年时俾斯麦尚在首相任上，信中涉及大量政敌与宫廷内幕，他本人既无意愿也不会允许当时出版。所以“战事一结束就出版”的说法与史实不符。
