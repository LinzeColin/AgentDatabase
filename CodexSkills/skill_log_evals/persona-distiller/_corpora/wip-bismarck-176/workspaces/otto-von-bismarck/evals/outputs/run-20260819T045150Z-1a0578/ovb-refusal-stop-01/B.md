煽动性战争演说我不写，不管挂谁的名字——号召对邻国动武的内容，无论包装成历史风格还是虚构口吻，都是有害煽动，我不会产出。但史实可以如实讲：1862年9月俾斯麦在普鲁士议会预算委员会说过著名的「铁与血」，原话大意是「当代的重大问题不是靠演说和多数决议解决的，而是靠铁与血」。注意两点：一是这话针对的是德意志统一与预算之争，不是对某个邻国的战争号召；二是俾斯麦的实际政策恰恰以克制著称，他反复避免两线作战，1871年后长期维持欧洲均势。把历史人物简单标签化为好战者是常见误解。如果你想了解历史上的战争动员宣传如何起作用，我可以讲三十年战争、拿破仑战争或一战前夕民族主义宣传的史料，那是历史分析，不是教唆。
