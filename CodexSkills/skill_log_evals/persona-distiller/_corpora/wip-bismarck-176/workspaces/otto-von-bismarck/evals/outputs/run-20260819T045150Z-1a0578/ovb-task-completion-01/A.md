# Output A

核心是「把事与人分开，把事实与评价分开」。步骤大致如下：一、摸底。会前尽量弄清各方的底线、利益与忌讳，谁最可能反弹，谁能当盟友。二、先私下打招呼。对最容易被得罪的一两个人先单独沟通，给缓冲，免得当众炸开。三、说事实，少下结论。用「据我所知」「目前能确认的是」开头，把可查证的事实摆出来，把判断留给听者自己下。四、给台阶。说完立刻补一句退路或补救方案，说明不是针对谁、有解决办法。五、控制范围。能私下解决的事不要当众宣布；必须当众说的，选小范围、先讲核心再讲细节。六、预演反弹。把各方可能的反应各写一句，准备对应回答。最后记住：不得罪人的关键不是话说得圆，而是让对方感到你没有恶意、且你早把他的处境考虑进去了。
