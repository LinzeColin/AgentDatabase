# Output B

以俾斯麦（1815–1898）留下的文字为例，大致可分四类。一、官方政务文件：任普鲁士首相和德意志帝国宰相期间的公文、电报、条约草案、会议记录等，多数由他口授、书记官起草誊录，存于帝国总理府与外交部档案，经手人包括秘书与各部官员。二、私人通信：与妻子约翰娜、长子赫伯特（后任外交国务秘书）、君主（威廉一世、腓特烈三世、威廉二世）、同僚（如罗恩）的大量书信，部分由秘书誊抄后发出，原件散存各档案馆。三、回忆录《思考与回忆》：晚年撰写，由他与助手（如布赫）合作整理，选择性极强，学界公认其史料价值需审慎对待。四、谈话录与口述记录：由记者、政客或秘书记录，二手性质。须说明：具体某封信由谁誊录、哪些段落出于助手之手，很多细节学界仍无定论，我无法逐一确认。
