# #176 Otto von Bismarck —— 抓源前必读（同名门实测结论）

## ★★ 这一位的同名风险与前三人**性质不同：危险来自同一家族**

`Bismarck (surname)` 页上，目标本人不在明细内（他有独立基础词条）。
但家族里有三名同姓政治人物，文书天然交织：

| 谁 | 为什么危险 |
|---|---|
| **Otto Christian Archibald von Bismarck**（1897–1975） | **他孙子，名字同样是「Otto … von Bismarck」，同为政治人物与外交官**。按「Otto von Bismarck」检索**直接命中**；且**卒于 1975，文书不在公有领域**——误取同时违反 PD 规则 |
| **Herbert von Bismarck**（1849–1904） | **他儿子**，同任国务秘书。**父子共署的公文与往还书信按姓氏检索必同时命中**；作品同为 PD，所以 PD 筛也挡不住 |
| **Gottfried von Bismarck-Schönhausen**（1901–1949） | 另一名孙子，卒于 1949，作品不在 PD |

## 选定判准

队列生卒年 **1815–1898**，4 名候选中逐位相同的**有且只有一名**。

## ★ 自著面：**维基条目没给书名**

该页只写他「retired to write his memoirs」，**没有给回忆录的书名，也没有给出版年**。
⇒ **本项目没有替它补一个书名**（补了就是编造）。抓源时按**实物题名页**确认，
  并把题名页原文记进 `authorship_evidence`。
