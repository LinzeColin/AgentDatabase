### ★ 判据第一版是我写错的，自测当场挂了

第一版把「谈人物」也写成关键词表，而
「后面每一笔都必须比上一笔贵。」这句关于人物的话不含表里任何词。
**靠关键词猜「这句是不是在谈人物」猜不准，而记账用语是封闭集合。**
改为取补集。**判一件事只判它能判的那一面。**

反向对照钉死：**塞入 20 个 claim 标记必须让 `payload_ratio` 下降**，
否则它又是一个「多挂几个 id 就达标」的代理量。

**不设阈值**——只有一个人物的实测值，不足以定线。现在拍的任何阈值都是编的。

## 七、已知缺口

1. **只测了一个人物、一个领域。** −0.1075 是 Livermore 的数，不是全库的数。
2. **只测了「单人物产物 vs 裸模型」，没测「团队 vs 裸模型」**——
   用户评分问的是后者，第 2 项还差这一臂。
3. **评委仍是同族模型。** 盲判缓解了归属偏见，缓解不了同源问题（第 3 项要解决的）。
4. **记账词表是手工的**，会随人物领域失准；它只用于报数，不参与任何判定。
