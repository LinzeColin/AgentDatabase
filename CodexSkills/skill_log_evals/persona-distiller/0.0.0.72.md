## 判据

发抓源指令前，满足其一：卒年 **< 1930**，或**已有探测产物**。

## ★★ 默认方向就是它的全部价值

**卒年缺失一律当「需要探测」，绝不当「可以直接抓」。**
反过来写，它就是一台**为省事而放行**的机器。

## ★★ 卒年必须带来源，否则不作数

**我不能凭记忆填年份。** 所以留的是入口不是表——
队列旁的 `_卒年.json`，**没有 `source` 的条目判据当它不存在**。

## 判不了什么

- **判不了探测结论对不对**——只判「探过没有」。
- **1930 是版权 95 年线的粗略代理，不是法律判断。**
  卒于 1930 年前的人也可能有身后出版的受保护材料，
  那由抓源方的 `rights` 与 `POSTHUMOUS` 去管。
