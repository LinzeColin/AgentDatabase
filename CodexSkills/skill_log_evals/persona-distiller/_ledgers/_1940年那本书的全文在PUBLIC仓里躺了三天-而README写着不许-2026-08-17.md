写成了 `Path(__file__).parents[1] / "_corpora"`，跑出来 **rc=4「扫描面是空的」**。

> 这道守卫是同一天早些时候在另一个判据上修的。

`_corpora/wip-livermore-100/README.md` 第 16–22 行：

> ## 二、★ 1940 年那本书**没有**放进来，必须自己重抓
> **原因是版权状态存疑，不宜随仓库分发**：该副本属 `opensource` 集合、
> 上传者标了 CC public-domain mark，但来源署 "Anna's Archive"，

**两条规则都写对了，两条都没有执行者。** [[a-rule-in-a-doc-has-no-enforcer]]

## 怎么进去的：一个 15,070 个文件的批量提交

    bfe16379a  2026-08-14  Rousseau 当样例真量了一次：91 份 train → 独立作品 57…

那次提交动了 **15,070 个文件**。这 5 份是被顺带卷进去的 ——
提交标题跟 Livermore 一个字都不沾。[[git-status-folds-untracked-dirs]]

> **★ 订正（同日晚）**：`bfe16379a` **没有父提交 —— 它是本仓的根提交**。
> 那 15,070 个文件是**初始导入**，不是日常开发里一次粗心的 `git add -A`。
> 提交标题写着 Rousseau，只是因为建仓那一刻会话正在做那件事。
> ⇒ 措辞要改：不是「被顺手卷进来」，是**建仓时它就在那儿，此后没人再看过**。
> 这一点对处置有影响：改写历史要动的是**根提交**，代价比改一个中间提交更大。

而远端 `LinzeColin/AgentDatabase` 实测 **`visibility=PUBLIC`、`isPrivate=false`**，
`git ls-tree origin/main` 确认 5 份**都在**。⇒ **公开分发了三天。**

## 判据为什么没拦住

`check_private_assets_not_public.py` 我每次推送前都跑，每次都绿。
读它：`PRIVATE_PATH_PATTERNS` / `INFRA_PATTERNS` / `CREDENTIAL_PATTERNS`
—— 三档全是**按路径或凭据模式**判「本仓不该有的**私有资产**」，
**没有「第三方在版权期内的全文」这个概念**。

> **它守的是「我们的秘密别外泄」，不是「别人的东西别乱放」。**
> 两件事都要，而只做了一件。[[every-requirement-needs-an-owner]]

## 处置

**已做**：5 份 `git rm` 出 HEAD（先按 sha256 备份到本机 scratchpad，不丢），
目录下留 `README.md` 写清为什么不能放、要用怎么办。已推 `ecd1715a7`。

**核实**（不是「我删了所以没了」）：
- 从备份的正文深处取 **6 条长句**当探针 ⇒ 当前 HEAD **0 命中**
- `git ls-tree -r origin/main` 该目录 ⇒ 只剩 `README.md`

★ **只删「像全文」的那 5 份。** 全仓另有 **14 个**文件含书名 1–2 次
（`research/01-writings.md`、`claims.jsonl`、`namesake_gate*.json`、
`experiments/gt_*.json` 等）—— 那是**正当引用**，一个都没动。
判别用的是**版权页逐字串**，不是书名。

★★ 我第一版的核验探针选错了串：拿 `COPYRIGHT, 1040, BY` 去 grep，
HEAD 上还有 **6 个**命中 —— 全是**引用那行当标记串**的工具与文档
（`check_authorship.py` 两份镜像、`split_book_1940.py`、CHANGELOG、
版本说明、工作区 README）。**又是「判据扫到了说明层」**，
换成正文深处的句子才是真的。[[my-checkers-are-mis-cut-six-times-in-one-day]]

## ★ 还有一半没解决 —— 只能由 Owner 定

移出 HEAD **只停止了往后的分发**。这 5 份**仍在公开的 git 历史里**
（`bfe16379a` 及其后每个提交，任何人 clone 都取得到）。三条路：

    A. 改写历史（filter-repo）+ 强推 —— **让所有已有 clone 失效**
    B. 联系 GitHub 支持请求清除
    C. 维持现状，只保证往后不再分发（**当前状态**）

**都不可逆或对外**，不由我定。已挂任务簿 #130。
