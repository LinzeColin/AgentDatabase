## 顺带查到的两个真缺口（这两个是台账层面的，可当场看见）

`nikolai-benardos`／`john-amos-comenius`／`adolf-martens`／
`william-chandler-roberts-austen`／`ignaz-semmelweis`。
他们既拿不到 A-* 证据，也没有替代的权威，**两头都空**。
Comenius 的研究门实测 rc=1、**34 条 unproven**。

★ 我先报的是「15 个里缺 1 个」——**那一次只扫了有 `HIS-OWN` 行的工作区**，

## ★★★ 第三层：`attribution` 有两代 schema，我按它做的**所有**统计只覆盖一半

修好工作区发现之后重跑署名 sweep：扫了 **54** 个工作区，**仍只量到 21 个**。
去看那 33 个为什么是 0 —— 它们的 `attribution` 栏里根本不是 `HIS-OWN`／`OTHER`，
而是**一整段归属理由**：

> `**整卷扫图，已切边界**：她署名的报告在第 250–729 行，末行 `CLARA··BARTON.`
> （第 728 行，双空格为 OCR 原样）。**第 60–249 行是 Dorence Atwater 的第一人称自述**……`

实测（`check_attribution_tier_consistency` 现在自己印出来）：

| | 工作区 | 行数 |
|---|---:|---:|
| 枚举型 `attribution` | 26 | — |
| **散文型 `attribution`** | **28** | **1,224 行（占全库 38.5%）** |

⇒ 凡是写 `attribution == "HIS-OWN"` 的过滤，对这 1,224 行**恒为假**，
而屏幕上看不出区别——**它们不是「没问题」，是「没被问到」**。

### 这一层影响了我今天报的哪些数

| 我报过的 | 实际射程 |
|---|---|
| 「`attribution` 与 `tier` 打架 **15 行 / 2 个工作区**」 | **只覆盖枚举那一半** |
| 「声称 P1 **1023** 份、有据 541（52.9%）」 | 只覆盖 21 个工作区（枚举 ＋ 有语料） |

| Brandeis「HIS-OWN 池里 32.0% 是 S1」 | **不受影响**（他是枚举型） |

### 处置

- **不改台账**（㊵ 冻结；且那 1,224 行的散文是**有价值的归属推理**，
  不是脏数据——Barton 那条写明了「第 60–249 行是别人的自述，绝不可当作她的话」，
  比一个 `HIS-OWN` 有用得多）；
- **改判据的说法**：`check_attribution_tier_consistency` 现在**先印两代 schema 的行数**，
  再印结论，并在文件头把「本件只判得了一半」写成第 0 条射程；
- ⇒ 以后引用任何按 `attribution` 算的数，**必须带上「只覆盖枚举那一半」**。

★ 这是同一天里**第三个**「集合比实况小」：① 路径 glob 漏 11 个工作区；
② 抽引文的正则长度下限漏掉短引文；③ 这一条，字段跨代换了类型。

## ★★★ 第四层：`attribution` 的**词表**也有两套，我比的那两个值只覆盖 40.7%

`build_source_ledger.py:61` 声明的合法值是**五个**：

    ATTRIB = {"HIS-OWN", "CO-AUTHORED", "THIRD-PARTY", "ATTRIBUTION-UNCLEAR", "OTHER-INVENTOR"}

而 **`OTHER` 根本不在里面**——数据里却有 108 行是 `OTHER`。
反过来，builder 声明的 `THIRD-PARTY`(4)／`CO-AUTHORED`(5)／`ATTRIBUTION-UNCLEAR`(1)
我的 `clash()` **一条都没在判**，其中 **`THIRD-PARTY` ＋ P1 正是本件要抓的那一种**。

全库 `attribution` 短值分布（3181 行）：

| 值 | 行数 |
|---|---:|
| （散文） | 1224 |
| `HIS-OWN` | 1184 |
| **（缺失）** | **655** |
| `OTHER` | 108 |
| `CO-AUTHORED` | 5 |
| `THIRD-PARTY` | 4 |
| `ATTRIBUTION-UNCLEAR` | 1 |

⇒ 改法：两套词表**取并集**，并把「他的话」（`HIS-OWN`）、「不是他的话」
（`OTHER`／`THIRD-PARTY`／`OTHER-INVENTOR`）、「中间态」（`CO-AUTHORED`／
`ATTRIBUTION-UNCLEAR`，合著与存疑配任一 tier 都讲得通，**有意不判**）分清。

**改完 15 行没变** —— 那 10 行中间态与 `THIRD-PARTY` 本身是自洽的。
这是个**闭掉的暗坑**，不是新发现的问题：以后若真出现 `THIRD-PARTY` ＋ P1，现在抓得到了。
