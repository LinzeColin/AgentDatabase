## ★ 我自己在这一轮里量坏了一次

    git ls-tree -r -l HEAD -- '*.txt' | awk '$4>20480' | wc -l   →  0

我据此差点写下「HEAD 上没有一个 .txt 超过 20 KB」。**那是命令坏了不是事实**：
`ls-tree` 的 pathspec 默认不跨 `/`，`*.txt` 只匹配**仓根下**的 `.txt`，一个都没有 ⇒
整条 pathspec 返回 0 行，`awk` 在空输入上当然数出 0。
不带 pathspec 自己筛，实数是 **68 个**。

**「0」出现的时候，先问命令看不看得见它。**
[[webfetch-truncates-and-reports-absence]]｜[[read-the-hits-before-reporting-the-rate.md]]
