# `emit_lane_scope --check` 对「**根本没有那一节**」的文件打绿

**2026-08-14**｜发现路径：修完 Comenius 的研究稿之后，顺手数了一遍
「六条道的研究稿里有几份带 `## Scope and assigned sources`」。

## 实测

    有六道研究稿的工作区 **39** 个
      六份全有 Scope 节（`--check` 真的在比）        **27**
      **一份都没有**                                 **4**
      部分有（比了一半，另一半静默放行）             **8**

对那 4 个（**六份研究稿一份都没有 Scope 节**）跑 `--check`：

```
$ python3 emit_lane_scope.py <robert-koch> --check
台账 121 行；道文件 6 份
Scope 节与台账一致，无需改动          ← ★ rc=0
```

Pasteur（台账 60 行）、Blackwell（95 行）、Lister 三人一模一样。
**它对着不存在的东西说「与台账一致」。** [[empty-default-swallows-unknown]]

诚实的话应当是：**「6 份里 0 份有 Scope 节 ⇒ 未检查，不是一致」**。

## 这让我今天早些时候报的那个数变得不准

我用它扫全库，报「**一致 32／过期 8**」。
那 32 里**至少 4 个是「什么都没比」**，另有 8 个只比了一部分
（Adams 2/6、Cicero 2/6、Shewhart 2/6、Bessemer 3/6、Coffin 3/6、
Rosenhain 3/6、Whitworth 3/6、Gantt 5/6）。
⇒ **真正被逐份比过的只有 27 个**；「32」把未检查算进了通过。
[[a-gates-scan-set-is-smaller-than-reality]]

★ 工具**写盘那一侧是对的**：它的自测里明写「没有 Scope 标题的文件**原样不动**」——
不擅自往手写文档里插一节，这是对的。**错的只是 `--check` 把「没得比」报成「比过了，一致」。**

## 本轮不改它（说清为什么）

- `quality_check.py` 里引用了 `emit_lane_scope`；改 `--check` 的语义
  等于**动一道接在合成门链条上的判据**，而用户 8-12 的批次指令写着
  「门、席位一概不动」；
- 改完必须全库回归（27 个现在绿的要确认仍绿，12 个会从绿变成「未检查」），
  **那不是今天能收干净的一趟**；
- 更要紧的是**方向**：改完之后会有 12 个工作区从「绿」变成「未检查」，
  其中 Koch／Pasteur／Blackwell／Lister 都是已入库或已判分的人。
  这类改动要在批次之间做，不是在移交当天做。

## 留给下一轮

1. `--check` 的输出与退出码改成三态：**一致 / 过期 / 未检查**，
   并把「6 份里 N 份有 Scope 节」印出来（分母摆在明面上）；
2. 那 49 份没有 Scope 节的研究稿，逐份定：
   **是该补一节（走机械导出）还是本来就该整份手写**。
   4 个「全无」的人（Koch／Pasteur／Blackwell／Lister）是同一批老工作区，
   多半是那一代流程还没有这件工具，属于**历史遗留**而不是有意为之。

## 复现

```bash
python3 - <<'EOF'
import pathlib, re
C = pathlib.Path("CodexSkills/skill_log_evals/persona-distiller/_corpora")
L = ("writings","conversations","expression","decisions","timeline","external")
for ws in sorted(p for p in C.glob("wip-*/workspaces/*") if (p/"references/research").is_dir()):
    mds = [m for m in (ws/"references/research").glob("*.md") if re.sub(r"^\d+-", "", m.stem) in L]
    if not mds: continue
    n = sum(1 for m in mds if re.search(r"^##\s*Scope and assigned sources\s*$",
            m.read_text(encoding="utf-8", errors="replace"), re.M))
    if n < len(mds): print(f"{ws.name:30s} {n}/{len(mds)} 份有 Scope 节")
EOF
```
