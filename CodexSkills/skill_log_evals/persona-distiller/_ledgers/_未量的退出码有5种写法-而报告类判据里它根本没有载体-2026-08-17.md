# 「未量」的退出码有 **5 种**写法 —— 而报告类判据里它**根本没有载体**（2026-08-17）

## 怎么问到这一步

修 `check_rubric_independent_verification_gate.py` 时，我把它的「未量」从 rc=0 改成 rc=4
（原来指错根也返回 0，调用方读成 PASS）。改完顺手问一句：
**这个 4 是仓里的约定，还是我自己定的？**

## 实测：76 个判据里，提到「未量／未核／未跑」的有 32 个

    用 return 4 ：**18** 个   ← 主流
    只用 return 1：**6** 个
    两者都没有  ：**8** 个

再逐条看那 6 个的未量分支，发现远不止两种：

| 判据 | 未量时说的话 | 退出码 |
|---|---|---:|
| `check_cases_match_generator.py` | 「工作树不干净——**未核验，不是通过**」 | **2** |
| 同上 | 「一个生成器都没找到——**未核验**，不是通过」 | **1** |
| `check_example_knuth_mirror.py` | 「有一侧不存在 —— **未核，不是通过**」 | **1** |
| 同上 | 「两侧都没有 .py —— **未核，不是通过**」 | **1** |
| `check_impossible_by_lifespan.py` | 「**未跑，不是通过**：读不到生年表」 | **5** |
| `check_one_ledger_per_workspace.py` | 「一份账本都没扫到 —— **未核，不是通过**」 | **0** |

**同一件事：0 / 1 / 2 / 4 / 5，五种。**

## 那个 rc=0 **不是缺陷** —— 我差点报错

`check_one_ledger_per_workspace.py` 的 rc=0 看着最像假绿：话说「不是通过」、
码说 PASS，而且我实测复现了（空语料目录 ⇒ 印 ✗、`rc=0`）。

**但它文件头自己写着**：

> 「动它要 Owner 定。本件把这件事从「看不见」变成「可复算」，**永远 rc=0**。」

⇒ 它是**报告不是门**，rc=0 是**明写的设计**。报成缺陷就错了。
[[checker-blindspot-read-as-defect]]

## 真问题在这儿：报告类判据里，「未量」**没有任何机器可读的载体**

「报告永远 rc=0」是对的 —— **发现的内容不该拦流程**。
但它顺带把**另一件完全不同的事**也压成了 0：

    「我量了，结果是这样」        → rc=0   ✓ 应该的
    「我**没量成**（扫描面是空的）」→ rc=0   ✗ 这一条被吞了

两者在退出码上**完全不可区分**，只剩散文里那句「不是通过」——
而消费者读的是 rc。本项目已有实测：`run_checks.py` 与
`report_expert_team_state.py` **都只分 `rc==0` / `rc!=0`**，
散文一个字也不看。[[empty-default-swallows-unknown]]

**⇒ 正确的形状（我在 `check_rubric_independent_verification_gate.py` 里已落地）：**

    0  量到了。**发现的内容永远不拦** —— 这是「报告不是门」的本意。
    4  **未量**：扫描面为空、根指错了、依赖读不到。
    ★ 「报告不是门」管的是**发现**，不是**没量成**。这两件事必须分开返回。

## 为什么本件不改那 6 个文件

1. **没有消费者能区分** 1 / 2 / 4 / 5 —— 现有两个调用方都只判 `!= 0`。
   改了当下**零行为变化**，属于可读性整改，不是修缺陷。
2. `check_one_ledger_per_workspace.py` 的 rc=0 是**明写的设计**，
   动它文件头自己说「要 Owner 定」。
3. 本项目的规矩：**没有实测代价就不动手**。上面 6 处我一处都没量到它造成过错误结论。
   （我自己那处**量到了**——所以那处改了。）

⇒ 本件把这件事从「看不见」变成「可复算」。要不要统一成 4，是一次
**跨 6 个文件的约定变更**，代价小但要一次做完、且要同时给 `run_checks.py`
加一列「未量」而不是继续和「红」混在一起。

## 可复算

    cd CodexSkills/skill_log_evals/persona-distiller/_ledgers/_pipeline
    python3 - <<'EOF'
    import re, pathlib
    four, one, none = [], [], []
    for f in sorted(pathlib.Path(".").glob("*.py")):
        t = f.read_text(encoding="utf-8", errors="replace")
        if not re.search(r"未量|未核|未跑|够不着", t):
            continue
        (four if re.search(r"return\s+4\b", t)
         else one if re.search(r"return\s+1\b", t) else none).append(f.name)
    print("提到未量的 %d 个｜return 4：%d｜只 return 1：%d｜都没有：%d"
          % (len(four)+len(one)+len(none), len(four), len(one), len(none)))
    EOF

    # 那个 rc=0 的复现（是设计，不是缺陷）
    T=$(mktemp -d); python3 check_one_ledger_per_workspace.py --corpora "$T"; echo "rc=$?"; rm -rf "$T"

命中 3 处；换成 `not (X or Y)` 又出 6 处（语义相同、写法不同）。
