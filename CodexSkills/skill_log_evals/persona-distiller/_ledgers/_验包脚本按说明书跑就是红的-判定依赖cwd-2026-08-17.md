# 接手方**照说明书验一个好包，会看到 ✗** —— 判定依赖 cwd（2026-08-17）

## 怎么撞上的

核 #87 那个待上传的移交包，用**封面信里写的那条命令**、站在交付目录里跑：

    cd _protected/agentdb-handover-20260814
    bash …/verify_handover_bundle.sh . --expect-tip bc7f4247…

    ✓ 包在（974369862 字节）
    ✗ git bundle verify 不通过        ← 这一行
    ✓ sha256 … ✓ tip … ✓ 真 clone 成功 … ✓ tip 与外部期望值
    ❌ 1 项不通过（过 7 项）

而我几分钟前在仓里跑**同一条 `git bundle verify`** 拿到的是 **rc=0**。

## 成因：一个字都没错，只是 cwd 不同

    在 git 仓里          rc=0
    在交付目录里（非仓）   rc=1  error: need a repository to verify a bundle
    在**空的** git init 仓里  rc=0   ← 决定性：包自足，空仓就够

`git bundle verify` **需要一个仓**才跑得动（它要核前置提交）。
脚本此前直接在当前目录跑 ⇒ **同一个包、同一个脚本，站的位置不同结论就不同**。
[[a-checkers-verdict-must-not-depend-on-cwd]]

### 自测为什么一直 8/8

因为**我每次都在仓里跑它**。自测从没在非仓 cwd 下跑过一次。
[[untested-fallback-branches-only-fire-on-their-machine]]（「没走过的那条路」）

### 严重性：这个脚本是**随包发给接手方的**

`make_handover_bundle.sh:744` 生成封面信时写死的就是相对形态：

    bash …/verify_handover_bundle.sh . --expect-tip %s

⇒ 接手方拿到包、照说明做，第一件事就是看到一个**假红**。
  一个好包被判「1 项不通过」，比没有验包脚本更坏。

## 修了什么

    VT="$(mktemp -d)"; git init -q "$VT/probe"
    B_ABS="$(cd "$(dirname "$B")" && pwd -P)/$(basename "$B")"
    git -C "$VT/probe" bundle verify "$B_ABS"

用**空的临时仓**——顺带还堵掉「借本机对象把包缺的那块补上」那种假绿。

## ★★ 我修第一处时**当场引入了第二个错**

`git -C` **会先切目录**，而接手方传的是 `.`，`$B` 就是 `./agentdb-…bundle` ——
切完目录就找不着了。改完第一版，实测**仍然红**，只是成因换了个。
补 `pwd -P` 转绝对路径才真好。[[printing-relative-paths-misreports-location]]

## ★★★ 而这个新错，我原来那条断言抓不住

第一条新断言传的是**绝对路径**（`verify "$T/d"`），
**封面信教的是相对目录**（`verify .`）—— 两者走的不是同一条路。
⇒ 又补一条，照**说明书里的形态**跑：

| 自测断言 | 抓的是 |
|---|---|
| 好包在非 git cwd 下仍 rc=0 | 判定依赖 cwd |
| **「verify_handover_bundle.sh .」相对目录 → rc=0** | `git -C` 之后相对路径失效 |

**文档里怎么写的，自测就要照那个形态跑一遍。**
[[a-gates-scan-set-is-smaller-than-reality]]｜[[the-comment-states-the-rule-the-code-narrows-it]]

### 变异对照（两条断言各管各的，不重合）

| 变异 | rc | 抓住它的那一条 |
|---|---:|---|
| 退回「直接在 cwd 跑」 | 1 | 「同一个好包在非 git 目录下 rc=1 —— 判定依赖 cwd」 |
| 去掉绝对路径转换 | 1 | 「『verify .』rc=1 —— 文档教的用法自己跑不通」 |

## ★ 附带：提示语里的反引号被 bash 真跑了一遍

`say "… \`verify .\` …"` —— 双引号里的反引号是**命令替换**，
输出里当场多出一行「验：.」。改成「」括起来。
