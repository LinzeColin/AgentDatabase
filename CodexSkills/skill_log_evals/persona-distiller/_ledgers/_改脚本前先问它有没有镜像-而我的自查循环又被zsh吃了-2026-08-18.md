# 改脚本前先问它有没有镜像；而我那次自查循环**又被 zsh 吃了**（2026-08-18）

## 事故本身

给 `collect_honest_delta.py`（**「诚实 delta」的唯一口径**）加了一段席位线索披露后，
`self_check --skip-tests` 从 **rc=0 / errors=0** 变成 **rc=1 / errors=1**。

仓里的漂移门当场说清了后果，一个字都不用我猜：

> `contract drift: [流程工具镜像] collect_honest_delta.py 两处不一致
>  （镜像 24648 字节 / 脚本 29014 字节）——**跑的是 `scripts/` 那份，装出去的是 `references/` 那份**；
>  收件人照镜像跑会拿到另一套结果`

改动前两份**逐字节相同**（`HEAD~1` 各 24648）⇒ **确实是我这一次弄断的**。
`cp` 同步后 `cmp` 逐字节相同、镜像那份自测全过、`self_check` 回到 rc=0/errors=0。

★ **这次不是我自查发现的，是仓里已有的 `check_contract_drift` 抓的**，
  而它挂在 `self_check` 里 —— 「独立脚本不是门，必须挂进 self_check 才会有人跑」那条纪律生效了。

★★ **同一天第三次踩「修了源，派生副本还是坏的」**：
  前两次是台账与 CHANGELOG 的**文字**，这次是**可执行文件**，
  而且**装出去的正是没改的那份** —— 比文字那两次严重得多。

## ★★★ 接着自查「还有没有别的镜像被我弄断」，**自查本身又是坏的**

我写了一个 shell 循环去比对，报出「配对 **0** 对、不同步 **0** 对」。
**那个 0 是假的**：

    CHANGED=$(git diff --name-only ...)
    for f in $CHANGED; do ... done      # ← **zsh 不做 word splitting**

整个多行串被当成**一个值**，循环只跑了一次、`basename` 拿到一串垃圾 ⇒ 什么也找不到。
**而 `collect_honest_delta.py` 明明就有镜像**，它必须出现在结果里 ——
**「0」与已知事实矛盾，这才是发现它坏了的线索。**

★ 这条我的记忆里就写着（zsh 不做词分割），**照样踩**。
  ⇒ 教训不是「记住 zsh 的特性」，是：**自查报 0 的时候，先找一个你已知必然命中的样本，
    看它在不在结果里**。[[zero-hit-gates-must-prove-they-can-hit]]

## 重做之后的真实结果

改用 Python 重做（本轮改过 **21** 个 `.py`，与全仓同名副本配对 **3** 对）：

    ✗ 唯一被标「不同步」的：
        registry/codex/persona-distiller/tests/helpers.py      **21610 B**
        registry/codex/teleiosis/tests/helpers.py              **3130 B**

逐个打开头几行：**两个不同 skill 各自的测试辅助文件**，只是撞了 `helpers.py` 这个通用名
（一个 import `subprocess`、一个 import `copy`）—— **不是镜像，不该同步**。
⇒ **我的「同名即镜像」启发式在这里误报**；真正的镜像关系只有一对，且已同步。

**结论：本轮没有弄断别的镜像。** 但这个结论**是重做之后才敢下的**，
第一版那个「0 对」如果直接汇报，就是拿一个坏循环去背书「一切正常」。

```bash
# 自查「还有没有别的镜像断了」——**别用 shell for 循环**
python3 - <<'PY'
import subprocess, pathlib, filecmp, collections
changed=[c for c in subprocess.run(["git","diff","--name-only","origin/main..HEAD"],
        capture_output=True,text=True).stdout.split() if c.endswith(".py")]
idx=collections.defaultdict(list)
for p in pathlib.Path("CodexSkills").rglob("*.py"): idx[p.name].append(p)
for c in changed:
    p=pathlib.Path(c)
    if not p.is_file(): continue
    for q in idx.get(p.name, []):
        if q.resolve()!=p.resolve() and not filecmp.cmp(p,q,shallow=False):
            print("不同步：", p, q)
PY
```
