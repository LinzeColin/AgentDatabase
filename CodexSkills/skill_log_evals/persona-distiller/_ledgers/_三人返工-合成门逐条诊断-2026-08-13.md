## 已修（机械类，零发明）

**`status` 与 `category` 被混成了一套。** 合法 `status` 只有
`fact / pattern / hypothesis / unknown / superseded`（`ledger.CLAIM_STATUSES`），
而我的生成器写的是 `"status": cat` ⇒ `work-method`／`boundary`／`value`／`mental-model`
这些**类别名跑进了 status**，每人 6–8 条 `ledger.invalid`。

映射**读自全库 570 条已有断言的实际用法**，零例外：

    fact → fact          boundary → fact
    heuristic → pattern  mental-model → pattern  work-method → pattern
    value → pattern      epistemic → pattern     blind-spot → hypothesis

另有每人 1 条 `category: "hypothesis"` —— **`hypothesis` 是 status 不是 category**
（合法类别里同义的是 `blind-spot`，且库里 `blind-spot` 全部配 status `hypothesis`）。已改。

★ **数据与生成器一起修**，并重跑生成器验证**逐字重现**（Brandeis／Dewey／Churchill 三份都 ✓）。
★ **Michelangelo 的 `gen_claims.py` 不在仓里** —— 他的 `claims.jsonl` 是唯一真源，
  没有可重跑的生成器。这是「每人一份的临时脚本不进仓」那条老病，单独记。
