## 三、关键经验（已部分写入 THREAD-FEEDBACK / HANDOVER，这里补 T3 独有的）

1. **DeepSeek flash 并发必 402**：>1 个 active 代理同时调 wf.py 必触发 402 限流。
   **串行模式（唯一 active 代理）是唯一可行路径**——本项目从并发 14 代理 0 落地转为串行 3 人落地。
2. **代理反复卡死 ≠ 死亡**：flash 代理每完成一个阶段就长静默（20-40 分钟无写入）。
   处置：`>20 分钟无写入 + 无 wf.py 进程/日志` → TaskStop + resume（保留上下文续跑）。
   Wanamaker 3 次 resume、Ivy Lee 5 次 resume 才完成/接近完成。
3. **wf.py 判卷返回空 content 的根因**：DeepSeek flash 的 `reasoning_content` 独占 token 预算——
   整批判卷 prompt 触发超长推理，8000 token 全进 reasoning、content 为空（`"content": ""`）。
   **修复：判卷改单 case 单调用 + prompt 明示「直接输出 JSON，不要输出推理过程」+ 校验 content 非空。**
4. **quality_check.py markdown 崩溃 bug**（已修并提交 main `7cd8126d2`）：
   `run_lane_quotes_verbatim` 以字符串 append warning，`markdown_report` 假定 warnings 全为 dict 致崩溃。
5. **缺坐标引文定位**：check_quote_locator 按「引文出现段落」计数（非唯一引文）——同一引文在
   带坐标段出现算过、在无坐标段出现算缺。修法：无坐标段落末尾补「（书名 年份 `src-xxx`）」即可。
6. **quality_check 调用**：`--cache` 是 `nargs='*'` 会吞掉后面的 target → **target 必须放在 --cache 之前**；
   cache 应指向含 `raw/` 的工作区根（非 references 目录）。
