# 静态形状预测 **11 个**，实测只有 **1 个** —— 「有这个形状」不等于「有这个毛病」

**日期**：2026-08-18　**两处修改都在 `persona-distiller`，均为工具侧不升版**

---

## 1. 起点是我自己犯的一个 cwd 错

我为了查镜像漂移，从 `CodexSkills/` 跑了
`registry/codex/persona-distiller/references/pipeline/checkers/check_contract_drift.py`，
得到 **`✗ 合同漂移 1 条：缺 VERSION 文件（真源不存在）`**（rc=1）。

**那不是仓的问题，是我跑错了副本。** `ROOT_DEFAULT = Path(__file__).resolve().parent.parent`：

```
scripts/ 那份 → skill 根 ✓
镜像那份     → references/pipeline/，那里当然没有 VERSION
```

但停在「我跑错了」是不够的 —— 留下的真问题是：
**这个判据在「根不是一个包」时，把「我没量到」报成了「它违规」。**

## 2. 修法：未量 ≠ 通过 ≠ 违规

改判 **rc=4**，并印出：解析到的根、根是怎么来的（`--root` 还是默认）、
以及「本文件还有一份镜像，真正的调用方是 `scripts/`」。

★ 落了**未量对照**：`mkdir scripts/` 的空目录，`check()` 必须**只**返回未量标记。
用退化版（缺 VERSION 时又报回漂移）实跑 ⇒ 自测**确实判红**。这条断言不是空的。

★★ 改的过程里被这道门自己抓了两次：
只改 `scripts/` 那份 ⇒ 它报「[检查器镜像] 两处分叉」；
`cp` + `cmp` 之后 ⇒ 又报「checksums.sha256 与磁盘对不上」。
**一道守着「两处副本要一致」的门，在我把它改成一半时准确地指认了我。**

## 3. ★★★ 然后我差点做错的那一步

修完之后，第一反应是：**「这个形状肯定还有很多处，全改一遍。」**

静态扫（同名 + 逐字节相同 + 所在深度不同 ⇒ `__file__` 往上推出的根必然不同）：
**11 个判据符合。**

**我没有照着这 11 个去改。** 改成了实测：把每对的两份各跑一遍，比退出码。

```
93 对逐字节相同的 check_* 镜像
  一致                                        91 对
  0 vs 4  check_contract_drift.py             （本轮刚修的）
  0 vs 3  check_distillation_freshness.py     （rc=3 = 用法错误，诚实，不是假红）
  0 vs 1  check_disposition_exclusive.py      ← **唯一的真假红**
```

**静态形状高估了 11 倍。**

大多数判据从镜像跑也没事 —— 它们要么收显式参数、要么根解析方式不同、
要么本来就返回非 0。**符合某个危险形状，绝大多数时候只是符合形状。**

> 如果我按形状改了 11 个文件，其中 10 个改动**没有修复任何东西**，
> 却各自带来一份新的镜像同步负担和一次回归风险。
> **修一个真问题，胜过修十个形状。**
> [[samples-cannot-support-universal-claims]]｜[[missing-guard-versus-bypassed-guard]]

## 4. 那唯一的一个

`check_disposition_exclusive.py` 里 `errors` 把
**「读不到文件」和「真的有人重复」加在一起**，`main()` 又 `return 1 if errors else 0`。

最讽刺的是：**它已经印了这句话** ——

    ★ **有文件读不到时，本件的结论不完整** —— 不许读成「没有重复」

**散文说对了，退出码把它出卖了。** 读散文的人懂了，读 `$?` 的流水线没懂。

改法：`check()` 多返回一个 `unmeasured`，`main()` 见到就 rc=4。
自测那条「台账读不到必须报错」跟着改口径（`err>0` → `unm>0`）。
★ 反向对照：把 `unmeasured` 并回 `errors` 的退化版，自测**确实判红**。

> **一个判据的对外接口有两条**：印出来的话，和退出码。
> **它们可以互相矛盾，而只有后者被机器读。**
> [[a-refusal-to-check-prints-one-error]]｜[[pipe-to-tail-hides-the-exit-code]]

## 5. 射程

- 「93 对」只数 `persona-distiller` 下 `scripts/` 与 `references/pipeline/checkers/`
  两处**逐字节相同**的 `check_*.py`。别处的镜像（如 50 份工作区模板）不在内。
- 「实测」是**不带参数**跑两份比退出码。带参数跑会不会分叉 —— **没量过**。
- 修的两个都只动**退出码语义**，判定逻辑一行没动；真根下 rc 均不变。
