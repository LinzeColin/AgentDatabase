# ★ 同日续测：②④⑤ 三条都追到了根

上面那版写于第一轮观测。后续把任务集补到 24 条、逐层分层、并把
`team-dossier` 逐字段拆开之后，②④⑤ 三条**都从「现象」变成了「机制」**。

## ② 路由 —— 完整因果链，每环有数

    92 词的关键词表（9 个领域，平均每域 10.2 个）要分 12 个专业族
      → 分类召回 **10/24 = 42%**（标签预注册，无偏）
      → **54%** 的任务 `domain_match` 对 101 个候选全为 0
      → 这些任务排序落到 `currentness`（人物年代新旧，极差 0.65）
      → 这些任务 **−1.7 pp**（SE 2.1），**低于随机抽人**
      → 与有信号那 9 题的 **+5.3 pp**（SE 3.6）平均 = **+1.6 pp**
      → 看上去「判不出与零的差别」

**机制不是假的，喂给它的分类是瞎的。** `software-ai` 那 14 个词里**没有「测试」**，
于是纯软件测试题上 34 个软件开发师全部 `domain_match=0`。

★ 我在这一条上连报了两个假数（+4.0、+11.7），真因是**把 n=1 的 single_expert
与 n=9 的 small_team 混进同一个平均**，σ 从 2.2 撑到 26.7。分层后团队模式
那把尺子 SE 只有 2.2 —— 它一直很准。

## ④ 有效激活调用 —— **载荷是实的，这一条要给回公道**

    status=ready｜requested=9｜loaded=9｜missing=[]
    **261 条 claim**（平均每人 29）
    每人 5 份正文全文 + 8 个 runtime 文件（含 evidence/claims.jsonl）
    mental_models / heuristics / work_methods / values /
    hard_boundaries / blind_spots / contradictions 各人齐备（9 人里 7 人全非空）

⇒ **「人物名称不替代能力、方法、工具、证据和边界」这条不变量，实测是守住的。**
不是「只有名字」。**这一条不该算进「接近 0 分」。**

（仍然成立的限制：入口只到 `prepared_for_host_execution` —— **它只准备，不执行**；
执行由宿主完成，那一段没有任何自动化的成功率记录。记录数仍是 **0**。）

## ⑤ 真正独立性 —— **反伪共识的机制 0% 触发，且是结构性的**

`usage_contract` 承诺「Documented divergences are surfaced and adjudicated;
they are not averaged away」。实测：

| | |
|---|---|
| 检测方式 | A 的 `divergence-map.md` 里**字面包含** B 的全名/slug |
| 全库可产生分歧的配对 | **24 / 5151 = 0.47%**，且**全部同族** |
| 而路由 | **跨族分散选人** |
| **24 个任务里队内含可分歧对** | **0 个（0%）** |

⇒ `divergences: 0` **不是「这队恰好没分歧」，是几乎任何一队都必然是 0**。
一盏永远红不了的绿灯。

★ 射程：这**没有**证明人物之间真的没分歧，只证明**系统没有办法发现分歧**。
⑤ 那条「同一个基础模型 ⇒ 相关性错误与伪共识」**依然成立且不可迭代消除**，
现在多了一句可验证的：**连「发现它」的机制都没在运行。**
