# 裸 clone 里，吃语料的那些工具会怎样（2026-08-14 逐件实跑）

**接手方一定在裸 clone 里。** 语料按裁定不进 git（仓里只放指针），
所以每一件「读 `raw/*.txt` 才能算」的工具，在他手上第一次跑都是**读不到正文**的状态。
问题不是「会不会为空」，是**它会不会把「读不到」印成一个结论**。

逐件在**同一个移交包的真 clone** 里跑过（工作区取 `jean-jacques-rousseau`，
台账 103 份、clone 里 `raw/*.txt` 只有 6 份且都不是正文）：

| 工具 | 裸 clone 里的行为 | 判定 |
|---|---|---|
| `measure_voice` | rc=3，「**一份都没量到** —— 不是「没有声口」，是没有 ≥500 词的一手文件」 | ✅ 本来就诚实 |
| `pull_quotes` | rc=3，「这一道没有可取的一手 train 源」 | ✅ 本来就诚实 |
| `measure_distinct_works --all` | rc=0，逐人印「**未量，不是通过** —— 台账指到的文件 N 份不在本机」，末行印覆盖面（量到 35／**未量 19**） | ✅ 本来就诚实 |
| `check_claim_evidence_independence --all` | 逐条印「读不到正文、**未判**（不是通过）」 | ✅ 本来就诚实 |
| `worth_starting` | rc=2，「**pending 为 0——未核验，不是「都做完了」**」 | ✅ 本来就诚实 |
| **`scan_copyright`** | **rc=0**，印「扫 103 份｜**红 0**｜黄 0｜绿 0」 | ❌ **坏的，已修** |
| **`dedup_corpus`** | **rc=0**，印「文件数 0」并宣告「**独立文献数上界 = 0**」 | ❌ **坏的，已修** |

## 那两件为什么最险

- `scan_copyright` 的「红 0」是**版权结论** —— 本项目的铁律是「只取公有领域」，
  而它在一份都没读到的情况下说「红 0」。红＋黄＋绿 = 0 ≠ 它自称扫的 103，
  **三个数各自看着都正常，合计对不上分母才露馅**。
- `dedup_corpus` 的「独立文献数上界」正是阶段 2 判「来源够不够门」用的那个数，
  报 0 会让下游以为语料是空的。

两件的共同成因是同一行：`if not p.exists(): continue` —— **读不到就静默跳过，没人数它**；
再加上标题行数的是**台账条数**而不是真读到的份数。

## 修完之后两端的样子（都实测过）

    scan_copyright  本机   台账 103 → **真读到 103**｜读不到 0；红＋黄＋绿 = 103 = 真读到
                    clone  台账 103 → **真读到 0**  ｜读不到 103；❌ 本次没有任何版权结论，**rc=3**
    dedup_corpus    本机   清单 103 → **真读到 103**｜读不到 0；文件数 103（rc=0）
                    clone  清单 103 → **一份也读不到** ⇒ ❌「未量，不是 0」，**rc=3**

## 给接手方的一句话

**在裸 clone 里，凡是印出「0 个问题」的工具，先看它有没有印「真读到几份」。**
没印的那些，`0` 有两种意思，而它们长得一模一样。
