## 三条各自怎么看

**① 「8 份」对。** 数字稳定，口径也对得上（中文 = 汉字数 > 拉丁字母数）。

**② 「最少差 8 个字」不复现 —— 今天是 60。**
最可能的成因是**文档后来被编辑过**（这正是「标着被 X 挡住的待办要先重跑 X」的理由）。
也可能当初用的是别的口径（比如只数汉字），但按 `len(text)` 这个门自己的口径，**今天就是 60**。
**不去猜当初，只记今天可复算的数。**

**③ 「对中文更严」—— 按失败率看方向是反的，但原意可能不是失败率。**

- 按**卡住率**：中文 19.0% < 英文 24.2%，**英文更容易卡**。
- 但按**信息量**：同样 500 个字符，中文承载的内容明显多于英文
  （英文 500 字符 ≈ 80 词；中文 500 字符 ≈ 400+ 个有效汉字）。
  **在「要写多少东西才够 500 字符」这个意义上，中文那一档确实要写得更实。**
- ⇒ 两句都成立，只是量的不是同一件事。**「更严」是个论证，不是一个读数** ——
  今天的数据既没支持它，也没推翻它。**说「更严」之前得先说清「按什么算严」。**

## 可复算

    cd CodexSkills/skill_log_evals/persona-distiller/_corpora
    python3 -c '
    import pathlib, re, collections
    rows=[]
    for p in sorted(pathlib.Path(".").rglob("references/research/0*.md")):
        t=p.read_text(encoding="utf-8", errors="replace")
        zh=len(re.findall(r"[一-鿿]", t)); en=len(re.findall(r"[A-Za-z]", t))
        rows.append((len(t), "中文" if zh>en else "英文"))
    short=[r for r in rows if r[0]<500]
    c=collections.Counter(r[1] for r in rows); cs=collections.Counter(r[1] for r in short)
    print("总 %d｜<500 的 %d｜按语种 %s｜卡着的 %s" % (len(rows), len(short), dict(c), dict(cs)))
    for L in ("中文","英文"): print("  %s 卡住率 %.1f%%" % (L, 100*cs[L]/c[L]))
    '
