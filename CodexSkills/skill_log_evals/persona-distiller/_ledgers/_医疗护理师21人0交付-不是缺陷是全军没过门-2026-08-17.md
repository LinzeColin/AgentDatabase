## 我是怎么少数了 2 个（订正的机制，比数字值钱）

原表最后一行我写的是「未细分 **10** 人：Osler、Fleming、Nightingale、Henderson、
Barton、Blackwell、DeBakey、Gawande、Farmer**…**」——**列了 9 个名字，填了 10**。
那个 `…` 就是我知道自己没列全的证据，而我还是在旁边写了个数。
**总数 19 是把我自己四行加起来得到的，不是从文件数出来的。**

但更深的一层是：**三行都错了，不止最后一行。**

    我 grep 「第三类」      → 6      各拼法并集 → 8   （Clara Barton 写作「③ 语料充足…判分不合格」）
    我 grep 「第五类」      → 2      各拼法并集 → 13  （另有「② 尺子够不着」「天花板」）

`处置类` 这个字段在全库 **186 条里有 126 种不同取值**——**它是散文，不是枚举**。
而这个文件自己的 `★ schema 说明` 早就警告过：
「四种历史**键名**的规范镜像……**按任一原键计数都会漏，按 `处置类` 计数不会。**」

**我照做了，用的就是 `处置类`。碰撞在「值」上，不在「键」上，那条警告没覆盖到。**
[[eval-artifacts-have-five-schemas]]、[[counts-need-their-cutoff-stated]]

**⇒ 落成纪律**（已写回 `_延后名单.json` 的 schema 说明）：
1. 报分类计数**必须打印 `各档合计 == 全集`**，不相等就是漏了一档。
   本次订正后 7+5+1+8 == 21 ✓。[[a-rights-check-said-zero-red-after-reading-nothing]]
2. **不许用单一子串 grep 归类 `处置类`**，先 `len(set(...))` 看它是不是枚举。
3. 表里出现 `…` ⇒ **那一行的数字作废**，要么列全要么别给数。

## 可复算

    python3 - <<'EOF'
    import json, pathlib, collections
    L = pathlib.Path("CodexSkills/skill_log_evals/persona-distiller/_ledgers/_延后名单.json")
    d = json.loads(L.read_text(encoding="utf-8"))
    med = [x for x in d["deferred"] if x.get("family_zh") == "医疗护理师"]
    def bucket(s):
        s = s or ""
        if "第三类" in s or "③ 语料充足" in s: return "第三类"
        if "第五类" in s or "够不着" in s or "天花板" in s: return "第五类/尺子够不着"
        if "第四类" in s: return "第四类"
        return "其它"
    g = collections.Counter(bucket(x.get("处置类")) for x in med)
    print(dict(g), "合计", sum(g.values()), "== 全集", len(med), sum(g.values()) == len(med))
    print("处置类取值种数 / 全库条数 =",
          len({x.get("处置类") for x in d["deferred"]}), "/", len(d["deferred"]))
    EOF
