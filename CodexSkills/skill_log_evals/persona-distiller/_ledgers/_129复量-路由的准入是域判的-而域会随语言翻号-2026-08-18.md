# #129 复量：卡点不在「卡片是中文写的」，在 **`infer_domains` 一个函数**（2026-08-18）

## 原记录的方向要订正

原标题：「**路由对英文题只看得见 30% 的人**」，根因记为「67 份卡片是中文写的，
四项词面重合分对英文题失效」。**复量下来：现象在，因果错了，而且方向不是单向的。**

## ★★★ 第一件：**准入不是文本相关分定的，是 `domain_match` 定的**

实测（`route_team_moe.score_candidate`，strategy=B，`accept_threshold 0.17`，102 份产物）——
统计**每个合格者是被哪一项抬过 0.17 的**：

| 题 | 语言 | 合格 | 谁把他抬过门 |
|---|---|---:|---|
| 遗留微服务代码库的测试与重构 | 英 | **91** | **domain_match 83**、packet 4、task 3、scenario 1、capability **0** |
| ↑同一内容 | 中 | **58** | **domain_match 34**、packet 24 |
| 医院灭菌流程安全论证评审 | 英 | **55** | packet 41、task 12、capability 1、scenario 1 |
| ↑同一内容 | 中 | **87** | **domain_match 83**、packet 4 |
| 与难缠供应商谈供货合同 | 英 | **44** | packet 37、domain 7 |
| ↑同一内容 | 中 | **44** | packet 37、domain 7 |

⇒ **四项文本重合分几乎不参与「谁能进池子」**（软件英文题：91 人里靠 task/scenario/capability
进来的合计 **4 人**）。卡片是中文还是英文，主要影响的是**排序**，不是准入。
**原记录把排序层的现象当成了准入层的因。**

## ★★★ 第二件：「只对中文有效」被三道题里的两道证伪

- 软件题：英 91 > 中 58
- **医院题：英 55 < 中 87 ← 反过来**
- 供应商题：**英 44 ＝ 中 44 ← 一模一样**

**不是「中文占便宜」，是「换语言就翻号，而往哪边翻不定」。**

## 真因：**同一件事，中译一遍，域就换了** —— 6 对里 3 对不同

| 同一内容 | 英文 → | 中文 → | |
|---|---|---|:--:|
| 遗留微服务代码库的测试与重构 | `software-ai,operations-product` | `software-ai` | ✗ |
| **诊断分布式系统线上故障并写复盘** | **`general-decision`**（一个信号都不命中） | **`healthcare`** | ✗ |
| 40 公顷再生农场轮作 | `agriculture` | `agriculture` | ✓ |
| 与难缠供应商谈供货合同 | `legal-policy` | `legal-policy` | ✓ |
| 医院灭菌流程安全论证评审 | `healthcare` | `healthcare,operations-product,software-ai` | ✗ |
| 小众 B2B 产品上市方案 | `operations-product` | `operations-product` | ✓ |

**两侧各有一种错法，方向相反：**

- **中文过火**：`诊断` 是 `healthcare` 的**裸关键词**（`_signal_hits` 对 CJK 走子串匹配），
  于是「诊断分布式系统的线上故障」整题判成医疗；
  `评审` 是 `software-ai` 的裸关键词，于是「评审医院灭菌流程」也带上软件；
  `流程` 拉进 `operations-product`。
- **英文欠火**：`Diagnose a production outage in a distributed system and write the postmortem`
  **一个信号都不命中**，退回 `general-decision`。

### ★ 这不是新缺陷类 —— 是仓里已有那一类的第 3、第 4 个实例

`tests/test_generic_verbs_do_not_claim_a_domain.py` 早就为 `设计`/`design` 立了
`WEAK_SIGNALS` 装置（通用动词只有同域另有强词时才计数），并写死了扩表规则：

> 「只降这两个，且都是**实测误发过的**；不凭感觉扩名单。」

`诊断`、`评审` 现在有了那个「实测」。**但加词会改变每一道真实任务选出的人**，
属「门、席位一概不动」的射程 ⇒ **我不加，列为 Owner 选项 E。**
（同一天第 N 次：先搜仓，仓里早有 —— [[three-times-in-one-day-i-rediscovered-what-the-repo-already-had]]）

## 本轮落地的（不动门、不动席位）

新增 `scripts/check_domain_inference_language_parity.py` ＋ 调用方
`tests/test_domain_inference_is_language_neutral.py`：

- 断的是**关系**不是绝对标准 —— 同一内容的中英两版必须落进同一组域。
  谁对谁错都行，**但不许因为换语言就换域**。夹具的题是我写的，而关系断言不受这个影响。
- **非退化负对照（防共用零件）**：本件调的 `infer_domains` 正是被判对象；
  一个恒返回 `[]` 或恒返回单域的坏实现会让**平价率满分**。所以硬下限：
  两侧都推出真域 ≥3 对、不同域 ≥3 种，达不到 **rc=4 未量**。自测里两个坏实现都被打掉。
- **是回归地板不是门**：首跑就 3/6，一道从建成起就红、要改代码才转绿的门不是信号
  ⇒ rc=1 只在平价**掉到基线以下**时。修好一对就抬基线。

**反例实验（两个方向都做了，且都断言了目标真的变了）：**

    ① 把 `诊断` 从 healthcare 词表拿掉 ⇒ 该题域 `['healthcare']` → `['general-decision']`
       ⇒ 平价 **3 → 4**（证明那一对的分歧就是这个词造成的）
    ② 给 software-ai 塞一个只命中中文农场题的 `轮作`
       ⇒ 该题域 `['agriculture']` → `['agriculture','software-ai']`
       ⇒ 平价 **3 → 2**，判据 **rc=1**，调用方测试 **2 项失败**
    ③ 复原后 `git diff` 空、判据 rc=0

★ 两个反例都先断言了「被改的东西真的变了」，不是空操作。
  [[a-noop-counterexample-looks-exactly-like-a-broken-guard]]

全套 13 件测试绿 13 红 0；`validate_group` rc=0。

## 要 Owner 定的（原四个选项 + 复量后新增两个）

原 A/B/C/D-1/D-2 保留，但**代价要按上面的实测重估**：

- **A（四项全零不许入选）**：复量后**它管不到准入** —— 软件英文题 91 个合格者里
  只有 4 人是靠这四项进来的，砍掉「四项全零」等于砍掉 87 人，而留下的多是靠
  `design`（27 人命中）、`strategy`（15 人）这类**通用词**撞上的。
  真正的话题词命中人数：`refactoring` **1**、`test` **2**、`legacy` **2**。
  ⇒ **A 不是「留下相关的人」，是「留下撞到通用词的人」。**
- **★ E（新增·我推荐先议这个）**：把 `诊断`、`评审` 按仓里已有的 `WEAK_SIGNALS` 机制降为弱信号。
  代价：**会改变每一道含这两个词的真实任务选出的人**，因此是决定不是清理。
  好处：它打的是**准入层**（83/91 靠 domain_match），A/B/D 打的都是排序层。
- **★ F（新增）**：`Diagnose/outage/distributed system/postmortem` 在英文词表里一个都没有。
  补英文词是**扩词表**，同样移动准入。要不要补、补哪些，是同一个决定的另一半。
