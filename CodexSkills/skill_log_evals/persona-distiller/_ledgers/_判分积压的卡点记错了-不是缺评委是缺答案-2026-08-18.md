## ★★ 我在查这件事时犯的错（当场被自己的下一步抓住）

第一遍我按**文件名**找答案，报「6/13 位有答案文件」：
`tj-candidates.json`、`ob-candidates.json`、`ff-candidates.json`、`al-candidates.json`、

打开一看：**这些是「同名候选」，每份只有 2 项。**
改按**内容**判（≥16 项、值全是字符串的字典 / ≥16 条含 A|B|answer|text 的数组），

## 可复算

★ **本节的命令必须算出上文那三个数**（13 / 417 / 1）。第一版没排除已结案的 4 位，
算出的是 17 / 483 / 3 —— **可复算命令算的不是文中那个数**，这正是本仓一直在挑的毛病。
已修正：`CLOSED` 显式列出，两个口径都印。

```bash
cd CodexSkills/skill_log_evals/persona-distiller/_corpora
python3 - <<'EOF'
import json, pathlib
CLOSED = {"wip-blackstone-169", "wip-cicero-166", "wip-kelsen-171", "wip-paton-162"}
rows = []
for ws in sorted(pathlib.Path(".").glob("wip-*")):
    cj = list(ws.rglob("cases.jsonl"))
    if not cj:
        continue
    n = len([l for l in cj[0].read_text(encoding="utf-8").splitlines() if l.strip()])
    res = list(ws.rglob("results.jsonl"))
    if not (n and not (res and res[0].read_text(encoding="utf-8").strip())):
        continue
    ans = 0
    for p in ws.rglob("*.json"):                    # ★ 按**内容**判，不按文件名
        if p.stat().st_size > 5_000_000:
            continue
        try:
            d = json.loads(p.read_text(encoding="utf-8"))
        except Exception:
            continue
        if isinstance(d, dict) and len(d) >= 16 and all(isinstance(v, str) for v in d.values()):
            ans += 1
    rows.append((ws.name, n, ans))
for label, sel in (("全部未判分", rows),
                   ("**扣掉已结案后的真积压**", [r for r in rows if r[0] not in CLOSED])):
    print("%-22s %2d 位｜%3d 题｜有两侧答案 %d 位"
          % (label, len(sel), sum(n for _, n, _ in sel), sum(1 for _, _, a in sel if a)))
EOF
# 期望输出：
#   全部未判分              17 位｜483 题｜有两侧答案 3 位
#   **扣掉已结案后的真积压**  13 位｜417 题｜有两侧答案 1 位
```
