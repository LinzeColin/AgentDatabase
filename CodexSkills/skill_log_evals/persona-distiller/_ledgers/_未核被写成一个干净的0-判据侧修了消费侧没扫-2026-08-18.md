# 「未核」被写成一个干净的 0 —— 昨天扫的是**判据侧**，消费侧没人扫过（2026-08-18）

## 一句话

判据把「我一个字都没读到」说得清清楚楚，**退出码却是 0**；
调用点两句 `.get(键, 0)` 把它翻译成「**0 条问题**」。
本机 **77 个 `raw/` 目录里 73 个（95%）一份 `.txt` 都没有** ——
所以这一栏在绝大多数工作区上，**从建成起给的就是假读数**。

已修 2 处并各配正反实测，均为**工具改动、不升版**（2026-08-04 裁定）。
提交：`b246ba120`、`312e832c2`。

## 一、今天修的两处

### ① `check_source_header_quotes` 的调用点（`quality_check.py:1702`）

`raw/` 为空时判据印的原话是：

```json
{"状态": "**未核（不是通过）**：没有找到任何 .txt"}
```

**而它的退出码是 0。** 调用点：

```python
_n, _bad = _h.get('头部里的引文', 0), _h.get('**正文里找不到的**', 0)
```

⇒ review 记成 **「头部引文 0 条，正文里找不到 0 条」**。

**同一行上方第 1701 行是我自己写的告诫**：「报 0 时必须连覆盖面一起报，
否则那个 0 会被读成全库体检合格」。**告诫在，代码照吞** ——
因为 0 的两种来源（真的 0 条 vs 一份没读到）在那两句 `.get` 之后长得一模一样。

**改法**：判定 key 在**闭集合**上（两个计数键在不在），**不 key 在「未核」这个措辞上**。
措辞归判据作者，键归数据结构；追措辞的判据永远慢一步。

**这是本文件里同一形状的第三处** —— 前两处是 `check_ocr_language_death`（`:2200`）
与 `check_claim_coverage` 的 code 2，**两处都留了注释说「空扫描面被读成通过」**。
注释拦不住同形状的第三次。

### ② `check_checkers` 的调用点（`quality_check.py:1860`）

解析失败时它**确实**写了「本次未做检查器先验（不是通过）」——
但写在 `metrics['content_review']`，而 census 落在 `metrics['checker_census']`，
**另一个键**，内容 `{'负对照可用': 0}`。

同一件事两处记录：一处说未核、一处给了个数。**只看后者就是「0 件判据有负对照」。**
改为两个键给同一个答案，且没解析成功就不写那个数。

**边界（已 grep 确认）**：两处都只进 `report.metrics`，**不进 warnings / errors**，
没有任何地方按「未核」二字判红 ⇒ **不改变任何门的结论、不会新拦打包**。

## 二、★★★ 我的假设被自己的实测证伪

昨天 `_零扫描面假绿-全判据交叉喂测-2026-08-17.md` 的处置规矩是：
**「只改措辞、不改退出码」，并在消费点写明「不当成通过也不当成失败」**。

我据此提了个假设：**那 51 处的修法依赖一个并不存在的消费端行为**。
把昨天动过的 21 件判据逐个对到 `quality_check` 的消费点上复量：

> **会吞的：0 件。**

**假设不成立，原样记下。** 昨天那轮是对的。

那今天这两处为什么漏了？——因为**两次扫的是不同的一侧**：

| | 扫什么 | 方法 | 抓到的 |
|---|---|---|---|
| 昨天 | **判据侧**（生产者） | 给每件判据喂空扫描面，看它印什么 | 51 处措辞 |
| 今天 | **消费侧**（调用点） | 22 个 `run('check_*.py')` 块里找空默认值 | 2 处 |

`check_source_header_quotes` **昨天的扫法测不到** —— 它的措辞本来就是对的，
坏的是读它的人。**一件东西的两侧要分别扫，扫过一侧不等于扫过。**

## 三、22 个消费点，按「怎么读判据的答案」分类

### ★★★ 订正（同日）：「按措辞读 13 处」是**错的**，真数是 **7**

我先前的分类口径是「块内**出现过** 未核／未检查／状态 任一词」——
**而绝大多数块出现这些词，是因为它们自己写「未核（不是通过）」当输出，不是因为读。**
把口径换成「真的拿字面串去匹配判据输出」（`'X' in out`、`.startswith('X')`、
`.find('X')`、`re.search`），重量一次：

| 分类 | 处数 | 性质 |
|---|---:|---|
| ① **按字面串读判据输出** | **7** | 判据作者改一个词，消费点就聋了 |
| ② 键在闭集合上 | 3 | 措辞怎么变都不影响（今天新增 2 处到这一档） |
| ③ 只取退出码 / 原样转述 / 自己写未核 | 其余 | 不按串识别 |

**这 7 处一共 14 条串，逐条到判据源码里核过：**

| 结果 | 条数 | 说明 |
|---|---:|---|
| 判据里确有此串 | 11 | 耦合成立 |
| 判据里没有，但**是二选一里的死分支** | 2 | `if '未检查' in l or '未核' in l` —— 判据只吐「未检查」，另一半有效 |
| 判据里没有，但**是运行时拼的** | 1 | 判据印 `f"  ⚠ {cid}"`、cid 形如 `研究/x.md` ⇒ 字面搜索看不见 |

> **断掉的耦合：0 处。** 三条「找不到」全部是我扫描器的局限，不是缺陷。

**最后那条是实测定的案，不是读代码猜的**：造夹具跑 `check_quote_integrity`，
消费点那行 `startswith('⚠ 研究/')` 真筛出 1 条 ⇒ 耦合是通的。

★★ **造这个夹具连踩两个坑**（都是本仓的老病）：
① 第一版引文只有 9 个字，而 `MIN = 20` ⇒ 「引文 0 条」，`bad` 为空 —— 我差点据此写「耦合断了」；
② 第二版够长了但是**中文**，而 `Q` 要求引号内首字符是**拉丁/希腊字母** ⇒ 仍是 0 条。
换成英文引文才真正触发。**空结果的成因有三种，得先证明夹具能触发。**

## 四、★★ 量的过程本身：同一个测量给了我三个答案

追「题面里的年份能不能在语料里找到」时，同一句话我量出过三个数：

| 扫描面 | 结果 |
|---|---|
| `rglob("raw/*.txt")` | Steinhardt **0 份 / 0 字符** ⇒ 「1991 出现 0 次」 |
| ＋ `raw/*/*.txt` | 128 题里 **找不到 4 处** |
| 全树 `*.txt` | 223 份 / 3.8M 字符 ⇒ **「1991」出现 335 次**，找不到 **1 处** |

**变的全是扫描面，不是数据。** 本机语料有三种布局：

```
brandeis / dewey    →  workspaces/<person>/raw/
godin               →  ws-godin/<person>/raw/  ＋  references/sources/
steinhardt          →  corpus/  ＋  references/sources/  ＋  raw/
```

**救我的是那行 `0 份 / 0 字符`** —— 因为我把扫描面连同结论一起印了出来。
如果只印「1991 出现 0 次」，我会照着这个 0 写下一段完全错误的结论。

## 六、可复算

```bash
cd CodexSkills/registry/codex/persona-distiller/scripts

# ① 空 raw/ 时判据说什么、退出码是几
T=$(mktemp -d); mkdir -p "$T/raw"
python3 check_source_header_quotes.py "$T/raw"; echo "rc=$?"

# ② 消费点普查（22 处，按怎么读判据的答案分类）
python3 - <<'EOF'
import re, collections
src = open('quality_check.py', encoding='utf-8').read().splitlines()
calls = [i for i, l in enumerate(src) if re.search(r"run\(\s*'check_[a-z_]+\.py'", l)]
DEF0 = re.compile(r"\.get\(\s*['\"][^'\"]+['\"]\s*,\s*(0|\[\]|\{\}|''|\"\")\s*\)")
c = collections.Counter()
for i in calls:
    blk = "\n".join(src[i:i+22])
    w = any(k in blk for k in ("未核", "未检查", "本判据不适用", "状态"))
    c[("①按措辞" if w and not DEF0.search(blk) else
       "②闭集合" if w else "③只取rc")] += 1
print(dict(c))
EOF

# ③ 射程：多少个 raw/ 是空的
python3 - <<'EOF'
import pathlib
n = e = 0
for root in ("../../../../skill_log_evals/persona-distiller/_corpora", "../references"):
    p = pathlib.Path(root)
    for raw in p.rglob("raw") if p.is_dir() else []:
        if raw.is_dir():
            n += 1
            e += not any(q for q in raw.rglob("*.txt") if not q.name.startswith("_"))
print("raw/ 共 %d 个，空的 %d 个" % (n, e))
EOF
```
