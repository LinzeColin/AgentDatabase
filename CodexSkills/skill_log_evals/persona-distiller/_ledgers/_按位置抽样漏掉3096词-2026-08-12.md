# ★★★ 一个 3096 词逐字相同的段落，在我的指标里是 **0.0%**

给 Kant #179 选 holdout，我的指标报**中位重合率 0.0%**、53/61 份 ≤5%。
据此选出 11 份，送进 `check_holdout_overlap`：

    硬失败 1 / 待人工核 1

## 根因：**按位置抽样**

`assign_holdout.py` 的 k 词片是这么取的：

```python
for i in range(0, max(1, len(w) - K + 1), 5):   # ← 每 5 个位置取一个
```

两份文档若在**共享段上的起始偏移模 5 不同**，
各自抽到的 k 词片**一个都不会重合** —— 哪怕那一段逐字相同。
**漏报概率 4/5。**

## 正对照（现造，两边偏移错开）

同一段 **3096 词逐字相同**的文本，A 前面垫 3 个词、B 前面垫 7 个词：

    按位置抽样：A 616 片、B 616 片，**重合 0 片** → 报 **0.0%**
    按哈希抽样：A 614 片、B 615 片，**重合 613 片** → 报 **99.8%**

## 修法：**按哈希值抽，不按位置抽**

```python
h = blake2b(" ".join(w[i:i+K]).encode(), digest_size=8).digest()
if h[0] % SAMPLE == 0:      # ★ 与位置无关
    out.add(h)
```

同一段文字无论落在哪个偏移上，被抽中的那些片都一样。抽样率不变，漏报没了。
