# #169 Blackstone 卡在合成门：**证据簇只有一种，方法类断言立不住**

日期：2026-08-11。研究门 0 错通过之后立刻撞上的。

## 门要什么

`quality_check --phase synthesis` 对 `mental-model / heuristic / value / work-method /
blind-spot / contradiction` 六类断言要求**每条 ≥2 源、≥2 语境、≥2 独立证据簇**
（`quality_check.py:200-209`），并且 quick 档要 **≥2 条 mental-model、≥3 条 heuristic**
（`common.PROFILE_THRESHOLDS['quick']`）。

    4a6e386d  work-method   源3 境3 **簇1**  → 降为 fact
    acb2dad4  work-method   源2 境2 簇2     → **唯一够得着的一条**
    06c31dcc  mental-model  源1 境1 簇1     → 降为 fact

降级后：`mental models 0 < 2`、`heuristics 0 < 3`。

★ **降级是把断言说弱，不是把门放宽。** 每条降级的正文里都加了一句
「本条只有一种证据簇，故降为对该文本的事实陈述，不作为持续的方法／心智模型断言」。

## ★★★ 根因：**能引的那一种，和能证明的那一种，不是同一批材料**

本工作区 15 份语料的证据簇实际只有四种：

| 簇 | 内容 | 能不能支撑方法类断言 |
|---|---|---|
| A | **1898 年印本正文块**（逐条过 `verify_quote.py`） | **能**——但只有这一种 |
| B | 台账逐字照录的扉页／首行 | 只能证明「有这本书、哪一年、谁署名」 |
| C | 他人所著印本的扉页（S1） | 只能证明「同代人怎么称呼他」 |
| D | 规范档四库（Wikidata/LCCN/GND/VIAF） | 只能证明身份与生卒 |

**B/C/D 都不承载他的思路**，因为承载思路的正文全部长 s 讹字
（8 份讹字率 0.97–0.99，取不出可核逐字串，见 `_corpus/00-编者注与逐字引文.md`）。

于是每一条关于「他怎么想、怎么做」的断言，**证据只能来自 A 这一个簇**——
而门要的正是「不能只有一个簇」。

★ 唯一够得着的 `acb2dad4`（纲目先于全书）能过，是因为它恰好**同时被 A 与 B 证到**：
A 里他自陈 `follow the same that I have already submitted to the public`，
B 里那份纲目的扉页独立存在。**这是巧合，不是可复制的路子。**

## 与既有延后类别的关系

- **不是** ①一手规模不够：15 份、1500 万字节，quick 门要 8 份。
- **不是** ②尺子够不着：还没走到判分。
- **不是** ⑦（Pacioli：方法证据全部汇到一部作品）：**成因不同**——
  Pacioli 是**作品只有一部**，这里是**作品有好几部而只有一部的扫描能引**。
  ★ 建议记为**新类别：可引面与可证面不重合**（扫描质量把证据簇压成一种）。

## 能不能救——三条路，都量过

1. **换干净扫本**：1765–1771 各版原刊实测长 s 全被读成 `f`
   （1771 都柏林本 `fhall`=182 / `shall`=0）。**换版救不了，问题在 OCR 不在版次。**
2. **自己还原长 s**：**禁止**——改讹字再当逐字引文用是本项目记档过的事故形态。
3. **把 1781 判例汇编算成第二簇**：它保留本字 `ſ`，理论上可无歧义还原，
   但同样落在第 2 条禁令里；且**它证明的是「他编了什么」，不是「他怎么想」**。
