## 为什么不能直接推公开仓（实测，不是推测）

    gh repo view LinzeColin/AgentDatabase --json isPrivate
    → {"isPrivate": false}          ← **公开仓**

而 `origin/main` 上那份 HANDOFF 自己写着移交规则：
**「任何 private-only 资产一个字节都不许进 AgentDatabase」**。

把本地分支推上 `main` 会**新公开 11,631 个文件**：

| 类别 | 份数 | 说明 |
|---|---:|---|
| persona-distiller 其他 | 7,278 | 产物、模板、判据 |
| **语料正文** | 4,067 | 公开仓现有 246 份，会变成 4,313 |
| **★ 教训库** | 141 | 本机 `~/.claude/.../memory/` 的副本；**公开仓现在是 0 份**；其中 **19 份**出现 OVH／R2／Private-Database／token／账单金额 |
| 台账/流水线 | 141 | |

⇒ 走 bundle：**内容打包进私有仓 Release，公开仓只更新指针**。
