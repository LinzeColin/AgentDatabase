## 最硬的那一档：账本自己写着「不假定可再分发」

Steinhardt 那 55 条的 `rights` 逐字是：

    publicly-accessible-for-analysis; **redistribution-not-assumed**

**账本自己说不假定可再分发，而仓库正在分发它们全部**，1.13 MB。
这与同日 Livermore 那件是**同一个形状**：
[[a-rule-in-a-doc-has-no-enforcer]] —— 规则记在了正确的字段里，没有执行者。

★ 差别在于载体：Livermore 那次规则写在**散文 README** 里；
这次写在**结构化字段**里，机器读得到 —— **更容易做成判据，也更没理由漏**。

## 可复算

    cd <repo>
    python3 - <<'EOF'
    import json, pathlib, subprocess, collections
    ROOT = pathlib.Path(".").resolve()
    tracked = {p for p in subprocess.run(["git","-c","core.quotepath=false","ls-files","-z"],
               capture_output=True, text=True).stdout.split("\0") if p}
    base = pathlib.Path("CodexSkills/skill_log_evals/persona-distiller/_corpora")
    agg = collections.defaultdict(lambda: [0,0,0])
    for f in base.rglob("source-ledger.jsonl"):
        wd = f.parent
        for line in f.read_text(encoding="utf-8", errors="replace").splitlines():
            if not line.strip(): continue
            try: d = json.loads(line)
            except Exception: continue
            r = str(d.get("rights","")).strip()
            key = ("redistribution-not-assumed" if "redistribution-not-assumed" in r
                   else r[:34] if r else "(空)")
            a = agg[key]; a[0] += 1
            lp = d.get("local_path") or ""
            for c in (wd/lp, wd.parent/lp, base/lp):
                try: rel = c.resolve().relative_to(ROOT).as_posix()
                except Exception: continue
                if rel in tracked:
                    a[1] += 1; a[2] += (ROOT/rel).stat().st_size; break
    for k,(n,g,b) in sorted(agg.items(), key=lambda kv: -kv[1][2])[:8]:
        print("%-40s 条目%4d  在git%4d  %10s B" % (k[:40], n, g, f"{b:,}"))
    EOF

★ **`local_path` 要按三种基准逐个试**（相对工作区 / 相对其父 / 相对 `_corpora`）——
只按一种拼会漏掉一半。我第一版用 basename 匹配，会误配同名文件。
