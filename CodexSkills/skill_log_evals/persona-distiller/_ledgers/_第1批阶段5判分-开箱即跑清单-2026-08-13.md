## 二、装置（**两侧同规格，否则格式与长度就是泄题通道**）

- **两侧答案各由一个独立子代理生成**，格式要求**完全相同**：
  纯散文、120–260 字符、禁一切 Markdown（粗体／反引号／标题／列表／表格／引用块）。
- **基线方**：只给 `prompts-only.json`；**不给 rubric、不给人物档案、不许读工作区任何别的文件、不许联网**。
  逐字用 `_ledgers/_pipeline/BASELINE-PROMPT-FROZEN-v1.md`，**一个字都不许改**。
- **候选方**：给十份产物正文 ＋ 研究道文档 ＋ `evidence/claims.jsonl` ＋ `references/sources/`；
  **不给 rubric**（不许读 `evals/cases.jsonl`）；**`references/holdout/` 明令禁读**；
  ★ **连 `ls references/` 都不许**——要列目录只列 `references/sources/`
  （上一个人物的候选为摸目录跑了 `ls -R references/`，看见了 holdout 的目录名）；
  ★ 若不慎接触到 holdout 的任何信息（哪怕只是目录名）**必须主动上报 `__incident__`**。
- **题号做成不透明的**：`case_id` 本身在告诉答题方该怎么答
  （`ff-refusal-stop-01` 一看就知道要拒答）。用 `build_blind_payload.py` 出
  `q-01ed7de2` 这类号并**按 sha256 重排序**；映射存 `prompt_key.json`，**不发答题方也不发评委**。
- **两席评委互不知情，且都不喂 rubric**——做处置的一直是这一对的**诚实 delta**
  （[[rubric-fed-judges-flip-the-sign\]]：喂 rubric 会翻号，已在两个人物上复现，摆动 0.58／0.60）。
- 评委指令用 `_pipeline/judge_prompts/seat_D_score.md` 与 `seat_E_strict.md`，
  **一个人物的全部轮次同一份，中途不得增删检查项**。

## 三、判读规则（**现在定死，判完不许改**）

用户 2026-08-12 的规则优先：**第 1 轮 delta < −0.011 → 直接结案，不跑二三轮。**

| 实测 | 怎么读 |
|---|---|
| 第 1 轮 delta **< −0.011** | **直接结案**（用户规则），不跑第 2、3 轮 |
| 两席**跨零** | 无论均值多少，**一律读作测不出** |
| \|delta\| < 2 SE（见上表逐人取值） | **读作「测不出差别」**，不读「打平」也不读「略胜」 |
| delta ≥ 档位门 **且** ≥ 2 SE | 才算「过门且分得出」 |
| delta ≤ −档位门 **且** ≥ 2 SE | 才算「明确劣于基线」 |
| 两轮之差本身 > 0.0650 | 判「装置在这个人物上不成立」（Rosenhain #138 的摆动量） |

★★ 补题之后四个 quick 档的人**已经可以触发第 4 行**（门 2.59–2.67 SE > 2）。
但**在最坏的噪声估计（sd×2.2）下他们仍只有 1.18 SE**——
所以判完若落在 +0.03 到 +0.04 之间，**要连这句一起写**：
「按借来的 sd 分得出，按 sd 的区间上端分不出。」

★ 合并规则：**合并，不挑轮**。不许在看到第 2 轮更高之后说「取最好的一轮」，
也不许在更低之后说「第 1 轮已经过门了」。

## 五、步骤（每人一遍）

```bash
S=CodexSkills/registry/codex/persona-distiller/scripts
W=CodexSkills/skill_log_evals/persona-distiller/_corpora/wip-<人>/workspaces/<slug>

# 1. 出不透明题号与盲判载荷（它自带硬门，拦得住有引文缺坐标的载荷）
python3 $S/build_blind_payload.py "$W" --round 1

# 2. 派两个答题子代理（基线侧／候选侧），格式要求见上「装置」一节

# 3. 派两席评委子代理（互不知情、都不喂 rubric），指令用冻结文件

# 4. 判读之前先量泄题通道：长度比、九条表面特征、出戏、判据抄答案（两侧各量，不合并）

# 5. 只有一轮时，check_delta_resolution 会印「未核：只有一轮，量不出噪声」
#    ★ 这不表示噪声小，只表示没量
python3 $S/check_delta_resolution.py "$W"
```

★ 第 2 轮的目的**不是再赢一次，是把噪声量出来**：两侧文本一字不改、A/B 归属逐条相同
（`build_blind_payload` 的归属是 `sha256(case_id) % 2`，**无轮次种子，两轮天然相同**，
且有硬门拦不一致的 key）、**两席全部换新**。
