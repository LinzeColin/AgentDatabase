# 短于 19 字的逐字串，`check_quote_integrity` 从头到尾没看过一眼

日期：2026-08-11　起因：Grotius #168 派发判分前逐条核题面

## 一句话

`find()` 里写着 `if len(q) < MIN: return "exact"` ——
**「太短，不作判据」和「已核实」共用一个返回值。**
于是我拿它去核一个语料里根本不存在的名字形，它答「有」。

## 怎么撞上的

题面里有一串 `Auctore Guilielmo Grotio jcto Delphensi`。
`Delphensi` 在 21 份语料里 **0 次**——那张题名页是我编的。
顺手把同类的串都过一遍时，`find("Guilelmus Grotius")` 答 `exact`，
而 grep 报 0 次。**两个仪器打架，去坐实，坐实的是判据在说谎。**

★ 同一轮里我还犯过一次相反的错：grep `GVILIELMO GROTIO` 报 0 份，
我一度以为产物引了不存在的串——**语料里是两个空格**，
判据归一化空白所以命中是对的，**错的是我那条 grep**。
两个方向都撞过一次，记法：**仪器不一致时先定位到字节，不要先选一个信。**

## 两道门槛叠着

| 门槛 | 值 | 后果 |
|---|---|---|
| `Q` 抽取正则 | 首字母之后还要 `{18,300}` 字符 | `Guilelmus Grotius`（17 字）**根本不会被抽出来** |
| `find()` 判定 | `proj` 后 `< MIN(20)` | 就算抽出来了，也直接答 `exact` |

实测 `facts.md`：**10 条引文只有 5 条进了核验**，屏幕印的是「✓ 全部可在语料中找到」。
被吞掉的 5 条是 `LIBER XI, Anno 1602.` 那一批——**「一卷一年」那条断言的全部证据**。

## 本次改了什么、没改什么

**没改**两个门槛——动它就是全库一百多份产物一起变，那是另一件事。
**改的只有一件：让「没查」不再冒充「查过了」。**

- `find()` 短串返回 `"short"`；
- 新增模块级 `count_unchecked()`；
- 汇总行改成「**已核的**片段全部可在语料中找到（未核的那 N 处不在此列）」。

Grotius 实测：63 条已核 0 未命中，**另有 60 处未核**——这一行此前不存在。

★ 自测里我又犯了同一族的错两次，两次都是变异测试抓出来的：
① 计数逻辑在测里**抄了一遍**，关掉真代码自测照样全绿；
② 反对照夹具写的是 `check_quote_locator.py`（23 字），
**被 `{2,19}` 的长度窗口挡在门外，根本走不到要测的那一步**。

## 全库回扫（23 个有语料的工作区）

    短原文串 338 条，回语料对不上 37 条

**37 不是 37 条编造**，逐条读过之后分三类：

| 类别 | 条数 | 说明 |
|---|---|---|
| 分道名／文件名 | 14 | `02-conversations.md`、`01-writings` 之类，不是引文 |
| 字段名／类别值 | 7 | `historical`、`birthDate`、`falsifiers` |
| **★ 疑似逐字串** | **16** | 分布在 **8 个人**，**只有这一类需要逐条读原文** |

16 条里最扎眼的规律：**一半是同名者的名字形**——
`C. A. Adams, Jr.`（Adams #131）、`CoFFIN, CHAs. A.`（Coffin #130）、
`William Agnew Paton`（Paton #162）、`Naesmith`（Nasmyth #153）。
**与本人物那四串同一族**：产物在说「别把我和 X 弄混」，
而 X 的名字形本身拿不出印本。

抽两条坐实（不是推断）：

- `CoFFIN, CHAs. A.` 只出现在 `facts.md`、`meta.json` 与 `raw/_ids.txt`——
  **`_ids.txt` 是清单不是正文**，18 份语料 .txt 里一处也没有。
  这是 [[i-almost-deleted-guards-that-blocked-my-number]] 那一族：
  **我自己写的元数据被当成了印本证据。**
- `William Agnew Paton` 只出现在 `README.md`，20 份语料 .txt 里 0 次。

★ **这 16 条本轮不改**：它们在已交付／已判过分的产物里，
改动射程远超一个人物，属于既有的「已入库产物技术债」那一档。
**量清了，写在这里，等排期。**

## 射程（本文自己的）

- 全库扫的是各工作区的 `raw/`。抽查过 Coffin 与 Paton：
  `references/sources/` 与 `raw/` 份数一致（18/18、20/20），

  **16 条里可能仍有非引文**，逐条读原文才作数。
