## 我的负对照本身有缺陷

在 Comenius 上我查过「有没有人工痕迹」，查的字段是
`tier=U` ／ `namesake_note` ／ `attribution_note` ／ `extraction_status=failed`
—— **没有 `tier_reason`**。Comenius 恰好一条都没有，所以结论碰巧是对的，
**但方法是不成立的**：我用一张自己拟的字段清单去证明「没有人工痕迹」，
而人工痕迹可以落在任何字段上。[[a-gates-scan-set-is-smaller-than-reality]]

**正确的做法（这次第二遍用的）**：不预设字段清单，
**对 union(前后所有键) 逐个比**，差异字段是什么就报什么。

1. `emit_source_ledger.py` 需要一个「**保留人工裁定**」的口径
   （至少 `tier`／`rights`／`tier_reason`／`extraction_status` 这几类不许被生成值覆盖），
   或者一个「重跑前先 diff、有人工痕迹就拒跑」的守卫。**本轮没做**——那是改工具，
   而工具改完要全库回归，不是今天能收干净的。
2. 第 1 批判完分之后，Jefferson／Rousseau 的台账再与 `_lanes.json` 对齐。

## 复现

```bash
# 全库看谁的台账与 _lanes.json 对不上（只读）
python3 - <<'EOF'
import json, pathlib, collections
C = pathlib.Path("_corpora")
for lj in sorted(C.glob("wip-*/workspaces/*/raw/_lanes.json")):
    ws = lj.parent.parent; led = ws/"evidence/source-ledger.jsonl"
    if not led.is_file(): continue
    a = {k: v for k, v in json.loads(lj.read_text(encoding="utf-8")).get("逐道份数", {}).items() if v}
    b = collections.Counter(x for l in led.read_text(encoding="utf-8").splitlines() if l.strip()
                            for x in (json.loads(l).get("dimensions") or []))
    if a != dict(b): print(ws.name, "\n  _lanes:", a, "\n  台账  :", dict(b))
EOF
```
