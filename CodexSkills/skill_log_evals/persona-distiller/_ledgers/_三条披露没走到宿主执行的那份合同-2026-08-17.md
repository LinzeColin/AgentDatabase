# 今天加的三条披露，一条都没走到宿主真正执行的那份合同里

**2026-08-17**｜「单步命令都验过 ≠ 链条走得通」的又一次，**而且是我一天内连犯三次**。

## 发生了什么

v0.0.0.16 / .17 / .18 各加一条如实披露：

| 版本 | 披露 | 我在哪验的 |
|---|---|---|
| .16 | 无领域信号时明说「不是按专业选的」 | `route_team_moe.py` 的输出 |
| .17 | 遥测读的是哪个文件、在不在 | `route_team_moe.py` 的输出 |
| .18 | 分歧的可检出性分母 | `build_team_dossier.py` 的输出 |

**三条都通过了。** 然后我从用户真正的入口 `run_team_pipeline.py` 整条走一遍：

    execution-contract.json:
      domain_signal              **不在**
      ranking_driver             **不在**
      telemetry_path             **不在**
      divergence_detectability   **不在**
      NO DOMAIN SIGNAL           **不在**

**而 `execution-contract.json` 正是宿主 agent 实际执行的那份文件。**

## 为什么这一条不是「好看不好看」

合同里 `user_output_contract.show` **本来就写着**要呈现 "material disagreements"。
宿主拿到 `documented_divergences: []`，旁边**没有任何分母**，
它最诚实的写法就是「专家们意见一致」——
**断言了一件从来没有被测量过的事**。

⇒ Owner 说的「伪共识」，**就是在这一行被生产出来的**。
我在 dossier 里写的那段解释，宿主根本读不到。

## 补了什么

- `divergence_detectability` 从 dossier 原样带进合同
- `selection_caveats` 把 route-plan 的 `NO DOMAIN SIGNAL` 带进合同
- `user_output_contract.phrasing_rules` 明令宿主：
  **空列表不许写成「专家一致」，要写「没有检出分歧」并给出分母**

仍然是**只披露、不改行为**：选人／打分／裁决／人数／控制面一律不动。

## 落成守卫

`tests/test_disclosures_reach_the_contract.py`：跑**真实用户入口**，
断言在**最终**产物上、不在中间产物上，两个方向都钉
（有信号 → caveats 必须空；无信号 → 必须带 `NO DOMAIN SIGNAL` 进合同）。
反对照实跑：把合同那行接线换成 `[]`，当场变红。

## 可执行的一条

**「我在哪验的」和「谁在读它」是两个问题，我今天三次只问了第一个。**

产出一条信息之后，别停在「产出它的那个脚本打印对了」。
往下追一步：**这条信息最终要被谁读？那个人读得到吗？**
本项目已记过同型：
