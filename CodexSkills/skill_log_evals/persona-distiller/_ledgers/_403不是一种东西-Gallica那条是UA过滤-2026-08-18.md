# 403 不是一种东西 —— Gallica 那条是 **User-Agent 过滤**，不是访问控制（2026-08-18）

## 实测

延后名单 186 条里，**31 条**提到 403／401／429／Access Interdit／blocked。
今天只探了其中**一条具体通道**（Gallica SRU），因为有两个人的记录都点了它。

| | 记录里写的 | 今天实测 |
|---|---|---|
| 裸 `curl` 打 SRU | 「**Gallica SRU 403 Access Interdit**」（Eiffel #142）｜「Gallica 403」（Benardos #128） | **403，复现了** |
| 带一个如实标明身份的 UA | —— | **同一个 URL 200 / 59 KB** |

UA 用的是 `persona-distiller-probe/1.0 (public-domain corpus availability check; contact: …)`。
**这不是绕访问控制** —— Gallica 是免费公共数字图书馆，其 API 本就要求带 UA；
挡住我们的是**机器人过滤器**，不是任何权利或授权边界。

## 两个人，两种结果 —— 这正是为什么必须逐个探

- **Eiffel #142**：`dc.creator all "Eiffel Gustave"` → **32 条**，其中
  `Auteur du texte` 且 ≤1930 的 **14 条**（1885–1913 法文原著），
  `unblock_todo` 点名的 1907／1910／1911／1913 四部**全在**（ARK 已记进名单）。
  ★★★ **但 `.texteBrut` 取不到正文**（三种形式返回逐字节相同的 50212 B 网页外壳，
  法文关键词 0 命中）⇒ **仍不解锁**。书目命中 ≠ 正文取得到。
- **Benardos #128**：403 同样是 UA 过滤，**但墙后确实没有他** ——
  `dc.creator all "Benardos"` → **1 条**，还是**另一个人**（`Bénardeau, Fabien`）。
  ⇒ 延后按实质成立，理由从「被挡住」改为「**探过了，没有**」。

## ★★★ 不许把这条推广成「把那 31 条都用 UA 重试一遍」

那 31 条里**绝大多数是真的访问控制**，记录里写的「**未绕过／停手不绕**」是**对的，且必须保持**：

- Cloudflare 质询（Jean Watson 的 Wiley/Elsevier、Peplau 的 AJN）
- 付费墙 / 受控数字借阅（Templeton 直取 `_djvu.txt` 得 **401**，确认借阅限定）
- 验证码（Heinrich 撞 JSTOR 验证码，**探测方退了出来 —— 这是对的**）
- WAF（Gawande 的 `foreign.senate.gov` Akamai 403，curl 与 WebFetch 双通道同样 403）

**能重试的只有一类：免费公共 API 上的机器人/UA 过滤。**
判别法：换 UA 后**同一 URL 直接 200**，且站点本身不要求登录/付费/接受条款。
凡是要点「我同意」、要登录、要解验证码、或要绕 WAF 的，**一律停手**。

## 给下一个人

1. **Gallica 不必再打 403**：带 UA 即可读 SRU。
2. **正文改走 IIIF／ALTO**（`https://gallica.bnf.fr/iiif/{ark}/manifest.json`），
   不要再试 `.texteBrut` —— 它对页范围不敏感，返回的是网页外壳。
3. **取到正文之后再说「取到了」**：先数法文实词命中，别拿书目条数充数。
