## 二、判据形状：规则，不是阈值

**凡长逐字引文，同段内必须出现至少一项坐标线索。** 不设比例阈值。

理由写在文件头里：我没有任何实测能支持「八成带坐标就够了」这种数字，
而 v0.0.0.36 的 `METHOD_FLOOR = 3` 已经留了一个「暂定值，无实测支持」的疤。

> **能写成规则就别写成阈值。规则不需要标定，阈值需要。**

## 三、复用而非另抄

引号形态与取组直接 `from check_quote_integrity import Q, _q`。

v0.0.0.37 的教训是「判据只认中英式引号，法文 «» 一条扫不到，
Pasteur 64% 的引文从未被核过而判据照样报绿」。
若这里再抄一份正则，两边迟早分叉——**而分叉的那一侧会静悄悄地报绿。**

## 四、负对照（5 条，含三条反向）

```
$ python3 scripts/check_quote_locator.py --self-test
══ 负对照 ══
  ✓ 抓到 同段无任何坐标线索的长引文

══ 反向对照 ══
  ✓ 同段带刊名年份页码的同一条引文 → 放行
  ✓ 坐标落在另一段 → 仍抓出（窗口有效）
  ✓ 短引文（不足 18 字母）不计入
  ✓ 无引文 → total=0（调用方须据此报「未检查」而非「通过」）

  ✓ 负对照通过（5/5）
```

第二条与第三条是这件判据的关键：

- 没有第二条，本件就只是「凡引文皆报」，等于没判据。
- 没有第三条，窗口写多大都无所谓——全文一搜，任何一篇带年份的文档全绿。

## 五、射程边界（写进文件头，不靠人记）

- **坐标对不对，它不判。** 写个错页码照样过。它挡的是「一个坐标都没有」。
- 同段内出现即算数——段落是读者的实际检索单位。
- 短引文不计，否则术语加引号会灌水分母。
- 中文引文不计：本流水线的逐字引文都是原文，中文的是译述。

## 六、接线与普查

退出码 `0=都带坐标　1=有缺　2=自测未过　3=一条都没扫到（未检查，不是通过）`，
接进 `--phase release`，缺坐标记为硬错 `content.quote-no-locator`。
**不需要 `--cache`**——它判的是文本自身可不可回查，与语料无关。

门实测：

```
"code": "content.quote-no-locator",
"message": "有逐字引文无从回查：同段内既无年份也无卷页刊名。长逐字引文 17 条，同段带坐标 8 条，**缺坐标 9 条**"
```

元检查器普查：可用负对照 **15 → 16**。测试 70/70，契约漂移 0。

## 七、这一版没做什么

- **没有顺手把 9 条补上再报版本。** 判据先落地、先量出数，再改产物——
  反过来做的话，这一版的证据就变成「我改完了所以是绿的」。
- **没有把它接进 research / synthesis。** 它判的是被发布的答案层，
  而答案层要到 release 才成形。接早了只会在每个人身上空跑一遍。
