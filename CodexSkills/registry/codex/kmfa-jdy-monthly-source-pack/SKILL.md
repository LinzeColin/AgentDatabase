# KMFA 金蝶月度一级来源归档

## 目标和边界

本技能只取得、核验和归档一级来源。二级指标、管理报表、项目成本分摊和合并抵销由下游分析流程完成。

始终在用户已明确授权的 Chrome 已登录会话中操作。不得记录、输出、上传或复用账号、密码、身份证件、银行卡信息或税务敏感标识。不得修改凭证、单据、账套设置或向外部系统上传文件。

## 开始前先建立范围矩阵

1. 写明报告期，例如 `2026-07`，并使用自然月筛选区间。
2. 在金蝶账套切换器中逐个读取当前可见账套名称；它是本次在线账套范围的事实来源。
3. 同时检索授权 SMB 的财务一级原始数据目录，列出同月已有离线账套包。
4. 建立“主体 × 来源类别”矩阵，状态只能使用以下明确值：
   - `已归档原始文件`
   - `已采集页面快照`
   - `业务模块无记录`
   - `来源未取得`
   - `不适用`
5. 历史主体名册不能自动视为本月已关账范围。没有本月可用来源的主体必须单列为 `来源未取得`，不能将历史月份或其他主体数据混入本月合计。

## 每个账套的实际操作顺序

按账套循环执行，完成一个账套再切换下一个。每个页面都先确认账套名称、会计期间和筛选条件，再查询或导出。

### A. 总账和会计资料

1. 凭证查询：导出当月凭证 / 凭证明细；记录凭证张数、分录数、借贷合计。
2. 明细账：选择全部启用科目，导出当月明细账。
3. 科目余额表：导出或查询月末余额表。
4. 科目基础资料：导出会计科目基础资料并记录启用科目数量。
5. 三大报表：逐一导出资产负债表、利润表、现金流量表，确认报表期为目标月。

### B. 业务明细

1. 应收和应付：分别取得明细、账龄和预警表。若页面无法提供账龄字段，保留该限制。
2. 发票：分别查询销项税票登记、进项税票登记、费用发票明细，使用目标月自然日区间。
3. 固定资产：导出资产卡片及目标月折旧明细。
4. 资金：导出银行流水 / 现金银行流水，使用目标月自然日区间。

## 下载判定和异常处理

### 下载成功的唯一判定

只有同时满足以下三项时，才写 `已归档原始文件`：

1. 金蝶导出任务完成；
2. 结果页出现可用的下载入口并实际下载；
3. 本地文件可打开，表头、账套名称和期间与目标相符。

文件命名采用：`主体_来源类别_YYYYMM期.扩展名`。归档到：

`/Volumes/share/03_资料库/MetaData/KMFA_MetaData/财务/一级原始数据/金蝶导出/YYYYMM/主体/`

建议子目录：`01_账务基础`、`02_财务报表`、`03_往来与资金`、`04_税票与资产`。

### 导出任务成功但无下载链接

若“引出结果”显示成功而“结果文件下载”没有链接，状态必须写为 `已采集页面快照`，不能称为已下载。

创建页面快照，至少记录：账套、期间、页面名称、筛选条件、记录数、关键汇总金额、页面显示的导出状态和采集日期。保存至：

`一级原始数据/YYYYMM全公司补充/主体/04_系统页面采集/`

### 业务模块显示“暂无数据”

将状态写为 `业务模块无记录`。该状态只说明该模块没有可用记录，不能把收入、开票、应收、税费、资金或固定资产写成零。

继续以已关账总账、三大报表、科目余额表和外部已归档税务申报包作为主来源；在二级报表中清楚标明指标口径和模块限制。

## 归档后的必做核验

1. 对每个文件检查主体、报表期和文件类别，不匹配的文件不得进入当月包。
2. 资产负债表检查：资产总额 = 负债总额 + 所有者权益总额。
3. 现金流量表检查：现金净增加额 = 经营 + 投资 + 筹资活动净额，且期末现金与资产负债表货币资金可比。
4. 凭证检查：借方合计 = 贷方合计。
5. 输出一张来源覆盖矩阵，所有单元格填写状态或限制说明，不能留空。

## 向下游交付的最小包

每个主体和月份至少交付以下可追溯信息：

| 类别 | 最低交付 |
|---|---|
| 财务主表 | 资产负债表、利润表、现金流量表 |
| 总账 | 凭证、明细账、科目余额表、科目基础资料 |
| 往来 | 应收应付明细与账龄；不可得时注明页面限制 |
| 税票 | 销项、进项、费用发票或明确的模块无记录状态；已有税务申报包一并归档 |
| 资产 | 固定资产卡片、折旧明细或明确状态 |
| 资金 | 银行流水或明确模块状态；同时提供现金流量表口径 |
| 留痕 | 下载核验结果、页面快照（如需要）、来源覆盖矩阵 |

## 停止条件

当每个可见在线账套和已授权离线账套包均已写入范围矩阵、每个来源类别具有明确状态、归档路径可追溯且关键勾稽成立时，一级来源任务完成。

如果缺少账套、某个主体未关账、下载入口失效或需要补充非金蝶数据，只报告缺口、已核验事实和最小所需授权；不得以估算值补齐。
