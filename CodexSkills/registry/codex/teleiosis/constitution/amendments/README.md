# Genesis Amendments

Genesis amendments are append-only and require explicit user authorization under WBI-GB-026.

- `WBI-GB-AMENDMENT-001-v0.0.0.2.zh-CN.md` adds WBI-GB-028 without changing WBI-GB-001—027.
- The byte-preserved base remains anchored by `constitution/genesis-lock.json`.
- The effective set is anchored by `constitution/effective-genesis-lock.v0.0.0.2.json` and projected in `constitution/effective-requirements.v0.0.0.2.json`.
- A later change must add another amendment; do not edit or re-sign an existing amendment in place.
