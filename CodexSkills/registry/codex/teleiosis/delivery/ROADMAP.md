# Roadmap / Reheat Triggers

The release is installable without the following future adapters. Reheat is event-driven, never recursive:

1. provider- or hardware-attested independent SubAgent runtime becomes available;
2. remote Git access, source adapter or sandbox capability changes;
3. a stronger peer wins a protected task without hard regression;
4. Agent Skills specification, runtime installation convention or security guidance changes materially;
5. a real target task fails, a protected task regresses or a dependency is deprecated;
6. a new evaluation method materially improves truthfulness, transfer or cost measurement;
7. the user explicitly amends a Genesis Requirement ID.

Each trigger opens a new bounded run from the last stable Baseline. No roadmap item may silently become Genesis or a prerequisite for normal installation.
