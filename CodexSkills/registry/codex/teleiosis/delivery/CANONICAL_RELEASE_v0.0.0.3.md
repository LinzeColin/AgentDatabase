# Teleiosis v0.0.0.3 Canonical Release

当前唯一产品身份为 `teleiosis`，当前唯一版本为 `v0.0.0.3`。Raw Teleiosis、Skill Market Lab 与 Product Reality Lab 是同一 Registry Skill 的内置模块，不是三个路由分支，也不产生三个独立安装项。

固定执行：

```text
一轮：T1 -> C1 -> S1 -> C2 -> P1 -> C3
一组：三轮
一次 Run：三组
```

`C` 是迭代对象本身的连续 Candidate revision。任何 fingerprint 或 hash 仅在阶段后用于审计、证据绑定和篡改检测，不作为下一阶段、安装或移动 main 语义合并的固定前置条件。

当前安装、GitHub 集成和回滚命令以 `delivery/INSTALL_AND_GITHUB.md` 为准。其他标题中含 v0.0.0.1 或 v0.0.0.2 的文件属于保留的历史谱系材料，状态为 `SUPERSEDED_FOR_EXECUTION`。
