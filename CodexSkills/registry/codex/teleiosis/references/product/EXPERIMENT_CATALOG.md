# 产品现实试炼目录

- 前端：跨浏览器、响应式、键盘、焦点、缩放、长文案、空态、加载态、错误态、刷新、后退、多标签、旧页面、弱网、可访问性。
- 后端/API：Schema、鉴权、状态链、非法/边界输入、幂等、重试、乱序、并发、事务、队列、Webhook、缓存和外部依赖失败。
- 数据：约束、迁移、账务/汇总不变量、重复导入、损坏文件、时区日期、备份恢复、跨系统对账。
- 可靠性：Smoke、Average、Stress、Spike、Breakpoint、Soak，以及网络、DNS、CPU、内存、磁盘、进程、队列、缓存、依赖故障。
- 防呆：误点、连点、双击、重复提交、刷新、旧页面、错误角色、过期 Session、半失败、重试、Undo、Rollback 和审计责任。
- 安全：仅在授权边界内测试权限、输入、供应链、Prompt Injection、敏感数据和危险副作用。
