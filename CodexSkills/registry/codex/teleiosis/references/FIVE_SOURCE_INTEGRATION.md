# Five-source integration

The v0.0.0.3 installed tree preserves and integrates:

1. Teleiosis v0.0.0.1 immutable Genesis and white-box principles.
2. Owner Teleiosis v0.0.0.2 complete engineering/control-plane source.
3. Public market-integrated Teleiosis v0.0.0.2 market evidence kernel.
4. Skill Market Lab v0.0.0.1 complete source under `modules/skill_market_lab`.
5. Product Reality Lab v0.0.0.1 complete source under `modules/product_reality_lab`.

Only the top-level `SKILL.md` is registry-discoverable. Nested source uses `MODULE.md` so installation yields one Skill identity and one promotion authority.
