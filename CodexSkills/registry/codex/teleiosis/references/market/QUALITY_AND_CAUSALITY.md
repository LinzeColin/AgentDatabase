# 质量与因果硬门

Teleiosis v0.0.0.2 在任何结果汇总和市场结论前，强制执行以下不可补偿硬门：

1. sealed holdout 与可见分区的精确/近似污染审计；
2. 离线 paired full-factorial 或线上 exclusive assignment 完整性；
3. Sample Ratio Mismatch（SRM）与跨臂暴露检查；
4. 同一配对单元的模型、运行时、工具、权限、预算、系统与数据集一致性；
5. 运行前冻结的 fixed-horizon power plan 或预声明 sequential contract；
6. LLM-as-judge 仅在启用时使用，必须与生成者分离并经人类金标校准；
7. 真实市场事件的时效、重复、未来时间与臂间时间偏斜检查；
8. task → result → feedback → artifact 的引用完整性；
9. Subject、Spec、Dataset、Assignment、Result、Quality、Summary 与 Gate 的单一证据链摘要。

任何 BLOCKED、REHEAT_REQUIRED、NOT_RUN 或缺失证据不得被平均分补偿。
