# Freshness and Future Adaptation

Every formal run freezes a dated source dataset covering:

- models and Agent runtimes;
- optimization methods and architectures;
- evaluation and judge methods;
- standards, security and deprecations;
- direct, indirect and craft peers.

Prefer official documentation, source repositories, standards and primary papers. Record query date, release/version, claim, evidence status and unknowns. Search results are discovery, not proof.

## Validity

A run defines `valid_as_of`, validity duration and reheat triggers. Status becomes `REHEAT_REQUIRED` when evidence expires or when a major model/runtime release, stronger peer, real-task regression, security advisory, standard/dependency change or Genesis amendment appears.

## Future-proofing

Future adaptation comes from replaceable adapters, source registries, capability detection, cross-model testing and reheat—not from predicting every future technology in a long prompt. Unknown future systems are explicit `UNKNOWN`, not silently treated as covered.
