# Freshness and Future Adaptation

Every formal run freezes a dated source dataset before mutation and a second `current_environment_snapshot` before delivery. Sources cover models/runtimes, optimization methods, evaluation, standards/security/deprecations, direct peers and library-scale routing conditions.

Every final output carries an `evidence_lease`: `valid_from`, `expires_at`, comparison set, environment, evidence hashes, unknowns and reheat triggers. Expiry or a material model/runtime/peer/security/standard/requirement change turns any previous strength status into `REHEAT_REQUIRED`.

Future-proofing comes from replaceable adapters, capability detection, current evidence and bounded reheat—not from predicting every future technology or freezing one vendor in Genesis.
