# 用户使用说明

## 安装后唯一需要记住的用法

```text
$prompt-compiler
优化下面这条提示词。逐字保留原文，生成 ChatGPT、Codex、Claude、Gemini 四个版本；先跑原版基线，再做多引擎优化，最后用三次重复、回归、红队和独立终审验收。

【原始提示词】
在这里粘贴
```

## 四种结果

- **正式通过**：真实最终案例、双版对照、回归、红队、独立终审和外部证据全部通过；仍需责任人看完差异后采用。
- **临时通过**：数值改善，但主要依赖临时或合成案例；只适合试用，不能当成正式证明。
- **退回**：优化版本提升不足、旧能力退化、硬约束失败或稳定性变差；继续使用原版。
- **阻塞**：缺模型、数据、Promptfoo、独立终审或真实外部证据；先解决报告中的第一项阻塞。

## 三种运行强度

- **冒烟模式**：只验证整条管线能运行，不证明质量。
- **快速模式**：日常默认选择，控制成本并保留完整门禁。
- **正式模式**：真实案例充分且准备正式发布时使用；代码、架构和配置还必须接入目标项目自己的测试预言机。

## 历史与文脉记忆

每次输入都永久追加，不覆盖旧记录。每次原始输入和对应四模型版本都有独立编号、哈希和父子关系；优化后的获胜候选也会再生成四个版本并写入同一账本。

可以让 Codex 执行：

```text
$prompt-compiler 查看这个项目的全部历史输入，并按每次输入列出对应的 ChatGPT、Codex、Claude、Gemini 四个版本和获胜版本。
```

## 你不需要做的事

不需要手写 Python，不需要理解 GEPA，不需要制作 Promptfoo 配置，也不需要手动管理数据文件。代理能访问终端时应代你完成；只有模型授权、真实业务案例、费用上限和最终发布责任需要你决定。
