# 独立评测与发布门禁

## 默认发布阈值

- 最终测试均值至少比种子版本提高 0.05；
- 优化版本硬失败数必须为 0；
- 同一最终数据重复至少三次，并真实覆盖每个案例；
- 提示词长度增幅不超过 30%；
- 方差增幅不超过 0.02；
- 任务模型与独立终审模型身份不同；
- Promptfoo 在同一次独立对照中真实产生种子版本和优化版本两组结果；
- 旧案例回归通过；
- 固定红队和 Promptfoo 官方红队通过；
- 真实 GEPA 安装、Codex 调用、Promptfoo 对照证据通过；
- 持续集成重新核验独立证据后才允许发布。

## 决策含义

- **正式通过**：全部真实门禁通过，允许责任人人工复审差异后发布。
- **临时通过**：数值满足阈值，但最终案例含合成数据或存在实验性限制；不允许正式发布。
- **退回**：候选未达到提升、硬约束、长度、方差、稳定性或回归标准；继续使用种子版本。
- **阻塞**：缺运行环境、独立终审、Promptfoo 双组、红队、外部证据或目标项目真实预言机。

机器可读报告保留稳定状态代码供自动化读取，用户可见报告必须显示上述中文决策。

## “比竞品好”的证据规则

只有下列条件全部满足，才允许写：

```text
在当前封印数据、当前模型身份、当前相同预算、当前统一预言机和相同重复次数下，获胜候选的独立最终结果不低于所有实际运行的请求引擎。
```

不得写“普遍优于 GEPA、Promptfoo 或所有竞品”。以下任何一种情况都只能写“尚未证实”：

- 竞品没有实际运行；
- 预算、可见数据或终审模型不同；
- 最终测试不一致；
- 终审身份不独立；
- 只比较最好一次而非三次统计；
- 外部工具自报分数但未由本技能独立复评。

## 持续集成防伪完成

持续集成不能只相信报告中的“允许发布”布尔字段。它必须重新检查：

1. Promptfoo 最终双版对照；
2. Promptfoo 回归；
3. 固定红队双版对照；
4. Promptfoo 官方红队的实际结果行；
5. 同预算独立终审竞赛证据；
6. 外部真实验收状态。

任一证据缺失、被篡改或不一致，发布即阻塞。
