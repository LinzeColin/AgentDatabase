# 自适应双角色路由与冠军合成

## 双角色不是降级关系

四个核心竞品同时存在于两个平面：

```text
同层竞技平面：GEPA | AutoResearch | Meta-Harness | Promptfoo | Prompt Compiler
下层能力平面：反思演化 | 单变更实验 | Harness 搜索 | 评测红队 | 冠军合成控制
```

Prompt Compiler 必须击败同层对手；同时可复用各自已验证机制。复用后的 Prompt Compiler 候选仍需与来源竞品在独立最终测试中重新比较，不能因“包含对方能力”自动判胜。


## 原生路径前置门

预算路由之前，四条核心路径必须先满足原生执行合同：GEPA 官方 API、Promptfoo 官方 CLI、AutoResearch 可验证工作区真实命令、MetaHarness 官方入口真实命令。任何路径失败时 Omni 不进入第二阶段，预算不能转移给本地同名模拟。

## 一个总预算

预算分配使用：

```text
最低探测预算
+ 当前最弱维度差距
+ 任务剖面
+ 执行器能力先验
+ 最大余数整数分配
```

所有分配之和必须精确等于冻结总预算。Prompt Compiler 的合成预算也在其中，禁止额外无限调用。

## 能力路由

| 发现的主要差距 | 优先执行器 | 路由理由 |
|---|---|---|
| 正确性、覆盖、总体效果、复杂交互 | GEPA | 完整轨迹反思、变异、Pareto 搜索 |
| 稳定性、归因、成本、回归 | AutoResearch | 一次一个假设、保留或丢弃、实验记忆 |
| 结构、工具、检索、恢复、可执行性 | Meta-Harness | 搜索固定模型外围的 Harness |
| 安全、断言、回归、红队、Oracle | Promptfoo | 评测、断言、红队和 CI 证据 |
| 多项差距并存 | Prompt Compiler | 从各维度领先候选中进行受控合成 |

能力先验只用于预算分配，不能决定冠军。

## 冠军合成

1. 验证四条独立原生路径均为 PASS 且各自产生至少一个候选；
2. 选择验证集上稳健排序最佳的原生候选作为 Portfolio Baseline；
3. 计算 Prompt Compiler 当前候选与所有候选的逐维差距；
4. 选择最大差距维度；
5. 载入该维度领先候选、硬安全领先候选、成本领先候选和当前总体最佳；
6. 只允许一个可归因机制变化；
7. 使用统一预言机独立验证；
8. 按“硬安全→最弱维度→最弱切片→总体→稳定性→长度”比较；
9. 改善则 KEEP，否则 REVERT；
10. 重复直到轮次或预算上限。

同正文候选可复用模型评测结果，但必须保留不同引擎来源记录，避免省成本时抹掉竞品身份。
