# 写用例第一稿时逐条对照（由 `judge_prompts/seat_E_strict.md` 的七项检查倒推）

Robertson #97 的教训：**加评审轮次补不上第一稿的质量差距**——
十三轮下来分数没有单调上升，而换成冻结尺子后同一批产物一轮就过。
所以这一次**在写之前先把尺子摆在桌上**。

严格席的七项检查 → 我写每一条 candidate 时要做的事：

| 它查什么 | 我要做什么 |
|---|---|
| **1. 算术** | 凡写数字关系，**自己先算一遍并把算式留在答案里**；同一个数在不同用例里口径必须一致 |
| **2. 证据分层** | 每条答案分三层并**各自标注**：**【他说的】**（原话，带年份场合）/ **【推算】**（我算的）/ **【推断】**（我的读法 + 推理链）。**三层不得混排。** |
| **3. 承重证据出处** | 先问「这条结论主要靠哪一句撑」，**那一句必须有年份与场合**。最重的那句不能是最薄的那句 |
| **4. 绝对语** | 「从不 / 唯一 / 一条都没有」一律写成「**在我手上的材料里**……」；并写明我是**用什么检索式、在什么范围**确认它缺席的 |
| **5. 过度解读** | 并列 ≠ 顺序；两个时点 ≠ 一段连续期；一两个事例 ≠ 一贯；A 类对象 ≠ 任何对象。**要说「一贯」得先有他把理由本身说出来过** |
| **6. 自造框架** | 不发明分类轴。要用框架就说明「这是我加的框架，语料里没有」 |
| **7. rubric 反向作弊** | rubric **只写「要测什么能力」，不写答案的措辞与推算结果**。写完自问：**一个只读到 prompt 的人有没有可能想到这一条？** |

## 另加三条（Robertson 轮实际扣分处）

- **加粗只承载限定，不承载结论**；覆盖率控制在 20% 以内。
- **先正面回答提问**，再讲引证纪律。答案不能通篇是元讨论。
- **说清楚语料里缺什么**（规模、年份、名单、理由），不是只说有什么。

## 本人物（Steinhardt）特有的三个高风险点

1. **1994 年国债市场操纵的和解**——不得写成「被误解」或略过；
   同时**和解 ≠ 认罪**，这个区分要写准。
2. **2021 年掠夺文物归还与终身禁令**——不得省略、不得只说「收藏家」。
   这是最容易被产物粉饰的一处。
3. **「variant perception」是他自己的词**——引用要给原话与出处，
   不要把它扩写成一套我编的方法论。
