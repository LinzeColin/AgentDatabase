## ⑦ 三轮盲判：**A/B 映射固定** vs **每轮重随机**——两者不能兼得

**实测（2026-08-04 全量）**：9 人 × 32 题 × 3 轮，290 个（人物, 题）组合
**全部在 ≥2 轮里出现，跨轮换过边的 0 个**——翻转率 **0%**，8 人无一例外。

**★ 这不是疏漏，是有意的设计。** `build_blind_payload.py` 里写着：

```
# 轮次之间 A/B 映射必须一致，否则各轮不可比
```

并有一道**硬门**：映射与第 1 轮不一致就中止（`return 3`）。
分配用 `sha256(case_id) % 2`，与轮次无关，正是为了满足那道门。

### 权衡的两面

| | 固定映射（现状） | 每轮重随机 |
|---|---|---|
| 各轮逐题可比 | **是** | 逐题对照会被打乱 |
| 三轮是独立复现 | **否** | 是 |
| 第 1 轮认出的边 | **后两轮原样有效** | 每轮要重新认 |

**代价是实的**：两席已实测能靠格式认出候选侧（Barton **100%**、四人合计 116/128 = **91%**），
靠长度也能（席 D：「长的一侧在 32/32 全部命中同一个系统」）。
**所以「三轮 delta 逐轮向零」这类跨轮趋势，不宜当三个独立样本读。**

★ **这不推翻任何已记录的 delta**——那些数是真的。推翻的是「三轮 = 三次独立测量」这个读法。

## ⑩ **五条公有领域依据全是美国法**——非美国人物怎么判？

## ⑬ **盲判的最后一条泄题通道，堵不上——因为它就是产品本身**（2026-08-05，Carver #127 量出）

### 事实

Carver #127 第 1 轮载荷，泄题门逐通道实测：

| 通道 | 候选 | 基线 | 可利用率 | 门 ≤75% |
|---|---|---|---|---|
| 粗体/反引号 | 0/16 | 0/16 | 0% | ✓ |
| 项目符号 / 标题行 / 空行分段 | 0/16 | 0/16 | 0% | ✓ |
| 破折号 | 13/16 | 11/16 | 19% | ✓ |
| **「」直角引号** | **15/16** | **2/16** | **81%** | **✗ 超门** |

### 这一条是怎么被发现的

**是我自己撞出来的，过程不体面，但正是它说明了问题。**

第一版候选答案用反引号标引文，门报 **「粗体/反引号 88% 可指认」** 并拒发。
我把反引号改成「」，**门立刻变绿**。
——**绿的是门，不是事实。** 破绽只是从一个被查的通道挪到了一个不被查的通道。

### 「」为什么不在通道表里：那是量过的决定，不是疏漏

`check_answer_surface_leak` 的源码里写着：四人实测「」可利用率
**16% / 19% / 31% / 31%**，两侧都在用；且**删引号会同时弄瞎三道引文判据**
（`check_verbatim_quotes` / `check_quote_locator` / `check_quote_integrity`
正是靠 `「…」` 认出「这里有一条逐字引文」的）。

★ **Carver 是 81%——那个「两侧都在用」的前提，在本人物身上不成立。**

### 为什么它堵不上

**候选带引号，是因为它在引语料；基线没有语料可引。**
这不是格式习惯的差别，是**有没有根据**的差别——
而「有根据」正是这个产品声称提供的东西。

**任何忠实的候选都会比基线更常引用。要让两侧在这一点上无法区分，
只有两条路：要么让基线也有语料可引（那它就不是基线了），
要么让候选别引（那它就不是这个产品了）。**

### 我做了什么、没做什么

- **做了**：把「」加为**只报不拦**的测量项，每轮都印出来，并写明
  「改法绝不是把候选的引号删掉」。
- **没做**：没把它设成拦截通道（删引号的代价更大），

## ㉓ 产品的**立身之本**同时是一条完美的破盲线索——盲判在这个产品上可能根本盲不了（2026-08-05 记，席 F 提出）

### 事实

席 F（无 rubric 席）在 Bessemer #132 第 2 轮自己发现：载荷里两种作答风格可分，
「一种带章次页码逐字引文，一种明说我手上没有那本自传的文本」，而且**不跟 A/B 列走**。
它没有拿这个去反推系统（做得对），只报了形状。

按 key 回查后逐人物实测：

| 工作区 | 候选带坐标 | 基线带坐标 | 现行通道口径 | 两侧不同的题 | 其中带坐标的是候选 |
|---|---|---|---|---|---|
| henry-bessemer | **9/16** | **0/16** | 56% | 9 | **100%** |
| george-washington-carver | 2/16 | 0/16 | 12% | 2 | **100%** |
| comfort-avery-adams | 1/16 | 0/16 | 6% | 1 | **100%** |
| elihu-thomson | 1/16 | 0/16 | 6% | 1 | **100%** |
| gregor-mendel | 0/16 | 0/16 | 0% | 0 | —— |

★★★ **基线在五个人物上、80 道题里，一次坐标都没给过。**
所以「看见章次页码 → 这是候选」这条规则，**在全库 13 道可分辨的题上一次都没错过。**

### 现行判据为什么放它过去

`check_answer_surface_leak` 的可利用率是 `|候选命中 − 基线命中| / 总题数`。
Bessemer 算出 56%，门 75%，**过**。

**但这个式子把两件事混成了一件**：「这条线索多久出现一次」和「它出现时有多准」。
- `破折号` 候选 16/16、基线 13/16 → 19%。**对**：看见破折号什么也说明不了。
- `坐标` 候选 9/16、基线 **0**/16 → 56%。**错**：看见坐标就**一定**是候选。

**一侧恒为 0 的通道，是「有则必是」，不是「多一点少一点」。**
分母该是「两侧不同的题」，不是「全部题」。按后者算，五个人物全是 **100%**，远在门上。

### ★★★ 但这一条**不能**照常规办法修

粗体、项目符号、★ 那些是**排版**，删掉不损失任何东西。
**坐标不是排版，它就是这个产品本身**——
`fact-preservation +0.3100`、`引文坐标门 23/23`、整条流水线的卖点都是「说的话能回查」。

**为了过盲判门而把出处删掉，是拆掉产品去迁就仪器。**

### ★★★★★ 病根定位到一行代码——**而且不是 OCR**

顺着「第三条路」往下量，`ocr_byline_evidence` 的失败点是精确的：

```python
toks = [t for t in re.split(r"[^A-Za-z]+", body) if t][:5]
a = toks[0].lower()
if len(a) < 4 or not _edits_within(a, first_l, 2):
    continue          # ← 名必须**恰好是第一个词**
```

对 `By W. Chandler Austen.`：`toks = ['W','Chandler','Austen']`，
`a='w'`，`len(a)<4` → **整行丢弃，从不尝试 `Chandler`**。

隔离实验（**去掉 OCR 干扰，用干净字符串**）：

    By Chandler Austen.              → 命中
    By Chandler Austen, F.R.S.       → 命中（逗号不是问题）
    **By W. Chandler Austen.         → None**   ← 只多了一个首字母
    By W. Chandler Koberts- Austen.  → None

**所以主因不是 OCR，也不是连字符姓，是「署名里名字前面有个首字母」。**
`By <首字母>. <名> <姓>` 是维多利亚期刊最常见的署名式样。

## ㉝ **`status: hypothesis` 在本流程里没有落脚点**（2026-08-10，Pacioli #161）

### 事实

`quality_check.evaluate_claims` 对 `mental-model／heuristic／value／work-method／
blind-spot／contradiction` 六类要求 **≥2 处来源、≥2 个语境、≥2 个证据簇**，
而它**只排除 `superseded|unknown`**：

```python

...
if claim.get('category') in {'mental-model', 'heuristic', ...}:
    if len(set(claim.get('source_ids', []))) < 2:
        report.error('claim.insufficient-support', ...)
```

**于是 `hypothesis` 与 `pattern` 被一视同仁地要 ≥2 处。**

### 后果

**「我认为这是个模式，但只有一处证据」这件事，本流程里没有诚实的记法。**
只有两条路：

1. 去凑第二处 —— **造假**；
2. 降成「某来源记载了什么」的事实条 —— **少说了**，且把「这可能是他的一种模式」
   这条信息从断言层挤到备择解释里。

### 本轮我做了什么

**选了 2，并且没有去改那条门。** 我正被它挡着，
**这时候去改它就是「为凑数放宽判据」的标准形状。**

### 已量清的两件事（供裁定）

- **爆炸半径**：全库 602 条断言里 `status=hypothesis` **13 条**；
  「需 ≥2 处却不足 2 处」的 active 断言**只有 2 条，都是本轮刚写的**。
  → **改这条门对存量恒无影响。** ★ 但那让它**安全**，不让它**正当**。
- **不会放水**：`min_models`／`min_heuristics` **只数 `status == 'pattern'`**，
  所以豁免 hypothesis **不会让任何人多过一道门**，只会让「证据不足」这件事
  能被如实记在断言层里。

### 请裁定

**`status: hypothesis` 是否应豁免「≥2 处来源／语境／簇」？**

- **是** → 改 `evaluate_claims`，把那三条判定限定在 `status == 'pattern'`；
  同时给 `hypothesis` 加一条硬要求：**必须写明「还缺什么才能升为 pattern」**。
- **否** → 维持现状，`hypothesis` 事实上等同 `pattern`，
  **那么应把它从 `--status` 的枚举里删掉**，免得下一个人再走一遍这条死路。
