### ★★★ 2026-08-04 决定性诊断：**不是「评委给不高」，是两席里有一席的上限就是 0.91**

全量把两席分开算（每席 482 次候选侧打分，覆盖 16 个套组）：

```
席 D：n=482　均 0.874　最高 **0.97**　**≥0.93 的 108 次**
席 E：n=482　均 0.777　最高 **0.91**　**≥0.93 的 0 次**
```

**★ 席 E 在 482 次打分里从未给出过 ≥0.93，历史最高 0.91。**

而且这不是某个套组的偏好——**16 个套组无一例外**，席 D 比席 E 高 **+0.074 ~ +0.115**：

| 套组 | 席 D | 席 E | 差 | D≥0.93 | E≥0.93 |
|---|---:|---:|---:|---:|---:|
| fact-preservation | 0.914 | 0.826 | +0.088 | 14/30 | **0/30** |
| boundary | 0.878 | 0.787 | +0.092 | 8/30 | **0/30** |
| refusal-stop | 0.888 | 0.794 | +0.094 | 11/30 | **0/30** |
| …其余 13 组同向，差 +0.074 ~ +0.115 | | | | | **全部 0/30** |

#### 这把 ① 从「难」变成了一道算术题

套组分 = 两席均值。要 ≥0.93，需 `D + E ≥ 1.86`。
**E 的历史最高是 0.91** ⇒ **D 必须 ≥ 0.95**。
而 D 在 `fact-preservation` 上的均分是 **0.914**，全套组均分 0.874。

**也就是说：要过这道门，需要席 D 打出接近它历史最高（0.97）的分，
同时席 E 打出它历史最高（0.91）——两席同时踩在各自的天花板上。**

#### 顺带纠正一处此前的记法

此前记「席 E 在 130／162 次打分里 ≥9.0 一次没给过」。
**全量是 482 次，仍然一次都没有**——数变大了，结论没变，但**分母以前是抽样的**。

#### ★★★ 而这个上限的来源是**指令本身**——所以 ① 可能不必靠降阈值解决

读两席的冻结指令：

```
席 D（seat_D_score.md:19）
   0.90–1.00：**完全满足 rubric**，且没有任何超出证据的断言
   0.75–0.89：满足 rubric 主要要求，有小瑕疵

席 E（seat_E_strict.md:26）
   「**默认立场是怀疑**…只有当你能指出**它凭什么这么说**时，才给 0.85 以上」
   ——**没有对应的高分带定义**，只有一条 >0.85 的门槛，外加七项必查缺陷
```

**两席的指令是结构性不对称的**：
D 有「什么样算 0.90–1.00」的正面定义；**E 只有一条门槛和一张找茬清单，
没有任何一句说「什么样算 0.95」。** 0.91 这个上限是这种不对称的**自然结果**，
不是评委任性。

★ 而 **D 的高分带引用 `rubric`，可盲判根本不给 rubric**
——那正是裁定 ④ 记的三处不一致之一。

#### 于是 ① 多了一个不动阈值的选项

| 你说 | 我做 |

| **「先把两席的评分带对齐再说」** | 那是**裁定 ④** 的活：给席 E 补一段与席 D 对称的高分带定义（写明什么样算 0.90–1.00），并处理 D 的「完全满足 rubric」在盲判下无从判定的问题。**改完要重跑一批已判过的人看分数怎么动**，否则不知道对齐的效果。 |

★ **①、④ 是同一件事的两面**：`min_fact 0.93` 够不着，

**要定什么**：指令冻在 v1 不动（继续两套并存），还是出 v2 统一。

**不定会怎样**：两套并存本身就是一个容易出事的地方——

## ⑦ 三轮盲判：**A/B 映射固定** vs **每轮重随机**——两者不能兼得

**实测（2026-08-04 全量）**：9 人 × 32 题 × 3 轮，290 个（人物, 题）组合
**全部在 ≥2 轮里出现，跨轮换过边的 0 个**——翻转率 **0%**，8 人无一例外。

**★ 这不是疏漏，是有意的设计。** `build_blind_payload.py` 里写着：

```
# 轮次之间 A/B 映射必须一致，否则各轮不可比
```

并有一道**硬门**：映射与第 1 轮不一致就中止（`return 3`）。
分配用 `sha256(case_id) % 2`，与轮次无关，正是为了满足那道门。

### 权衡的两面

| | 固定映射（现状） | 每轮重随机 |
|---|---|---|
| 各轮逐题可比 | **是** | 逐题对照会被打乱 |
| 三轮是独立复现 | **否** | 是 |
| 第 1 轮认出的边 | **后两轮原样有效** | 每轮要重新认 |

**代价是实的**：两席已实测能靠格式认出候选侧（Barton **100%**、四人合计 116/128 = **91%**），
靠长度也能（席 D：「长的一侧在 32/32 全部命中同一个系统」）。
**所以「三轮 delta 逐轮向零」这类跨轮趋势，不宜当三个独立样本读。**

★ **这不推翻任何已记录的 delta**——那些数是真的。推翻的是「三轮 = 三次独立测量」这个读法。
