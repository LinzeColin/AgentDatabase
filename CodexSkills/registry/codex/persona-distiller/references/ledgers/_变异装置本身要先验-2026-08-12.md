# 变异测试的装置本身要先验 —— 2026-08-12

> 起因：给 `check_quote_integrity` 的判定函数补自测（`check_selftest_reach` 的
> `KNOWN` 名单第 13 件）。自测一次写成、六条全绿，**而随后的变异测试证明它什么也没验到**。

---

## 一、两件事故

### ① 四个变异体全 rc=1，而一条 ✗ 都没有

| | |
|---|---|
| 我看到的 | `M1 rc=1 / M2 rc=1 / M3 rc=1 / M4 rc=1` |
| 我差点写下的 | 「四个变异全部被打红，自测有效」 |
| 真相 | 四个都死在 `ModuleNotFoundError: No module named 'common'` |

变异体被复制到 scratchpad 跑，而判据 `from common import corpus_body`。
**把未变异的原件放进同一套装置——它也是 rc=1。**

⇒ **正例不绿，所有的红都不作数。** 设 `PYTHONPATH=<skill>/scripts` 后装置才成立。

★ 判断法极便宜：**变异之前先跑一次 M0（原件）**，看见 rc=0、零条 ✗，再开始变异。
  这一步花 3 秒，省掉的是一条假的「已验证」。

### ② ⑳c 绿着，而它走的不是要验的那条分支

`acc["unchecked"]` 有**两个来源**：

| 来源 | 触发条件 | 代码位置 |
|---|---|---|
| 文本级 | `Q` 根本抽不到（它自己要求 ≥18 字符） | `acc["unchecked"] += count_unchecked(text)` |
| 段级 | `Q` 抽到了，但 `proj(seg) < MIN`（20 字母） | `if len(proj(seg)) < MIN: acc["unchecked"] += 1` |

第一版 ⑳c 只断言 `a["unchecked"] >= 1 and a["segs"] == 0`，夹具是
`他写道：\`too short\`。`。**它的 quotes 是 0**——`Q` 压根没抽到，
走的是文本级那条。于是把段级那行改成 `acc["segs"] += 1`
（＝**让「没查」冒充「查过了」，本件最要命的那个缺陷**）——**自测一条都没红**。

**一条来源坏掉，另一条替它挡了枪。**

⇒ 修法：拆成 ⑳c（段级）与 ⑳c′（文本级），**各自把其余来源钉成 0**——
  ⑳c 多加一句 `count_unchecked(_t) == 0`。

⇒ 夹具是**先单独喂给 `scan_text` 确认它报出东西之后**才写的断言，不是写完断言再去验。
  段级夹具用的是真实形态：**页码引注**（`"Vol. II, pp. 101–103, 210–214."`）
  ——够 18 字符进得了 `Q`，而投影后字母只有 19 个，正好落在两道门槛的缝里。

## 二、附带修掉的一处「补完得很假」

提取 `scan_text()` 时我在 `main()` 里留了个同名薄委托 `scan()` 少改四处调用点。
`check_selftest_reach` **照样把它算进缺口**（它匹配 `^scan`）。

两条路：

| | 后果 |
|---|---|
| 改名成 `_sc` | 不匹配 `^scan` 了，判据闭嘴 —— **只是躲开正则** |
| 真删掉 | 四处调用点各多传 `texts, folded` |

选了后者。**留一个空壳绕过判据是最差的一种「补完」：名单少一件，实际一件没补。**

★ 中途还犯过一次「注释说了一件没做的事」——注释写着「删掉它」而我实际只改了名。
  在这个项目里那正是要命的那种漂移，当场改回。

## 三、验到什么程度

| 项 | 结果 |
|---|---|
| M0 正例（同一装置） | **rc=0，零条 ✗** ← 装置成立的前提 |
| M1 段级 unchecked→segs | ⑳c 红 |
| M2 标识符不再单列 | ⑳d 红 |
| M3 未命中不记进 bad | ⑳b、⑳e 红 |
| M4 `count_unchecked` 白算 | ⑳c′ 红 |
| M5 `find()` 短路成「一律命中」 | ⑳b、⑳e 红 |
| 探针实测 | `{"file": "check_quote_integrity.py", "rc": 0, "没进入的": []}` |

**改的是 `check()` 的调用点，所以还在真实工作区上比了改动前后：**

| 工作区 | 语料 | 引文 | rc | 前后 |
|---|---|---|---|---|
| Koch #107 | 122 份 | 29 条 / 20 片段 / 3 未命中 / 19 未核 | 1 | **逐字节相同** |
| Lister #108 | 62 份 | 25 条 / 21 片段 / 0 未命中 / 15 未核 | 0 | **逐字节相同** |

一失败一通过，两条路都走到——不是「两边都空所以相同」。
