# 抓源坑位清单 —— 每一条都是实测换来的，**不是设想**

本文件只收「已经在真实抓源里出过、且会静默给出错数」的坑。
**给探测代理下指令时按这份清单逐条写进去**；每加一条要写清是哪次、错到什么程度。

---

## 一、0 命中不等于没有

**任何返回 0 命中的检索，先用一个已知会命中的对照查询验证语法本身，再下「没有」的结论。**

| 实例 | 表征 | 真值 |
|---|---|---|
| Gawande #120 | `curl` 把 `filter=original:.*[Gg]awande.*` 里的方括号当 **URL glob** 吃掉（`bad range in URL position 117`），而 stderr 被丢进 `/dev/null` | 报「usaid.gov 全域 **0 个** Gawande 页面」；加 `--globoff` 后同一查询返回 **33 个页面**，含 4 份材料的唯一线索 |
| Farmer #121 | DDG 连续 3 条查询返回空 | 重跑 2 分钟前刚命中过的对照查询，得到 **HTTP 202 + 67 处 "anomaly"** 的封禁页——那 3 条是**假阴性** |

★ 同一天里，这个坑也在 shell 层咬了一次：**zsh 不做词分割**，
`for X in $LIST` 把整串当成一个参数，`curl` 报 `Malformed input to a URL function`，
**34 个下载静默变 0**。批量循环改用 Python。

## 二、多人转录必须按说话人切分——**而切分器两个方向都会错**

不切分，字数虚高 **2.0–7.5 倍**（参院听证页面总字 35,409、本人 4,724）。

而切分器本身的两种错法都出现过：

| 版本 | 错法 | 后果 |
|---|---|---|
| v1 | 宽松正则把 vocative「Mr. Chairman,…」当说话人标签 | 造出幽灵发言人 `Mr`(19 次)、`Dr`(6 次)，并**从真发言人处偷走文本** |
| v2 | 终止符 `RESPONSES` 带了 `re.I` | 匹配到句首普通词 `responses to this massive earthquake`，把开场陈述从 **1,932 字截成 193 字（10 倍低估）** |

**★ 交叉验算是唯一抓得到的办法：
切分结果的轮次数必须等于说话人标签行的直接计数（`grep -c '^    Dr\. Farmer\.'`），不等就是错的。**

## 三、国会出版物内部会有第三方版权声明

`CHRG-108shrg90723` 第 2829 行是 `[Reprinted with permission from Elsevier.]`，
后面 **2,573 字**是《Lancet》原文重印——**在一份公有领域听证里，这一块不是 PD。**

**每份国会包先扫 `Reprinted|permission|Copyright|©`，命中的段落排除。**

★ 反过来这条声明是**正面内证**：委员会在有第三方版权时会标注，
未标注部分按 PD 处理的读法因此更站得住。

## 四、书面证词可能是图片，只读 HTML 会静默漏掉

`CHRG-113shrg94193` 的书面预备证词：目录列在印本第 14 页，
HTML 里是 `<GRAPHIC(S) NOT AVAILABLE IN TIFF FORMAT>`，
PDF 第 18–19 页是 `Farmer2.eps`–`Farmer5.eps` **四张幻灯图，无文本层**。

**判据：目录列了 prepared statement 页码、而 HTML 找不到对应文本块时，
必须去 PDF 查 `.eps` / `GRAPHIC(S) NOT AVAILABLE` 占位符**——
否则会输出一个「看起来完整」的字数。

## 五、判重用 token shingle，`difflib` 会给出反向结论

`S.Res.95` ／ `S.Res.358` ／ `BILLS-118sres95is` 是同一文本的 3 个 source_id：

```
difflib.SequenceMatcher（BILLS vs CREC）：**0.010**   ← 被排版噪声淹没
8-gram containment：                      **0.915**
```

**只信 `difflib` 就会把塌缩当成 3 处独立证据。**

## 六、同名陷阱要逐场核身份，不能只匹配姓名

Farmer #121 实测：国会记录里至少 **4 个 Farmer**——
Dr. Paul Farmer（医生）、**Paul Farmer FAICP（美国规划协会 CEO，本人也作过 2 次证）**、
Paul G. Farmer（退伍军人）、John J. Farmer Jr.（Rutgers）。

直接搜 `"STATEMENT OF PAUL FARMER"` 返回 2 条，**其中 1 条是规划协会那位**。
**不逐条验身份（题名、头衔、机构）就会多算 2 场听证。**

## 七、公有领域的四条依据不能互相顶替

| 依据 | 射程 | 能外推吗 |
|---|---|---|
| §105 联邦职务作品 | 这个人**在联邦任内**写的 | **能**——同期作品同理 |
| 1909 年法无标记 | **这一份印本**没有版权标记 | **不能**——一份一份判 |
| 国会记录 | **出版物性质**，与雇主无关 | 只判这一份 |
| §303 未刊作品 | 卒年+70，下限 2003-01-01 | 按人判 |

实例：
- **DeBakey #119**：三卷 GPO 卷册是 PD，但依据是 1909 年法——脚注实录 `Formerly Colonel, MC, AUS`，写作时已是平民教授。**§105 口径实为 0。**
- **Gawande #120**：2021 提名听证不算 §105——正文自述 `as President Biden's nominee`，**当时是被提名人不是官员**。**判在职看就职日期，不是听证日期。**
- **Farmer #121**：2010 那场他的头衔是联合国副特使，依据仍是「国会记录」——**联合国职务不是美国联邦职务，§105 覆盖不到。**

## 八、机构署名不算个人一手

洛克菲勒基金会／CIMMYT／PIH／UN 特使办公室的文件、USAID 政策文件、
28 人集体署名的总统委员会报告——**是联邦/机构出版物、可能是 PD，但不是他的散文**。
归「归属不成立」，**不要混进可得性统计**。

## 九、聚合器与馆方的 license 字段不是权利声明

同一份 1964 年报告：NIH 本标「无版权限制」、Wellcome 本标 `InC`。
Wayback 页脚的 `17 U.S.C. §108(a)(3)` 是**存档方的免责模板**。
**都不采信，也不反向采信。** 要核就核扫本正文里有没有版权标记。

## 十、核验强度要如实标注

- **强**：印刷页 OCR 全文 / 官方全文 grep `copyright|©` 得 0 命中
- **弱**：某站 HTML 转录里没看到 © —— **扉页背面是版权标记的常规位置，转录站可能根本没转**

**没见过页面影像就明说没见过。**
