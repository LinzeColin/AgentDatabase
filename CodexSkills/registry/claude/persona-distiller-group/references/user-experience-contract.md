# 用户体验合同

用户只做一件事：描述目标。系统内部完成身份推断、模式选择、人数、任务图、人物路由、工具、复审和裁决。

目标体验指标：

- One-shot Completion >=95
- User Experience Score >=95
- Time to First Useful Result Score >=95
- Progress Legibility >=95
- Artifact Usability >=95
- Recovery Quality >=95
- 任一模型／框架／模板／任务切片 >=75

用户不应看到身份菜单、权重、内部会议记录或大量 claim_id。用户应看到任务正在完成什么、哪一项已通过、哪一项仍阻塞，以及最终一个可直接使用的成品。
