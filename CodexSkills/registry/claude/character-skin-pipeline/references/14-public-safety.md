# 14 · 公开安全规范（v0.1.0）

**对标公开抖音等平台的安全产出规范。本文件是 character-skin-pipeline 的公开安全宪法。**

## 一、产物逐张自查（落登记前必过）

```text
□ 无隐私部位暴露（生殖器/阴部/乳首）
□ 无低机位仰拍 / 无身材构图占主导（= L3 禁区，限流 30 天）
□ 泳装类带「无不良引导」合规条（帧内烧）
□ 体型照锚图自然（PHYSIQUE 条款在，禁加粗）
□ 锚图高清（官网优先；Fandom 低清需文件名归一化，防用错）
□ 版本为最新修复版（发前核对素材总账 README 版本标记）
```

## 二、色情度档位（公开 = G 轴 L0-L2）

| 档 | 内容 | 公开 |
|---|---|---|
| L0 | 立绘原生（官方原设） | ✅ |
| L1 | 换装展示（旗袍/JK/汉服/OL） | ✅ |
| **L2** | 泳装/沙滩，正常站姿 + 合规条 | ✅ 强制带合规条 |
| L3 | 低机位仰拍+紧身+身材构图 | ❌ 限流 30 天 |
| L4 | 准性暗示 | ❌ |

**L3+ 一律移交 character-skin-sexy（非公开）**，本 skill 不产出、不写 L3+ prompt。
