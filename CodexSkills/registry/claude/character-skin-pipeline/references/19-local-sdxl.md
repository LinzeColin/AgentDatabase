# 19 · 本地 SDXL 出图（零成本路线）——跑通了什么、卡在哪

**2026-08-24 实测，DEV-MACPRO（M2 Max / 32GB）。代价约 2.5 小时 GPU。**
本篇是**已验证的边界**，不是方案推荐。要走这条路先读完，能省掉全部踩坑时间。

## 何时考虑这条路

gpt-image-2 的成本结构：单变体 $0.07（L2）～ $0.34（L5 全强度），
414 变体已花 $25+。**L5 实测 67/110 被拒**，可用变体掉到 9/55 —— 拒绝也计费。

本地路线：边际成本 **$0**，**零内容审核**，但**单张 555 秒**且和同机其它 GPU 任务互斥。

## 已证明能做到

- **画质够。** 服装口径（丝袜+吊袜带+高露肤+pin-up）、锁左三分之一构图、
  手部正确、体型不被拉粗 —— 一次成。
- **零审核。** 全强度 pin-up 直接出，**不需要 `erotic_levels.py` 那套 L4→L3→L2 降级阶梯**。
  这条路上那套东西可以整个删掉。
- **能只修手。** MeshGraphormer 框出手部 + inpaint，其余像素不动。
  **gpt-image-2 做不到**（无 mask，只能整图重出=重掷骰子），而缺陷里手占大头（13 张里 10 张）。

## 卡在哪（这四条不解决就不能切）

1. **人物辨识度**。有专属 LoRA 的角色都会丢标志配件（帽子、特征配色），
   踩「严格不能偏离基准人物特征」。**27 个 LoRA 只覆盖 33/414 变体 = 8%**。
2. **IP-Adapter 救不回来，反而更差** —— 见下节，别再试第二遍。
3. **LoRA 采购路径不通**。Civitai 返回 **451 REGION_BLOCKED**，需另找源。
4. **吞吐**。555 秒/张 × 414 变体 ≈ **64 小时**连续占机，且与同机视频线抢 32GB 统一内存。

## ⚠️ 合规上最容易被忽略的一条

**OpenAI 的审核以前是一道没人算进去的兜底。**
那 67 次拒绝实际替产线挡下了 67 张过线素材。切到本地后**这道兜底消失，
合规 100% 落在自己的 G 轴闸门上**。切之前 G 轴判定必须先证明能独立扛住 ——
否则等于把限流风险从 OpenAI 手里接回自己手里。**这条该由 T00 拍板，不是产线能自己决定的。**

## IP-Adapter：错的工具，别再试

`IPAdapterAdvanced` weight 0.7 / end_at 0.75 / concat / V only，两种失败模式（用户全否）：

- **画面长出两个人**。`ConditioningSetArea` 只约束**文字条件**在左 512px，
  而 **IP-Adapter 是全图生效的** —— 它在整幅画上都"想要一个人物"。
  多出来那个还穿全遮挡长裙，服装口径整条作废。
- **渲染扁平劣质**。锚图的平面立绘风格被一起搬进来。

**不加锚图、只用角色 LoRA 的那张画质明显更好。**
锁人物身份的正解是 **LoRA**（只带身份，不带风格污染），不是 IP-Adapter。

## 环境坑（每一条都直接烧几小时）

| 坑 | 判据 / 解法 |
|---|---|
| **`--bf16-unet` 让 SDXL 在 MPS 上出 NaN** | 产纯色图但 ComfyUI 报 `success`。同一最小图：bf16→3KB 纯灰，fp16→1133KB 真图。日志证据 `RuntimeWarning: invalid value encountered in cast`。**用共享实例前先 `ps -o command=` 看精度参数** |
| **纯色废图判据** | 3840×2160 的 PNG 只有 ~27KB，或缩到 64px 后 <1200 字节 |
| **queue/history 是内存态** | 重启即全清。一小时内被别的线程重启三次，排的队两次整队蒸发、一秒 GPU 没拿到。**判产物在不在一律扫盘** |
| **同一配方连败 2 次就停手** | 立刻跑最小图二分（无 LoRA/无 IPA/无 hires/无放大/1024²/euler），两分钟定根因。换 seed 重试是把确定性故障当随机故障 |
| **诊断前先停守护进程** | 否则它一边帮你重试一边烧算力，还掩盖问题 |
| macOS 无 `setsid` | 后台起服务用 `nohup ... &` |

## 结论口径

**不是「本地能替代 API」，也不是「本地不行」，而是：**
> 画质、成本、审核三项本地赢；**身份保真与吞吐两项没过关**，
> 且身份保真卡在 LoRA 采购（Civitai 被封）这个非技术障碍上。
> 现状能吃下的是**有 LoRA 的那 8%**，其余 92% 需要先解决 LoRA 来源。
