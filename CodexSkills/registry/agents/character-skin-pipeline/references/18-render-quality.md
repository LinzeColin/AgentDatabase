# 画质与「AI 感」：三条后端与怎么选

用户 2026-08-24 的原话：「本地大模型太 AI 质感机器质感了，OpenAI API 更精度更高更真实」。
这个判断是对的，但**「AI 感」不是本地模型的固有属性，是缺了三个环节。**
本文件先拆病因，再给后端选择。

---

## 一、「AI 感」的四个具体来源，各有各的解

| 症状 | 病因 | 解 | 本机现状 |
|---|---|---|---|
| 皮肤塑料、高光死白 | CFG 过高 + 步数不足 + 没有超分 | CFG 4.0–4.5、35 步、`RealESRGAN_x4plus_anime_6B` 超分 | ✅ 超分模型已装 |
| 构图千篇一律 | 纯文生图无空间约束 | **ControlNet-OpenPose** 用骨架图钉死姿势 | ⚠️ 预处理器已装，**缺权重** |
| 脸/手崩 | 全图一次采样，脸只占几十像素 | 区域重绘（ADetailer 等价） | ❌ **缺 Impact Pack** |
| 身份漂移 | 只靠 tag/LoRA | **IPAdapter** 用锚图约束身份 | ✅ `ip-adapter-plus_sdxl_vit-h` + CLIP-ViT-H 已装 |

**只有两样要补，都免费：**
- `xinsir/controlnet-openpose-sdxl-1.0`（~2.5GB，HuggingFace）
- `ComfyUI-Impact-Pack`（custom node）

> **ControlNet-OpenPose 对 H 轴是决定性的。**
> 65 条姿势用英文描述，模型命中率有限；用骨架图，姿势是**精确复现**的。
> 而且骨架图**一次做好 65 张就永久复用，所有角色共享** —— 这是姿势轴唯一
> 「做一次、用无数次」的实现方式。没有它，H 轴就是在赌模型理解力。

## 二、三条后端

| | **本地 ComfyUI + WAI-Illustrious v17** | **OpenAI gpt-image-2** | **MiniMax image-01（mmx）** |
|---|---|---|---|
| 单价 | **$0** | $0.03–0.42/张（实测均值 ~$0.12） | 未知，订阅未标定 |
| 质感 | 装齐四件套后接近；裸跑有 AI 感 | 精度高、真实 | 中 |
| 身份锚定 | LoRA / IPAdapter / Danbooru tag | `image[]` 锚图 | `--subject-ref type=character,image=` |
| **姿势精确控制** | **✅ ControlNet 骨架** | ❌ 只能靠文字 | ❌ 只能靠文字 |
| 画风控制 | ✅ tag + LoRA + CFG + 权重 | ❌ 弱（自然语言、无负向词、无权重） | 弱 |
| 负向词 | ✅ | ❌ **没有这个参数** | ❌ |
| 重试成本 | $0，可无限试 | 每次都要钱 | 要钱 |
| 分辨率 | 832×1216 原生 + 4x 超分 | 3840×2160 直出 | ≤2048 |
| 安全系统 | 无 | 有，且**随机**（同 prompt 三次结果不单调） | 有 |

**gpt-image-2 的三个硬伤，在姿势轴上尤其致命**：没有负向词（钉不死 `low angle`）、
没有权重（调不了姿势强度）、安全系统随机（同一条配方结果不可复现）。
而 H 轴的整个价值建立在「配方可复现、可回填数据」上。

## 三、推荐：混合链，钱只花在要发的那几张上

```
   ① 本地出量（$0）                    ② 人工挑（$0）        ③ 精修（选付费）
   ┌──────────────────────┐         ┌──────────┐        ┌─────────────────┐
   │ WAI-Illustrious v17  │         │ 联络表    │        │ 本地：超分+区域重绘 │
   │ + LoRA/IPAdapter     │ ──60张→ │ 逐张扫   │ ──8张→ │ 或                │
   │ + ControlNet 骨架    │         │ 挑出可用 │        │ API：img2img 精修  │
   │ + 65 条姿势全排      │         └──────────┘        └─────────────────┘
   └──────────────────────┘
   废片全在这里烧掉，$0                                    只对成品付费
```

**为什么这样最优**：这条产线的重试倍率实测到过 3:1（后来降到 1.08:1）。
在 API 上跑，**你为每一张废片付全价**；在本地跑，废片是免费的。
把「探索」放本地、「定稿」放付费，单位成本按可用成品算能降一个数量级。

**默认口径（2026-08-24 用户裁决）**：
- E 轴默认走**本地**
- **保留 API 通道**：配方里 `BACKEND=openai` 或 `BACKEND=minimax` 时切过去
- 用户明确说「先不使用 OpenAI API」期间，`BACKEND` 只允许 `local`

## 四、本地质量参数（已标定，别乱改）

WAI-Illustrious v17 官方：Euler / CFG 4–5 / 28–35 步 / 竖版 832×1216 或 896×1152。
本项目标定：**CFG 5.0 / 35 步 / LoRA 强度 0.8 / scheduler normal**，
质量词固定加 `masterpiece, best quality, absurdres`。
实测锐度 298→412（+38%），用户打 70–80 分。

改这些参数前先读 `00_治理与登记/06_视频治理/产线配置与节点接线-260823.md` §4，
那是权威 runbook；别重跑甘雨质量 sweep，结论已经在里面了。
