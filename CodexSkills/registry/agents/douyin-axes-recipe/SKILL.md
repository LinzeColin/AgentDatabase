# A–L 十一轴维度体系 + 配方编译器

**为什么存在**：九张维度表在 `00_治理与登记/05_素材维度/` 躺了很久，每行都带实测出处，
**而产线一张都没读** —— 414 个变体 = 414 个角色 × **1 个配方**（场景每 IP 一句硬编码、
光照两句、景别一种、姿势全是正面直立）。`axes.py` 把维度表接成产线的输入。

**合规闸写在代码里，不写在文档里 —— 文档拦不住任何人。**

## 用法

```bash
cd /Volumes/share/04_DouyinOps/02_通用资产

# 单条配方 → 看编译结果
python3 axes.py --line public --recipe "CHR=genshin/shenhe H=PS-DM-06 F=wd_qipao I=thighhighs/black/sheer"

# 批量：配方 CSV → 任务 CSV（01_壁纸批量出图.py 直接吃这个格式）
python3 axes.py --batch 配方.csv --out 任务.csv --line public

# 查某个轴当前线有哪些可选项
python3 axes.py --list H --line public
```

输出四列：`输出名, prompt, LoRA名, 负向`

### H 轴为什么最值钱
**姿势是性价比最高的一环。** 41 → 65 条扩充后，公开线四个权力轴覆盖：
**对等 100% · 支配 71% · 服从 100% · 诱惑 89%**（用户要求 ≥50–75%）。
机位从 B 轴迁进 H 轴 —— **姿势和机位本来就是一回事**，拆开写必然打架。

### L 轴为什么必须显式写进 prompt
**LoRA 学到的是整体画风与体态，标志配件反而容易被构图/服装词冲掉。**
红绳、云纹、角、铃铛、梅花瞳、异色瞳 —— 这些丢了就不是那个角色了。
解法：把标志特征当独立轴，**位置紧跟角色 tag**。

## 七道硬闸（`raise Gate` 在代码里，逐条实测拦得住）

| 闸 | 拦什么 | 为什么 |
|---|---|---|
| **1** | 轴代码不存在；I/J 轴格式不对 | 打错字静默降级 = 出一批废图才发现 |
| **2** | 公开线 G 轴 > L2 | 尺度红线 |
| **3** | H 轴标了「非公开」 | 有些姿势本身就不能上公开线 |
| **4** | H 轴机位字段为空 | 没机位 = 模型自由发挥 = 可能仰拍 = **限流**（补_B06 实测限流 30 天） |
| **5** | **R5 幼态角色**：禁诱惑/支配/服从三个权力轴，服装锁 `wd_default`，腿部锁 canonical | 红线中的红线 |
| **6** | J 轴与 H 轴权力轴不协调；物理矛盾（要求眼神交流却闭眼） | 眼神跟姿势打架 = 观感违和 |
| **7** | A 轴底色档与场景档同时指定 | 互斥 |

## 改维度表的纪律

1. **表在 SMB 是唯一真源**，本机镜像只读
2. **写 SMB 一律 `rsync` + 读回校验** —— `Path.write_text()` 直写 SMB 会写成**全 NUL**（我犯过，脚本和 .bak 一起废）
3. **改 CSV 按表头名定位，不用写死列号** —— 我用列号覆盖过相邻两列
4. **改表前先备份带日期的 `-vN备份.csv`**（H 轴 41→65 就是这么留的回滚点）
5. 新增条目要带**实测出处**，不是拍脑袋

## 已知缺口

- **`axes.py` 只覆盖静态图**，视频线（C 轴动作风格）还没接进编译器
- **3D / MMD 线还没接本轴系** —— 接的时候复用 A/D/E/G/H/L，C 轴才是视频独有
- **R5 幼态名单未定** —— 闸 5 依赖这份名单，**卡 T00/T02 裁决**，名单不到位闸 5 是空转
