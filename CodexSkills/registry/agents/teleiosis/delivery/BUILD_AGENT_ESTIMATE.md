# Build Agent P80/P95 估算

范围：仅执行目标仓最新 main 的语义对账、安装/适配、原生测试、Catalog、回滚证明，以及在 Owner 已授权时提交、推送和远端回读。

| Stage | 任务数 | P80 turns/tokens | P80 active/wait/wall | P95 turns/tokens | P95 active/wait/wall |
|---|---:|---:|---:|---:|---:|
| Stage 0 语义对账 | 4 | 3 / 12,000 | 9/3/12 分钟 | 5 / 22,000 | 17/8/25 分钟 |
| 安装、适配与原子应用 | 5 | 4 / 16,000 | 11/7/18 分钟 | 6 / 30,000 | 24/16/40 分钟 |
| 测试、Catalog 与回滚证明 | 5 | 3 / 10,000 | 6/9/15 分钟 | 5 / 18,000 | 14/21/35 分钟 |
| 授权后的提交、推送与远端回读 | 4 | 2 / 5,000 | 3/5/8 分钟 | 3 / 9,000 | 7/13/20 分钟 |
| **总计** | **18** | **12 / 43,000** | **29/24/53 分钟** | **19 / 79,000** | **62/58/120 分钟** |

最大五个成本驱动因素：
1. 目标 main 的未知可执行冲突或语义漂移
2. 目标仓原生测试与依赖安装时长
3. Catalog 当前格式和生成器差异
4. 远端 main 在推送前前进或权限不足
5. 真实 Adapter、凭证或生产授权被新增到当前范围

任何触发项使架构、权限、数据、成本、Scope 或 Acceptance 发生超过 30% 的实质变化时，返回 Preparation Agent 重新定版；普通兼容调整留在最后一公里。
