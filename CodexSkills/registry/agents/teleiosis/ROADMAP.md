# Teleiosis Roadmap

## 当前 v0.0.0.5 已冻结范围

- 一个物理 Skill，T/S/P/A 四个逻辑引擎；
- v3 非降级语义与来源边界；
- 36 阶段连续 Candidate Run；
- Stage 0 Semantic Reconcile；
- 三次 Skill Catalog Audit；
- dossier/claim_id 人物专家硬门和中立回退；
- 十视角、两轮六角色；
- Taskpack、Fresh Builder、8192 条回归；
- Doctor、事务安装、升级、回滚、确定性封包；
- 冻结 External Verifier handoff。

后续路线不改变 v0.0.0.5 的当前 Acceptance，也不进入当前 Task DAG。

## Future Roadmap

| 阶段 | 条件 | 目标 | 不得提前宣称 |
|---|---|---|---|
| L3 原生竞技 | 官方框架、相同模型、相同真实任务、相同预算与授权齐备 | 运行 GEPA、AutoResearch、MetaHarness、Promptfoo 和 Teleiosis 的原生同场 | 方法适配器结果等于官方产品胜负 |
| 独立 Verifier | 可用隔离运行时和冻结 handoff | 输出唯一正式 PASS/FAIL/CONDITIONAL PASS | 本地工程 PASS 等于正式放行 |
| L4 生产盲测 | 真实用户、真实任务、同意、隐私、成本和事故回流齐备 | 验证长期真实效果与 Kill Criteria | 合成语料等于真实市场 |
| Registry 发布 | 目标仓写权限、最新 main 和治理规则齐备 | Stage 0 后安装、测试、提交 main | 当前 ZIP 已自动部署 |
