# 人物专家团队真实性边界

有效人物团队调用必须同时满足：

1. 路由到 Registry 中 readiness=ready 的人物；
2. 打开每位成员内层 runtime ZIP 并载入 dossier；
3. 每条实质贡献引用该人物自己的 claim_id；
4. 显式呈现组内真实 divergence；
5. hard boundaries、refusal template、known distortions 在生成前生效；
6. 正向解决、反证、复审和裁判互相隔离。

本次构建环境没有取得人物 dossier 字节，因此状态是 `INSUFFICIENT_ROSTER_FALLBACK`。v5 只应用真实性合同和中立六角色复审，不写任何人物口吻、claim_id 或“专家一致认为”。取得真实 dossier 后可生成新 Candidate 并重跑 Pass B/C。
