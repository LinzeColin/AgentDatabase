# L3 原生同场执行合同

L3 需要五个参赛者使用官方原生框架、同一真实任务集、同一模型角色、同一总费用或 Token 预算、相同重复次数与密封终审。执行前冻结：

- 官方版本、commit/tag、许可证和安装命令；
- 优化器、目标模型、judge 模型的角色隔离；
- 开发/选择/隐藏 IID/OOD/红队/回归集；
- 候选数、Token、费用、墙钟和重试预算；
- 失败、不可比、超预算和停止条件；
- 原始日志、环境快照、账本、结果和哈希。

当前包不内置官方 GEPA、AutoResearch、MetaHarness 或 Promptfoo，也不需要其依赖才能运行。没有这些原生证据时，Arena 结果最高为 L2。
