# Arena Lab 合同

## 两个竞技场

**Development Arena** 可重复执行并暴露失败轨迹，用于下一轮 Candidate；状态仅为 `IMPROVED / DEGRADED / REHEAT_REQUIRED / INSUFFICIENT_EVIDENCE`。

**Sealed Arena** 使用冻结协议与不可被 Candidate 读取的隐藏数据；同一 CandidateIdentity 原则上只运行一次。状态仅为 `ARENA_EVIDENCE_READY / BLOCKED / INVALID_RUN`。

## 公平主榜

参赛身份、版本、模型、任务、评分、预算、重复次数、随机种子和停止条件在运行前冻结。公平主榜要求同数据、同模型、同规则、同总预算。不同预算、不同模型或代理实现只能进入清楚标记的附榜。

默认经验效果权重：隐藏质量 30%、最弱切片 20%、硬约束 15%、红队 15%、回归 10%、成本效率 10%。权重属于协议，冻结后不能修改。任何安全、真实性、权限、数据完整性或密封泄漏硬失败不可补偿。

## 三层输出

1. 经验效果主榜：只反映任务结果和成本。
2. 治理能力榜：版本、谱系、数据隔离、证据、回滚、发布门。
3. Pareto 前沿：在质量、安全、稳定和成本之间报告非支配集合。

## 证据等级

- L1：结构与治理审计。
- L2：统一模拟器或方法适配器。
- L3：官方原生实现、相同真实模型和预算。
- L4：授权真实用户或生产盲测。

任一参与者不是官方原生执行，整场原生胜负表述最高为 L2。Arena 不提供 formal PASS。
