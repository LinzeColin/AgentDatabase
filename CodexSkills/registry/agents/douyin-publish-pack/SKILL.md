## 2 · 选素材

**母版**：`~/.harness-ui/master/<ip>/<角色>/<变体>/{light,dark}.png`，全部 3840×2160。

- **`light` 和 `dark` 是两次独立生成，不是同一张调色** —— 姿势/场景/时间/构图全不同，都可单独用。
- **优先选有 ≥3 套未发变体的角色**，三张出三套不同服装，差异最大。
- 只有 1 套变体时**不要硬凑三张** —— 同源裁切用户一眼看穿（踩过）。宁可换角色。

## 3 · 裁切（坑最深的一步）

竖版 1080×1440（3:4）。**框宽必须由人物宽度决定，再反推框高**，放大倍数是结果不是前提。

```python
# 错误写法（会把人物切成左右一半）：
ch = ih * 0.50; cw = ch * 0.75      # → 810px，而人物常宽 1000-1500px
# 正确：先测人物水平范围 → cw = 人物宽 × 1.18 → ch = cw × 4/3
```

> **人能接受上下一半（半身照），不接受左右一半的残缺。**
> 半身模式放大不足 1.25 倍时退回全身，否则出现「半身=全身」。

**人物检测只能用高频拉普拉斯列和 @阈值 0.30。**
边缘能量和饱和度都会被云、水面、粒子污染 —— 实测某张检出「人物宽 3824px」= 整幅图。

参考实现：`02_通用资产/做封面.py` 的 `subject_x()`，半身另需 `subject_top()`。

### ⚠ 判定图片重复度只能靠看，不能靠 dHash
dHash 对裁切极度敏感：同一张母图的三个裁切算出相似度 45~65%、判「有差异」，
肉眼一看就是同一张图。**生成对照表（contact sheet）自己看一遍，这步不能省。**

## 4 · 文案（两条垂直赛道，写进同一条）

唯一真源：`00_治理与登记/03_规则与规范/文案模板.md` v4。

```
{① 角色跟你发生关系的一句}。{② 这张图能被你拿去用的一句}。
└─ 拉赞率 ──────────────┘  └─ 拉收藏率 ───────────┘
```

**赛道① 温情女友风**（实测：让角色与观众发生关系的写法，赞率显著高于只描述图片/身体；本账号具体读数见工作间 `03_发布复盘/`）
四个句式：观众自述 / 人设自辩 / 挑衅提问 / 生理反应。

**赛道② Wallpaper Engine**（实测：带取图钩子的那条，收藏率为账号内最高；读数见工作间 `03_发布复盘/`）
取图钩子优先用已验证原话 **「要原图评论区吱一声」**。

**三条不许**：不介绍图片（4K/高清/壁纸/几张/展示/套装/尺寸一律不出现）·
不用第三人称客观描述 · 版本活动话题必挂当期。

> 🛑 **不要照抄对标博主的句式。** 「360°XX展示」博主 9.5 万赞，我们 128 粉照抄，
> 该模板在本账号实测两项指标均垫底。**模板只给候选，判据只能是你自己账号的读数。**

**句式必须条条不同** —— 平台会对同质化文案发出 AI 内容警告，实测遇到过。
注意：只是给它们起不同的名字不算不同，结构要真的不同（SCNet 犯过这个错）。

## 7 · 收尾校验（不做等于没做）

```bash
rsync -a --inplace --exclude='.DS_Store' --exclude='._*' <源>/ <SMB目标>/
python3 00_治理与登记/查重.py --目录 <批次>          # 复查零重复
python3 00_治理与登记/audit.py empty                 # 查 SMB 静默写 0
tr -d ' \n\t\0' < <文件> | wc -c                     # 单文件读回，必须 > 0
find <批次> -name '._*' -delete
```

> **SMB 会静默把文件写成全 0**：`ls` 正常、大小正常、内容全空。
> 实测两天内四类「成功」都是假的。**禁用 `cp` / `shutil.copyfile`，一律 rsync + 校验。**

## 7.5 · 代设定时发布（2026-08-24 首次执行，三个坑）

> ⚠ **前提**：红线是「发布永远人点」，**定时发布也是发布**。
> 只有用户**明确授权覆盖这条红线**时才做，且要在治理台账留痕。

流程：`creator.douyin.com/creator-micro/content/upload` → 点「发布图文」tab → 上传 → 填 → 定时 → 发布。

| # | 坑 | 怎么避 |
|---|---|---|
| 1 | **`find` 会同时返回视频和图文两个 file input**。我用了返回的第一个（`ref_48`），那是**视频**的 —— 3 张图传进视频框，页面不跳转，后续输入全打空 | **必须读 find 结果的描述**，认准「图文 / 发布图文 tab panel」那个。上传成功的判据是 **URL 变成 `/post/image`** |
| 2 | **音乐推荐榜排序是动态的**。第一次 `Stay with me`（1303万）在第 1 位，第二次它掉到第 3 位，第 1 位换成了 26 万的曲子 | 规则是「取**使用量最高**那首」，**不是取第一位**。每次都要读右侧的「xx万人使用」再点 |
| 3 | 点话题候选时**可能误触旁边的「官方活动」区**，自动挂上活动（如 #抖音创作者大会） | 点完检查一下官方活动区有没有变成「已添加」。挂上了未必是坏事（官方活动有流量扶持），但要知情 |

其它注意：
- 话题**必须逐个从候选里点选**（蓝底才有流量，白底是纯文本零流量）
- 关闭音乐面板用 `Escape`，**别点右上角 X** —— 那个坐标附近是账号菜单，我误触过，差一点点到「退出账号」
- 定时时间选择器：日期点日历，时分是滚轮列，**滚到附近后直接点具体数字**更准（滚轮 1 格 ≈ 3 个单位）
- 发布后去 `content/manage` 确认，看到「定时发布中 / 审核中」+ 正确时间才算成功
