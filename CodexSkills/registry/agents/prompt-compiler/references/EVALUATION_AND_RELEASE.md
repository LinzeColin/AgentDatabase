# 评测、冠军门与发布合同

## 三层门禁

### 第一层：候选有效性

- 原文、版本、链接、阈值、路径和硬约束无遗漏；
- 结构化断言、业务 Oracle 和自定义评分器通过；
- 无硬失败；
- 训练与验证数据未污染最终测试。

### 第二层：全维冠军

- 全部必选竞品有终审候选；
- 四条核心优化路径均由原生实现产生独立候选，且没有本地同名模拟或兼容回退；
- Promptfoo 候选来自官方 `Best prompt` 区段，AutoResearch/MetaHarness 具有工作区来源与变更树证据；
- 同一最终测试、同一最终评委、相同重复次数；
- 15 个内置维度和全部冻结附加维度有逐行证据；
- 对每个竞品、每个维度均为 `STRICTLY_FIRST` 或满分 `TIED_FIRST_AT_CEILING`；
- 总体、最差案例和最弱切片都不能丢失；
- 证据文件 SHA-256 与报告一致。

### 第三层：现实发布

- 最终测试相对原版达到冻结提升阈值；
- 旧案例回归通过；
- 固定红队和 Promptfoo 官方红队通过；
- Promptfoo 同一配置真实产生原版、优化版两组结果并覆盖全部重复；
- 任务模型与最终评委身份不同；
- 真实外部验收证据通过；
- CI 独立重读全部证据后放行。

## 默认阈值

| 项目 | 默认值 |
|---|---:|
| 最终均值提升 | ≥ 0.05 |
| 硬失败 | 0 |
| 重复次数 | ≥ 3 |
| 长度增幅 | ≤ 30% |
| 方差增幅 | ≤ 0.02 |
| 冠军置信度 | 95% |
| 逐维最小优势 | > 0；可配置 margin |

## 证据状态

- `PASS`：所有层级通过；
- `PROVISIONAL_PASS`：数值改善但最终数据含合成案例；
- `REJECTED`：候选退化、硬约束失败或竞品明确领先；
- `BLOCKED`：缺环境、身份、竞品、维度、外部证据或独立验收；
- `CHAMPION_PASS`：仅表示当前封印竞技场的逐维冠军门通过，不自动等于生产发布。

## CI 防伪

`ci-gate` 会：

1. 重读最新报告；
2. 重读独立冠军证据文件；
3. 校验 SHA-256 和报告内 Payload 完全一致；
4. 逐竞品、逐冻结维度核对状态；
5. 核对缺失竞品为空；
6. 核对 Promptfoo 最终、回归、固定红队和官方红队；
7. 重读真实外部证据文件；
8. 任一失败则返回非零退出码。

单纯把 `release_allowed` 改成 `true` 无法绕过。
