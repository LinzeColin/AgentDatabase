# 研究与整合报告 v0.0.0.2

## 结论

公开生态已有高质量局部方案，但没有一个项目同时覆盖：自然语言判断、剪辑/T2V/I2V/Reference/Edit/2D/3D 路由、电影导演语法、工业物理、微表演、多模型适配、参考视频反推、评分和最小修复。因此不建议原样安装某一个仓库；本版采用“薄运行时 + 可审计文档 + 当前适配器”的整合方式。

## 最有价值的机制

1. **判断优先**：Vibe Creating 的 S/E/I 逻辑证明不是所有输入都应该无脑扩写；
2. **模型适配器**：Square-Zero 将模型差异放在独立参考文件；
3. **双分支择优**：RAPO 证明单次重写不是唯一解，检索增强/指令改写后择优更稳健；
4. **生成后闭环**：RAPO++、ai-video-skill 和 VideoFeedback2 支持 Observe–Diagnose–Delta；
5. **物理复核**：PhyT2V/PhyPrompt 将物理问题从“加真实感”升级为规则和迭代；
6. **连续性生产链**：Reference Sheet → Anchor Frame → 每镜复用同一参考；
7. **确定性剪辑优先**：已有素材的剪切、字幕、裁切、音量和拼接不应用视频生成模型重做；
8. **证据拆分**：结构分、真实模型结果、人工观看和独立 Verifier 必须是四个状态。

## v0.0.0.1 的主要问题

- 96.1% 评分把自评设计覆盖与真实效果混在一起；
- `Wan 2.x/2.6`、`Seedance 2.5 类能力` 等标签缺乏当前官方核验；
- 一段统一 Prompt 再做轻量适配，无法处理 H3 Full-reference、Runway I2V、LTX 单段落等实质差异；
- 工业规则有关键词，但缺少完整物理账本；
- 生成前只有单一改写，没有候选竞争与显式选择；
- 参考人物连续性和剧本转分镜不是正式工作流。
