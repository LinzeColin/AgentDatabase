# Integration Decisions

| 决策 | 采纳 | 原因 |
|---|---|---|
| 独立 Skill，不覆盖 prompt-compiler | 是 | 视频领域需要专用 IR、模型适配和物理/时间结构 |
| 两个候选而非大量随机变体 | 是 | 控制成本，允许候选竞争，同时保持可审计 |
| 运行时不下载 Prompt enhancer 模型 | 是 | 避免重型依赖、许可和模型时效风险 |
| 当前官方模型注册表 | 是 | 防止旧标签/供应商标签被当作事实 |
| 工业物理账本 | 是 | 关键词不足以约束轨迹、接触、材料和状态 |
| Reddit 经验写进硬规则 | 否 | 证据等级过低，只保留为待验证假设 |
| 使用单一综合分发布 | 否 | 结构、真实生成、人工审美、独立验收是不同证据 |
| 自动调用收费生成 | 否 | 默认编译-only，用户批准后才运行 |
