# Architecture v0.0.0.2

```text
Natural-language front end
  ├─ constraint ledger
  ├─ production router
  └─ asset-role resolver
          ↓
VideoPromptIR
  ├─ scene/action/camera/time/audio
  ├─ continuity/reference policy
  └─ industrial physics ledger
          ↓
Dual candidate optimizer
  ├─ precision branch
  └─ expressive branch
          ↓
Hard gates + structural score
          ↓
Model renderer registry
          ↓
Copy prompt / director pack / EDL / handoff
          ↓
Optional native generation
          ↓
observe → diagnose → one-variable delta repair
```

运行脚本均为 Python 标准库；实际媒体生成不属于默认运行依赖。
