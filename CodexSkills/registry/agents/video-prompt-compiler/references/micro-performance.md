# 微表演与情绪视频语言

## 目标

把“她很难过、他很愤怒、两个人有破碎感”等抽象情绪，编译成模型可见、可听、可按时间执行的身体行为。

## 八层微表演

1. **动因**：什么触发了变化；
2. **呼吸与生理**：呼吸停顿、吞咽、喉结、鼻翼、泪膜、皮肤张力；
3. **视线**：看向哪里、何时回避、是否追随、眨眼频率；
4. **面部**：眉心、眼睑、嘴角、下颌、唇部和面部不对称；
5. **身体**：肩膀、胸口、颈部、手指、重心、步伐；
6. **道具与空间**：门、杯子、手机、桌面、距离和阻挡；
7. **台词与声音**：速度、音量、停顿、触发词、呼吸、环境声；
8. **结束状态**：人物最后看哪里、身体在哪里、情绪是否转化。

## 时间段模板

```text
【全局锁定】
人物外观、服装、场景、时间、光线、环境声、镜头基调。

【0–4 秒｜触发】
可见事件；第一反应；呼吸；视线；镜头距离。

【4–8 秒｜内在转折】
眼神变化；眨眼/泪膜；嘴角、下颌；手和肩颈；摄像机轻微变化。

【8–12 秒｜关键台词或动作】
说话者；原样台词；语速与停顿；对方反应不能提前；声音背景。

【12–15 秒｜余韵】
后退、转身、停下或保持；镜头是否拉远；环境声衰减；最终状态。
```

## 表演控制规则

- 一次只让一个表情转折成为中心；
- 反应发生在触发之后，不能提前；
- 台词结束后保留 1–2 秒反应和声音余韵；
- 大哭、尖叫、摔物不是“更有情绪”的默认答案；
- 克制表演用更细的呼吸、视线、手指和重心，而不是更多形容词；
- 快速运镜会破坏微表情时，使用锁定镜头或极慢推近；
- 极近景不安排大幅全身动作；
- 台词必须给自然可播放的时间。

## 原创示例骨架

```text
中近景，阴天办公室门口，一名年轻工程师握着刚被退回的项目文件。
0–3 秒，她先看文件上的退回标记，呼吸短暂停住，拇指缓慢压住纸边；摄像机稳定。
3–7 秒，她抬眼看向会议室内，眼睑轻微收紧，嘴角试图保持平直，肩膀却缓慢下沉；镜头极慢推近。
7–11 秒，她低声说出指定台词，中间在关键词前停顿半秒；会议室中的人保持沉默，不提前做夸张反应。
11–15 秒，她收回视线，把文件贴近胸前，向后退半步后停下；摄像机轻微拉远，空调和远处脚步声留在画面中。
结束时她没有哭，视线停在地面，身体保持克制而僵硬。
```
