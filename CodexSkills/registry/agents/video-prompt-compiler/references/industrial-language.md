# 工业级视频语言

## 工业镜头的核心不是“火花越多越好”

工业可信度来自关系稳定：

```text
工件
↔ 工具/机器人/夹具
↔ 运动轨迹
↔ 材料反应
↔ 工艺顺序
↔ 检测证据
```

## 必须描述的关系

### 工件

- 几何类别、尺度感、固定方式；
- 旋转轴、方向、速度感；
- 损伤或加工区域；
- 表面材质、温度和光泽只在有依据时描述。

### 工具与机器人

- 工具朝向；
- 与工件的接触或稳定间距；
- 轨迹、速度与方向；
- 电缆、送粉、焊枪或刀具只在画面需要时出现；
- 不允许工具穿透工件、无夹持悬浮或突然改变结构。

### 材料反馈

- 熔池、火花、粉尘、切屑、烟气、反射、热光；
- 反馈必须与动作位置同步；
- 火花数量、方向和速度克制、符合工艺；
- 不自动生成爆炸、熔化整件工件或奇幻粒子。

### 工艺顺序

工业宣传不能把几个动作随意重排。先依据资料建立：

```text
检测/清理 → 找正/夹持 → 预处理 → 熔覆/焊接/加工 → 稳定/冷却 → 精加工 → 复检
```

具体项目不同，无法确认的步骤写 `UNKNOWN`。

## 工业摄像机语言

| 目的 | 景别/运动 |
|---|---|
| 建立设备规模 | 稳定广角或缓慢横移 |
| 证明真实工艺 | 中景跟随工具与工件 |
| 看清接触关系 | 近景或微距，锁定/轻微跟随 |
| 展示轨迹 | 侧视、俯视或小幅环绕，避免快速旋转 |
| 展示检测 | 手、量具、工件区域同框 |
| 品牌结束 | 稳定全景、成品或团队，不用虚假英雄镜头替代证据 |

## 工业光线与色彩

- 真实车间主光方向保持一致；
- 石墨灰、钢铁本色、受控橙色可用于品牌增强；
- 不默认生成蓝紫色霓虹和未来城市；
- 保留材料纹理、氧化、加工痕迹与油污的真实程度；
- 不把所有设备变成无尘实验室，除非确实是该环境。

## 工业声音

- 机械转动、风机、金属摩擦、焊接、冷却、车间空间混响；
- 声音与动作同步；
- 旁白优先时降低 BGM 与环境声；
- 不使用与画面不对应的发动机、爆炸或枪声式冲击音。

## 物理不变量模板

```text
工件几何结构和夹持位置始终保持不变；
机器人末端沿既定曲面匀速移动；
工具中心线与工件表面保持稳定关系；
材料反馈只出现在实际作用区域；
背景设备保持静止；
不新增零件，不改变轴线，不发生穿模、漂浮或整体熔化；
镜头结束时工具停在指定位置，工件仍稳定固定。
```

## 事实与宣传边界

以下内容没有文件或技术人员确认时不得进入 Prompt 或旁白：

- 材质；
- 温度；
- 硬度；
- 公差与精度；
- 使用寿命；
- 节省金额；
- “完全恢复”“零缺陷”“行业第一”；
- 客户名称和项目归属；
- 检测结果。

可改为：

```text
“展示检测和复检过程”
而不是
“证明所有指标已经达到最高标准”
```
