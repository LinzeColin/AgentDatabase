# Prompt 优化与生成闭环

## 生成前

1. 建立事实与约束账本；
2. 生成 Precision / Expressive 两个候选；
3. 先过硬门槛；
4. 多维评分；
5. 选择一个默认候选；
6. 只在关键镜头保留一个 A/B 备选；
7. 渲染目标模型格式。

这借鉴 RAPO 的“双分支后择优”机制，但不引入其训练模型或检索服务作为运行依赖。

## 生成后

评估维度参考 VideoFeedback2 / VideoScore2 的三类主轴，并扩展为项目可执行项：

- Visual Quality：结构、纹理、闪烁、形变；
- Text Alignment：主体、动作、相机、结束状态、声音是否遵守；
- Physical/Common-sense：重力、接触、轨迹、人体和环境反应；
- Continuity：身份、服装、几何、空间、光线；
- Editability：是否能通过局部 Delta 修复，而非重做整条。

## 最小变量修复

每轮只改变一个高杠杆变量：

```text
KEEP: 构图、主体身份、时长、色彩、声音
CHANGE ONLY: 工具与工件间距
NEW BEHAVIOR: 工具中心线沿既定轨迹保持固定法向距离
END STATE: 工具停在工件右侧，几何和夹持保持不变
```

仍失败时的回退顺序：减少动作 → 拆镜头 → 增强参考锚定 → 换输入模式 → 换模型。不要先增加更多形容词。

## 学习记录

只记录可迁移的因果规则，例如：

- “I2V 中重复重述外观导致主体重绘；改为只写运动后几何更稳定”；
- “短镜同时环绕与推近造成相机冲突；保留环绕后动作清晰”。
