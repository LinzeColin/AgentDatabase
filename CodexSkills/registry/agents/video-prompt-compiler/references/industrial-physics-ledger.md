# 工业物理账本

## 目标

把“工业感、真实、专业”转成能被模型观察并能被人工复核的关系，不用虚构参数或堆火花。

## 九层账本

1. **Entities**：工件、工具、夹具、机器人、传感器、操作者、环境；
2. **Geometry & constraints**：尺寸关系、轴线、夹持、可动/固定部件；
3. **Contact / clearance**：接触点、法向间距、啮合、避让、不得穿模；
4. **Energy / force source**：电机、切削力、激光/电弧、重力、液压、气流；
5. **Trajectory**：起点、路径、方向、速度变化、结束点；
6. **Material response**：熔池、切屑、塑性变形、反射、热变色、液体流动；
7. **Environment response**：火花、粉尘、烟雾、地面反射、声响，只在因果允许时出现；
8. **State transition**：作用前 → 作用中 → 作用后；
9. **Final invariants**：工件几何、轴线、夹持、工具距离、作用区域和最终位置。

## 局部—全局两遍复核

局部：每个动作片段是否有正确的施力者、受力者、接触/间距和反馈。

全局：不同时间段中的几何、旋转方向、夹持、材料状态、光向和声音是否连续。

## 事实边界

真实参数只来自用户资料、图纸、检测报告或可靠来源。没有证据时用：

```text
UNKNOWN — 不进入公开宣传
概念示意 — 非工程计算结果
```

## 示例

差：`震撼的机器人激光熔覆，大量火花，极致工业感。`

好：`近景锁定固定夹持的十字轴和熔覆头。熔覆头沿曲面法向保持稳定间距并匀速移动，作用区只形成连续窄熔池，少量颗粒沿运动反方向落下；工件几何、轴线和夹持位置始终不变。最后熔覆头减速并停在工件右侧，车间机械声自然衰减。`
