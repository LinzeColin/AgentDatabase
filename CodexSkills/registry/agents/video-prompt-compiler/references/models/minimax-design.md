# MiniMax Design 项目桥接

状态：`PLATFORM_VERIFY_AT_RUNTIME`。

MiniMax Design 作为创作工作台/路由层处理项目级任务，不等于一个固定视频模型。

输出 `MINIMAX_MASTER_PROMPT`：项目目标、约束账本、素材角色、时间线、每个节点的方法与默认模型、生成前停止门、费用未知项和验收标准。

不得假设已勾选模型全部并行运行；每个节点默认只选一个模型，只有明确 A/B 的关键镜头允许两个。要求平台在生成前报告实际模型、输入、时长、分辨率、变体数和预计消耗；读取不到时写 `UNKNOWN`。

账户中的模型、插件、地区可见性和 Router 行为必须在运行时核实。
