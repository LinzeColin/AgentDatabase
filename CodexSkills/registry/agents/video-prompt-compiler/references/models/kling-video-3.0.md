# Kling VIDEO 3.0 Adapter

状态：`ACTIVE_OFFICIAL`；核验日期：2026-08-17。

适合人物/产品元素绑定、多镜头、对白与原生音频。模型能力是否在用户账户开放仍以当前界面为准。

## 单镜头

主体身份 → 触发/主动作 → 细微表演或物体运动 → 一个主要相机行为 → 声音 → 结束状态。

## 多镜头

只有确实需要 Multi-Shot 时才写多个镜头。每个镜头重新锚定人物/产品、服装、空间与光线；写切换原因，不为“电影感”随机切镜。

## 对白

明确说话者、情绪/身体状态、精确台词、对方反应和音频环境。用户给定台词逐字保留。

## 连续性

优先使用 Element/Reference 绑定和统一 Reference Sheet；Prompt 不替代素材一致性。
