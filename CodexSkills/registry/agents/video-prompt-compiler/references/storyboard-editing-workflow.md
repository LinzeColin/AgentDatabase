# 剧本、分镜与剪辑工作流

## 剧本转分镜

1. 先拆场景目标、冲突、信息和情绪转折；
2. 建立角色/产品/空间 Bible；
3. 每镜只承担一个叙事功能；
4. Blocking before framing：先人物与物体在空间中的位置，再决定景别和机位；
5. 逐镜建立 IR 和目标模型 Prompt；
6. 跨镜记录连续性：方向、眼线、动作接点、服装、道具、光线、声音。

## 真实素材剪辑

剪辑不是电影散文。最低字段：

| 成片时间 | 素材 ID | 原片入点 | 原片出点 | 叙事功能 | 裁切 | 字幕 | 声音 |
|---:|---|---:|---:|---|---|---|---|

必须区分：

- 实拍证据镜头；
- 生成补镜头；
- 2D 解释层；
- 文字/字幕层；
- 旁白、现场声、音乐和音效。

可确定的剪切、裁切、拼接、字幕和音量操作优先交给可编辑时间线/FFmpeg/HyperFrames，不用生成模型重做真实画面。
