# 参考视频反向拆解

## 目的

参考视频的价值不只是“风格像它”，而是提取：

- Prompt 如何组织；
- 哪些全局信息先锁定；
- 时间段如何拆；
- 人物或工件的动作如何具体化；
- 运镜、声音和结束状态如何同步；
- 哪些信息密度真正提升控制；
- 哪些内容属于原作，不应复制。

## 离线抽取

```bash
python3 scripts/inspect_video.py reference.mp4 --detail standard --output analysis
```

输出：

```text
metadata.json
frames/frame_01.jpg ...
contact_sheet.jpg
```

脚本不做 OCR。屏幕文字由 Agent 视觉理解，且只做摘要。

## 六层分析

### 1. 媒体层

时长、比例、分辨率、帧率、音频、有无字幕或画中画。

### 2. 全局锁定

人物/主体、服装、场景、时间、光线、色板、画幅、声音基线。

### 3. 镜头层

景别、机位、主要运镜、剪辑点、前后景关系。

### 4. 时间节拍

每段的触发、动作、反应、台词、转折和结束状态。

### 5. 表演/物理层

人物：呼吸、视线、微表情、身体、道具。  
工业：工件、工具、轨迹、接触、材料反馈。

### 6. Prompt 组织层

- 先写全局还是逐镜；
- 使用标题、时间码还是散文；
- 每段平均控制多少变量；
- 硬约束放在哪里；
- 结束状态是否明确。

## 通用可迁移结构

下面是从常见“提示词拆解/成片展示”类短视频归纳出的结构，不绑定任何未随包提供的媒体：

1. 先统一人物或工件、服装/材料、场景与氛围；
2. 按有效时长拆成少量可执行节拍，而不是堆叠镜头；
3. 每个节拍只控制必要的触发、动作/反应、镜头和声音；
4. 抽象情绪改写为可见的生理、行为或材料反应；
5. 每段必须推动状态变化；
6. 结尾保留稳定状态或余韵，不在关键动作刚发生时立即截断。

原 v0.0.0.1 中曾有一个约 18 秒竖屏演示的文字观察样例，但原始媒体未包含在本安装包中，因此 v0.0.0.2 不把该观察写成已复核事实，只保留上述通用方法。
