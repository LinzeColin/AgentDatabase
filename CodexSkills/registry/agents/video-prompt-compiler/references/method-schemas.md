# 生产方法语法

## Text-to-Video

```text
镜头/构图 + 主体 + 一个主动作 + 环境 + 光线/材质 + 时间节拍 + 声音 + 结束状态
```

适合：完全没有素材、允许创作、短概念镜头。

风险：人物、产品、工件和空间容易漂移。需要精确主体时应先生成或提供关键帧。

## Image-to-Video

```text
保持输入图中的身份、构图、服装/工件结构、环境和光线。
描述摄像机运动、主体运动、环境反应、时间和结束状态。
只列真正需要改变的内容。
```

适合：主体、品牌、设备外观已经正确。

禁止：把图片内容重新写一遍并同时要求模型重新创造。

## Reference-to-Video

```text
参考 A：主体/身份/产品/工件
参考 B：色彩、光线、材质
参考视频 C：动作、运镜、节奏
参考音频 D：音乐、声音、台词节奏
目标：生成什么新镜头
保持：哪些参考不可漂移
```

适合：迁移动作、镜头、风格、人物和声音。

## Video Edit

```text
严格编辑视频 X。
保留：主体结构、动作时序、摄像机、时长、未指定区域。
只修改：对象/属性/背景/时间段/位置/程度。
结束：修改后的稳定状态。
不得改变：具体高风险项。
```

适合：换背景、删元素、清理现场、局部视觉增强。

## Video Extend

```text
从原视频最后已确认状态继续。
沿用人物/工件、空间、光向、动作速度、声音和镜头路径。
新增一个主事件或动作转折。
明确续段结束状态。
```

## Footage Edit / EDL

必须表格化：

| 成片时间 | 素材 | 原片入点 | 原片出点 | 叙事功能 | 裁切 | 字幕 | 声音 |
|---:|---|---:|---:|---|---|---|---|

剪辑 Prompt 必须包括：

- 目标时长与比例；
- 素材 ID；
- 时间码；
- 真实素材和生成素材的区别；
- 裁切与安全区；
- 转场；
- 字幕和旁白；
- 现场声；
- 不得重新生成的画面。

## 2D Motion Graphics

```text
信息目标
→ 信息层级
→ 图形对象
→ 布局
→ 动画顺序
→ 时间
→ 文字层
→ 色彩和品牌
→ 转场与结束画面
```

文字和数字尽量为独立可编辑层。生成模型负责图形资产或背景，不负责复杂正文排版。

## AIGC 3D Concept

```text
对象几何外观
→ 材质和表面
→ 摄像机视角
→ 结构/剖面变化
→ 光线
→ 动画
→ 结束状态
→ 概念示意声明
```

适合：品牌 CG、结构概念、未来工厂、不可见原理的视觉化。

## True 3D / CAD / Blender Handoff

输出字段：

- 输入图纸、尺寸和参考；
- 坐标系、单位和公差；
- 部件与装配关系；
- 材质；
- 运动轴、轨迹、速度和限制；
- 镜头与渲染；
- 输出格式；
- 技术复核和验收标准。

若缺尺寸或图纸，标记 `NEEDS_ENGINEERING_INPUT`，不得通过视频 Prompt 伪造。
