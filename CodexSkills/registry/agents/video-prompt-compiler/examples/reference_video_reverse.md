# 参考视频反向分析示例（通用、非特定媒体）

> 本例演示输出格式。它不是对当前包内某个真实视频的已复核结论。

## 假设观察摘要

- 竖屏人物微叙事短片；
- 画面包含角色参考区、生成画面与分段 Prompt；
- Prompt 采用全局锁定 + 少量时间节拍；
- 节拍分别承担触发、对视转折、关键台词、后撤余韵；
- 每段同时控制必要的眼神、呼吸、面部、身体、台词、镜头与声音；
- 结尾保留人物后撤和声音余韵，而不是台词结束即切断。

## 可迁移语法

```text
【人物与基础设定】
外貌、服装、道具、关系、场景、时间、光线与声音基线。

【0–4 秒｜触发事件】
外部触发 + 第一生理反应 + 视线 + 单一主景别。

【4–8 秒｜内在转折】
眨眼/泪膜 + 眉眼嘴角 + 肩颈/手/重心 + 极小运镜。

【8–12 秒｜关键台词/动作】
说话者 + 原样台词 + 停顿/音量 + 对方反应时机。

【12–15 秒｜余韵】
后退/转身/停下 + 镜头拉远/保持 + 环境声衰减 + 最终状态。
```

## 不可迁移

- 原人物设定；
- 原台词和剧情；
- 屏幕上的完整 Prompt 文本；
- 原创作者的具体画面和剪辑表达。
