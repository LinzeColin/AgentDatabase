# 示例：克制的人物微表演

## 用户口语

```text
女生听到项目被取消，心里很难受，但不要大哭，要有那种电影里细微的破碎感。
```

## 可复制 Prompt

```text
【全局锁定】现代工业企业办公楼的会议室门口，阴天傍晚，冷灰色自然光从走廊窗户斜向进入。年轻女工程师，浅灰工作外套，头发整齐束起，手里握着一份刚被退回的项目文件。中近景，稳定镜头，浅景深；走廊空调声、远处脚步声和纸张摩擦声构成安静声场。人物外貌、服装、文件和光线方向全程保持一致。

【0–4 秒｜触发】她先低头看见文件上的退回标记，吸气在胸口短暂停住，右手拇指不自觉压紧纸边。她没有立刻抬头，眨眼变慢，下颌轻微绷紧；摄像机保持稳定，让文件、手和半张脸同时清晰。

【4–8 秒｜对视】她缓慢抬眼看向会议室内的人，视线先停在门框边缘，再移到对方脸上。眼睑轻微收紧，泪膜增加但眼泪没有落下；嘴角试图保持平直，左侧嘴角却极轻地颤了一下。肩膀缓慢下沉，身体重心从前脚移回后脚。摄像机极慢推近，不改变机位高度。

【8–12 秒｜宣告】她用很低、很稳的声音说：“我知道了，我会把资料整理好。”在“知道了”后停顿半秒，声音末尾略微变轻。对方保持沉默，不提前做夸张反应。她说完才轻轻吞咽一次，视线从对方眼睛移到桌边。

【12–15 秒｜余韵】她把文件贴近胸前，向后退半步后停下，没有转身逃走。摄像机缓慢拉远少许，让门框逐渐把她和会议室分隔开。远处脚步声经过，空调声保持。结束时她仍站在门外，目光停在地面，呼吸恢复但肩膀仍僵硬；画面停留一秒再结束。
```

## 为什么不是“文学堆字”

每一段都控制：触发、呼吸、视线、脸、身体、台词、摄像机、声音和结束状态。没有一句只为“唯美”存在。
