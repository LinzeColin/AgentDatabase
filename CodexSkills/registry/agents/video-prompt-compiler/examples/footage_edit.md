# 示例：真实素材剪辑 Prompt

## 输入假设

- A01：磨损工件，推荐 00:05–00:10
- A02：机器人熔覆全景，推荐 00:12–00:22
- A03：熔池近景，推荐 00:04–00:08
- A04：测量，推荐 00:07–00:12
- A05：精加工，推荐 00:15–00:21
- A06：复检，推荐 00:03–00:09

## MiniMax Design 剪辑总控 Prompt

```text
使用当前 Canvas 中的真实项目素材，创建一条 40 秒、9:16 的可编辑粗剪。真实项目画面承担全部项目证明；本轮不生成新的现场画面。

时间线：
0–3 秒：使用 A03 的 00:04–00:07，熔池近景，保留关键机械声；字幕“十字轴磨损，不是补一层材料就结束”。
3–8 秒：使用 A01 的 00:05–00:10，展示磨损区域和工件尺度，旁白进入。
8–13 秒：使用 A04 的 00:07–00:12，展示测量和判断。
13–18 秒：插入批准后的 2D 流程动画“检测—找正—熔覆—加工—复检”。
18–29 秒：先使用 A02 的 00:12–00:19，再使用 A03 的 00:04–00:08；让全景与熔池近景形成动作连续，不重复同一段。
29–35 秒：使用 A05 的 00:15–00:21，展示精加工。
35–38 秒：使用 A06 的 00:03–00:06，展示复检。
38–40 秒：真实车间全景淡入公司名称和单一 CTA。

剪辑规则：
- 横屏素材裁为 9:16 时，工件、工具和作用区域必须完整；
- 使用硬切或 4–8 帧短叠化，不使用炫技转场；
- 每屏字幕最多两行，每行不超过 14 个汉字；
- 旁白优先，保留少量同步机械声，BGM 降低；
- 不修改、移动、重命名或覆盖原始素材；
- 输出一个可编辑 Timeline 和一个内部预览；
- 完成粗剪后停止，不自动生成补镜头。
```
