# 示例：2D 与 AIGC 3D

## 2D 五步流程

```text
制作一个 5 秒、9:16 的工业流程动态图。深灰纯色背景，中间从左到右排列五个统一线宽的简化图标：检测、找正、熔覆、加工、复检；一条激光橙细线连接五个节点。

0–1 秒，橙色连接线从左向右绘制；1–4 秒，五个图标依次淡入并轻微上移，每个图标出现时对应节点短暂高亮；4–5 秒，全部图标保持，标题“修复不是简单补料”作为独立文字图层淡入。扁平化技术信息图，金属灰和激光橙，不使用蓝紫霓虹、粒子爆炸或无意义 3D 翻转。正文和标题必须保持可编辑，不烧进背景图。
```

## AIGC 3D 概念剖面

```text
5 秒、9:16 的高端工业 3D CG 概念镜头。大型钢制十字轴置于黑灰摄影棚环境，机械比例可信，金属表面保留真实加工纹理，磨损区域以克制的暖橙光带标记。

摄像机从四分之三视角缓慢环绕约 20 度；第 2 秒开始，外层表面逐渐半透明，显示磨损区与待修复层的空间关系，结构不分解、不新增零件。深色金属材质、真实反射、稳定侧逆光，背景简洁。最后停在剖面和磨损区域同时清晰的视角。无文字、无测量数字、无应力云图。这是结构概念示意，不是工程计算或真实 CAD。
```
