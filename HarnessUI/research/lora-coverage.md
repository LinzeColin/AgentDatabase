# 角色 LoRA 覆盖率调研

2026-08-19 实测。**这份是整个项目的可行性底线**——没有 LoRA 的角色做不出高质量产物。

## 一、主源换了：Civitai 打不开

```
GET https://civitai.com/api/v1/models
→ HTTP 451  {"error":"Access to this service is not available in your region
             due to legal restrictions.","code":"REGION_BLOCKED"}
```

Civitai 是动漫角色 LoRA 的主流集散地,**从这台机器的网络位置访问不了**。
换 Hugging Face 作主源(实测 200 可达)。这直接压低了覆盖率上限——
HF 上的角色 LoRA 是 Civitai 的一个子集,由几个镜像/自动训练账号搬运。

## 二、实测数量

用 `author + search` 组合查询(避开 API 的 1000 条返回上限):

| 来源 | Genshin | Zenless | 说明 |
|---|---|---|---|
| `CyberHarem/*` | **56** | **0** | 自动训练账号,按角色一仓一模型,命名规范 `<name>_genshin` |
| `Muapi/*` | **34** | **14** | **带 `illustriousxl` 标记**,与选定底模同代 |
| 全站 `"<game> lora"` | 73 | 2 | 含上面两家,去重后不会更多 |

对照名单规模:**原神女角色 78 · 绝区零女角色 45**。

## 三、覆盖率结论

| | 名单 | 有 LoRA(乐观估计) | 覆盖率 |
|---|---|---|---|
| 原神 | 78 | 40–56(56 个仓里含男性角色) | **约 50–70%** |
| 绝区零 | 45 | 约 14 | **约 30%** |

**绝区零是短板**:CyberHarem 完全没有覆盖,只有 Muapi 那 14 个。
所以"全量 123 个角色都做成高质量"**做不到**,现实是:

- 约 55–70 个角色可走 LoRA 路线(高质量)
- 其余 50 多个只能走降级路线(mmx + 官方立绘参考),**质量档位明确不同,不要混在一起交付**

## 四、两家的关键差异（决定能不能用）

| | CyberHarem | Muapi |
|---|---|---|
| 数量 | 多(Genshin 56) | 少(Genshin 34 / ZZZ 14) |
| 底模世代 | **未核实,疑为 SD1.5 期** | **明确标 `illustriousxl`** |
| 与选定底模兼容 | **待验证** | ✅ 同代 |

**这是下一步必须先解决的问题。** SD1.5 期的 LoRA 挂不到 Illustrious/SDXL 底模上——
如果 CyberHarem 那 56 个全是 SD1.5,实际可用覆盖率会从 50–70% 掉到 **Muapi 那 34 个(约 44%)**,
甚至要连底模一起换成 SD1.5 世代(画质会明显下降)。

## 六、诚实说明

上面的"乐观估计"是按仓库名匹配算的,**没有逐个打开验证**。
真实可用数只会更低,不会更高。理由:
- 仓名带角色名不等于里面真有可用权重(实测 `xiaozhangMJXXZ/Genshin-lora-all` 名字像全集,实际只有 2 个权重)
- 部分仓是 RVC 语音模型、真人风格模型,不是插画 LoRA
- 底模兼容性还没核
