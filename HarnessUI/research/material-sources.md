## 但更重要的是：多数平台的素材对质量没有贡献

按 `generation-stack.md` 的结论,质量由 LoRA 决定。素材的作用只有三种,按价值排序:

### 一等：角色 LoRA（Civitai / Hugging Face）

**这是唯一能大幅提升质量的东西。** 每个角色一个权重文件,直接决定像不像。
- Civitai:原神/绝区零角色 LoRA 覆盖最全,按角色名搜即可
- Hugging Face:部分作者会镜像一份,许可信息通常更清楚

### 二等：官方立绘（做参考图 / 校验基准）

用途有两个,都不是拿来直接用:
1. 喂 `--subject-ref` 或 IPAdapter 做角色锚定
2. **做质量校验的基准**——生成出来的图跟官方立绘并排看,不像就重摇

来源:官方 wiki(Fandom)、游戏内立绘、官方账号发布图。

### 三等：同人图（Pixiv / Bilibili / X 等）

对本项目**基本没用**,而且有两个实际问题:
- 有 LoRA 之后不需要它——LoRA 已经是几百张同人图训练出来的产物
- 单张同人图的版权归画师个人,拿去做生成参考比用官方素材更敏感

**结论:不建议为此去爬这几个平台。** 投入产出比很低。

## 版权口径

这批皮肤的定位和你机器上已有的明日方舟、初音那几个一致:**个人自用、非商业、不分发**。
每个皮肤包会带 NOTICE 写明角色版权归原厂。

具体到素材:
- 角色 LoRA 各有各的许可,下载时把 `license` 字段记进 `character.json`,别混着用
- 官方立绘只做参考和校验,不进产物
- 产物不上传、不分发、不进公开仓(见 README 的 `.gitignore` 约定)
