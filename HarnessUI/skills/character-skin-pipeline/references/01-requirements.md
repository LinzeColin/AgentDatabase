## 三条最容易被挤掉的，和它们怎么丢的

### R7「不要 Q 版」——一次都没进过 prompt

用户截图否决 Q 版后，我改了 v1.5/v1.6/v1.7 三个版本，
而 594 条 prompt 里 `chibi` 出现 **0 次**，直到成品出来才发现。

**根因**：任务包里有一个 `negative_prompt` **字段**，看起来像是写了负面约束，
但 `gpt-image-2` **没有这个参数**——字段发不出去，等于没写。

**判据**：不要检查「配置里有没有这一条」，要检查「**发出去的 prompt 正文里有没有**」。

### R5「丝袜/露肤度」——被自己的另一条要求抵消

原 prompt 写的是 `sheer tights / stockings where the design allows`——
那个 *where the design allows* 是逃生口，角色原设穿长裤时模型直接跳过。
而同一段还要求 `matching the reference character design exactly`，两条直接打架，
模型只能随机取中。

**做法**：**冲突要显式裁决**。改成：
身份（脸/发色发型/瞳色/标志配饰/配色）严格照锚图；
服装造型按规则，**冲突时以规则为准**；
原设是长裤/铠甲腿的，把腿部改造成丝袜，但保留该设计的配色与纹样。

验证用最难的案例（原设全长裤的角色），不要用本来就穿丝袜的。

### R12「参照抖音三博主」——从头到尾没有输入

我在 `material-sources.md` 里早就写了「抖音我的工具拿不到正文，要你手动存图给我」，
而那批图**始终没有过**。所以这条不是漏做，是**从一开始就没有输入**。

**做法**：清单里要区分「没做」和「做不了/缺输入」，并写清缺什么。
后来实测：用用户 Chrome 的登录态能读到作品标题里的 `#角色名` 话题标签
（读文字比认缩略图可靠），但抖音的无限滚动在自动化环境里不触发，
**只能拿首屏样本，拿不到全量**，也认不了画风。

## 核对命令（每次改完任务包跑一遍）

```bash
python3 - <<'PY'
import json, pathlib, re
man = json.loads(pathlib.Path("<pack>/manifest.json").read_text(encoding="utf-8"))
t = man["tasks"]; n = len(t) * 2
for label, pat in [
    ("丝袜强制", r"MANDATORY WARDROBE"), ("优先级裁决", r"PRECEDENCE"),
    ("禁Q版", r"chibi"), ("禁废土", r"wasteland"), ("禁都市", r"modern city"),
    ("左35%构图", r"left 35%"), ("右侧留白", r"RIGHT 65%"),
    ("锚图一致", r"matching the reference"), ("官方立绘质感", r"splash-art quality"),
]:
    c = sum(1 for x in t for s in ("light","dark") if re.search(pat, x["outputs"][s]["prompt"], re.I))
    print(f"  {'✅' if c==n else '❌'} {label:<12}{c}/{n}")
PY
```

**任何一条不是满分就别开跑。**
